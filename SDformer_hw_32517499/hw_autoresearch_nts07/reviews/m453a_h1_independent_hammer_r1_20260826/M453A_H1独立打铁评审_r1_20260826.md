## 关键结果

1. **M73 全量身份与范围通过。** 256/256 payload 逐文件重算 SHA 和字节范围，合计 135,249,485 bytes；32 samples × 4 operators 唯一完备，独立解码 165,888,000 rows。每个 operator/partition 恰有 96,000 train rows。
2. **完整 catalog 结构通过。** 4×432=1,728 个 partition 全查；每个 32 parents 与 M430 逐项、逐序一致，165,888 个 children 均为每 parent 3 个；每 partition 的 flat 128 全唯一且 child 全在同 partition 的 M73 train observation 中。所有 mismatch 为 0。
3. **19 个 outside-local-route child 不是 objective 泄漏。** 逐个重算表明 candidate 只从同 partition M73 observation 扩池；每个 candidate 的 objective 仍只用当前 parent 的 `bucket_values/bucket_counts`。19 个跨 bucket child 与 1 个 local candidate 仅 2 个的 bucket（operator 1 / partition 301 / parent 30）全部按冻结的 `(objective, prefer-local-route, Hamming-to-parent, numeric-mask)` 顺序得到，最优性 mismatch=0；未发现 global、heldout 或 M40 objective 引用。
4. **独立 scalar/vector 重放通过。** 合同 8 个实际首尾 partition，加预冻结 8 个随机 partition，共 16 个完整 partition、512 个 parent 的三步 greedy sequence/objective/tie 全量重算；再覆盖 19 个 outside bucket，共 531 scalar parent calls。与 catalog 及独立 chunk-vector 实现逐步 mismatch 均为 0，重算摘要 SHA 为 `7344ac286076af4d7ec9010686e767204a8918c33c20c99d22a77e5ef712a854`。
5. **全 train 统计通过。** source/zero/active/PWP/fallback/correction/separate/fused 全部独立复算并与 JSON 一致：PWP 55,834,749，fallback 30,552,848，correction 89,648,482，separate 145,483,231，fused 116,989,929；所有守恒式成立。全 1,728 partition ×128 patterns ×768 outputs 的 INT8 PWP 静态范围为 signed12 `[-1089, 1059]`，overflow=0。
6. **CSV/JSON/双封通过。** 55,296 条 CSV parent row 与 catalog/audit JSON 零 mismatch。候选 inner manifest SHA 为 `4c633bb6c3de99607e35843732515fb6ca19b5bbe1b30caaed7285b7c8f63427`，outer seal 文件 SHA 为 `e154a4a1667458732fac1bbb2416d8966e9569d00401ba8bc66c7701cc695de8`；M430 双封亦复验通过。
7. **失败链处理正确。** r1、r2、r3-preinput、r3rev2 均为 fail/abort receipt，统一标记 `DO_NOT_CITE`，各自双封可复验。需要精确表述：r1→r2 有一次预先冻结且必要的 candidate-extent 科学变更；从 r2 到 r3/rev2/rev3，parent route、route-bucket objective、candidate population、tie 与 parent order 均未改变，仅实现向量化。
