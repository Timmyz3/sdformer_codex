# M707 first-principles lower-bound and idea screen

This directory is a read-only evidence review. It contains:

- `lower_bound_ledger.json`: machine-readable source/weight/state/psum/commit and service lower bounds for eight H67 operator classes;
- `evidence_inventory.json`: exact evidence paths and observed SHA256 identities;
- `review.json`: admission decisions, simulated DATE score and two bounded CPU-only fast-kill proposals;
- `review.md`: human-readable independent review.

No GPU, EDA, remote, RTL authoring, paper-body writing, training or production performance run was used. The review does not authorize new RTL.
