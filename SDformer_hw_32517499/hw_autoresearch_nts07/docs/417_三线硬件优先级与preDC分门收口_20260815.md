# 三线硬件优先级与 pre-DC 分门收口

日期：2026-08-15。本文不修改 `docs/359` 的封存数字。

## 1. 独立裁决

当前不是三条等权 RTL 主线：

1. **P0 Motion/H67**：冻结 H67 ep35 身份，先交付 Fixed2S/RQTB2S
   attention-row 组件的 pre-macro Synopsys 包。
2. **P1 Local5**：组件包已经可交；本机最高价值缺口是把当前
   `QS -> FCSR -> source-owned -> TCFM5` 生产边界重绑到最终
   checkpoint，并在同一边界运行有界的 12-block 数值回放。
3. **P∞ H81**：算法选择器正式改选且真实 H81 trace 通过 G0/G1 与
   innovation gate 之前，不开 RTL。

H81 若改选，RQTB 的 pair-local exact 合并电路可能复用，但 H67 的
MSSB5、分布、`1.1865x` 和创新 3.2 均不得继承。Local5 的 self+4
拓扑也不得移植给 H81。

## 2. 两级完成度

### component-pre-DC

组件满足：冻结身份、声明边界内 RTL/活动合同、脚本 fail-closed。
当前 Motion 与 Local5 均为 `READY_PREMACRO`。这里的 memory 均是
`MEMORY_IMPL=0`/`ACC_MEMORY_IMPL=0`，只允许做 pre-macro 逻辑综合。

### paper-system

组件过门不等于论文只差 DC：

- Motion 仍缺同一生产边界的完整 block/cross-head/12-block 系统闭合；
- Local5 已完成 deterministic oracle 下的 3-head OUT32 生产组件闭合，
  以及 12-block 壳的结构检查；仍缺最终 checkpoint 重绑和
  同一生产边界的有界 12-block 数值回放；
- 两条线均缺目标宏 adapter、目标 `.db`/PVT、DC/Formality/STA/SAIF/PTPX。

Local5 新证据的边界见
`docs/419_Local5当前生产前端跨Head_OUT32闭合_20260815.md`；它不是最终
checkpoint、不是完整 encoder，也不改变 DATE 创新评分。

  --output results/grok_codex_collab/three_line_predc_gate_20260815.json

## 4. 服务器交接边界

目标服务器需要补入真实 SRAM/RF wrapper、对应 `.db`、PVT/operating
condition，再运行已有 DC/Formality/PTSTA/PTPX 脚本。未知 foundry 宏名和
pin mapping 不在本机猜测，避免把伪 adapter 误写成 SRAM 化完成。
