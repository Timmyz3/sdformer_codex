# DATE第十一轮独立复审与DQFS负结果封存

## 1. 复审结论

第十一轮并行进行了ASIC RTL审阅和DATE审稿。两者在得知真实
`OUT_DIM=4`后均给出：

> **DQFS到product/TCFM集成：NO-GO。**

DATE评分：

| 维度 | 分数 |
|---|---:|
| 创新性 | 3.4/5 |
| 完整度 | 4.0/5 |
| 证据 | 3.6/5 |
| 总体 | 3.5/5 |
| Recommendation | Weak Reject |

相比上一轮，RTL完整度提高，但1024-bit错误口径导致架构优势被撤回。

## 2. 主要拒绝原因

1. 真实product为128 bit，不是1024 bit；
2. C256/W6 DQFS的存储与product计算均劣于4-way cache；
3. DQFS member排出当前最高0.5 term/cycle，未对齐TCFM的1 term/cycle；
4. 单17-term事务不足以证明一般死锁自由和链表完备；
5. 19个`$mem_v2`尚未收敛成明确SRAM宏合同；
6. 无同宏DC/STA/SAIF。

## 3. 本轮整改

- 用真实128-bit重做全部存储-计算Pareto；
- 16/16个DQFS配置确认被支配；
- DQFS转为负结果，不再扩展product/TCFM；
- 非法term语义改为原子abort-and-drain，非法final不再永久占住事务；
- Icarus、Verilator、SVA、lint、Yosys回归重新PASS；
- 新主候选收敛为GS-TTB跨阶段无替换gate-slot表。

## 4. 保留DQFS的意义

DQFS仍保留三项研究价值：

1. 证明row-owned value quotient可以有限资源精确分段；
2. 证明窄term重排只有在product足够宽时才可能优于cache；
3. 提供论文负结果：不能从“term比product窄”直接推出架构收益，必须带入
   真实output tile、命中率和排出II。

它不再列为主贡献，也不进入当前PPA主表。
