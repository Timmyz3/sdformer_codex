工作量、SVA 数量或开放映射面积替代架构创新。

## 2. Motion

### 可列为一条贡献的内容

只保留一条：

```text
MSSB5 score-front CSE
  -> Q7 temporal-pair score equivalence
  -> one-class descriptor + multiplicity + temporal membership
  -> weighted Shiftmax
  -> ordered K recovery
```

核心架构对象是 pair-local 的可逆 Q7 score-class descriptor。MSSB5 是 score
归约前端的实现支撑，denominator certificate 是冻结 leaf-only 注脚，均不单列。

### 为什么创新由 3.1 提到 3.2

`docs/406` 对 ep30/ep35 的 100 sample、四个 stage、672,000 head-row 和
151.2M pair 重算 Q7 score，stored equal-pair 统计逐记录一致。实证对象是
`E/P` 的跨 checkpoint、sample 和 stage 分布，不是 `D_min=2P-E` 的复杂程度。

RQTB 达到 `D_min` 是发射规则的定义性结果；不得写成“在 672,000 行真实 RTL
中实证打到信息论下界”。公平 `[rtl]` 主锚点仍固定为 sample0/window0 的 138 行：
`112589/94891=1.1865x`、slot `62100/34099`、equal `28001`。本轮进一步从
冻结公平日志逐行审计，138/138 行实际 RTL `rslots=450-equal`，且 equal 与独立
整数 score 重算一致；随后完成 ep35 十样本真实 Q/K 的 1,380 行 Icarus 与
Verilator+SVA 公平回放。十样本总计 `1057895/899249=1.176421x`，10/10 样本
均改善，最小 `1.169380x`，Acc32 checksum 零失配。该结果提升覆盖面，但不替换
冻结主锚点，也不是 full encoder。

### 为什么仍不到 3.5/4.0

1. `D_min` 只覆盖 pair-local、one-class-per-descriptor 合同，global bitmap/CAM
   改变合同后不适用；引理本身接近计数定义。
2. RQTB 改变的是 score/normalization descriptor，K payload 在投影边界仍按原
   destination 恢复；尚无第二个不可化约的 projection-side 执行对象。
3. MSSB5 相对最强 SSR5 只是小幅 CSE 支撑，不构成新数据流。
4. class folding、FCIP/public-K multicast、interval early-stop、ECGB、denominator
   directory 拆分等候选已分别因目的地址、重复对象、收益上限或 LAWS 冲突否决。
5. 重新审计旧 FGP late-gate projection：138 行、两个真实 INT8 输出通道的 276 个
   Acc32 均与 direct 0 mismatch，lane-wise multiply 可减少 73.22%；但它仍比
   row-resident gate-weight 强下界多 3.407 倍 multiply 和 12.722 倍 weight read，
   且 gate 后换序不改变跨 stage 物化对象，裁决为实现 DSE，不作为新贡献。

### 当前最高优先级缺口

1. 多样本真实 INT8 全输出通道 projection，并补 bias/BN/requant/residual 或完整
   block 边界；当前十样本 Acc32 仍是 synthetic lane-weight checksum；
2. score、SCS/Shiftmax、K-read、projection、stall 的完整分段周期与活动；
3. 所有空间窗口或有代表性的分层窗口，而不是每样本只选一个 all12 窗口；
4. full-encoder operator shell 与 Amdahl，不再克隆选中窗口；
5. 同库、同 SDC、同宏、同公平 LFSR 激励的 DC/STA/SAIF/PTPX。

这些主要提高验证和实验完整度。若没有新的执行/存储对象，补完后也不能自动把
架构创新提高到 4 分。

## 3. Local5

### 可列为一条贡献的内容

只保留一条端到端数据流：

```text
Query-Silent exact early-out
  -> fixed-stencil inverse transpose / compiled last-consumer
  -> source-owned equal-gate destination mask
  -> TCFM5 conflict-free multicast
  -> Acc32
```

其中 FCSR、generation、五 bank、source-owned builder 与 TCFM5 共同实现该流，
不拆成多条贡献。Relation Memo、W4 cache、1RW wrapper 和 compiler codegen 均不是
独立贡献。

### 为什么创新仍为 3.1

1. source-owned scatter 属于 Gustavson/source-stationary 类；固定 stencil 的
   live range 与 affine banking 也有经典近邻。
2. 可守差分是：在固定五邻域 descriptor 退休时，完整 edge-label 集合已知，
   对相同 Q1.7 gate 形成 destination mask，并直接映射到五色 Acc 写使能。
3. 该局部对象达到 one-source/one-lane/one-gate-per-issue 合同的最少 message
   issue，但不是全局最少乘法、周期或能量。
4. W4 profile 已把 MFEP/source-owned 的 product start 都压到约 5.5k；生产
   C-vs-QC 只证明 source-mask 相对 source-one-hot 少发命令，不能替代真正的
   destination MFEP+W4 强基线。

### 当前最高优先级缺口

1. 同端口 1R1W/1RW 在目标宏和 matched SAIF 下的真实能量；
2. 生产 `QS+rolling/FCSR+source-owned+TCFM5` 的共享前端多 output tile 与
   cross-head 调度，不能用 EREP Memo 或前端重放模型替代；
3. 多 window/stage 的生产链，继续检查真实 INT8 权重 Acc32；
4. 三冻结顶层的 DC/STA/SAIF/PTPX 与 SRAM/RF 宏；
5. full-encoder operator/IO shell。

Local5 新机制探索暂时冻结。Memo、stripe、promotion、dyadic gate、source
wavefront、leftover 第三路径和 W4 cache 均已有负结果或被强基线支配，不换名重开。
进一步的生产多 tile 边界审计表明：term-stationary 路径若保持所有 Acc 上下文，
就是状态随 tile 数扩展的既有 packed OUT32；若固定 OUT2 面积并存储 replay 对象，
expanded term tape 又被既有 factorized source descriptor/Relation Memo 支配。因此该
缺口仍可作为系统完整度工作，但不再作为新架构候选。

## 4. 4 分与 best-paper 标准

当前两条线都不是 `4/5` 架构创新，更不是 best-paper 完成度。要达到弱 4 分，至少
需要满足以下一种，而不是仅补综合：

1. 新机制改变现有 descriptor/term/accumulator 的物化对象或跨算子执行边界；
2. 给出非按候选量身定制的精确合同或下界，并由实现达到；
3. 对点名最强 exact baseline，在同端口、同容量、同频率和真实活动下形成稳定
   latency-energy-area Pareto；
4. 收益进入完整 attention block 或 encoder，而不是停在 OUT2 tile/head-row。

DC/STA/SAIF/PTPX 是投稿完整度的必需证据，但不能把 3.1 的架构创新自动变成 4.0。
后续创新候选只允许先做只读 go/no-go；若没有新物化对象，宁可保留可信的 3.1/3.2，
也不把普通 cache、bank、FIFO、编码或编译器工具包装成新贡献。
