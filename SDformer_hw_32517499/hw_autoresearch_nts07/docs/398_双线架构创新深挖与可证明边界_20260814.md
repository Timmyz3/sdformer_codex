# 双线架构创新深挖与可证明边界（2026-08-14）

## 1. 本轮结论

本轮只接受两类动作：改变存储/执行对象，或证明现有对象达到严格限定的问题下界。
不把字段变窄、公共子式、FIFO、banking 名称和代码生成量当作新贡献。

结论：没有筛出值得进入主线 RTL 的第三个机制。新价值来自把两条已有数据流从
“工程上有效”收紧为“在明确合同下达到下界”：

1. Motion RQTB 达到 pair-local、单 score-class descriptor 的最少 descriptor 数；
2. Local5 FCSR 达到单遍 raster、无重算/外溢的最少 live-row span；
3. Local5 TCFM5 达到单拍五目的、每 bank 单写口的最少 bank 数。

机器可检查证据：

```text
results/dual_line_optimality_bounds_20260814/report.{json,md}
```

这会增强 DATE 贡献的可辩护性，但不自动构成新的第四项贡献，也不是 ASIC PPA。

## 2. Motion 最优性边界

### 2.1 Descriptor 数下界

限定合同：pair-local ordered stream；每个 descriptor 只能携带一个 Q7 score class；必须
精确恢复 score multiset 和 temporal membership。

对于一个 temporal pair：

- score 相等时至少一条 descriptor；
- score 不等时至少两条 descriptor。

因此：

```text
D_min = E + 2(P-E) = 2P-E
```

封存公平包中：

```text
P = 31050
E = 28001
D_min = 34099
RQTB actual = 34099
```

即 `slots + equal = 2*pairs` 不只是统计恒等式，而是上述合同下的达到性证据。
另外，非空 temporal subset 只有 `{t0},{t1},{t0,t1}` 三种，编码下界为 2 bit；RQTB 的
temporal mask 正好使用 2 bit。

不扩大为：跨 pair 全局排序、多 class descriptor、K payload 下界或通用 attention I/O 下界。

### 2.2 论文主张建议

Motion 不再主打“两个值相等所以压缩”，而写成：

> 在冻结定点语义下，RQTB 把 temporal score stream 映射为最小 pair-local quotient
> descriptor 集；multiplicity 保持归一化分母，2-bit membership 在投影边界可逆恢复全部
> K contribution。

这仍与 Bishop 的 TTB 区分：Bishop 打包 activity 并允许 ECP 近似剪枝；本工作证明的是
量化 score 等价类的 exact representation bound，不声称发明 token-time bundle。

## 3. Local5 最优性边界

### 3.1 Live-row span 下界

限定合同：固定 source-relative stencil、row-major 单遍输入、不重算 relation、不向片外
spill，并保留 relation 到最后一个 consumer。

对 offsets 的垂直范围：

```text
Dr_min = max(delta_y) - min(delta_y) + 1
```

cross-r1 的 `delta_y in {-1,0,+1}`，所以 `Dr_min=3`；生产 FCSR ring 正好是 3 行。

### 3.2 Bank 数下界

限定合同：内部 source 的五个 destination 同拍更新；每个 Acc bank 单写口；无复制后归约。
五个同时写目的由抽屉原理要求至少 5 bank。TCFM5 使用：

```text
bank(x,y) = (x + 2y) mod 5
```

并在 T2x15x15 全几何上给出 338 个 interior K5 witness、全部邻域无冲突且
`(bank,address)` 单射，因此达到 5-bank 下界。

不扩大为：任意图、任意 stencil、多周期 scatter、多端口 SRAM 或最小 ASIC 面积/能量。

### 3.3 论文主张建议

Local5 不把三行 buffer 和五 bank 分开列创新，而写成一条合同：

> 固定五邻域的 topology-compiled source-major relation flow，在不物化全关系表的情况下，
> 同时达到 raster live-row span 与 one-cycle scatter bank-count 两个受限下界。

Query-Silent 是该数据流前端的 exact early-out，TCFM5 是后端达到性实现；二者不拆成
额外“首次”。

## 4. 本轮否决项

### 4.1 Local5 uniform-relation certificate

`[prof]` 45000 行中 uniform-score relation 占 92.21%，但去掉已有 QS/ident-K 后真正新增
覆盖只有 711 行，即 1.58%。五个 role 必须独立读，Dr=3 exception CAM 的 p95 为 43/45；
候选 p95 状态 3450 bit，相对 2250-bit gate+valid 强基线增加 53.33%，周期对象不变。

证据：`results/local5_uniform_relation_certificate_profile100_20260814/`。
裁决：`NO_GO_AS_DATE_CONTRIBUTION`，不写 RTL。

### 4.2 Motion active-payload compaction

该筛选仅针对 TTB8-ZKQI 的四宏 Q/K preload/row-store 旁路，不是封存 RQTB 的 K-only
streaming 主线。`[prof-sample0]` 138 行的 active pair mean=105.46，但 p95/p99/max 均为 225；9 行全活跃，
33 行超过 192。固定 exact 硬件仍需四个 256x32 payload SRAM 宏。原地址 sparse-write CE
与 packed-address 获得相同 payload write-bit 活动，后者还需 packed address 与双遍历；
宏数和 score/projection issue 均不变。

证据：`results/h67_active_payload_compaction_screen_20260814/`。
裁决：`NO_GO_AS_DATE_CONTRIBUTION`，不写 RTL。

### 4.3 Motion online denominator

running-max/denominator 会改变执行边界，但强 class-cache 基线只有 1317 次 class
transaction，占 94891 周期约 1.39%；即使全部免费，周期上限也仅约 1.014x。并且
base-2 online normalization 与 integer Shiftmax 均有直接近邻。裁决：不 profile、不写 RTL。

### 4.4 Local5 destination-local gate count

该 exact 等式就是旧 MFEP multiplicity：

```text
m[d,l,g] = sum_s 1[K(s,l)=1 and gate(d,s)=g]
```

全量 13800 group 中，逐 edge work 29164959、destination multiset 22848620、当前
source-major term 9870505。候选虽然打赢弱逐 edge 基线，却是当前强基线的 2.315x，且与
旧表示完全相同。裁决：重复旧机制，不进入新候选。

### 4.5 Local5 相邻 destination score-object reuse

按完整 `{valid,Q,K0..K4}` 比较左/上邻居，并用 Q7 score 与 Q1.7 gate 做输出 miter。
`[prof]` 100 group、45000 destination 中，邻接输入全同边为 35184/84000，即 41.89%；
但这些全部已经落入 Q-silent/ident-K 快路。剔除现有快路后，1347 个 normal-score
destination 中可新增复用数为 0，理想 score-service 降幅 0.00%。即使存在重复值，邻接
destination 的 inverse-stencil source 坐标仍不同，因此 relation slot 降幅也为 0.00%。

证据：`results/local5_neighbor_score_object_reuse_20260814/`。
裁决：`NO_GO_AS_DATE_CONTRIBUTION`，不写 RTL。
