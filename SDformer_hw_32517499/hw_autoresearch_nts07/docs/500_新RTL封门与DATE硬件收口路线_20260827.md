# 新 RTL 封门与 DATE 硬件收口路线

日期：2026-08-27

## 结论

本轮以后不再新增第四种 sparse matcher、bitmap decoder、event router 或
delta-cache RTL。独立开源工作审计的裁决为
`NO_GO_NEW_RTL__CLOSE_EXISTING_MODULES`，报告位于
`reviews/date_open_rtl_gap_mining_r1_20260827/`，outer seal 为
`aa498796d99a1d79599a73e8f1b1084de54ee7871e994cb78fcc619e0e92da26`。

这一裁决不是停止硬件工作，而是把硬件工作从“增加模块名”切换为以下
四项论文准入工作：同资源物理比较、每完成工作量能量、公共 SRAM 模型、
多序列/统一表。`docs/359_DATE终局冻结_20260813.md` 不修改。

## 性能口径锁

1. FC2 `4.764209x` 是 shared K8 相对低带宽 canonical K1 的 H67 局部周期比；
   FC2 只占冻结 envelope 的约 6.68%，不能写成系统 4.76x。
2. K8 与 K1x8 在相同 8-bank 峰值下四个非零定向点均周期相同；FC2 的
   核心论文指标应是 throughput/mm2 和 energy/completed-work，不是等峰值正周期倍速。
3. M497 的 K1x8/K1 几何 5.8634x、聚合 6.2343x 均是 8 倍服务/银行复制的
   资源—性能 Pareto，不是 same-resource speedup。
4. M473 fused Conv `1.9436x` 是 parent-read/完成泡被理想移除后的机会；
   unfused 约 `1.015x`。在 M498 物理与可执行 schedule 闭合前不升主表。
5. 官方 Prosperity artifact 在 H67 四 Conv 上的 `2.4595x` 是
   product-vs-bit 的外部 iso-workload 机会，只进对标/动机列，不冒充本项目 RTL。
6. attention 份额约 0.59%，RQTB 保留为 exact 可逆机制和局部 RTL 结果，
   不承担系统倍率 headline。

## 新 RTL 候选的最终裁决

对 Prosperity、Phi、FireFly-T、LoAS、FEATHER、SNE、ActiveN、ELSA、
ESDA、DeltaCNN/MotionDeltaCNN 的机制映射后，没有发现同时满足以下条件的
新模块：

- 打到 H67 大份额算子；
- 在现有最强基线和 SRAM 端口下仍有正周期收益；
- 状态/目录/重排税可被当前三周验证预算覆盖；
- 与现有贡献有足够新颖性距离。

唯一保留的未来条件候选是 drift-bounded cross-frame tile cache。它当前
只有约 2.7% 自然 source-work 机会，必须增加前帧状态 SRAM，并与
DeltaCNN/MotionDeltaCNN 直接比较。因此本轮只允许多序列离线 DSE，不允许写 RTL。

## 收口执行顺序

1. M498 DC 结束后立即独立打铁；失败则 Conv dual-slot 物理线永久关闭。
2. M496 三点 matched DC；只有逻辑 Pareto 门通过才进入 Formality 和 SAIF/PTPX。
3. 为 FC2 报 `cycles/work`、`area`、`throughput/mm2`、`energy/work` 四列；
   SRAM 宏/CACTI 与逻辑分列，不能用 0-macro DC 当 paper PPA。
4. C1/C2/C3/A1 统一到同一 28 nm、3 ns、公共 SRAM/DRAM 能量假设和同一
   H67 operator population；局部结果与 full-network sensitivity 分列。
5. 补至少三个 DSEC sequence 或 event-density 分层；没有多序列数据时，
   只保留单序列结果并显式标注，不把十个 window 当十个 sequence。
6. 最后做 receipt-blind DATE 模拟评审；BP 目标要求 validation、novelty、
   reproducibility 三项同时达到 strong accept，而不是靠增加贡献数量。
