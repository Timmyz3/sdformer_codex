## 2. 现有 RTL 已经是 C7，不能改名当 4.0

`rtl_h67/h67_temporal_weighted_scs_directory_2s.sv` 已经有 class hist + 450 条 active 名单。`h67_temporal_slot_shiftmax_sync_k_2s_top.sv` 里：

```
class_sum_term = class_exp_q8 * class_multiplicity
row_sum += class_sum_term
emit: gate = exp(token_score - row_max) / row_sum
```

这正是 C7 那句话：directory 记 multiplicity 和 temporal mask，K 按 mask 展开；Shiftmax 分母按重数加权。同分 Q7 时它和 token Shiftmax 代数相等。Parfit 给过 3.6。把这句再润色一遍不是 4.0。

另外，现有 `MAX_SCORE=162` 是 H67 popcount 分数上界，不是 H82 的 STE 网格。H82 class_id 是

`round((score - (-2)) / (1/128)) ∈ {0…512}`

共 513 档。硬件 Class File 不许继承 163 档直方图当 ISA。

## 3. 新存储 / 执行对象

| 字段 | 宽 | 含义 |
|---|---:|---|
| `class_id` | 9 | STE Q7 档，0…512 |
| `multiplicity` | 9 | 该档 token 数，≤450 |
| `temporal_mask` | 2 | bit0=T0 有成员，bit1=T1 有成员 |
| `gate_c` | 9 | 一类一票 Shiftmax 之后的 Q1.7 |
| `member_base` | 9 | 指向 score-less CSR |
| CSR 项 `(pair_id, k_mask)` | 8+2 | 不再存 per-token score |

调度必须换成：

`ST_CLASSIFY → ST_SHIFTMAX(one vote) → ST_EXPAND(broadcast gate_c)`

禁止再走 `class_sum_term *= multiplicity`，禁止 `active_score_store[450]` 当 Shiftmax 操作数。K-store 可以留；变的是 directory / ISA。

参考实现：`scripts/h82_class_file_reference.py`。单测：`tests/test_h82_class_file_isa.py`。

面积账（模型，不是 DC）：450 条带 score 的 active 名单大约 `450×(8+16+2+2)=12600 bit`；10 条 Class File + 450 条无 score CSR 大约 `10×38 + 450×10=4880 bit`。省掉的主要是 450×16 的 score RAM，不是 41% 的 active 名单本身。成员名单还在。差分 directory 要等 member Jaccard 明显高于冻结包上的 0.30。

## 4. 合同里有、软件还没吐的东西

算子合同写了 `(class_id, multiplicity, temporal_pair_mask, class_score)`。现网 `_class_major_shiftmax_gate` 只回了标量 `pair_class_equal`，没有 per-class mask，也没有 member CSR。训练前向不需要这些也能出 gate，所以现在不改 `bsa_attention.py`（SHA 已冻，训练在跑）。rank-1 之后补 stats hook，按本 ISA 吐 Class File。

C8.1 现网是窗内空间 score TV，不是相邻 T450 行的 member-set TV。CPU 代理（合成分数场、15×15 滑窗，`results/h82_class_file_isa_20260817/isa.json`）：

| 场 | occupied | class Jaccard (东邻) | member Jaccard (东邻) |
|---|---:|---:|---:|
| 原始高斯 | 195.05 | 0.957 | 0.0012 |
| 空间 TV | 61.85 | 0.990 | 0.021 |

空间光滑会减 class、略抬 member Jaccard，但离冻结包上的 0.30 和“差分能碰 41%”都还远。它不是 checkpoint 证据，也代替不了跨行名单正则。若 ep14 上 member Jaccard 仍接近 0.30，下一轮 FT 要把正则改成幸存 class 的成员 TV，而不是再加一层空间平滑。

“相等重数退化为旧式”只在每个 occupied class 的 multiplicity=1 时逐点成立。两类各 225 人时，H82 与 token Shiftmax 只是同类相对比例相同，绝对值差一个重数因子。单测已钉死，避免以后写成 C7。
