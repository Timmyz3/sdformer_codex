## 2. 哪些贡献可保留

### C1：条件保留

**Topology-Quotient Multi-Relation Score Fabric**

可辩护差分：

> 四方向 residual 进入同一带 direction tag 的 event domain，在同总 residual
> lane 数下跨方向借用空闲 lane，并更新四个 exact raw accumulator。

以下不是创新：

- `Kneighbor XOR Kself`；
- residual 公式；
- compactor；
- popcount；
- direct fallback；
- 多 accumulator。

### C2：条件保留

**Bounded-Lifetime Online Relation Transpose**

可辩护差分：

> destination-major 动态 gate 在 source 最后消费者越过 frontier 时在线转成
> source-major relation，同时缩短 K/gate 生命周期并解除完整窗口 barrier。

必须击败 row/stripe fused baseline。

### C3：删除独立贡献地位

`Quotient-to-Frontier Elastic Pipeline` 只作为：

- 系统集成；
- combined ablation；
- 端到端执行结果。

可变延迟 producer、FIFO、backpressure 和 retirement hold 都是必要工程机制，
没有足够独立新颖性。

论文最多写：

```text
两项架构机制 + 一项端到端联合结果
```

不能写三项独立架构创新。

## 3. 最危险的 related-work 解释

审稿人最可能将 QFSA 解释为：

```text
Phi式pattern/residual
  + FireFly式event compaction
  + streaming-stencil融合
```

因此论文差分必须只落在：

1. pattern 不是 learned codebook，而是网络固定 self/stencil 关系；
2. 四方向 residual 共享 W4 lane，但保留 direction identity；
3. 四个 exact score accumulator 同时由 tagged events 更新；
4. high-density direction 由 exact cost router 转 shared direct；
5. 输出 relation 又由同一 stencil 图的 consumer frontier 在线转置。

Bishop、Prosperity、Phi、FireFly 和 butterfly 都必须写
`inspired/adapted`，不能写成重新命名后的“首次提出”。

## 4. 第17轮发现的两个强基线缺口

### 4.1 Score：4×W1 独立方向 residual

旧基线不公平：

- serial direct 太慢；
- 5-way parallel direct 面积太大；
- 旧 TARE 每 neighbor 串行，控制开销过重。

新增 `4×W1`：

- 总 residual lane 数与 QFSA-W4 相同；
- 同一个 shared direct engine；
- 同样四个 score accumulator；
- 每个 W1 只服务固定 direction；
- 空闲 lane 不能跨 direction 借用。

逐 destination 最小额外周期：

```text
min over direct subset D:
  direct_cycles(D)
  + max(residual_count[i] for i not in D)
```

QFSA-W4 的 CDRP 独立收益只允许写：

```text
4xW1 cycles / QFSA-W4 cycles
```

不能继续只对 serial direct。

### 4.2 Relation：row/stripe fused baseline

新增 R1：

- 整 source row 在下一 consumer row 结束后可见；
- 两个 row descriptor buffer；
- source row 投影与下一 destination row score 重叠；
- `O(W)` 状态；
- 与 FCSR 使用相同 source work 和 backend。

FCSR 的独立收益只允许写：

```text
QFSA+Stripe cycles / QFSA+FCSR cycles
```

若该比值接近 1，FCSR 只能作为状态/尾延迟机制，不能主打吞吐。

## 6. 仍不能进入完整 RTL 的原因

缺少：

1. post-G0 fullres joint delta；
2. per-source ordered term/retire；
3. 4×W1 与 QFSA-W4 的真实 stage 分布；
4. Stripe 与 FCSR 的真实 FIFO/stall；
5. source builder scan、term fanout delivery 和 Acc conflict；
6. QFSA tagged reduction 物理时序；
7. row/stripe baseline RTL；
8. DC/STA/SAIF。

因此当前只允许：

- 继续准备接口；
- 运行真实 profile；
- 依据真实结果决定是否写最小 RTL。

不允许：

- 直接实现完整 encoder；
- 复制四套复杂 backend；
- 先写 butterfly 再找收益；
- 将解析 cycle 写入论文主表。

## 9. 下一评分门槛

评审给出的 Borderline 条件：

- QFSA-W4 相对 4×W1 同资源 EDP 至少改善 15%；
- FCSR 相对 row/stripe fused baseline EDP 至少改善 15%；
- combined 相对 `4×W1+Stripe` 保持改善；
- Fmax 下降不超过 5%；
- direct score 与最终 Acc 零失配；
- post-G0/fullres 多 stage mean/p95/p99 成立。

只有满足这些条件，评分才可能从 2.9/5 升到约 3.6/5 Borderline。

本轮结论：

> **不再扩展新 idea。下一阶段只做真实 profile、两个强基线和最小可切换
> RTL；QFSA 是否成立由这三项证据裁决。**
