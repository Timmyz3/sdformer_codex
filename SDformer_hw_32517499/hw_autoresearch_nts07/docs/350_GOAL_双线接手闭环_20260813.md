3. ep35 sample0/window0 全部 138 行：每行 gated-K 与顺序 RQTB2S bit-exact。  
4. 报告 wall cycle，并与相位模型 1.292x 对照；偏差须解释。  
5. 不得把 2x 面积写成共享后端已实现。

### G2 Local5 同顶层 `[rtl]`

1. `qfit_local5_encoder_job_scheduler` 与 Q-silent score 叶在同一 TB/顶层握手。  
2. 至少一个真实 descriptor window（≥1 个 window 的全部 head）用真实 Q/K 跑完，score/gate mismatch=0。  
3. 记录 scheduler issue → score done 的 wall cycle。  
4. 12-block 21600 外推仍标 `[rtl校准模型]`，不得升级。
