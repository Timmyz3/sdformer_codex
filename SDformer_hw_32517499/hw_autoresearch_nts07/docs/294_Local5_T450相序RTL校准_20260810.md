# Local5 T450 相序 RTL 校准

> 历史说明：第一次独立复审给出 `2/5、DENY`，指出“RTL 计数器”措辞错误及
> 四段分账存在代数自证。整改后的五段接口边界观测与新结果以
> `docs/296_Local5_T450相序校准复审整改_20260810.md` 为准。

## 1. 目的与边界

本轮为正式 EREP adapter 增加一个只读 RTL 相序探针，用实际握手计数拆分 Direct
路径的：

```text
prepare -> relation fill -> term execute -> compute drain
```

探针只在 `+EREP_PHASE_TRACE_V4` 打开时输出，不改变核心 RTL。当前固定校准使用
真实 T450、`HEAD_DIM=32`、`OUT_DIM=2` 的既有 4800-group 向量集前 4 组。因此
证据只能标为 `[rtl校准]`，不能标为正式 `OUT_DIM32`、13800-group、1200-window
profile 或 EREP G0。

结果目录：

```text
results/local5_erep_t450_phase_calibration_v4_20260810
```

`complete.json` 固定记录：

```text
status = PASS_RTL_CALIBRATION_ONLY
formal_adapter_status = DENY
```

## 2. 日志合同

每组必须依次出现一条 `EREP_PHASE_V4` 和一条旧 `GROUP`，随后全局只能出现
唯一终止 PASS 和可选的 Verilator `$finish`。解析器逐组检查：

- `prepare=2`、`fill=450`；
- `prepare + fill + execute + compute_drain = total`；
- phase 与 GROUP 的 total/active/term/update/stall/SRAM 计数完全相等；
- `updates=sram_writes`，`active+avoided=450`；
- backend/new1rw/mode/latency 固定为 `0/1/0/1`；
- group 必须从 0 连续递增；
- 终止 total/descriptors 分别等于逐组 total/active 之和。

向量证据采用传递 SHA 绑定：manifest schema、shape、4800 条 identity、qualified
source manifest、source payload，以及 9 个 `.memh` 的集合、entries、width、行数
和 SHA 均需成立。任一 artifact 篡改即拒绝。

## 3. 本地结果

| 指标 | 4 组总计 |
|---|---:|
| prepare | 8 |
| fill | 1,800 |
| execute | 2,432 |
| compute drain | 12 |
| total | 4,252 |
| active source | 470 |
| term | 1,551 |
| update/write | 5,206 |
| term stall | 370 |
| SRAM read | 4,253 |

4 组逐项 Acc32 检查沿用原 TB，仿真 PASS。关闭探针后重新运行同一 binary，日志
与打开探针日志删除 `EREP_PHASE_V4` 后逐字相等，`compatibility.diff` 为 0 byte；
旧 `summarize_local5_exact_backend_rtl_replay.py` 仍能解析 4 组和 4,252 周期。

单元/破坏性测试 `5/5` 通过，覆盖未知字段、错误顺序、相序求和、跨行计数、终止
汇总、finish 顺序和 artifact SHA 篡改。结果 SHA 通过 `sha256sum -c`。

## 4. 当前裁决

该包已本地通过，正在等待独立 DATE 风格复审。即使复审接受，它也只证明“相序
探针与小规模 T450 校准可用”，不等于正式 adapter 或候选架构通过。

正式路径仍需：

1. 等 producer 生成 13800-group/1200-window manifest；
2. 绑定 `OUT_DIM32` Direct 全量回放；
3. 分别校准 epoch capture、epoch replay 与共同 vector drain/serializer；
4. 输出逐窗口 command ledger 和 Acc32 miter；
5. 经独立复审后才允许运行 G0。
