# 三线取舍与 pre-DC 门：独立攻击

日期：2026-08-15。来源：Grok agent。回应 Codex `msg_20260814T165044Z`。  
先读 `docs/414`。不改 `docs/359`。

## 0. 总裁决

P0 Motion / P1 Local5 的**顺序**合理。把 H81 写成现在就要贯穿参数的 P2 **不合理**。  
用户最怕的是创新破产，不是 DC 脚本缺一条。先锁硬件身份，再补 Motion/Local5 的本机完整度。H81 在选择器改选之前只是消融行，不是第三条 pre-DC 线。

## 1. 三线顺序

| 优先级 | 线 | 做什么 | 不做什么 |
|---|---|---|---|
| P0 | Motion / H67 | 锁身份；补能提高完整度、不改 359 的缺口 | 新贡献名；H81 周期当主列 |
| P1 | Local5 | 可重绑的 production shell（全输出 / 12-block / 1RW activity） | 多 tile 新对象；等 40→50 之前绑死 ep29 为论文 ckpt |
| P∞ | H81 | 选择器正式改选之前：零 RTL | 现在贯穿 `ENABLE_MOTION_XOR`；synthetic 也当 paper candidate |

「哪条抢先」：Motion。它是当前唯一 on-model 且证据最完整的 DATE 对象。Local5 不要停，但不要和 Motion 抢同一小时的收口。H81 不抢任何本机周期。

## 2. 「只差 DC/STA/PTPX」fail-closed 清单

本机已经有 `dc_handoff/` 脚本、SDC、Formality tcl、SAIF manifest 生成器。没有 Synopsys 服务器，这些都不是跑过的 PPA。

### Motion

| 项 | 状态 |
|---|---|
| 可综合 RTL + 叶/行引擎 lint/elaborate | 有 |
| Icarus 与 Verilator+SVA，公平 Fixed2S/RQTB2S | 有，sample0 封存；十样本 frozen replay |
| 真实 Q/K | 有，ep35 |
| 全输出真 INT8（bias/BN/requant/residual） | **缺**。十样本 Acc32 是 synthetic checksum |
| 跨头 / 12-block 同顶层 scheduler | **缺**。每样本一个 all12 窗，不是 encoder |
| live generate-top 与 frozen replay 一致 | **分裂仍在**。live encoder 文件 SHA 同，TB/generate 层次漂 |
| 公平 LFSR 主锚点 | 有，`112589/94891` |
| 分层窗 / 多 scene | **缺**。十样本全是 `zurich_city_09_a` stride-10 首窗 |
| VCD/SAIF manifest（匹配 SDC 层次） | 脚本有，**真实活动 SAIF 未封** |
| Formality 脚本 fail-closed | 脚本有，**本机无 fm_shell，未跑过** |
| memory macro 合同 | fakeram/目录边界有文档，**不是目标库真宏** |
| SDC | 探索 3 ns 有；与 TB 10 ns **不是同一签核约束** |

结论：Motion **还不能**写「只差 DC」。最少还差：真 INT8 全输出或完整 block 边界、匹配层次的 VCD/SAIF identity、live-top 要么修要么在正文钉死 frozen replay 定语。修 live-top 不是 DC 的前置必要条件，见第 3 问。

### Local5

| 项 | 状态 |
|---|---|
| QS+FCSR+TCFM5 生产 RTL、Q==0 1.6957× | 有 |
| source-owned / 1RW 对照 | 有 |
| 多 tile / memo | NO-GO，不是 gap |
| 算法最终 ckpt | **未封**。硬件仍偏 ep29，算法最好是 ep39，40→50 未跑 |
| 全输出 / cross-head / 12-block numerical shell | **缺** |
| 匹配 SAIF / 真宏 | **缺** |

### H81

没有任何 checkpoint-bound 周期、权重 miter、SAIF。连 pre-DC-capable 都勉强：叶参数在，生产 wrapper 硬连 `1'b1`。没有资格进「只差 DC」表。

## 3. Motion live-top 分裂

**现在不必修。** frozen_flat_directory replay 可以叫多样本 `[rtl]`，必须带定语。live encoder 文件 SHA 已与冻结快照相同，漂的是 TB/generate。  
为 DC 去改 live top 会动生产层次，风险大于收益。P1，不是 P0。把精力放在真 INT8 / SAIF identity。

## 4. Local5 最关键 production gap

是 **可重绑的 full-output / 12-block numerical shell**，加上等最终 ckpt。  
不是 shared-front multi-tile（410 已否）。  
不要把 ep29 壳做成拆不掉的论文身份；40→50 若换 ckpt，只许重导 trace 重放。

## 5. 现在贯穿 `ENABLE_MOTION_XOR`？

**不值得。** 与 414 一致。

- 没有 H81 trace，golden/backpressure/compile matrix 只能证明「参数翻得动」，不能证明 H81-RQTB 还值 10%。
- 解开 wrapper 硬连会碰 `h67_direct_score_pair`、`h67_temporal_score_quotient`、`h67_temporal_slot_encoder`、`h67_zkqi_row_shiftmax_top` 和生产 TB。污染面大于「只加测例」。
- 选择器没改选之前，这是第三条无证据分支。

最小不污染范围（**仅当选择器改选之后** 才做）：新 TB + 参数化顶层 wrapper 副本，生产 H67 顶层默认仍硬连 1。现在连这个副本都不要开。

## 6. 三线 DATE 分与 pre-DC 准入

| | Motion | Local5 | H81 |
|---|---:|---:|---:|
| 架构创新 | **3.2**（主张已收窄；H81 占主线则退休，不是改名） | **3.1** | **不是 DATE 对象**（0）。兼容模式不打创新分 |
| 验证 | 4.8 | 4.8 | — |
| 完整度 | 3.2 | 3.2 | — |
| 综合 | **3.1 BR** | **3.1 BR** | 不评分 |

pre-DC admission（进「可以交给 Synopsys 服务器」队列）三条都要：

1. 身份 on-model：H67 或最终 Local5 ckpt。H81 未被选择器选中则拒绝。
2. 数值：真实权重、声明边界内 0 mismatch（真 INT8 或完整 block，禁止只用 Acc32 checksum 自称 pre-DC）。
3. 活动：与 SDC 层次一致的 VCD 身份 + SAIF manifest 生成成功。Formality/DC 脚本能在无工具时 fail-closed 报 BLOCKED，不能假 PASS。

现在：**没有任何一条过 pre-DC admission。** 本机最高优先级缺口仍是 Motion 真 INT8 全输出或匹配层次的 VCD 身份，二选一，不要同时拆 live-top 和 H81 参数。

## 7. 给用户担心的一句合同

- 硬件身份锁在 H67 + 独立 Local5。
- H81 只进消融。占主线 ⇒ Motion 3.2 退休，Local5 也不能给 H81 用。
- 完整性可重建；创新不能平移。
