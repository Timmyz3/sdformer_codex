# DATE 第六轮独立复审与双线主张重构

本轮独立 DATE 审稿结论：

研究可以继续，Local5 局部 RTL 可条件冻结，但当前不具备 DATE 投稿成熟度。

| 维度 | 分数 | 核心判断 |

## 2. 本轮立即整改

### 2.1 取消 Local5 ordered-tail 豁免

旧 DSE 在 Local5 缺少 ordered trace 时把 `tail_pass=True`，造成 18/18 候选
看似完整通过。现改为：

- 三项预筛：吞吐、lane 归一、fabric bits；
- 尾延迟合同：无 ordered trace 时为 `None`；
- 正式 `passes=False`；
- 新增单元测试防止回归。

修正后：

| 主线/规模 | 候选 | 三项预筛 | 正式通过 |
|---|---:|---:|---:|
| Local5 T162 | 18 | 18 | 0 |
| Local5 T450 | 18 | 18 | 0 |
| Motion T162 | 18 | 0 | 0 |
| Motion T450 | 18 | 0 | 0 |

该表说明当前没有任何 Phi/Prosperity-like DSE 点完成全部晋级合同。

二次复审进一步发现 Motion T450 是 `25/9` 外推，却仍可被标成
`[prof-ordered]`。现已把 ordered-tail 可用条件收紧为：主线必须为 Motion，
且所有输入样本 evidence 必须为 `[prof-ordered]`。因此 Motion T450 外推也会
得到 `passes_tail_contract=None`，不能利用 T162 尾延迟跨规模晋级。

### 2.2 取消“默认共享执行核”强主张

Local5 同顶层结果证明当前 TARE 比 Direct 慢 10.20% 至 14.08%，开放门数只少
约 1.35%。因此论文不能继续声称 Motion/Local5 默认共享同一个 TARE 执行核。

双线主张重构为：

> **统一 topology descriptor 与 lowering 合同，执行后端按数据特征专化。**

```text
统一描述层
  topology / anchor / residual / valid mask / destination contract
        |
        +-> Motion lowering -> temporal-pair TARE -> SCS/SET-term -> M4
        |
        +-> Local5 lowering -> Direct5 score -> Shiftmax5 -> MFEP
```

共享的是编译/调度抽象和 exact 语义，不强迫共享吞吐不占优的物理 datapath。

## 3. 当前能否单列为 DATE 贡献

| 候选 | 当前结论 | 晋级所需证据 |
|---|---|---|
| Topology-declared exact lowering | 潜在主贡献，未完成 | descriptor ISA、双 lowering RTL、相对手工控制的控制/存储收益 |
| Motion temporal-pair exact pipeline | 潜在主贡献，链未闭环 | TARE 到 SCS/SET-term/M4/final 同顶层 |
| Local5 MFEP gate-stationary projection | 潜在第二贡献 | post-G0 profile、无 MFEP 公平消融、目标 PPA |
| SCS-Shiftmax | 算子微架构 | 只能作为 Motion 链的一部分 |
| TARE/Direct 消融 | 必要负结果 | 不能单列贡献 |
| 普通双 context/三 bank | 工程机制 | 不能单列贡献 |

本轮不靠 ZUI、代数闭包或新命名提高评分。只有形成可证伪合同、同顶层实现和
同约束收益后，才允许写入贡献列表。

## 4. 双线下一轮实施顺序

### P0：补真实 workload

1. Motion fullres T450、全部 block、hardware-order ordered trace；
2. Local5 fullres post-G0、真实 invalid mask、ordered destination trace；
3. 两线统一 sample/block/head/window 标识；
4. 报告 mean/p95/p99、最坏队列、gate cardinality、destination fanout。

### P1：闭合各自主链

1. Motion：`TARE -> SCS/SET-term -> fixed64/M4 -> final Acc` 同顶层；
2. Local5：`Direct5 -> Shiftmax5 -> MFEP -> projection` 的
   `MFEP on/off` 同顶层；
3. 模型对 RTL 逐 stage 校准，误差小于 10%，目标小于 5%。

本轮已经先补充 Local5 第六轮 artifact manifest；它解决日志和源码版本对应问题，
但不替代 fullres trace 或目标库 PPA。

### P2：实现统一 lowering

定义最小 descriptor：

```text
mode
anchor_id
candidate_valid_mask
neighbor_or_peer_offsets
token_count
destination_width
residual_policy
term_format
```

分别 lowering 到 Motion temporal pair 和 Local5 spatial stencil，不实现复杂
中央控制器。评价指标为描述符流量、控制状态、切换开销和双专用控制器面积。

### P3：目标库 PPA

同一 SRAM、SDC、PVT 下比较：

- direct baseline；
- Motion 专用；
- Local5 专用；
- 统一 lowering + 两个专用后端；
- 只有在 PPA 有利时才加入可切换共享核。

必须给出 STA、SAIF、泄漏、SRAM macro、EDP、FPS 和 energy/frame。

## 5. 下一轮 DATE 硬门槛

### Borderline Accept

- 双线 fullres 全 block：0 mismatch；
- 模型/RTL误差小于 10%；
- ordered `p99/mean <= 1.25`；
- 至少一个主机制吞吐或面积归一吞吐不低于 1.15 倍；
- EDP 改善不低于 15%；
- full encoder 改善不低于 1.10 倍；
- 目标库 STA/SAIF/LEC 和 artifact manifest 完整。

### Accept

- 若保留双线主张，两线分别达到上述门槛；
- 统一 lowering 相对两个独立控制实现具有可测 PPA 优势；
- full encoder 性能不低于 1.15 倍；
- energy/frame 改善不低于 15%；
- 多样本、多 stage、fullres 结果稳定。

在这些门槛关闭前，当前投稿状态继续按 **Weak Reject** 管理。
