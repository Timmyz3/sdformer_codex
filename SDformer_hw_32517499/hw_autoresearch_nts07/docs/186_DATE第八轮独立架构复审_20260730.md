## 3. P0 问题

### P0-1：Direct64/Direct160 lane 公平性不成立

`160/48` 只是 nominal lane 数比。full-score lane 与 residual update lane 在
selector、加法器、寄存器、布线和时序上不等价，不能把 `3.331x` 写成面积归一
吞吐。

### P0-2：吞吐模型漏掉完整流水

当前 residual service 模型没有包含：

- delta 生成；
- selector/partial butterfly；
- 四 FIFO 端口；
- candidate atomic join；
- weighted normalizer；
- dense multipass/escape；
- term builder；
- projection backpressure。

因此 `1.000x` 只表示 residual 服务下界，不是 TQ-FFE 吞吐。

### P0-3：TRCF 建表成本可能被隐藏

必须计入：

- destination 如何到达本地；
- list allocation/pointer；
- list SRAM 写读端口；
- product context；
- RAW/port conflict；
- ordered ack 与尾排空。

如果 destination 仍逐项经过全局 fabric，TRCF 没有架构收益。

### P0-4：projection 收益重复记账

unique term 可以减少 weight/product 生成，但每个 destination 的 Acc 更新、
list walk 和 SRAM RMW 仍必须执行。不能把 product reduction 和 destination
service speedup 相乘后写成端到端 EDP。

### P0-5：双线共享未证明

Motion 与 Local5 具有不同：

- candidate 数与输入端口；
- selector/fission 组织；
- FIFO；
- weighted SCS/Shiftmax5；
- invalid mask；
- downstream control。

当前只证明“residual slice 算术概念可共享”，没有证明重构核比两个专用核更省。

### P0-6：工作量仍不足

- TQ-FFE RTL 未实现；
- TRCF 逐 term replay 未实现；
- Local5 仍是 pre-G0；
- 无同 SRAM/SDC 的 DC/STA/SAIF。

## 4. P1 问题

1. T450 destination 至少 9 bit，旧模型的 8 bit 不合法；
2. backlog 是待服务 cycle，不是 FIFO entry；
3. sample-total p99 不是 transaction latency tail；
4. Local5 `max(direction service)` 是乐观服务下界；
5. weighted multiplicity 尚无 bit-exact normalizer RTL。

## 5. 可保留内容

1. 只折叠 valid 且 K 完全 identical 的 exact 数值合同；
2. multiplicity 进入 Shiftmax denominator，并在 gate 量化后参与整数投影；
3. profile 中 candidate、score lane-work、unique product 数的减少；
4. Motion W4 TQ-FFE 值得进入完整边界 RTL 原型；
5. butterfly、DCTF、3-bank、双 context 不是独立贡献。

## 6. 最小可证伪任务

只做 Motion W4 的同顶层：

```text
B0: Direct64
A1: 32-lane anchor + 4x4 residual slice
```

同一：

- Q/K 端口；
- weighted normalizer；
- source-push projection；
- SRAM latency；
- transaction 边界；
- ordered trace；
- SDC。

A1 必须包含有限 FIFO、真实 selector、dense multipass、atomic join 和完整反压。

淘汰门槛：

- 完整边界吞吐 `<0.95x`；
- FIFO 最大占用 `>256 entry`；
- 完整 score-to-term 逻辑面积或动态功耗未下降 20%。

任一成立就淘汰 TQ-FFE，不继续用 Local5/TRCF 扩大故事。
