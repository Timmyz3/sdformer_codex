## 1. 一句话

**硬件对象不用拆，论文主张必须改。**  
DSEC 精度台阶已被 H81 拆开：大头是「全二值 ATLIF + 统一 TTX」，Motion-XOR 几乎为 0，Local5 五邻域还有可见的一截。现有 Motion RTL 仍然服务冻结主线 H67 ep35 的精确部署，但 **不能再把 TESC+RQTB 写成精度引擎**。Local5 的 QS+FCSR+TCFM5 现在是唯一和额外汇报对齐的硬件故事。

DATE 真正的张力：

> 精度引擎是统一 TTX（H81），它没有专用硬件对象；专用硬件对象是 Motion 归并和 Local5 拓扑，前者 DSEC 精度≈0，后者泛化门没过。

这不会让现有 RTL 作废，但会让「Motion 是 DATE 主贡献」在审稿时被一刀问死。必须提前改主张，而不是改网表。

1. **不改** `docs/359` / `362` / `366`，SHA 仍以 `dedde7ce…` 为准。不把 1.176421×、H81 AEE、Local5 1.3153 写进 359 主列。

## 5. 推荐方案：现在走 A，条件触发 B

### 方案 A（现在就执行，推荐）

双线保留，**主张收窄**：

- **算法主线**：仍写 H67 Motion-TTX ep35。理由是 MVSEC 四序列过门 + 硬件证据绑定，**不是** DSEC 又准了一截。
- **Motion 硬件一句**：可逆时间分数类归并（TESC+RQTB / pair-local Q7 descriptor），把冻结部署里的 equal-pair 合成一类，周期主锚点 `1.1865×`。  
  禁止：「Motion 带来 8% AEE」「RQTB 是精度机制」「H67−H81 证明时间先验有效」。
- **Local5 硬件一句**：拓扑驻留的五邻域 Local-TTX 数据流（Query-Silent + 逆模板/FCSR + TCFM5）。  
  允许写它对齐 DSEC 上可见的额外汇报（约 −1.15% AEE / −2.37% AE-3D），必须同时写 MVSEC `indoor_flying1` 没过门、硬件仍绑 ep29。
- **H81**：只出现在算法消融。硬件文档里把它标成「统一 TTX 的 recipe 级对照，无硬件 provenance」。

DATE 叙事从「时间先验驱动的加速器」改成：

> 统一二值 TTX 给出精度和脉冲；硬件专做两类部署对象：  
> （1）H67 冻结合同上的时间分数类归并；  
> （2）Local5 五关系的源所有多播与驻留。

### 方案 B（条件触发，现在不做）

仅当下面全部发生，才讨论把 Local5 升为硬件第一贡献、Motion 降为支撑：

1. Local5 40→50 仍选 ep39 或更好，且不是过拟合回弹；
2. 同 checkpoint（不是 ep29）重绑 profile/RTL；
3. 等面积系统模型相对 H67 至少 10% 能量或 EDP，吞吐回退 ≤5%，面积 ≤15%；
4. 论文接受 MVSEC 用「宏平均更好、单序列失败」的附录写法，或补过门的新 Local5。

现在一条都不满足。B 不是本周任务。

### 明确否决的方案

- **C. 为 H81/统一 TTX 新开硬件线**：没有新执行对象，等于重做已有注意力核。
- **D. 看见 H81 就删 Motion**：H67 仍是选定主线，周期账和 exact 合同都在 Motion 上。
- **E. 用 1.176× 或 H81 0.069% 改 359**：封存合同禁止。

## 6. 后续硬件优先级（做完手头再看）

### Motion（不要再找 1.17× 新名字）

P0 主张修改：407 / 362 式贡献句改成「精确时间分数归并」，去掉任何「精度引擎」措辞。创新分仍 3.2，不因 H81 自动降到 3.0——对象还在，只是算法动机变窄。  
P1 完整度（有空再做，不改变创新分）：live generate-top 兼容 TB；真 INT8 全输出而不是 Acc32 checksum；按密度分层窗口，而不是 `zurich_city_09_a` stride-10 首窗。  
P2 可选低成本账本：同一冻结 Q7 轨迹上统计 equal-pair 率 / RQTB 周期，证明归并仍在做功。这不是新 RTL。  
禁止：H81 周期对照 RTL、再挖 class-folding / late-gate / den-directory。

### Local5（精度对齐的那条线，优先创新而不是换名）

P0 等算法：QF 结束 → Local5 40→50。硬件只读，不抢 GPU。  
P1 若 40→50 选出的不是 ep29：同 ckpt 重导出 Q/K/gate 向量，再谈绑定。现在仍写 ep29。  
P2 系统完整度：目标宏下 1R1W/1RW matched SAIF/DC/STA/PTPX；完整 block/encoder。这是完整度，不是新贡献名。  
P3 创新：只接受「改训练分布或改执行合同」的候选。410 已否决多 tile 新对象；orbit / dest-owned 计数有被 74,131 term 强基线反杀的风险，先只读账本，不接 RTL。

### 两边都不要做
