# HIFP 分层不变量外提投影架构与 PPDI/IBF 闭环

> 日期：2026-08-01  
> 范围：Motion 与 Local5 共用的 gate-term 到三 bank 投影后端  
> 证据边界：本文包含定向 RTL、动态 SVA、Yosys 结构检查和开放 Nangate45
> 逻辑映射代理；不包含 DC、STA、SAIF、SRAM 宏和芯片 PPA。

## 1. 本轮结论

本轮不再把“双 context、三 bank、FIFO、偏置旁路”拆成若干弱创新，而是冻结一条
统一架构候选：

**HIFP（Hierarchically Invariant-Factored Projection，分层不变量外提投影）**。

HIFP 从 gated-K 投影的两个嵌套不变量出发：

1. 同一 `(gate, lane)` term 内，`gate × weight` 对全部 destination token 不变；
2. 同一输出 tile 内，线性偏置对全部 token 不变。

因此，硬件不应按 token 重复计算产品，也不应把偏置逐 token 写回 accumulator。
PPDI 将第一层不变量映射到偶/奇双写端口，IBF 将第二层不变量映射到最终退休路径。
双 context 和三消费者有序 fabric 只是维持吞吐与正确性的支撑机制，不单列为贡献。

本轮已完成从 term adapter、三消费者 fabric、三 bank executor、六路 accumulator 到
final output 的组合 RTL 闭环。当前判定仍是 **Borderline Reject**，但架构主张已从
“若干工程模块”提升为一个可证明、可消融的数据流变换。

## 2. 数学与数值合同

对输出 token `n` 和输出通道 `o`，投影可写为：

```text
Y[n,o] = B[o] + sum over (g,l) where n in D[g,l] of g * W[l,o]
```

其中：

- `g` 是 Shiftmax 之后的定点 gate code；
- `l` 是输入 lane；
- `D[g,l]` 是该 term 的 destination token 集合；
- `B[o]` 是输出通道偏置，与 token 无关。

HIFP 的执行顺序为：

```text
tile_start
  -> bias descriptor B[o]只读取一次
  -> for each exact term (g,l,D):
       W[l,o]只读取一次
       P[o] = g * W[l,o]只计算一次
       parity-pair(D)后组播到偶/奇Acc端口
  -> product-only Acc驻留
  -> final read时执行Y = Acc + B
  -> 三bank原子完成
```

精确成立的条件为：

- PPDI 不改变任一 token 的 term 顺序，只把同一 term 的一个偶 token 和一个奇
  token 同拍提交；
- IBF 仍在全部 product 完成后加偏置，与原 `ST_BIAS -> ST_FINISH` 顺序一致；
- 偏置必须是逐输出通道或输出 tile 固定、token 间不变的线性偏置；
- accumulator 使用同一 INT32 合同，overflow 继续作为 sticky error；
- flush 同拍清 adapter、fabric、executor、accumulator 和 finalizer 生命周期。

## 3. 完整硬件数据流

```text
SCS/NMF 或 Local5 gate-equivalence producer
            |
            v
whole-term 2C adapter
  - 收齐destination
  - duplicate/range/count/head-last原子检查
  - 按token ID奇偶写入4-way parity token banks
            |
            v
PPDI command = {gate, lane, seq, even?, odd?}
            |
            v
Q深度三消费者有序fabric
  - 每entry三位consume mask
  - 三bank独立推进
  - 全部bank消费后全局有序退休
            |
    +-------+-------+
    |       |       |
  bank0   bank1   bank2
  取W一次 取W一次 取W一次
  算P一次 算P一次 算P一次
  偶/奇双目的提交到product-only Acc
    |       |       |
    +-------+-------+
            |
            v
IBF finalizer
  - 每bank只取一次bias向量
  - 复用产品累加相位的32-bit向量加法器
  - final read时加bias，不写回Acc
  - 六路输出可独立反压
            |
            v
三bank原子tile_done
```

### 3.1 PPDI 的本土化点

PPDI 不是一般的双发射。它依赖三个网络与物理端口联合条件：

1. 同一 term 的全部 destination 共享完全相同的产品；
2. flat token ID 的偶/奇恰好对应 accumulator 的两个独立物理 bank；
3. 配对只发生在同一 term 内，不需要跨 term 重排或推测。

因此每条命令最多携带一个偶 token 和一个奇 token，命令数为：

```text
commands(term) = max(even_count(term), odd_count(term))
```

Motion sample0/window0 的真实 term trace 中，命令由 23175 降至 16160，
command-work 降低 30.270%。这不是周期结论；profile100 尚未保存逐 term 奇偶分布。

### 3.2 IBF 的本土化点

原 RMW 路径为每个三 bank 输出 tile 读取 `3T` 个偏置向量，并把偏置逐 token
写入 accumulator。IBF 只读取3个 bank-local 偏置向量，降低比例为：

```text
bias_read_reduction = 1 - 1/T
```

| Token数 | 原偏置读取 | IBF偏置读取 | 解析降低 |
|---:|---:|---:|---:|
| 6 | 18 | 3 | 83.333% |
| 162 | 486 | 3 | 99.383% |
| 450 | 1350 | 3 | 99.778% |

偏置加法没有删除，而是从 Acc SRAM RMW 相位推迟到 final read 相位。该机制与
CICC 2026 光流芯片“避免高频冗余物化”的设计原则一致，但本工作不使用其
speculation：偏置不变量来自线性层定义，结果 bit-exact。

### 3.3 相位互斥加法器折叠

第一版 IBF 为 product update 和 bias final 各保留一套 32-bit `OUT_TILE`
向量加法器。代码审阅发现两个相位不可能重叠：

- product update 只在 `group_active && !finalizing`；
- bias final 只在 `finalizing`。

现已改为一套共享加法器，通过相位选择 product addend 或 resident bias。
四路功能周期不变，组合 Verilator 动态断言通过。最终面积收益以优化后开放库映射
为准。

## 4. RTL 等边界消融

统一设置：

- 同一个 `gatestack_dctf96_banklocal_projection_top`；
- `ADAPTER_CONTEXTS=2`；
- 同一静态线性偏置、同一 term/event、同一 weight/bias response 顺序；
- 相同六路 final backpressure、flush、stale epoch 和 same-tag recovery；
- 比较项只改变 `PPDI_ENABLE` 与
  `IMPLICIT_BIAS_FINALIZE_ENABLE`。

| 配置 | 周期 | 相对标量RMW |
|---|---:|---:|
| 标量 + RMW | 128 | 1.000x |
| PPDI + RMW | 125 | 1.024x |
| 标量 + IBF | 98 | 1.306x |
| PPDI + IBF | 95 | 1.347x |

这组 T=6 定向向量显示 IBF 是主要周期收益，PPDI 只贡献3拍。它不能代表 T=162
或 T=450 的真实 trace；其价值是确认两种机制在完整顶层可组合且输出一致。

### 4.1 Motion 真实四阶段回放

进一步使用 H67 sample0/window0 的真实 S0-S3 term、INT8 weight、INT32 bias 和
expected output 回放同一个完整顶层：

| 配置 | S0 | S1 | S2 | S3 | 总周期 | 加速 |
|---|---:|---:|---:|---:|---:|---:|
| 标量 + RMW | 764 | 718 | 5356 | 47072 | 53910 | 1.000x |
| PPDI + RMW | 732 | 718 | 5124 | 42776 | 49350 | 1.092x |
| 标量 + IBF | 523 | 236 | 4392 | 45144 | 50295 | 1.072x |
| PPDI + IBF | 491 | 236 | 4160 | 40848 | 45735 | 1.179x |

四种模式保持完全相同的 term 数、物理 weight 请求和 233280 个 INT32 final
逐元素检查，全部零失配。组合 S0 的 Icarus 与 Verilator 动态 SVA 均为491周期。

这组结果修正了 T=6 的错误直觉：

- 在真实高 term 密度 S3，PPDI 比 IBF 提供更大周期收益；
- IBF 对无 term 的 S1 最有效，将718周期降至236周期；
- 两者节省拍数在四个 stage 均精确叠加，说明数据流机制正交；
- 四阶段偏置请求由7290降至45，降低99.383%。

## 5. 开放库逻辑映射

- NangateOpenCellLibrary typical；
- 默认 `TOKENS=162, OUT_TILE=32`；
- 同一 RTL 输入、同一 Yosys 流程；
- `memory -nomap`，但部分行为存储仍被 Yosys 转成寄存器和 mux；
- 无 SDC、无 STA、无 SRAM macro、无布线和时钟树。

最终四路数字由
`results/ppdi_ibf_projection_20260801/report.md` 自动生成。开放库面积只能用来

## 6. Motion 与 Local5 的适用边界

| 机制 | Motion | Local5 |
|---|---|---|
| term 产品不变量 | 已由 SCS/NMF term 建立 | gate-equivalence producer 可建立 |
| PPDI | sample0真实trace降低30.270% command-work | RTL可复用，真实奇偶收益待 post-G0 profile |
| IBF | 线性偏置静态，直接适用 | 线性偏置静态，直接适用 |
| 三bank DCTF | 已有 Motion trace/RTL基础 | 可共用 projection backend |
| attention前端 | Motion-XOR + SCS | Local5 QFSA/MFEP，不共用 |

所以 HIFP 是双线共用后端，不要求 Motion 与 Local5 的 attention score 相同。
Local5 不能因为当前 profile 未完成而被删除；但在真实 `mfep_ppdi_delivery_exact`
和 hardware-order 数值结果出来前，不能把 Motion 的 30.270% 套到 Local5。

## 7. 与外部工作的差分

| 工作 | 借鉴的原则 | HIFP 的本土化差分 |
|---|---|---|
| Prosperity | exact product reuse | 复用键是有限 gate-code term，并继续映射到奇偶双目的 |
| Bishop | TTB/metadata-first执行 | 不做 ECP 近似；term destination 和偏置合同均精确 |
| PHI | 稀疏执行统计与 memory-aware 评估 | 后续采用其事件/存储分账方法，不复用其论文数字 |
| Sanger | stationary dataflow | stationary 对象从 score 扩展为 gate term 与 tile bias 两级不变量 |
| StreamTensor | 迭代空间显式编码 | destination set 在硬件 whole-term adapter 中原子验证 |
| CICC 2026光流芯片 | 避免冗余物化、memory-inclusive口径 | 用确定性偏置不变量替代 speculation，不跳算、不损精度 |

不能写成创新的内容包括：双缓冲、三 bank、普通 ready/valid、多播 FIFO、静态偏置
本身，以及“提出 product reuse”。可辩护主张是这些机制由同一投影方程的两级
不变量统一驱动，并完成端到端精确物理端口映射。

## 8. DATE 贡献表述冻结

建议主文只把本子系统列为一条架构贡献，下面的 M1/M2 是机制消融，不再凑成三个
独立创新：

**C-HIFP：面向 all-binary SNN gated-K 投影的分层不变量外提数据流。**

- **M1，PPDI 精确奇偶配对组播：** 将 term 内产品不变量映射到 accumulator
  物理偶/奇端口，在真实四阶段 trace 上获得1.092x周期加速；
- **M2，IBF 隐式偏置终结：** 将 tile 内偏置不变量从逐 token Acc RMW 外提到
  final retirement，偏置请求降低99.383%，单独获得1.072x周期加速；
- **相位互斥数据通路折叠：** product update 与 bias final 复用同一32位向量
  加法通路，使 IBF 单独面积增量只有0.045%，组合面积增量1.357%；
- **组合结果：** 同一真实四阶段 trace 上1.179x周期、1.163x开放逻辑面积归一
  吞吐代理，233280个INT32输出零失配。

论文中不能把1.163x写成芯片 PPA，也不能将 sample0/window0 写成数据集平均。
若后续多样本收益不稳定，PPDI 降为可选机制，但 IBF 的解析偏置流量结论仍成立。
