- 状态：`ADMIT_AS_EXISTING_LOCAL5_CORE_EXECUTION_OBJECT`。
- 证据：全量 100-sample profile 为 `[prof]`；sample-disjoint、stage-weighted 100-group、`OUT_DIM=2` score-to-Acc32 tile 为 `[rtl]`。

## 2. 精确执行对象

对固定 source `s`、活动 K lane `l` 和非零 gate `g`，定义 consumer 集合：

```text
D(s,l,g) = { d | d consumes s, K_s[l]=1, gate(d,s)=g }
```

生产 term 为：

```text
{source=s, lane=l, gate=g, destination_mask=D(s,l,g)}
```

硬件只计算一次 `g * W[l,:]`，TCFM5 再按五位 destination mask 对所有目标执行精确 scatter-add。与被否决的 class-wise K folding 不同，destination identity 没有被 count 替代；减少的是重复 product，destination update 必须守恒。

对应生产链为：

```text
Query-Silent / residual score + Shiftmax5
  -> inverse-stencil rolling frontier
  -> source descriptor {K_s, incoming gates, valid mask}
  -> source-owned unique-gate term builder
  -> TCFM5 five-color destination multicast
  -> Acc32
```

证据：`results/local5_source_owned_gate_quotient_profile100_20260814/report.json`，绑定 qualified 100-sample、13,800-group payload `05a4c4155c6e439760caeb0a5ed636d7a989d02c9be741ab0e159303d987f533`。

| 同 trace 执行对象 | product term / delivery |
|---|---:|
| raw relation-lane delivery | 29,164,959 |
| destination-local MFEP term | 22,848,620 |
| source-owned gate-lane term | 9,870,505 |

- source-owned 相对 raw relation-lane 少 `66.156%` product term。
- source-owned 相对 destination-local MFEP 再少 `56.800%` product term；MFEP term 为 source-owned 的 `2.315x`。
- 29,164,959 次 destination delivery 前后严格守恒；invalid candidate nonzero gate 为 0。
- 上述是 product-work 统计，不是周期、能量、encoder 加速或 ASIC PPA。

## 4. 生产 100-group 四方 miter `[rtl]`

最终证据：`results/local5_source_owned_gate_quotient_rtl_miter_v6_20260814/report.json`，SHA256 `119fe705d525894613af282d8ee10ce464d057866e0050ebf9da65c34aaf7af9`。

独立 miter 不调用向量生成器，而是从 destination-major `input_candidate_k`、`input_valid`、`expected_gates` memh：

1. 逆固定五邻域重建 source descriptor；
2. 为每个 source/lane 合并相同非零 gate，构造 destination mask；
3. 重新计算真实 checkpoint INT8 权重 Acc32；
4. 与 manifest row、expected memh、Icarus ledger、当前源码 Verilator ledger 比对。

结果：

| 项 | 数字 |
|---|---:|
| groups | 100 |
| active source descriptor | 11,245 |
| active-source unique gate instance | 17,246 |
| all-source unique gate instance（含 `K=0` source，仅作诊断） | 66,411 |
| source-owned term | 74,131 |
| destination update | 222,649 |
| destination-local MFEP term | 174,289 |
| production busy cycles | 155,791 |
| checked Acc32 values | 90,000 |
| all mismatch | 0 |

同一生产 cohort 上，source-owned 相对 destination-local MFEP 少 `57.467%` product term，和全量 13,800-group 的 `56.800%` 一致。

`v6` 修正了一个不影响 Acc32 的统计口径：旧 `unique_gate_instances=66,411`
包含 `K=0` source，不能与 `active=11,245` 相除。现拆成 active/all-source
两列，并断言 active 列不超过 `5*active`。冻结周期、term、update 和 Acc32
均未改变。

## 6. 强基线与创新裁决

近邻和 W4 强基线攻击后，不能把 source-owned scatter 单独写成首次：

- GRIP/GNN dataflow 已有 source/edge-centric 组织；
- I-GCN 已利用 shared-neighbor aggregation reuse；
- Prosperity 已提出 exact product sparsity；
- 普通 source-stationary/Gustavson scatter 本身不是新对象。

同一 100-group 上的 lane-local W4/W6 账本见
`results/local5_source_owned_cache_strong_baseline_20260814/report.json`（SHA256
`b35d8c0b22a5e9be889b269c2868476b2b53b59df5e52cf351152fc8f984e09c`）：

| 流 | issue | W4 product start | W6 product start |
|---|---:|---:|---:|
| destination-local MFEP | 174,289 | 5,551 | 5,503 |
| source-owned multicast | 74,131 | 5,561 | 5,507 |

因此 `74,131` 不是全局最少 product compute。W4 可跨 descriptor 复用
`(lane,gate)`，把两种流的 product start 都压到约 5.5k；source-owned 可守的
差分是把仍需经过后端的 message issue 和 W4 tag compare 减少 `57.467%`，并用
destination mask 保留全部独立更新。二者语义正交、物理竞争，必须做同边界
`Q/C/QC` 消融后才能声称 EDP 优势。

Local5 可守的差异不是单独的 source stationarity，而是一个统一、固定拓扑、exact attention 数据流：

```text
Query-Silent 代数旁路
  + inverse-stencil 编译期 last-consumer 三行前沿
  + source-owned gate quotient（destination mask 保序）
  + (x+2y) mod 5 的 TCFM5 无冲突多播
```

它避免 Prosperity 一类运行时 TCAM/排序查找，也不是一般 GNN 的不规则邻接；但这些差异目前仍应作为一条 Local5 贡献，而不是四条子贡献。
