## 0. 一句话结论（两个裁决）

1. **验证实验 3 通过**：eq=0.9748 是**运动边 XOR 驱动的构造属性，不是数据巧合**——三个数字：运动边 eq **0.904**、非运动边 eq **0.998**、Bernoulli 期望 eq **0.581**（全局 Σp²；同位置口径 0.697）。运动边 eq 是全局 Bernoulli 期望的 1.6 倍、运动边条件 Bernoulli 期望（0.151）的 6.0 倍，且随运动强度单调下降（m=1→0.993，m≥8→0.463）——机制实锤。
2. **双窗敏感度账不通过 0.95+ 区间**：T=5 组内 eq=**0.805**、T=4 组内 eq=**0.879**，均低于 0.95。**D1 主张确实依赖单点 0.979**（pair 级锚点），合同 I6 的广播位账（−78.3%/−73.4%）按实测组内 eq 重定价为 **−64.4%/−61.5%**（T=4 全组口径 −64.6%）。机制仍是大幅节省（均值账由线性性精确），但幅度必须修正（§5 弱点与补救）。

## 2. 验证实验 3：运动边 dump vs Bernoulli 界 `[prof]`（裁决：构造属性成立）

锚点复核：temporal pair eq（时间对 t0/t1 同 Q7 类）= **0.9748**（151.2M pairs；锚点 0.979 为 H82 rank-1 口径，全量冻结 ep35 复测为 0.9748；ep30 既有测量 0.9757，三者同量级）。运动边率 m>0 = 24.28%。

| 量 | 值 | 说明 |
|---|---:|---|
| **eq(运动边 m>0)** | **0.9042** | 运动 XOR 活跃的时间对仍 90.4% 同分 |
| **eq(非运动边 m=0)** | **0.9975** | K 静止对 eq≈1（= 非运动条件 Σp² 0.9975，见下） |
| eq(双 K 零) | 0.9975 | 与既有 ep30 报告 0.99751 逐位一致（交叉验证 ✓） |
| **Bernoulli 期望 eq（全局 Σp²）** | **0.5810** | 分数边际 top5 类 {2,3,4,5,6} p=0.756/0.071/0.041/0.029/0.023，Σtop5=0.92 |
| Bernoulli 期望 eq（同位置 Σp²） | 0.6971 | 固定位置随机跨时间配对的期望 |
| Bernoulli 期望 eq（运动边条件 Σp²） | 0.1512 | 运动边分数边际平坦得多 |
| eq 按运动强度梯度 | m=1: 0.9933 / m∈(2,3): 0.9867 / m∈(4,7): 0.9563 / m≥8: 0.4629 | **单调递减——m̄ 是 eq 的控制变量** |

**裁决**：eq(运动边)=0.904 ≫ 全局 Bernoulli 0.581（1.6×）≫ 运动边条件 Bernoulli 0.151（6.0×）。运动边活跃的 24.3% pairs 上分数仍 90.4% 相等——这远超任何随机配对水平；eq=0.9748 的"99% 置信"结构由（a）非运动边 K 静止 → 条件边际退化（单类质量 0.9975）与（b）运动边 Q/K 时间持续性（(o,sz) 主导项持续）共同构成，两者都是运动边 XOR 构造的直接体现。**不是数据巧合。**

**I6b 独立边假设的分布检验（新测，`/tmp/d1_runs_distribution_20260818.py`）**：runs 均值与逐边型 Bernoulli 模型"吻合"（T=5：1.7797≡1.7797）是线性代数恒等（E[runs]=1+Σ(1−p_e) 对任意相关性成立），**无检验力**；真正的检验是 runs 分布。实测显著拒绝独立假设：T=5 组 P(runs=1)=0.544 vs 乘积模型 0.384（1.42×），P(runs=5)=0.0029 vs 0.00008（37.8×）；T=4 同向（P(runs=1) 1.05×、P(runs=4) 12.9×）。**eq 边正相关聚类（静止段整体延续）**——方向对硬件有利（全组广播更常见），但均值账（1.780/5）由线性性固定，不受影响。

## 3. T=4/T=5 双窗敏感度账 `[模型]`（裁决：0.95+ 区间不成立，需重定价）

**关键结构发现（per-edge 视角）**：9 条时间边的实测 eq 呈两簇——**within-pair 边（5 条）eq≈0.975**（0.9715–0.9808），**cross-window 边（4 条）eq≈0.63**（0.5935–0.6846，≈ 同位置随机配对水平 0.697）。T=5 组内 8 条边 = 4 within + 4 cross → 混合 eq 0.805；T=4 组内 7 条边 = 5 within + 2 cross → 混合 eq 0.879。边覆盖从 T=2 的 55.6% 增至 88.9%（T=5）确实成立，但新增边主要是 eq 弱的 cross-window 边，且 T=5 丢失了 eq 最强的 (4,5) within-pair 边（组边界）——**覆盖 +33pt 与 eq −17pt 的对冲是本账的核心发现**。

**独立边模型验证（I6b）**：均值公式 `E[runs] = 1 + Σ(1−p_e)` 对任意相关性成立（线性恒等），模型结构正确，错的只是把 0.979 当成所有边的 eq。分布检验拒绝独立假设但方向有利（见 §2）：eq 边正相关聚类，全组广播（runs=1）实测 0.544 显著高于独立模型 0.384。

## 5. 弱点与补救（防自杀式投稿裁决）

**D1 主张的两处真实弱点（诚实列明）**：
1. **窗口级位账依赖单点 0.979**：T=5/T=4 组内 eq（0.805/0.879）远低于 0.95，广播节省实测 61.5–64.4% 而非合同声明的 73–78%。审稿人若拿实测窗口级 eq 反驳 0.979 锚点，现合同数字站不住。
2. **cross-window 边 eq 接近随机水平**（0.63 ≈ 同位置 Σp² 0.697）：T>2 新增的时间边信息量低于"8/9 覆盖"的字面暗示；S3 窗口级 eq（0.522）已无额外时间结构。

**补救（写作与位账层，均纯 CPU 可先行）**：
1. **位账重定价**：把 I6 账改为逐边型模型 `E[runs]=1+Σ(1−p_e)`，p_within=0.975 / p_cross=0.635（实测、独立边模型已逐位验证）→ T=5 节省 64.4%、T=4 节省 61.5%（全组 64.6%）。删除/改写"−78.3%"与"~73% 量级"两处承诺。
2. **主张重心转移**：从"eq=0.979 的高广播率"改为"eq 率任意下机制无损 + 实测 61–65% 门流量节省（pair 级 eq 0.975 构造性、运动强度单调梯度 0.993→0.463 是机制证据）"。
3. **验证实验 3 进正文**：三个数字（运动边 eq 0.904 / 非运动边 0.998 / Bernoulli 0.581）是"eq 是构造属性非数据巧合"的直接裁决，比 0.979 锚点更强、更不可反驳。
4. **T=4 与 T=5 的取舍按实测重写**：T=5 边覆盖 +33pt 但 eq −17pt、节省仅 +2.9pt（64.4 vs 61.5）——合同"T=5 优于 T=4"仍成立但优势收窄；写作按"覆盖优先（88.9% 时间边）而非 eq 优先"定位。

**不受影响的部分**（可放心引用）：I1/I2/I5 恒等（规范融合式、槽位分解唯一、商可逆）不涉及数据 eq；P(s_t==s_{t+1}|eq)=1 构造恒等与 eq 率无关；运动边驱动的 pair 级 eq（0.975）与强度梯度是新增的、更强的实证资产。
