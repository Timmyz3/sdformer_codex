# R30 固定机器的离散混合精度配额

`mixed_quota.py` 沿用冻结 R27 主机器：16 输出路、128 binary reduction 路、16 普通 gate-add/int8 reduction 路；既有 SRAM、输入/输出端口、双权重槽、DMA 和流水假设均未改变。它穷举 full/crop 所有整数配额变化断点，在 native 与 strong Q8 两个基线、PE arithmetic 与 PE reserved 两个口径上，均要求扣除原 10% 目标后能容下同一份 **36,529,550.59 tick** 规划预留。再检查原 8% 算子服务目标。预留是 native PE arithmetic 的 1%，不是已实现预测器的成本，也不是新的质量准入门。

相对更紧 native 分母，10% 门后剩余 arithmetic 39,490,402.10、reserved 36,905,914.30 tick。扣除规划预留后，较紧 reserved 仅剩 **376,363.71 tick**；后续真实预测、排序、位图生成、模式改变、物理资源与数值修正费用都必须重新核验，不能把此小余量宣传成已兑现净收益。不存在本轮质量结果参与参数选择。

新增费用逐仿射算子独列：两个精度域扫描的地址分类、每行保守位图读取、bit-packed 输入行暂存读写、真实横向 9 点输出 span 的 scatter DMA 启动、每个矩阵 job 的模式设置。完整输出写回、scale/int→FP32、producer mean、全 78 current BN、PSN、attention、卷积和未改公共服务仍由原模型付费。位图和地址计数器占既有 stats RF 中显式保留的 2 KiB，已检查与最大 BN carry 共存；暂存复用既有有限 I/O 槽，不增设免费整图缓冲。所有 8 个权重平面仍需读取，尾 Q8 不允许宣称 off-chip 权重流量自动下降。

这些数是**未校准资源模型的算子服务相加**，不是已验证整网拓扑执行轨迹、芯片周期或实测加速比。聚合端口模型尚未证明真实 bank 地址冲突；binary/普通路径面积频率归一化尚无 DC 校准。按 low/high 域打包执行后，producer 融合 BN mean 的 FP32 累加顺序尚未对齐 GPU canonical 顺序；若必须 canonical 重排或另一次 BN pass，必须追加费用。GPU 的整数逐字节一致性不能证明此硬件 BN 调度数值等价。普通基线也应享有同样的合法流水与融合机会。

`QUOTA_CPU_CHECKS_V1.json` 六项独立地址/整数检查通过：逐像素完整/尾/恢复分区、FC 成对一致、实际 job 总和、全部断点最大性、生产 `mask_contract.validate` 与固定训练 SHA 选择接口、暂存端口下界。`IMPLEMENTATION_CPU_REPLAY_V1.json` 是六项作者测试的独立重放，含真实原始 MLP/残差块六次微前向及 backward；没有整网推理、训练任务或 GPU。初版 `candidate_v1/` 保留为未封存草稿，其算术单口径候选不是最终运行契约。

可复算：`python mixed_quota.py --output-dir <新空目录>`；`python -m unittest test_mixed_quota.py` 读取本目录最终原件。固定的普通混合模式恢复还不是光流信息贡献；只有实际质量、同信息强普通对照与含评分器的净硬件账同时成立，才有理由继续主故事。
