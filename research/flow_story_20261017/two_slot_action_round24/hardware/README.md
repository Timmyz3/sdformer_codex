目标两次原生 currentBN 始终遍历23040000元素：FC1产生全部代表→展开完整网格→全图均值/方差屏障→完整归一化输出→回采代表→PSN2/FC2→再次展开和原生全域BN→残差。账含完整输入池化、代表存储、每个完整Z三次读取、完整BN输出、gather/repeat/残差及描述符事务。未选11MLP、attention/conv/decoder及另外76个currentBN保留；没有套旧串行BN分母或失败的weightedBN节省。

固定H1没有方向评分，枚举诊断也没有部署评分头；这不表示未来选择器免费。相对原生无评分路径，T2/singleton分别只剩153154632/139357664tick的局部附加服务盈亏空间。任何实际损伤预测器、普通同信息评分、排序及缓冲必须另计，并允许双方共享生产者和同精度算术机会。物理bank地址/冲突、系数寄存器端口、FP算术顺序与模型数值的一致性、面积/时序/功耗及完整网络调度均未闭合，所以这些是条件性服务tick，不是RTL测得周期或实际增速。

十二MLP原始FC MAC均相同，因此T2至多取消5.25%、singleton至多取消4.8125%的十二MLP FC MAC；包含其他PE工作的整网分母尚未闭合，这一单层动作不能证明整网10%门。它的用途是建立可用的粗/细动作，后续主贡献仍须证明真实光流损伤信息比强通用评分更适合分配整块预算。只改两槽表示精度最多是辅助贡献。实际122执行及质量门通过前，本表不能作为合格部署收益。
