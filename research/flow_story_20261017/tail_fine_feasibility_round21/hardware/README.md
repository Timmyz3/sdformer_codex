# R21 保尾加一个完整细块：服务义务与有限出口

这是一轮动作域存在性筛查。R20 的 F12/T8 都未过完整精度门；此次仅把固定八个真尾块保持 fine，并枚举十二个完整块中恰一个 fine。任何 H8 帧零个可行 singleton 就停止这个 T8+k1 selector 族，不用更强头、提高 k 或尾块子集网格回避失败。即使每帧都有可行点，也只说明值得考虑有限的新身份标签采集；GT oracle 不是算法成绩，H8 已暴露开发集不能称独立确认。

[tail_fine_service.py](tail_fine_service.py) 只调用已冻 R20/R19 有限资源模型，不改历史源或数值 primitive。[TAIL_FINE_SERVICE_V1.json](TAIL_FINE_SERVICE_V1.json) 对十二位置逐像素独立重建覆盖并检查有限容量、端口和阶段屏障：每点408个空间代表、每 FC4080行、全十二MLP每FC550080行。完整 T10/C、两个完整域 BN 的23,040,000元素、展开、BN1回采、pool/pack、残差及外部事务全部保留。三个固定锚点无评分头/在线selector，但部署费用绝不能沿用零；当前 u 在目标 MLP 前，只能决定该 MLP，不能取消已经完成的 attention。

T8+k1 相对 native/no-score 的条件性局部服务少161,049,154 tick（59.970705%），外部事务少390,517,968 B。附加 predictor 服务不能吃尽这161,049,154 tick，只是局部必要条件，不是可用预算或净硬件胜负。全十二MLP原 FC MAC 分母中取消比例只有5.5%，尚未包含其他 PE 工作，所以单层仍不足证明10%净整网门。资源沿原模型：2 MiB activation含统计保留区、512 KiB权重、16个32-bit1RW bank、8×32 PE、串行64 B/tick外部总线；目标峰值1,605,632 B。FP归约顺序、详细bank地址/系数RF端口、旁路面积和完整网络trace未闭合，表中不是综合后或实际GPU的延迟。

内部 TVLSI/TCAS-II 复审支持这一次有限筛查，其目的仍是确认光流损伤信息有没有可分配的动作空间；归一化实现与固定保尾本身不是 flow-specific 创新。只有可行动作存在后，才值得公平核算低分辨率 q/残差/邻接头与同信息普通头，所有方法享有相同 FP32/producer融合机会，不以旧FP64串行普通评分器人为压低对照。独立数据/协议代理只读本脚本并以真实原模块 FC/BN几何复核5.5%分母，未发现新增阻断；没有重跑模型或读取本轮质量。
