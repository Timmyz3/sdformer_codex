# R26：完整网格的位平面工作量与实现义务

本表只证明明确整数图的工作量及可取消对象，不给芯片周期、面积、能耗或整网加速结论。源为冻结的 `implementation/bitplane_linear.py`（759eaa69…）、`run_precision.py`（66ce0f8f…）；[可复算计数器](bitplane_counter_plan.py)和[原始 JSON](BITPLANE_COUNTER_PLAN_V1.json)另钉原生模型源。实际执行与质量由两个独立审计方另行闭合，不能用本表替代。

目标是 s2b2 的 FC1/FC2：每个 FC 都保留 T10、B1、30×40 的 **12,000 行**，通道分别384→1536和1536→384；其余11个 MLP 不变。12个完整9×9 tile有9,720行，8个真实尾 tile有2,280行。Q6/Q4仅完整 tile 丢弃Q8权重的低2/4位；二补码符号位系数为−128，负数采用算术右移再左移，不加中点修正、也不把−128重新裁回−127。这是特定嵌套截断图，不能代表所有6/4位PTQ或QAT。

| 单次目标调用 | Q8 位串行 | Q6，尾部Q8 | Q4，尾部Q8 |
| --- | ---: | ---: | ---: |
| 每FC实际整数平面调用 | 8 | 8 | 8 |
| 每FC row×planes | 96,000 | 76,560 | 57,120 |
| 两FC二值平面乘积项 | 113,246,208,000 | 90,313,850,880 | 67,381,493,760 |
| 相对同一目标Q8引擎的平面工作取消 | 0 | 20.25% | 40.5% |
| 若十二MLP均由同构Q8引擎执行，单目标占其FC平面取消比例 | 0 | 1.6875% | 3.375% |

最后一行的分母只有十二MLP FC、且明确是假想统一Q8机器；它不是实际混合FP32/整数图的周期，更不是整网分母。此次软件其余11个MLP仍为FP32。将动作推广到所有层时，各层真实尾块比例不同，必须重算，不能把20.25%或40.5%原样套到全网。整网可比工作量另作只读范围核查；10月10日288×384 first-cut粗账不作为当前完整480×640图的精确分母。

固定42次实验独立计数为：8个原生目标调用、8个整数Q8 reference、26个位串行调用；每FC的位串行 row×planes合计 **1,990,560**。全十二MLP逻辑行数仍每FC **23,436,000**；原Linear实际hook行数为 **23,028,000**，差额是34次目标被新模块替换，不能把模块替换记成空间行删除。模型内有432次整数算子调用，另有4次明确预算的真实形状后端检查，后者不是模型前向。全78 BN调用3,276次，共59,402,488,320输入元素。保存42个预测archive的314个数组，加独立量化archive的4个源数组。

可落地的候选模块是：位平面权重存储与完整tile/尾块行调度器，驱动二值乘积或AND/popcount归约；逐平面按带符号系数累积到int32，全部平面累积完后按输出通道只做一次FP32缩放，再接原current-BN/PSN。源模型两个FC均无bias。精度信息在该FC开始前必须可得；它不能取消更早attention、PSN或未选MLP的服务。普通与光流评分器必须共享相同执行器和同一净预算；当前固定布局没有运行时预测器，也没有算法信息贡献。

以下服务仍须付费：全T二值输入生成及必要格式转换；full/tail行地址、gather和scatter；整数部分和归约与存储；完整输出23,040,000元素的int32→FP32及缩放；两处全域current-BN和其屏障、PSN、残差与所有空间输出。单次目标两FC的int32输出合计92.16MB，输入u为18.432MB，不能假设小SRAM免费保留。FP32舍入、PE吞吐、SRAM容量/端口、权重复用、流水和附加控制未建成周期模型，不能把乘积项或PyTorch壁钟直接换算为芯片速度。

权重方面，两FC共有1,179,648个权重，原FP32占4,718,592B，Q8为1,179,648B；理想紧凑1-bit平面共1,179,648B只是候选物理布局。实际软件8个平面以int8承载，共9,437,184B，另外保留q8、转置q8、原FP32模块及7,680B尺度，不是1-bit SRAM实测。尾块仍使用所有8平面，故不能自动宣称整组权重off-chip读取或存储量下降；是否仅减少PE和局部权重读取要由真实调度证明。

独立CPU证据为765个带符号单权重精度恒等式、8,232个三项二值点积、真实QuantLinear反例/精度/行数测试，以及原MSMLP执行编排测试。[CPU与源码独审](../independent_execution_audit/INDEPENDENT_CPU_REVIEW_V1.json)并未把这些测试说成芯片实现。实际审计还固定13,300个原数组整数dot抽验，不新增模型前向；这也不是全矩阵独立重演。

在TVLSI/TCAS-II内部设计审视下，此轮只建立一个可能容纳后续动态计算分配的动作底座。需先过原生质量保护门，再证明同图整网PE净余量与真实预测器成本；合法的单MLP整数实现本身不足以支持长期算法投入或论文主贡献。后续总账必须包含patch/conv/decoder等共同工作。没有新的RTL/DC结果；历史k1选择器综合不能转称本位串行引擎的PPA。
