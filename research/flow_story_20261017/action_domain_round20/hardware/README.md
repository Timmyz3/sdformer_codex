# R20 固定动作域：无评分、完整域 BN 的局部服务账

这是实际 R20 结果读取前的条件性硬件账。F12/T8 使用不同预算，只诊断完整块与真尾的恢复范围，不作同成本算法胜负。模型继承 R19 最终 V3 的有限资源、算术延迟和阻塞调度；只在新函数的私有 globals 中替换真实 cell 覆盖函数，未改旧模块、源文件、数值 primitive 或冻结结果。

[domain_service.py](domain_service.py) 支持任意合法 4×5 布尔 mask；[DOMAIN_SERVICE_V1.json](DOMAIN_SERVICE_V1.json) 固定报告 native、FF、CC、F12、T8。[CPU_CHECKS_V1.json](CPU_CHECKS_V1.json) 的五项检查覆盖二十组随机 mask 的独立像素覆盖、固定锚点行数、非法 mask、历史函数身份保持、完整域 BN 与沿用的依赖/容量/端口检查。独立数据/协议代理已只读源和测试，未发现新增阻断；未代为复跑或读取 R20 质量。

真实 H30×W40/T10/C384 包含十二个完整 9×9 块与八个真尾块：完整区972像素/108粗代表，尾区228像素/32粗代表。所有表项都保留全部 T/C、两个完整域 native current BN、FC 展开和 BN1 回采；每次目标 BN 仍处理 23,040,000 个元素。其他十一 MLP 和54外部 BN没有取消。

相对 **native/no-score**，F12 条件性局部服务减少 **30,924,552 tick（11.515535%）**，但外部事务反增 **183,199,552 B**；增加的存储服务已在上述总 tick 中收费。T8 条件性局部服务减少 **176,764,452 tick（65.822692%）**、外部事务减少459,541,056 B。FF 的包装反增11,819,100 tick且不省 PE。这些不是实测速度或精度通过条件，F12/T8 的百分比更不能横向当算法效率优劣。

所有锚点都是预定固定 mask，因此评分与在线 selector 费用为零；真实 mask 对应的 cell descriptors、pooling、pack、读写和执行费用仍计。若未来加运行时预测器，F12/T8 上述净少 tick 仅是附加服务**不吃尽局部收益的必要上限**，不是可免费使用的训练或硬件预算，也不是10%整网门。原生全图域之外的共同工作分母尚未闭合。按最窄的十二 MLP FC MAC 分母，F12/T8 单层取消份额也仅为1.361111%/6.000000%。

资源为2 MiB activation（含128 KiB统计/元数据）、512 KiB weight、16个32-bit 1RW activation bank、32个weight bank、64 B/tick串行外部总线、8×32 FP32 PE。每批保留八空间点全部T，局部峰值1,605,632 B；pool算术和本地读写串行、逐task总端口时隙下界检查。详细系数RF端口、物理bank地址、FP归约顺序/数值与全部数据通路RTL/DC未闭合。整个数值图可能对微小算术差异敏感，所以不能把这些日程视为通过GPU精度门的实现。更换权重驻留次序或融合后必须重建两侧账，当前日程也不是最优实现主张。

内部 TVLSI/TCAS-II 审查结论：这份表仅为固定动作域筛查提供成本约束。若只有近全fine的点精度可用，廉价且公平的预测器实现是必要条件，但不能承诺解决动作可行性；若固定保尾已经足够，应先接受普通布局解释。单层、局部条件模型和公共selector组件不足以形成投稿贡献。
