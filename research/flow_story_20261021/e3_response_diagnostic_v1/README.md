## 实际数学与数据来源

全部计算使用float64：`e=f_Q4−GT`、`δ_a=f_a−f_Q4`、`u=e/max(||e||,1e−12)`。本16身份有效支持中没有精确零背景误差像素。norm为全GT上平均二维响应长度；full signed为全GT上平均`uᵀδ`。

4×4将480×640分成16个120×160格。在每格GT有效支持上，**分别**计算`u`均值和`δ`均值，再以`Nc/N`加权内积；没有先算逐像素内积再池化来假装压缩。1×1沿用完全相同定义。空支持格保留零权重，不删除身份；格均值方向不重新单位化。支持数、方向均值、六动作响应均值、全部分数、动作排序、regret均在`action_diagnostics`，可供独立重算。

活动控制固定选择全图macro footprint内`nonzero_voxel_bins`最大者，低ID tie；从原voxel与冻结tile重新计算并核对旧raw字段，选择没有使用GT mask或`valid_GT_*`字段。它不是强学习基线，弱活动规则失败不代表普通直接收益预测会失败。

16个身份/8个序列不是96个独立场景。主结果是解释性、带真实GT和反事实的理想标签诊断，不是泛化实验。尤其norm与signed之间增加了真实GT方向信息，因此不能把两者差别描述成同信息可部署算法的胜利。下一步仍必须让普通直接head获得相同合法前缀、任务标签和辅助监督。
