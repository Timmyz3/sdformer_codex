# AT-LIF 推理身份：二电平发放与阈值折权

2026-09-11，按用户最新明确更正。本页取代研究记录中将 AT-LIF 发放出口解释成“逐事件连续幅值、必须保留独立幅度 MAC”的前提；历史实验记录保留原样。

## 当前合同

AT-LIF 输出为 **z = θg，g∈{0,1}，即 {0,θ} 二电平**。θ可以是训练得到的实数参数，推理时固定；它不意味着每次非零发放都有独立变化的连续幅值。

下一层为线性/卷积时：

`y = W(θg) + b = W' g + b，W' = θW`。

若阈值按输入通道给出，则 `W'[:,c,...] = W[:,c,...] × θ[c]`。当前实现的 `thresh` 是逐模块标量。折权后发放接口可以只传一位 g；θ的数值贡献保留在有效权重中。卷积/FC可用位图、NRV、事件索引及条件权重累加，**无需仅为 AT-LIF 非零幅值设置逐事件幅度乘法器**。

直接消费 z 的其他路径各自保持原函数；涉及非线性或量化舍入时，在实际部署边界核对折权结果。此处不是把 θ丢掉或强设为1，也不自动改变现有量化权重和已测数值。

源码依据：`SDformer/neuron_experiments/H9_bipolar_self_attention/overlay/models/STSwinNet_SNN/atlif_ternary_psn/atlif_ternary_psn.py` 中 `OfficialATLIFSurrogate.forward` 计算 `out = (input >= thre).float()`，返回 `out * thre`。阈值更新属于训练流程。

## 对当前硬件工作的直接影响

- **Prosperity / GustavSNN / LoAS / ExSpike 的发放支持、跳零及共享机制保留直接适配资格。** 折后的真实 W'、完整先验实现与同资源对照仍须入账；先前具体融合布局的负结果不因本更正变为正结果。
- **取消“AT-LIF 幅值不能折权，所以必须 HBG 实值双轨/幅度 MAC”的贡献前提。** 任意逐事件 int8 p 是另一种模型合同，不能代替当前 θg。
- **PSN 发放前的连续时间混合、原始残差 I、连续 PED 支路仍需自己的数值通路。** lifting40 与连续投影研究的执行对象是这些计算及其门输出，不是为二电平发放保留任意幅度载荷。
- Motion-XOR 的二值支持叶按实际注意力算式评估；θ可折权不等于所有打分/归一化项都能删除。
- 当前 Stage B 已捕获两个学生的真实 θ，整数 helper 已有 `U_conv2_theta`。本更正主要纠正叙事与候选前提，不修改 checkpoint、已有 AEE 或服务数值。
