# C1 / C2 完整迁移与替换合同

状态：2026-09-07 研究合同。不是生产重构完成声明。用户已授权继续推进；当前未向主硬件树移入新 RTL。

## 共同的数值和完成边界

- ATLIF 数值保留为 `z = theta * g`。冻结 theta 为逐模块连续值标量；诊断中逐通道非单位有理数是更一般的算术压力，不是 checkpoint 的参数测量。
- 固定 theta/W 身份下，允许在线性段讨论 `phi = theta * W`。不得把这解释成 theta=1，也不得推出每事件任意 int8 幅值。
- 支持位/有理数等式不证明冻结 FP32 的归约顺序等价。当前没有新 AEE、Acc24 准入或数值卷积闭环。
- 原目的、符号、权重身份、完整 T 和真实下游消费者都必须保存。计数已登记的零贡献也要完成退休，不能因权重跳过而让最后成员永远不到达。
- 只能对同工作负载、同预算、同数值合同的完整执行时间线比较性能；检测、预处理、布局、缓存、尾块、排空、反压和回退成本全部进入。

## C1：Prosperity 必须迁移的完整链

`完整算子几何 / 源排列 -> 全 M/N/K 分块 -> 检测与剪枝 -> 依赖及顺序生成 -> 权重供数 -> 每 K 分区的父值构造/读写 -> 原目的跨 K psum -> 排空与提交`

现有 m935 已有三阶段匹配、active/next 元数据、预取、两个返回槽、1RW 仲裁/前递/死写抑制、原子提交与反压。它不是只有父行公式。研究中的局部加法计数省略了部分流水、加载和存储行为，不能用来代表整个旧 C1。

本轮完整外层参考恢复一个真实算子 M=3000、K=6912、N=768；官方 `run_fc` 的外层不改，内部子集回调仅做经核对的等价加速。两份官方仓库都为 commit `6ee1c6f1cb419fcf942f2eda63db84ca28248f4b`。公开工件没有被本轮找到可直接移入的完整 ASIC RTL；论文所述结构与模型中的理想化条件须区分。

物理迁移仍缺：官方时间交错顺序到捕获输入的布局成本、尾块完整64行开销、真实父缓存端口、SRAM宏、真实累加位宽和逐周期有限重叠。保留官方外层模型，另建明确修订的协议模型；不能静默修补并继续叫原版。

### Phi 根构造替换的接口否决点

候选只替换无合法父行的根构造，其余 Prosperity 边不动。必须迁移 Phi 的模式校准、PWP 构建/存放/加载、L1/L2 执行和同步，不能只接一个模式查表。

当前尚不成立：Phi 的跨 K 累加产物不能直接充当 Prosperity 每 K 父结果。`K0: B<-A`、`K1: A<-B` 两个各自无环的局部图，会在把依赖提升成完整行完成依赖后形成循环。若逐 K 返回，就必须重做并收费 PWP 分 bank、L1/L2 完成和跨 K 提交边界。独立概念评分仅5–6/10，暂不生产化。

## C2：完整 LoAS / FTP 路径中替换归约

`真实 FC1 -> BN1 -> 满秩 T=10 PSN / ATLIF -> 完整T源打包 -> 源/权重身份关联 -> bank请求与返回 -> 归约 -> 持久实值Y -> 当前域BN2 -> 各原位置真实shortcut相加 -> 原顺序提交`

LoAS 的完整时间展开、稀疏压缩/关联、供数与归约必须一起考虑，不能用只有一次时间读取的弱基线；同样纳入 LoAS 伪和/修正、直接 FTP、RSR/RSR++，分别标出模型能够复现的范围。H67 的 BN/PSN 保持自己的语义，不能直接换成原文普通 LIF。

已有共享和叶的状态：D8 字典、单源在途、多时间消费者确认后回收，三配置功能测试通过；实际持久 Y 在 C++ 消费者中，当前域 BN2 与真实残差尚未 RTL 闭环。单源状态机不能代表 K8 吞吐。

### 每 bank 一种模式：已做机会筛查，未做 RTL

1. 在预声明的校准位置上，每 bank 只选一个完整10位模式；按固定规则冻结，后续位置不再调参。
2. 打包时为各位置生成八个成员次数。选中源仍按通道布局供数，在 bank 局部寄存器求和；其他源直接送 FTP。
3. 最后一个成员的原返回位置发送共享和。没有逐类改排、字典驱逐或额外尾部共享和排空；这只是拟议协议约束，尚未证明物理无气泡。
4. 若权重关联层抑制选中成员，必须输出零贡献退休或从已关联集合计数；不能只把它消失掉。

当前筛查选用 `channel % 8`，匹配 m803 通道拆分接口的合法性规则。**捕获包自身按 source_group_id / row地址选 bank，不是该布局。** 因而结果只能叫“选择 m803 通道拆分布局后的算术机会”，不能声称已经保持捕获包原地址、带宽或请求节拍。

额外显式状态：stage0 每位置48位计数，stage3每位置72位计数；每层80位模式，以及八个活动输出瓦片宽度的部分和。计数生成/读端口、对齐、宽值操作数、同时间多bank输出仲裁、BN2等待期Y均未获免费实现假设。

### 晋级条件

- 原始权重身份到新布局的双射可核对；所有请求、响应、零贡献退休和原目的完成对应。
- 直接路径与候选同一几何、T、累加范围、资源、源布局、返回延迟和持久Y约束。
- 0/1成员、全失配、热点bank、相消为零、消费者反压、尾块和复位都正确；额外状态和模式校准计费。
- 整层运行时间以及能量有净优势，不能只看加法数；关掉候选的强基线也要收费其本来就需要的逻辑。
- 先验检查仍包括 LoAS、RSR/RSR++、SumMerge、相关共享归约；GustavSNN/Comperity 的全文访问缺口未解决，不能据此作排他性新颖声明。

## 停止的整行等价类版本

同一完整源向量只算/存一次Y，再按次数做BN，是有明确先验的组合。计入完整源键、每位置索引、每类次数后，所测stage0只省2.9235%状态，stage3增加12.2875%；还没有计哈希和端口。当前显式字典版本停止，不扩大到所有代表指针布局。

这三类状态必须分开：完整链是迁移目标；现有共享和叶是功能原型；每 bank 模式和 Phi 根构造是待证的替换候选。任何一项都没有被认定为 TCAS-II 强接收结论。
