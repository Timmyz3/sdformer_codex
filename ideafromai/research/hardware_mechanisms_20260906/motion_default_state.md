# 第二方向：运动残差网络中的动态默认状态与实值例外

状态：需要另训练、另评 AEE 的硬件共设候选。独立概念判断为 6/10；不是冻结 ep34 的无损替换，也未进入生产 RTL。把它作为第二研究方向，不与晚知分界包拼成一个多岛贡献。

## 为什么从裁剪改成表示

一面被正确预测运动的墙可以产生很多事件，但当前新增信息很少。单纯根据粗运动裁剪 token 已有直接先验：[Motion-aware Event Suppression，2026，§III、IV-H](https://arxiv.org/html/2602.23204v1)。按预期误差改善决定迭代次数也已有 [DFlow，AAAI 2024](https://arxiv.org/abs/2312.07180)。新的问题应收窄为：**已解释位置仍有连续值状态，且全域归一化能同时改变这些状态，怎样避免把共同变化展开成逐位置工作？**

拟议网络以旧窗口已完成的运动预测对齐当前事件，构造带符号实值残差；当前低分辨率全覆盖分支更新运动，包含新暴露区域与新生目标，成本必须计入。输入是固定物理时间格的事件表示，不能因窗口归一化比例改变制造假残差。最终仍输出稠密光流。这个新函数需要重新训练；已有 ep34 的 AEE 不跟随它。

## 可审阅的数据路径

每层以 `X[p,t,c] = b[t,c] + E[p,t,c]` 表示。没有例外条目的位置等于当前默认值 b；它可以为非零实值。表中存实值差，不限制为正数或 1-bit。

```mermaid
flowchart LR
  A[因果运动预测与当前事件] --> R[带符号运动残差]
  R --> L[默认状态与实值例外]
  L --> M[按默认位置数与例外求完整统计]
  M --> N[更新当前默认状态与例外]
  N --> P[完整 T 的 PSN 与阈值幅值]
  P --> O[默认修正加局部修正加粗流]
```

每个通道的统计必须包含所有位置；若每个 t 有 N_t 个位置：

`sum(X) = Σ_t N_t*b_t + Σ_(p,t in Ω) E_pt`

`sum(X²) = Σ_t N_t*b_t² + Σ_(p,t in Ω) (2*b_t*E_pt + E_pt²)`

得到当前域 μ、σ 后，BN 的默认值是 `γ*(b_t-μ)/sqrt(var+eps)+β`，修正是 `γ*E_pt/sqrt(var+eps)`。需要全域统计屏障，不能按活跃位置数作分母。满秩 PSN 对默认 T 轨迹算一次，对例外位置的完整 T 轨迹分别计算；时间并集上的缺项仍有默认值。

ATLIF 始终按 `z = θ*g`。若默认轨迹的发放为 g0、默认幅值为 θ0，则输出默认值 `θ0*g0`，某位置的例外值为 `θp*gp - θ0*g0`。输出 gate 全部为 1 时，θ 不同仍然需要实值例外。冻结 ep34 的逐模块 θ 可作为特例；**本方向不要求先把阈值改成逐位置参数**。若另模型确有逐位置阈值，应单独保留其修正；修正密化时允许退化为完整实值表示。

第一份执行合同应限制在 residual Conv/MLP—BN—PSN—ATLIF 链。零填充边界不能套内部位置同一个卷积默认值，需边界类别或真实例外；ConvTranspose 的相位也必须计入。Swin 的相对位置、掩码、门控及分母尚不能免费继承该表示，先保留显式接口。输入例外不足以证明经过多层后仍少，必须计卷积邻域扩张、时间并集和实值索引开销。

## 与强先验的关系

- [Graham 等，CVPR 2018，§3](https://arxiv.org/pdf/1711.10275) 已描述非零 ground state 与共享计算。默认状态本身不是本工作的创新。其 §4 的 active-site BN 不能代替此处全域统计；须另立“同函数、全域 BN 的 ground-state 执行”强对照，不能只比较一个忽略缺席位置的弱实现。
- [MotionDeltaCNN，ICCV 2023](https://arxiv.org/html/2210.09887v2) 已用对齐和增量传播减少视频计算；[EVA²，ISCA 2018](https://capra.cs.cornell.edu/pubs/eva2-isca2018.pdf) 已用运动补偿预测激活。新网络要证明不保留每层旧宽特征、而传播本次默认状态与残差的价值。
- TID/EDC 是运动残差的来源，不能把“残差”二字再算首创：[IDNet](https://arxiv.org/html/2211.13726v4)、[EDCFlow](https://arxiv.org/html/2506.03512v1)。

剩余待证明的贡献是：**因果运动残差、当前域完整统计及阈值幅值变化共同作用时，是否能保持有用的默认状态并减少宽状态服务。** 这比裁剪控制器更具体，但仍是中等新颖余量，不是稳录用结论。

## 必须保留的反例

1. 周期纹理的错误位移也可产生零残差；小残差不是正确光流证书，低分辨全覆盖分支不能省掉。
2. 亚像素插值、零填充边界和不同通道的错位活动会使例外增长；不能只展示整数平移的理想墙面。
3. 默认发放可以从 0 变为 θ，也可以从 θ 变为 0。若执行器把缺席位置当零，数值立即错误。

本次新增 [exact 示例](sim/check_default_state.py) 检查带符号例外的完整统计、满秩时间混合、θ 幅值，以及上述必须失效的简化。这是有理数表示验证，不是 DSEC 机会、部署精度或 RTL 收益。
