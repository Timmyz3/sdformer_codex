# ATLIF 晚知分界的编码与确认接口

状态：研究原型合同。新颖性来自待论证的执行问题，代码完成度不替代创新性。θ 是发放后的连续值幅值；τ 是前级数值经过 BN 与满秩 PSN 后换算的等效决策分界，二者不同。

## 本次实际实现的范围

已有构想：宽中间值出现时，最终全域归一化统计尚未知。保存候选发放位、少量边界残差及可验证范围，统计到达后才确认；失败项回放。此次把它落实为三个有限宽模块：encoder 输出压缩记录并释放本地上下文，verifier 之后读入记录与最终分界，group collector 处理完整 T 的确认与恢复事务。不会让一个编码包堵住整个 BN 域的产生。

输入一个固定 B 项的包。每项提供有符号 W 位区间 `[u_lo,u_hi]`，真实决策量 U 必须在其中；预测分界为 W 位有符号数。最终分界同样提供区间。上游若尚不能证明这些包含关系，就不能引用本电路作为原浮点网络等价证明。

正方向的判决是 `U >= τ`；负方向为 `U <= τ`。模块将负方向的区间变换为 `[-u_hi,-u_lo]`，使用 **W+1 位**，避免最小负数取反溢出。γ=0 是独立常量消费者，应由上游直接产生 `0` 或 `θ`，本模块不生成 BN 参数。

## 编码

每包固定预测分界，候选位取 `u_lo >= predicted_tau`（规范化方向后）。按区间到预测点的距离保留 K 项：点在区间内则距离为零；否则为到最近端点的距离。同距离优先更早的位置。K 是有限容量，默认 B=32、K=4、W=32。

其余候选 0 项记录最大上界 `a=max(u_hi)`，候选 1 项记录最小下界 `b=min(u_lo)`。某类为空由显式 valid 标志表示。被 K 集合逐出的项立即进入对应极值，不能直接丢弃。候选位和 K 位置保持原顺序。

## 确认

最终规范化分界 `[τ_lo,τ_hi]` 到达，首先核对 context、epoch 和区间合法性。仅当 `a < τ_lo` 与 `τ_hi <= b`（忽略空类）同时成立时，所有未保留项确定不变。每个保留项必须满足下列之一：

- `u_lo >= τ_hi`：确定发放；
- `u_hi < τ_lo`：确定不发放；
- 否则仍不确定，申请回放。

仅当整个包所有项都已确定，verifier 才返回包级确认。输出包含 B 个已确认发放标志以及 **原样 θ 幅值字段**。保留项的区间与分界相交时，不能强行按中点比较。θ 字段不参与此处比较，零位的下游数值为零，一位的下游数值为该 θ；其浮点或定点编码由上下文定义。

端点错误、context/epoch 不匹配返回 ERROR；合法但证据不足返回 REPLAY；完整确认返回包级 COMMIT。ERROR/REPLAY 的输出位必须为零。packet 存储须保持记录完整性；结构检查不代替存储 ECC 或全记录防篡改。

**包级确认不能直接送入 FC2。** 本次另实现 `atlif_threshold_group_commit`：同空间包、同 h 的全部 T 个结果按时间顺序收集，context 低四位为 t、其余位为组身份，epoch 与 θ 字段也必须相等。全部通过才暴露一个完整 T 组；任何包失败则整组保留，发送一次完整 T 恢复请求。外部恢复返回完整组的实际结果，并核对组身份、epoch、θ 后，才允许一次下游提交。内部已通过的时间步不会提前消费，因此完整 T 重算不会重复累加。

group 模块实现请求、等待、结果确认与提交，**没有实现恢复的 FC1/PSN 算术**。仿真明确以独立的稠密比较器提供恢复结果；现实中需接沿用强对照并已计成本的恢复执行器。它不把失败比例冒充免费恢复。

`replay_mask` 只是哪些时间包触发失败的原因位图，**不是允许只计算这些时间步的掩码**。恢复响应必须包含完整 T×B 位；满秩 PSN 的输入也必须来自完整 T。

## 协议和存储

encoder：`start_valid/ready` 接收 context、epoch、θ、方向、预测分界；随后 `in_valid/ready` 接收恰好 B 项；完成后 `packet_valid/ready` 输出记录。packet 被接受后才能接受下一个 start。背压期间所有有效输出保持不变。

verifier：一次握手接收 packet、最终分界与匹配身份；输出为固定记录的包级 COMMIT/REPLAY/ERROR，背压时稳定。group collector 之后才是消费者边界；没有对下游先发预测位再回滚的路径。reset 取消未确认工作，外部须重新提交被取消事务。

记录从低位开始依次为：B 位候选值；`a` 与 `b` 各 W+1 位；两位有效标志；K 个条目（lo、hi 各 W+1 位，index=`ceil(log2 B)` 位，valid 一位）；context 32 位、epoch 16 位、θ 32 位、方向一位、error 一位。B 至少 2；K 可为 0 或至 B。

总有效位数为 `B + 2*(W+1) + 2 + K*(2*(W+1)+ceil(log2 B)+1) + 82`。默认是 **470 位**，四个 128-bit 记录字为 512 位。与完整 W=32 的 32 个单值相比仅是裸记录大小；不包括全域源保留、端口、目录、工作寄存器、回放和首遍 PSN，不能当净存储或能量倍率。

encoder 的 K 项距离寄存器另外各 W+2 位，只在建包时使用，不进入持久记录；group 暂存 T×B 位、T 位失败掩码及身份/状态。示意 stage0 若 19200 个空间位置、T10、H384 都保存默认 B32 记录，则有 2,304,000 包，裸位数折合 135.36 MB，128-bit 对齐为 147.456 MB，尚未含上述额外状态。此前点值包的存储数字不适用于这个更保守的双端点接口。

有限宽区间是新增的安全接口，不是声称新的区间数学。单点区间可表达显式整数/定点消费者；原 FP32 网络如何生成可信区间仍是实质未闭项。正式对照必须同时包括融合保存、完整重算、已有 K 点值包，并分别收取编码、确认、传输和恢复成本。
