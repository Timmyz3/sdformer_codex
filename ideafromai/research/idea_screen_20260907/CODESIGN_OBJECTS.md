# 协同对象拼装（仍不选赢家）

调研结论，不是施工图。TCAS-II 只能讲 **一个对象的两面**。下面 8 个对象是 32 张卡的合法拼法：算法面改动能被同一电路吃掉。Codex 按测量合同做，不要八条一起开 RTL。

**关键新测量（本轮，ep35 路径 100×12，非 ep34）：**  
`T1_T4_ep35.json`

- token 级仍需打分叶 **43.9%** → 理想 token 跳过 56.1%
- **15×15 窗 OR dirty = 90.1%**，整窗干净只有 **9.9%**
- S1 窗干净 51%；**S3 窗干净 0%**
- dirty 以 K 单边为主（34%），不是 Q

因此：**B2 不能当 Shiftmax 整行 memo 来卖**；最多当 token ALU/能量门。这是 T1 在 ep35 上的 fail-closed 预演。ep34 仍要重测。

历史注意力信封 ~0.59% **从未在 ep34 上重测**（Grok46 T0 空着）。算法一换，信封会变。没有 T0，不能决定「注意力岛能不能当短文电路面」。

---

## 对象怎么用

每个对象给 Codex 的是：两面各一句、先验、已有证据、缺哪一测、反对。  
用户要求先筛全再套：这些对象是**并行测量包**，不是淘汰后的第一名。

---

### O1 — Motion-XOR 分数叶（电路面最像「我们改了算法所以有这个电路」）

| 面 | 内容 |
|---|---|
| 算法 | 冻结公式 `round_even(128*(overlap + same_zero/64 + motion_xor/4)/32)`，`attn=gate⊙K`。可选：α 可学，但 α-XNOR 已有共静默。 |
| 电路 | `h67_motionxor_score_q7.sv` 已存在：三 popcount + K_peer。对照 FireFly-T 只有 AND-PopCount。 |
| 拼进的卡 | B1 + B9 + B10 + C4（保持 z=θg） |
| 已有 | RTL 源码；ep35 三项均值 overlap 0.013 / motion 1.53 / same_zero 30.6 |
| 缺 | **ep34 T0 份额**；ep34 同口径 QK 普查；叶 vs AND-PopCount 同资源周期 |
| 反对 | T0 若 <2%，这是叶论文，摘要不能写系统加速。 |

### O2 — Token 级跳过（挂在 O1 上，不是第二条标题）

| 面 | 内容 |
|---|---|
| 算法 | 无损：K=0 或 Q/K 相对 t0 不变则跳叶。不要训「近似 skip」除非 AEE 过门。 |
| 电路 | 同一 MX3P 叶的 enable；K_peer 影子。 |
| 卡 | B2 + B3 |
| 已有 | token skip 56%；K 双 T 零 56%；**窗级 skip 仅 9.9%** |
| 缺 | Shiftmax **行**与 token 的对应（T1 ep34）；dirty 时三项是否仍能部分跳（T2） |
| 反对 | 把 56% token skip 写成 97% 分数相等/整窗跳过，会被打假。S3 窗干净=0。 |

### O3 — 脉冲 QK 换核（算法面，电路变简单或变 O1 的消融）

| 面 | 内容 |
|---|---|
| 算法 | stage2 一块：Motion-XOR vs 公开 SDSA vs QKFormer 线性 Q-K（NeurIPS’24，无 V/softmax）。从 ep34 微调。 |
| 电路 | 更简单的 AND-pop / 线性 QK 引擎，或证明 Motion-XOR 项不可少。 |
| 卡 | B4 + E1 + E2（E3/B5/B8 为后继插件） |
| 已有 | 无 AEE；只有结构可行性 |
| 缺 | 10 帧 AEE；换核后 T0 会不会把注意力份额做大 |
| 反对 | AEE 回到 ~1.58 则相对 ep34 失败（1.259 门）。QKFormer 是分类网络，不是光流。 |

### O4 — 混合 T 的 FC 执行（大份额电路面）

| 面 | 内容 |
|---|---|
| 算法 | 发放仍是 {0,θ}；可把 T=2 注意力纤维和 T=10 神经元纤维分开打包。 |
| 电路 | LoAS FTP/inner-join 当强对照；A6 有界时间共享和当候选；不要把 FTP 当标题。 |
| 卡 | A6 + D1 + D2 + C1 |
| 已有 | 8 槽相对 FTP 加法 −20.8%/−42.2%；A6 RTL 功能过；LoAS 官方无完整 ASIC RTL |
| 缺 | 持久 Y + 同资源周期（加法减量不是加速比） |
| 反对 | 审稿：这是 LoAS/RSR 换马甲。必须写出混合 T=2/10 与均匀 T=4 的差别。 |

### O5 — 权重行广播 TSBG（数字最大，创新最弱）

| 面 | 内容 |
|---|---|
| 算法 | 可选：训成更多同行复用。 |
| 电路 | B8 同行广播。ep34 CPU 序列化 **3.89×**、权重字节 −80%。 |
| 卡 | A4 |
| 已有 | ep34 同 I/O CPU premodel，checkpoint `4bbaf7fc` |
| 缺 | 同资源 RTL/VCS |
| 反对 | Gustavson/Eyeriss/TSBG 家族；用户已判过「没创新」。新合同允许重测数字，**不自动恢复标题资格**。 |

### O6 — 乘积林 + 可选 ep34-PAFT（大份额卷积）

| 面 | 内容 |
|---|---|
| 算法 | 默认无损林；PAFT 必须在 **ep34** 重训（旧 ep4 AEE≈1.47 过不了 1.259）。 |
| 电路 | Prosperity 完整链。本地官方外层 product/bit **2.33×**，mem stall≈0 → 换双口几乎无用。 |
| 卡 | A1 + A2 + A3 |
| 反对 | 就是 Prosperity。A2 +1.58% 不必重做。 |

### O7 — 神经元岛：膜留下、对外 1-bit + 晚知 BN 包

| 面 | 内容 |
|---|---|
| 算法 | 推理合同已是 z=θg；不要 Grok Bot int8 载荷。 |
| 电路 | C3 覆盖 + A8 确认包。 |
| 卡 | C1 + A8 + C4 |
| 已有 | A8 五配置功能过；C3 已有 DC/PT 史料 |
| 缺 | 真实 BN 区间恢复率 |
| 反对 | 「first mixed-T」不成立。 |

### O8 — 解码 ConvTranspose 岛

| 面 | 内容 |
|---|---|
| 算法 | 无，或轻量化转置零 |
| 电路 | 新岛。历史份额大（约 22% 信封，未在 ep34 闭合） |
| 卡 | D3 |
| 缺 | 完整 decoder Table-A |
| 反对 | 没有表就不能进系统摘要。 |

## 没有 T0 时，调研怎么读这 8 个对象

```
T0 注意力叶份额  未测（ep34）
        │
        ├─ 若 ≥ ~2% 且换核后更大 → O1 可以当电路面；O2 只能当能量/消融；O3 是算法面
        └─ 若仍 ~0.6%           → 电路面应在 O4/O5/O6（Conv/FC）；
                                  O1 最多当叶/完整性；O3 换核若能抬份额再回头
```

这是 **测量依赖**，不是选赢家。
