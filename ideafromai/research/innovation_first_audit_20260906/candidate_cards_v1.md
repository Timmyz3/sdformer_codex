# 新机制候选卡 v1：供独立反查，非投稿结论

2026-09-06。只有 TCAS-II。没有新增 RTL、PPA、AEE 或周期结果。下述数学例子不是 ep34 工作负载测量。评审应分别给新意 N、冻结语义适配 F、实现 H、短文主机制潜力 T（0–10），并列出最可能拒稿的理由；不以作者自评分引导。

## V1：C1 在线虚拟双源基

**改变什么：** 原 C1 的父节点必须是一条真实输入行；这里在当前二值激活 tile 内产生并不存在的双源基，一个输出可取多个基。64×16 的掩码加载时累计 120 个源对共现次数，选至多四对源端点不相交的源对。双源同时出现的行消费基，其他行消费原源；按边覆盖确保每个原始乘积恰好出现一次。

例：原输出为 `(a+b+c+d, a+b+e+f, c+d+e+f, a+c+e)`，构造 `u=a+b, v=c+d, w=e+f` 后变为 `(u+v,u+w,v+w,a+c+e)`。四条原行互不包含；普通二输入向量加法由 11 次变成 8 次。相对真实父行的区别明确，**相对通用公共表达式消除并不新**。

**最强先验：** [Prosperity HPCA 2025](https://arxiv.org/html/2503.03379v1) 主动舍弃非真实行交集；[SumMerge ICS 2021](https://cwfletcher.github.io/content/research/2021.ics.summerge.paper.pdf) 已生成递归虚拟交集 DAG；[RSR++](https://arxiv.org/html/2411.06360v3) 已递归分发部分和，不能只用完整签名相同的简化版；[Comperity TACO 2026](https://doi.org/10.1145/3828526) 已有邻行共享基与差分，出版商全文当前未取得，这是重大先验缺口。

**电路待证之处：** 120×7 bit 共现计数、最多四轮选择、16 源编码器、基生成及生命周期。四个 96-lane、9-bit 双 INT8 基裸载荷 432 B；若用既有 12-bit 接口则 576 B。原 96 lane 已并行，规划周期不可除以 96。一个共现 m 次的源对相对原始求和至多省 m−1 次向量加法，必须再扣掉最强父行算法已有收益、生成/存取基/选择开销。

**判断门：** 与 strongest-zero 单父、固定源配对、完整 RSR++ 和 SumMerge 离线图比较。若只改善算术而控制时间变差，或只在直接 bit-skip 上好看，即淘汰。潜在贡献只能是可在激活变化时及时完成且净划算的受限在线图构造电路。

## V2：C2 二值源统计先行，省去动态 BN 的隐层统计遍历

**真实问题：** `sn1→FC1→动态 BN1→sn2→FC2→动态 BN2`。ep34 的 BN 统计跨当前 T×B×H×W；不是训练后静态系数。传统路径必须先生成所有 FC1 输出，才能确定 BN1 系数。若保存隐层，需要宽张量写读；若不保存，第二遍必须重算 FC1。

设输入二值指示矩阵为 `S[N,C]`，有效静态权重为 `W[C,H]`，ATLIF 源阈值吸收进 W，`Y=SW`。当前输入的统计为

`k=Sᵀ1, G=SᵀS; sum(Y[:,h])=w_hᵀk; sum(Y[:,h]²)=w_hᵀG w_h`。

**v1 收窄执行：** 二值源计数 k/G → 通道统计与 BN 系数 → 重放二值源，正常 FC1→BN1→完整 T×T PSN→二值输出。只产生一次完整 FC1 数值，不物化全域 FC1 隐层。无需依赖阈值早停才能成立。是否保存/重读源位图、何时重放，全部计费。

**v2 可选扩展：** 系数确定后，对完整 T 组输出做阈值区间判定，只计算未决项。这是独立增量，不能把理想跳过率混进 v1 收益。

**最近先验与差异：** [Analytic Variance Propagation](https://arxiv.org/html/1803.10560v1) 已给协方差传播恒等式，不能称新数学。[BNFF，MLSys 2019](https://mlsys.org/Conferences/2019/doc/2019/18.pdf) 融合前层与统计、后层与归一化，但仍完整产生前层。仓库 `analyze_m480_dynamic_bn_materialization_elision.py` 已消除归一化张量写读，明确保留原始 BN 输入存储与回放；必须作为强对照。[OPN，TCAS-II 2024](https://doi.org/10.1109/TCSII.2024.3354738) 的出版记录已核，采样近似的完整原文仍有访问缺口，不能把它按普通精确 BN 基线处理。

**机制增量：** 将动态 BN 的统计对象从大量隐层标量换成可跨 H 个输出通道复用的二值源共发放计数，以改变第一遍实际计算和宽张量存活需求。不是把已有归一化融合改名。

**必须支付的成本：** C(C+1)/2 个至多 ceil(log2(N+1)) bit 计数器；密集位图 AND-popcount 与稀疏外积更新两种产生方式的真实吞吐/冲突；O(C²H) 的宽统计收缩。不能把非对角共发放项置零。不能免费预存所有 `w_i*w_j`，否则权重表由 CH 增至 C²H；可重用普通权重分块产生乘积，但要计执行。较大 C、较小 N 可能直接失败。

**算术合同：** 实数恒等式不等于冻结 cuDNN/TF32 的逐位复现。第一阶段可定义严格整数 `Acc24 → sum/sumsq` 的组件合同，与直接枚举每个 Y 的同一整数参考精确比较；部署量化另作 AEE，不偷用 ep34。Acc24 不缩位，sum/sumsq 累加必须按 N 扩宽。保留浮点身份的版本则要给统计误差区间和原路径回退，不能仅凭有限样本零错准入。

**强对照：** 同 SRAM/带宽的“完整 FC1+输出统计融合+保存原始隐层”和“完整 FC1+统计融合+丢弃隐层+输入重放重算”二者取优，再加本仓归一化与消费者融合。只比较朴素三遍 BN 会形成弱基线。

**判断门：** 先核 ep34 完整 BN 域 N/C、每行活跃数及其平方和、源位图字节、现有统计遍历代价。将第一遍统计服务单独闭环，随后才决定扩大为整段 FC1/BN/PSN 电路。当前没有实测速度、面积或能量。

**本轮只读元数据跟进：** 已核已有 S40 `layers.json` 的 SHA256，并逐层检查形状乘积与 token 数一致。FC1 的 N/C 从 stage0 到 stage3 分别为 2000、250、31.25、3.90625；每层一次调用的 Gram 计数裸载荷为 10476、37056、129360、442944 B，二次型收缩项数约为 1.79M、14.23M、113.54M、907.15M。它们是公式推导的容量和项数，**不是时间、面积或能耗**。据此将初始候选进一步收窄到浅层两个 FC1。原捕获只授权源载荷分析，不授权硬件或模型位等价声明；详见 `records/v2_existing_geometry.json`。没有从全网发放率推断共发放率。

**最小可审阅电路边界：** 第一阶段可以只比较统计子图：共同输入为完整同一 BN 域的二值源和同一 INT8 权重，共同输出为 count、sum、sumsq；基线为正常 FC1 接直接矩统计，候选为 k/G 接二次型收缩。归一化系数和消费者不是免费性能结果。对于无偏置、二值源、C≤768 的 INT8 FC1，数学点积界不会达到 Acc24 溢出，但仍保留 Acc24 接口。均值是否使用 N、方差是否使用总体方差，以及平方和的宽度必须一致；禁止以饱和中间结果套用未饱和恒等式。之后才能扩大为整个 FC1→BN1→sn2 的同资源数据流比较。

## V3：由二值消费者证书驱动动态 BN 逐步精化

**原始失败版：** 输入变化小就沿用某 token 的旧二值输出。动态 BN 会被其他 token 改变，局部输入不变不足以证明输出不变；DeltaCNN 的静态可融合 BN 不能直接解决。

**重构版：** 为当前 pre-BN 元素保留保守区间，维护全域均值/方差区间，经 BN 与完整 PSN 得到输出位的上下界。已经确定的二值消费者提交；不确定者触发部分完整 T 组 FC1 计算，收紧局部区间及全域统计，再唤醒未决消费者。若所有输出位都被证明，统计仍可为区间，无需展开全部数值。最坏情况完整原路径回退。

**潜在电路贡献：** 某 token 的精化会通过全局统计收紧，解锁其他未执行 token。调度“局部难判消费者”和“统计不确定性最大贡献者”是两个不同的选择目标；分轮批处理才可能抑制全域重扫。

**先验：** [DeltaCNN CVPR 2022](https://arxiv.org/html/2203.03996v2)、[Mixture-of-Rookies 作者原文](https://www.ac.upc.edu/app/research-reports/html/RR/2021/7.pdf)、[CNN-Cert AAAI 2019](https://arxiv.org/abs/1811.12395) 分别已有差分复用、算前零输出预测、保守界传播；不可重新声明它们的基本原理。差别必须是动态全域统计依赖下的正确提交与精化执行。

**致命代价：** 大图方差区间可能极松；锚点与上下界远大于一位输出；每次收紧全域重扫；FP/TF32 与不同 GEMM 形状的舍入包络；跨帧锚点版本。不得把 `E2−μ²` 换算成原 BN 的逐位等价结果。

**判断门：** 对比精确统计理想上限、一次区间检查、逐步精化和完整原路径；计实际 FC1 派发、精化轮数、锚点字节、证明读取与回退。若先算完 FC1 才能建立有效证书，就只能称 PSN 叶优化。

## V4：共享投影的阈值区间执行（另建模型身份）

将一组 m 个隐藏通道的完整 FC1 权重向量绑定为同一投影，保留各通道 BN γ/β。共有当前输入统计和完整 PSN 后，各位是同一标量跨不同阈值的判定；编译可达位模式对应的 FC2 权重和，运行时区间选择后直接消费聚合向量。

这不是冻结 ep34 即插即用机制：只有完整 FC1 行确实相同且 PSN 参数满足共享合同才可无损套用；普通 INT8 码重复不够。制造这种结构需要新训练/部署与 AEE 对照，本轮仅研究，未启动。

[Neuron Merging NeurIPS 2020](https://papers.nips.cc/paper/2020/file/0678ca2eae02d542cc931e81b74de122-Paper.pdf) 已合并相似完整滤波器并处理 BN，[LUT-NN MobiCom 2023](https://www.microsoft.com/en-us/research/wp-content/uploads/2023/09/LUT_NN_2023-3.pdf) 已学习中心并查表。潜在差别是保留多个不同阈值、编译受约束的可达模式与下层数值，不是普通神经元合并。

最坏每组 T(m+1) 个区间表项，并受 2^m 个位模式上限约束；各 t 的阈值排序不同，不能免费只算 m+1 项。m 个 INT8 权重和至少需 8+ceil(log2 m) 位。负 γ、零 γ、相等阈值边界必须编译。低发放下普通稀疏 FC2 可能更省。

强对照必须使用同一个共享投影模型，执行“共同 FC1 + 独立阈值 + 原稀疏 FC2”，分开模型结构收益与区间执行电路增量。
