# 原生 ep34：Prosperity迁移、Gustav供数和一次实际融合

2026-09-20。**本轮已经写并运行四份RTL：普通AAC/G4、Gustav式GP、ProSparsity父图执行、GP×G4融合。** 不是只列idea；也还不是完整原论文复现、完整网络或ASIC结果。

最重要的两个发现：Prosperity迁入原生ep34仍有很强的复用，旧融合负结果不能否掉这个底座；减少加法和减少权重取得是不同轴，实际融合能有净周期收益，但窄输出、冷表、父状态会改变排名。

用户逐项审阅入口：[详细数据流、算例、周期拆解与修改建议](TECHNICAL_WALKTHROUGH.md)。该页补充指出：当前PR即使免掉全部构图/排序/mask，仍比AAC慢82.8%；父计划缓存应当作对照补全，不能单独指望它翻盘。

## 2. 真实RTL共同筛选

输入为原生ep34 S0 block0、S2六块，sample0/10；每域八个均匀空间P8和两个输出H8，共**224个真实切片＋8个诊断切片**。每次覆盖完整C96或C384、80=T10×P8行、8个输出通道。

权重取真实checkpoint W×θ，逐输出通道round-even Q8。这是明示的新整数函数；没有借用FP32的AEE或宣称网络无损。各RTL输出与NumPy矩阵乘和独立C++标量计算一致。

共用1笔128bit源服务、1笔128bit系数服务、8条Acc24算术路径、真实Y存取和192bit输出。**专属表、源缓存、父RAM、比较器不同，尚不构成等面积/等频率证明。** 额外容量与访问见各实现说明。G4/GP4在C384/H8上需要15KiB子集表。

表中是`stream`实测：每套权重连续服务八个**不同**空间源块，真实计入首块构表和所有源配置；没有把所有块假定成warm。供数受限日历为源3/4、系数2/3、输出4/7可用，属于可复现压力点，非实测系统拥塞。

|---|---:|---:|---:|---:|
| 普通AAC，位跳过＋II1系数流水 | 961,270 | 基线 | 1,370,836 | 基线 |
| GP：Gustav式P8/NRV/局部累加 | 917,684 | 少4.53% | 961,860 | 少29.83% |

包含实际配置以后，AAC/GP/G4/GP×G4/PR正常供数为1,019,510 / 975,924 / 880,050 / 836,808 / 2,352,422拍；受限供数为1,429,076 / 1,020,100 / 1,219,940 / 920,418 / 2,509,146拍。全部原始CSV见下方。

**融合相对每个供数点最强的GP/G4单独端点，只多省5.26%和10.36%。** 这才是本轮融合增量，不能只展示相对AAC的19%/37%。因此它进入性能候选，尚不足以宣称标题新颖性或强接收。

冷启动没有隐藏：每个P8块都换W并重建表时，GP×G4正常供数反而慢15.95%，受限供数只少0.34%。完整层必须证明表驻留和源复播账，不能直接套warm结果。

## 3. 机制收益、代价分别在哪里

- **GP**：W读从781,826降至301,556次；有效贡献加法仍是781,826拍。它解决取权重和供数等待，不能叫乘积数减少。
- **G4**：运行时子集累加594,366次；stream另有36,000拍构表加法、38,400次表写。表项80bit，原W行64bit；共同总线事务和有效载荷字节分别看。
- **GP×G4**：stream系数读334,334次，少于G4的603,966，但高于GP；加法与G4相同。真实收益来自算术合并和请求共享同时发生，不是两个倍率相乘。四路组合构包的时序/面积尚未综合。
- **PR**：root/delta的W读降至357,284，但还有284,220次跨K合并、195,448次父读、284,220次父写；构图/排序/mask共537,008拍。Y共302,140读和302,140写。这是可测的待改接口。

PR负点**只说明这份M80/N8分阶段组织很贵**。它未具备官方N128的构图摊销，也未重叠matcher/执行；不能把它作为最终最强Prosperity并宣布击败原作。下一步先补跨输出通道的父图复用，再比较局部归约/残差供数。旧R8上零或onehot占93.565%的结论也不能直接移用到本次原生ep34。

## 4. 验证与后续

统一`run.sh`完成**6,960个任务、4,454,400个整数输出零差**，包括冷表、跨任务表失效、源重载、真实连续不同源块、C切换、−128/+127权重、空/全一/边界模式及输出背压保持。Verilator版本4.028。独立审阅发现普通AAC输出只能II2，已给所有方案相同II1输出后重测；没有保留弱分母。

这仍是**Verilator组件仿真**，无VCS/DC/PT/Formality、无频率/PPA、无BN/完整PSN/FC2/shortcut、无新AEE。生产nts07及main.tex未改。本轮不跑训练。
