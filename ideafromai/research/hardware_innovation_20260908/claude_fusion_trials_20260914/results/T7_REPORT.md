# T7：ConvReflex 式静态锁深调度 vs 运行时证书（L3）

## 照抄对象

ConvReflex（SenSys 26）：编译期捷径——离线分析出必被 clamp 的卷积、运行时直接跳过。
套用到 C1 门路 = 离线标定每 (p,h) 组的静态供数深度 d[(p,h)]，运行时按表供数、免区间
证书逻辑（硬件省掉 10×10 乘加 + 48bit 比较的单拍组合链）。

## 设计

- 每层固定同一 (p,h) 采样集（G=20000，seed 20260915），s0 标定 / s10 测试（跨序列
  泛化 = 部署场景）；口径与 T5 一致（U 侧 thr、BF 形态、FX 基线 24 拍/组）；
- 误 fire = j*_test < d（静态深度不足、未锁）；诚实计费带回退（误 fire 组继续供到
  平面 0：cycles = 1+e）。

## 结果

| 形态 | stage0 拍比 | stage3 拍比 | 误 fire |
|---|---:|---:|---:|
| 运行时证书（T5 基准） | 0.1739 | 0.1761 | 0 |
| 全局静态（MINT 式 q50/q75/q100） | 0.32 / 0.43 / 0.59 | 0.34 / 0.48 / 0.64 | 36–96% |
| 逐组静态表 pad0 | 0.351 | 0.370 | 37–38% |
| 逐组静态表 pad2（最优） | 0.301 | 0.310 | 11–13% |
| 逐组静态表 pad5 | 0.385 | 0.386 | 2% |

逐组 j* 跨序列差：均值 ≈ 0（无系统性偏移），**标准差 2.30–2.42 平面**，P(|Δ|≤1)=57%，
P(|Δ|≤2)=75–77%。

## 判读

1. **静态锁深杀**：即使逐组静态表（比 MINT 式全局常数信息多得多），换序列后
   37–38% 组供数不足；加深 2 平面后误 fire 仍 11–13%、拍比只到 30–31%（运行时
   证书 17.4%）。原因：j* 由该组瞬时的 margin 分布决定，跨序列波动 σ≈2.3 平面
   ——**锁深是样本性质，不是位置/通道性质**。
2. **运行时证书的必要性获得定量证据**（写作弹药）：离线 profiling 无论全局还是
   逐组都无法捕获锁深；这直接回答"为什么不学 MINT/ConvReflex 用静态预算"——
   静态预算在本负载上界是 30%+，运行时精确终止是 17.4%，差距 13pp 以上。
3. 次级发现：j* 跨序列均值无偏（±0.03 平面）——波动是零均值噪声而非分布漂移，
   与 T6 的"thr 平移不缩 margin"结论互洽。
4. 边界：数值试验；仅 s0→s10 单向泛化（反向由对称性 + 均值无偏推断）；tau 用
   各 trace 终态矩；仅门路。

**结论：ConvReflex 式静态捷径在 C1 负载上杀；运行时区间证书不可被静态表替代
（17.4% vs 最优静态 30%）。**
