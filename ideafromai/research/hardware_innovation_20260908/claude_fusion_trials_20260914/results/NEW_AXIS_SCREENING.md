## D. 净值：六轴的最终判读

**N1 杀（T30+T31）/ N2 杀（§E 结构论证）/ N3 杀（拓扑）/ N4 杀（依赖 N1）/
N6 只作引用（带宽轴，不改供数）/ N5 唯一存活**——而 N5 的形态被**双重收窄**：
T32 限定为**结构型**（幅度型经 BN 尺度吸收后供数零收益）、T33 限定为**标量**（行间分配形状无头寸）。
⇒ N5 现存可达前沿 = T20–T22 的标量稀疏度 Pareto（k=4 推荐）。

> **这构成本论文最强的完备性论证**：C1 的机制空间在 bit 级三轴（operand 序 / 终止信息 /
> 数据组织）+ 第四轴（供数粒度）+ 五个更大尺度（跨层 / 时域 / 多消费者 / 仲裁 / 接口）上
> **逐条以定量或拓扑原因关闭**，唯一存活的是**训练侧结构稀疏旋钮**（= 已实测 k 掩码
> Pareto 的加强版）。这与两条判负定理（无可更紧精确界、MSB-first 唯一最优）合起来，
> 把"设计空间完备性"做成论文的一个正面贡献，而非审稿人问一句答一句。

## E. 判负记录：N2 时域 —— 结构论证（为何整条时域轴被关闭）

挖掘代理给出 8 张时域卡（SkipSNN/SEENN/STAS/SpikON/ExSpike/SparseTem/FluxShard/Sparsity
Ceiling），旗舰是"膜电位先验收紧起始区间"。**它们全部属于"数据侧冗余"类机制**，与 C1
证书的信息结构**不相交**：

1. **C1 证书的不确定性 = "还没传到的比特"，不是数据本身的不确定性。**
   Y（fc1 输出）与 A_q 在生产者侧都是**精确已知的整数**；消费者区间
   `Vmin=(Vtop<<j)+N_t·(2^j−1)`、`Vmax=…+P_t·(2^j−1)` 里的 `(2^j−1)` 正是**未读低位**的
   可达上界（T27 已证该可达集就是全盒，即**界已对该信息集紧**）。因此任何"用 t−1 状态
   预测 t"的机制**无法减少消费者需要的比特**——可减少比特的只有三条路，全已关闭：
   (i) 改 Y/A 本身 → **训练侧（N5）**；(ii) 改比特数 → 编码/压缩，**只省带宽不改供数**
   （EBPC 卡 6）；(iii) 改组内联合锁定结构 → **T29 粒度轴已扫**，且逐 lane 头寸的
   **oracle 上限仅 +7.07%**（T28，且需元数据）。
2. **跨帧/跨 t 的"整组复用"要求 Y 精确相等**：Y = S·W，S 是该组感受野内**全 C 宽**的输入
   脉冲模式，其精确复现概率随 C 指数衰减（脉冲率 ~5%，C 达数百）。近似复用即放弃
   **零差证书**（C1 的核心卖点）→ 不成立。
3. **膜电位先验在拓扑上不存在**：本边被认证的量是 `V=Y·A`（A 为 T×T 时间混合），
   Y=S·W 由输入脉冲直接给出（输入即已知），**没有可作先验的递推膜状态进入被认证量**；
   组内 10 个 lane 恰是 T=10 个时间步，已由组级证书**联合**处理，无法再逐 t 省。
4. **粒度税（第 4 次）**：即使逐 t 有信息优势，组级共享（10 判决等最慢 unit）也会吃掉
   ——与 T19/T28 同因。
5. **名义门本就不足**：代理建议门 = 17%→13.6%（相对 −20%）> oracle 上限 +7% − 元数据，
   结构性不可达。

**保留引用价值**：①SEENN/SkipSNN/STAS 全是 learned/approximate 的时间维早退，
**无任何 exact-bound 的神经元级时间维终止** → 这是 C1 在 related work 里的一个干净差分点；
②Sparsity Ceiling（单作者 arXiv，未评审）只作"递推状态不能过度稀疏"的动机引用；
③EBPC 的 SystemVerilog 变长流拼接器是可抄资产（带宽轴）。

## G. 第七轴（新开）：数量维 —— "算多少个组/块/时间步"

§D 的六轴全部是**同一尺度**上的机制（"每组多少位"及其变体），T27/T28/T31/T32/T33 已把
该尺度在 operand 序 / 终止信息 / 数据组织 / 供数粒度 / 跨层 / 幅度-结构 / 分配形状
七个方向逐条关闭。**bit 级尺度内已无可开之坑。**

⇒ 唯一未开的尺度是**数量维**：不是"每组多少位"，而是**要算多少个组 / 多少块 / 多少时间步**。

| # | 方向 | 机制候选（挖掘代理回报） | 状态 |
|---|---|---|---|
| Q1 | **token 剪枝/合并** | ToMe（ICLR'23 Oral，arXiv:2210.09461，有码）/ AiluRus（NeurIPS'23）/ **Uncert**（arXiv:2605.09276，训练免费，SNN 版）/ TP-Spikformer（arXiv:2603.00527，事件域）；需重训：DynamicViT / A-ViT / EViT / SPViT | **供数侧弱（T34）；计算侧成立** |

| Q3 | **adaptive-T** | **SEENN**（NeurIPS'23，arXiv:2304.01230，有码）逐样本变 T | 需重训才公平（见下） |
| Q4 | **稀疏/局部注意力** | windowed/local attention | **判为 re-skin（代理自报）**：减的是交互数，且落在已关闭的数据复用/多消费者领地 |

### T34 关键定量：数量维在**供数**上是**次可加**的（`results/t34_group_supply_concentration.json`）

用真实 traces（4 层×10 序列×4000 组 = 40 万组）测逐组 plane 分布与供数集中度：

- **分布**：mean 2.938、median 3、max 16、std 2.10。
- **集中度**：top 20% 的组承载 **42.4%** 供数、top 50% 承载 77.8% —— **中等偏斜、远非高度集中**。
- **次可加性**（关键）：

| 剪掉的组 | 占组比例 | 省下的供数 | 代价比 |
|---|---|---|---|
| plane ≤ 1 | 26.6% | **6.10%** | 4.4 组 / 1% 供数 |
| plane ≤ 2 | 49.5% | **21.68%** | 2.3 组 / 1% 供数 |
| plane ≤ 3 | 66.6% | **39.09%** | 1.7 组 / 1% 供数 |

⇒ 剪掉**一半**的组只省 **21.7%** 供数；剪掉**四分之一**只省 **6.1%**。
**token 剪枝承诺的"按比例减供数"不成立**——因为 C1 的逐组证书本就把易组做得很便宜。
故数量维的真实收益轴是**数据通路周期**（少算多少个 dot10），**不是供数**；
论文中不得把它与 C1 的供数数字相加。

> **口径告诫（T34 副产品）**：`planes/组` 在近零组上会取**负值**（实测 min = −6，
> 7.9% 的组 ≤0）——`msb − j_star` 未设下界。相对比较（T32/T33）不受影响，
> 但**绝对供数聚合**须 `clip(planes, 0, None)` 后再求和，并与 T5/T19 的 RTL 实测口径区分开。

### Q3 adaptive-T：便宜探针存在但**不公平**，须重训才可结论

`configs/*.yml` 里 `num_steps: 10` 与 `num_frames: 10` 都是配置项 ⇒ 技术上可在
`num_steps ∈ {2,4,6,8,10}` 上直接评测现有 ep34 checkpoint（SEENN 式探针）。
**但**：本 checkpoint 是在 T=10 下训练的，截断 T 同时改变 (i) SNN 积分步数 与
(ii) 事件窗时长，两者都是分布漂移 ⇒ 截断评测**天然不公平**，负结果不可作为判负依据。
**要结论必须重训**（随机 T 分布，SEENN 式），这是一次真实训练投入，**优先级低于互补机制**。

> **重要限定**：数量维的收益**不是 C1 的机制收益**——它减少的是"被 C1 服务的对象数"，
> 与"每个对象花多少位"正交。若成立，它是**第二个机制**（可叠加），须与 C1 在论文里
> 分列，不得混算成一个供数数字。

## I. ★ 新机制候选（迁移路径产出）：支撑感知 lane 退役 SGLR（T38/T38b）

> **来源**：用户批评"分析判死不算数，要走照抄→根因→改进→实测"。按该路径重做 BitL 迁移后产出。
> 详见 [T38_MIGRATION.md](T38_MIGRATION.md)。

| 栏 | 内容 |
|---|---|
| **照抄对象** | **BitL**（MICRO'25）：组的周期数被"最密的元素"决定，靠行/列双向遍历 + 逐周期 pivot 逃逸 |
| **照抄结果** | **无对象**——BitL 的 pivot 杠杆是**权重位稀疏**；我方 A_q 稠密 10×10。dense 下 gating 收益实测 **0.00%** |
| **根因** | **选错了稀疏轴**（不是"组内临界路径不存在"）：真正被"最慢单元独吞"的是**未解析判决的支撑并集**，不是权重位 |
| **改进版** | **SGLR**：k 掩码后每判决只用 k 个 lane，判决逐个锁定 → 每平面只发"还没锁定的判决仍在用的 lane"。支撑集合是**部署常量**，退役判据消费者侧本地可算（它已在算 `jf`） |
| **改进实测** | **k=4：8,171,370 → 5,322,819 bits，省 34.86%**（2.043→1.331 planes/组）；dense 0.00%。`t38b` 断言 **PASS = 零差**（被省略 lane 对未解析判决权重恒 0） |

**为什么不是已关闭轴的重皮**：

| 已关闭轴 | 区别 |
|---|---|
| T28 逐 lane **静态尺度**（oracle +7.07%） | 那是每 lane 配自己的指数/尺度；SGLR 不改尺度，**按判决支撑整条退役 lane**，34.86% ≫ 7.07% |
| T29 **供数粒度**（每拍 g 平面） | 那是时间轴打包（周期/端口/bits 三元）；SGLR 只改**每平面发几条 lane** |
| T1B **逐判决证书**（须逐词归一化） | 那须把共享操作数重发 10×；SGLR 仍是**组级一次传输**，只退役无关 lane |
| **k 掩码**（T20–T22） | **互补**：k=4 给 −18.0% 供数 @ +1.0% AEE；**SGLR 在 k=4 之上再砍 34.86% 比特** |

**反馈成本三档（落地性的关键，`t38b`）**——退役事件仅 **0.79 次/组**（块对角支撑 **0.35**）：

| 反馈方案 | 代价 | 净效果 |
|---|---|---|
| per-lane ready（10 根控制线） | 0（控制线属端口/面积，非供数） | **净省 34.86%** |
| 事件编码（4bit lane-id × 0.79） | 3.16 bits/组 | **净省 19.4%** |
| 逐平面掩码（10bit × 0.79） | 7.9 bits/组 vs 省 7.1 | **净零**（第 7 次元数据税，这次是可算出的盈亏平衡边界） |

**变体 A（块对角支撑）**：收益 **−35.45%**（不降反升），事件减半，且 lane k 只被本块判决使用 ⇒
调度**可由"块完成"直接推导**。**代价**：top-k 自由度受限 → 供数 2.009→**1.074 planes/组**（AEE 代价待 GPU）。

② GPU 测块对角 k=4 的 AEE（定变体）；③ 与 T25/T26 面积口径合并。
