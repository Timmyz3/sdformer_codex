# T17：跨序列 trace 扩充验证——40 样本全量（2026-09-15）

> 脚本：`t17_more_traces.py`（自有解析：直接读 m1707 capture 的 fc_frames.bin，
> layer 8=stage0 block0 fc1、layer 28=stage3 block0 fc1）；数据：
> `results/t17_result.json`（80 trace）。capture 只读，未触碰生产树。

## 1. 动机

bn_state/T5 只用了 capture 的 s0/s10 两条序列（resources.json samples=[0,10]），
而 m1707 capture 实际含 **40 个样本**（每样本一条完整序列的 fc1 源帧流，
manifest population.samples=40）。拍比 17.3–17.7% 与 T16 解析模型此前只有
2 序列支撑——本试验补全序列轴广度，全部本地 CPU（无 DL 重跑）。

## 2. 口径与校验

- 与 `t5_c1_cert_core_model.py` 完全同口径：终态 tau（逐 trace 矩）、A_q f12、
  thr 48bit 方向折叠合同、组级 BFP + MSB-first 证书递推、G=20000 组/trace
  （seed=20260914+sid）；
- **解析器交叉校验**：sid=0 两阶段与 T16（t5_rtl/expected.npz 链）精确复现
  （17.55%/21.63% vs T16 17.5%/21.6%，同 seed 同采样）；
- 逐 trace 断言：证书判决 == 全深度整数判决（80×20000×10 判决），
  解析保守界 j_pred ≤ j_true 全成立。

## 3. 结果（80 trace = 40 序列 × 2 阶段，1.6M 组）

| 口径 | stage0（40 trace） | stage3（40 trace） | 全体 |
|---|---:|---:|---:|

| 解析保守界拍比 | 18.9–21.6% | 20.5–21.7% | 18.9–21.7% |
| ρ 边际 iid 预测 | 20.2–21.9% | 22.0–22.8% | 20.2–22.8% |

分布形状：序列间差异小（stage0 全距 2.4pp、stage3 全距 1.2pp），
无离群序列；均值 17.1% 略低于此前 2 序列口径的 17.4%（s0/s10 恰在
分布偏右尾）。E[planes]=3.04（1.6M 组池化），与 T5 的 3.2 一致。

## 4. 结论

**（1）拍比声明的序列轴闭合。** "BF+cert 供数 17.1%（15.2–17.7%）"
现在是 **40 DSEC capture 序列 × 2 阶段、1.6M 组、判决零差** 的部署级声明，
替代此前 2 序列口径——论文评估节可用全量数字。

**（2）T16 解析模型跨序列稳定。** 保守界拍比、ρ 边际 iid 预测、界松弛
（1.09–1.29 平面）在 40 序列上全距 <3pp——解析评估模型
（拍比 = f(ρ 分布, msb 分布)）不是 2 序列过拟合。

**（3）附带产出。** 80 trace 的 planes 直方图（`t17_result.json`）供 T18
推测+恢复支配论证使用（misfire(d) 曲线）。

诚实边界：40 样本同属一个 capture（同一 checkpoint、同一 DSEC 采集批）；
序列间独立性未验证（DSEC 场景可能有相似性）；tau 仍为逐 trace 终态矩
（T13a 已证 ck/dyn 判决差 0.46–1.04%，部署须 tau_ck）。
