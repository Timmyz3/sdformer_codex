# T8：AO-BFP/DMP-BFP 式离群感知按词打包（L2）

## 照抄对象

AO-BFP（DATE 26）/ DMP-BFP（ICCD 25）：运行时按指数/阈值做 BFP 精度调整、离群值
单独处理。套用到 C1：组级 BFP 共享指数 e 由组内最大 |Y| 决定，小幅度词在高位平面
全是冗余符号扩展位，占用 10-lane 供数口的空闲 lane。

## 设计

四 trace、T5 同口径（U 侧 thr、FX 基线 24 拍/组、20000 组/trace）：

1. **结构测量**：组内幅度谱（m1..m10 = |Y_s| MSB 降序）、供数平面 lane 利用率；
2. **打包 oracle**：同 j* 锁深下逐词实际需要 bit = max(MSB_s−j*, 0)，
   cycles = 1 + ceil(Σ/10)；
3. **优先级序运行时仿真（真实可达成）**：bit (s,ℓ) 优先级 = ℓ + w_s
   （w_s = max_t|A_q[t,s]| bit_length，静态），每 10 bit 一拍，拍尾异构深度区间
   锁定检查（Ytop_s init = −sign_s、j_s init = MSB_s；区间单调嵌套，全供数必锁）；
4. **元数据计费（同端口）**：逐词 MSB 边际熵（条件于 e）+ 符号 + 指数；
5. **静态 MSB 表替代**（T8b）：s0 标定 / s10 测试，assumed ≥ actual 时区间 sound
   （宽界延迟锁定）、assumed < actual = 溢出（头拍 flag + 回退全深）。

## 结果

| trace | 统一供数 | 打包 oracle | 优先级序（元数据免费口径） | 优先级序+元数据 | lane 利用率 |
|---|---:|---:|---:|---:|---:|
| s0_stage0 | 0.1755 | 0.1358 | **0.1232** | 0.3315 | 0.470 |
| s0_stage3 | 0.1740 | 0.1223 | **0.1122** | 0.3205 | 0.360 |
| s10_stage0 | 0.1729 | 0.1355 | **0.1236** | 0.3319 | 0.471 |
| s10_stage3 | 0.1766 | 0.1237 | **0.1135** | 0.3218 | 0.364 |

- 优先级序比 oracle 还好（按 A 加权影响排序优于统一平面序的均匀供数）；
- MSB 边际熵 2.69–3.23 bit/词 → 同端口元数据 = 10(符号)+5(指数)+~30(MSB) ≈ 45bit
  ≈ **+5 拍/组**，把 11–12% 变成 32%；
- T8b 静态表：逐词 MSB 跨序列差 std **2.96–3.53**（比 j* 的 2.3 更不稳——原始事件
  幅度比锁深更数据依赖），pad0 溢出率 96%、pad3 仍 50–70%；且逐 (p,h) 表存储
  = P×H×10×~4bit（stage0 ≈ 295Mb）不可行。

## 判读

1. **信息空间真实存在但不可及**：lane 利用率仅 36–47%，按词打包可再省 30%
   （17.4% → 11.2–12.4%），但逐词深度元数据的三条路径全死：
   传输（+5 拍，同端口计费 32%）> 收益；静态表（溢出 50–96% + 存储不可行）；
   自定界符号扩展位（每词多供 e−MSB_s 冗余位，总 bit 回到 10e）。
2. **证书形态的 1 拍头是结构性优势**：数据预算只有 ~3 拍/组，任何 ≥1 拍的元数据
   增量吃掉 ≥33% 预算——本项目第四次"元数据/粒度税"实例（前三：384 路求并、
   共享供数粒度、C3 连续分布）。AO-BFP/DMP-BFP 在 LLM 大激活上成立是因为其
   元数据摊在数千拍的计算上；门路消费者摊不动。
3. 优先级序仿真本身是方法论收获：异构深度区间证书（V ∈ [ΣA·(Ytop_s<<j_s) +
   Σ_{A<0}A·(2^{j_s}−1), 对称上界]）是 T5 统一区间的严格推广，若未来供数口
   有旁路元数据通道（非同端口），11–12% 可复活。
4. 边界：数值试验（非 RTL）；优先级序假设消费端可解析（静态 w_s + 已知 MSB）；
   仅门路。

**结论：离群感知打包杀（同端口口径 32% vs 统一 17.4%）；残留 30% 信息空间
列为"旁路元数据"条件性未来工作。**
