# 照抄实验工单（失败保留适配）

## Q1 — Zhang DLSS（先做）

- 输入：相邻两窗事件占用或 `preds.1`；阈值用校准集约 40–60% 跳过。
- 跳过时：decoder2 不执行，输出 = 粗流或上一窗流。
- 必付：动态 BN。对照包括「冻结 decoder2 BN 后仍全跑」。
- 记录：跳过率、AEE vs NB0、decoder 周期代理、假跳过（相似但 AEE 爆）。

## Q2 — C-STEP 块级早退（Q1 不够再做）

- 单元：2×2 tile 或 lane8，禁止整帧。
- 前 2 个时间 bin 的发放/占用 → 该 tile 是否算完剩余 T。
- 杀：并集后跳过率 <10% 或 AEE 差于随机跳过。

## Q3 — BitL 完整换向

- 对象：一块 Q2 或 Y24。
- 对照：纯行、纯列、Codex 5+5。
- 成功：叶子 ≥1.2×。失败：写下最密行占比。
