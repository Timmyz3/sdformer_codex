## 1. 他们的加速从哪来（精读后）

### 1.1 能成倍的：跳过层级 / 时间 / 区域

**Zhang et al., CICC 2026，28 nm 事件光流芯片**（`papers/649`）。Hybrid U-Net（Spike-FlowNet 类：SNN 下采样 + ANN 上采样），MVSEC AEE 基线 0.96。三刀：

1. **Dense-Channel-First Speculation：** MaxPool/ReLU 扔掉的值占 71.3% 运算；通道按密度排序，过阈值就推测冗余地址，后面通道对这些地址停算。冗余降到 0.26–0.82×。
2. **BWAC：** 组内最小位宽 + 非零 bitmap，权重 EMA −71.4%。
3. **Deep-Level-Skip（DLSS）：** 相邻事件窗特征平均相似度可 >90%（间隔 δ>10）。Level 0 必算；相似则 **整段深层 U-Net 不跑**，等于更浅的网。

硅上：运算 **0.20×**、EMA **0.08×**、能量 **0.12×**、延迟 **0.19×**（约 **5× 延迟、8× 运算**）。AEE +0.03。这是本地 20 篇里 **唯一已经在事件光流硅上做到成倍** 的。模型不是 SDformerFlow，机制可以搬。

**C-STEP, DATE 2026**（`papers/707`）。分类 ST：前半 T 算 LightSoftmax 置信度，过阈则 **剩下时间步全跳**；不退出的用早期静默通道剪后期权重；邻 token 公共脉冲算一次。QKFormer 突触运算到 **0.356×**。依赖 **分类 softmax**。稠密 OF 没有「这张图已经认出猫」。

**Scrooge, DATE 2026**（`papers/714`）。注意力：重要 token 先算，用已知平均分保守估计未知分，已知/总估计过阈则停。1.7×、访存 0.47×。SSA 上抄 = ESTU/FireFly/Jung 结构稀疏同一对象。

**ELSA, ISCA 2026**（`papers/686`）。弹性推理：显著输入更早出结果；token 一经产出立刻进下一层，首响从 O(LN)→O(L)。另有 bundled AER + mini-batch Gustavson。Codex 空间双 context 已经 **慢 74–94%**（连续 Q2 发射 3.1×）。弹性本身没测在 **光流区域** 上。

### 1.2 1.2–2× 的：关键路径 / 重排 / 调度

**BitL, MICRO 2025**（`papers/693`）。零比特跳过被 **一组里 1 最多的那条序列** 卡住；横查改纵查切关键路径。相对近期跳零最高 **1.24×**，相对早期 bit-serial **1.92×**。Codex T10 只做了 5+5 子集和，拍数不变——**不是完整 BitL**。

**Bootes, MICRO 2025**（`papers/695`）。谱聚类重排 A 的行，让 row-wise SpGEMM 对 B 更复用。片外 1.38–2.31×；有决策树判断「这次重排值不值」。预处理税必须付。

**SATA, DATE 2026**（`papers/717`）。TopK 选择注意力后 **重排 Q/K 提高局部性**，吞吐 1.5–1.8×。CIM 评估器；调度可借，CIM 禁标题。

**Jung TVLSI 2026**（`papers/709`）。SSA 自然出现整行/整列空，FSSA+低发放过滤，SSA 块吞吐 +24%。不是成倍，且是 SSA。

**STELLAR, HPCA 2024**（`papers/703`）。Few-spike 短窗 + stRS，硬件对比最高 7.1×——**换了神经元和 T**，不是无损底座。

**DJP, DAC 2025**（`papers/684`）。CIFAR SOP **126×** 是训练联合剪枝，不是本网硬件。

Prosperity / Phi / Gustav / Bishop / FireFly-T：已在 Codex 账上，叶子 8–28%，整链 4% 量级。

## 2. 照抄队列（失败也不扔）

挂点用 **当前 R8/粗头学生** 的真实份额，先做 P0 profile。下面预测是机制预测，不是测到的倍数。

### COPY-1（优先）：Zhang DLSS → decoder 级联

**照抄：** 相邻事件窗（或 `preds.1` 特征）算平均相似度；高则 **decoder2 整段 T10 不跑**，输出沿用粗流 / Level-0。  
**对照：** 全 decoder2；均匀降分辨率；冻结 BN 后的块 mask（Codex `FLOW_NEXT_INTERFACE` 已写动态 BN 是缺口）。  
**杀门：** 同环境 AEE 不优于 NB0；或跳过率高但周期几乎不降（wrapper 仍装全部源）。  
**失败后不停：** 把「整级跳过」改成 **空间 tile 级**（只有空背景 / 低事件密度块跳过）；BN 改成 tile 局部统计或冻结。这是 C-STEP 静默通道 × Zhang 浅网。  
**为何可能成倍：** Zhang 在 MVSEC 上深层可整段取消；本网 decoder 仍是未改贵算子之一。  
**不是 X 的部分：** 相似度检测、变位宽压缩、MaxPool 推测（本网 decoder 未必是 MaxPool 主导）。

### COPY-2：C-STEP 时间早退 → T10 **分块**，不是整帧分类

**直接抄 Softmax 退出：预期失败**（稠密 OF 每像素都要流）。  
**适配：** 每个 2×2/8×8 空间块，用前 2 个时间步的发放或 `preds.1` 幅度当置信度；高置信/低事件则 **该块剩余 T 和 decoder 细化取消**。静默通道剪枝可先在 r0.conv2 的后期 T 试。  
**邻 token 公共脉冲：** 与 Prosperity 森林同类；先当 A。  
**杀门：** 块级求并把跳过率吃光（Claude 已见 384 通道并到块 = 78% 块失败）。接受单元锁 **lane/tile**，不要整帧。

### COPY-3：Scrooge「足够就停」→ 不要 SSA，接到 PSN/decoder

SSA 早停 = ESTU。  
**适配：** 组内门已经能用区间证书停（叶子 34%，接 FC1 后 **4.32%**）。下一次只在 **H12 bank** 粒度测退休（探针已显示 H96 向量只剩 13% 平面工作、算术下界反超原 PSN）。  
**失败后：** 证书当 A；把「足够统计量」改到 **光流幅度已稳定的空间块停 decoder**（和 COPY-1 汇合）。

### COPY-4：完整 BitL，不是 5+5 LUT

对 **Q2 或 Y24** 子块跑 A* 横/纵换向。预期 1.2–1.9× **只在位串行 MAC 叶子**。整链会像证书一样被装载/PSN/消费者吃掉。失败则保留「关键路径是最密行」去解释为什么平均稀疏跳零不够。

### COPY-5：Bootes 行重排 r0 稀疏 W

W 静态，预处理一次。决策树先判断。预期片外/B 复用 1.3–2×，算力不一定。失败则说明本网 W 行已经够规则。

### COPY-6：Gustav 生产边界（已在计划里）

真源写出 → 代次 → NRV → 门。补 A，很难单独成倍。

**明确不要再当主抄：** Phi 叠森林、空间 phase3、一维 Winograd、块级门并集、运动 warp 对齐（C4 已杀）。

## 3. 原创（学思路，不抄电路）

独立生成，再和上表对齐。都是 **candidate**。

**O1. 事件窗相似 ⇒ 浅解码器（Zhang 思维 × 本任务）**  
观测：事件相机在静止/空背景窗高度相似（Zhang AS>90%）。机制：SDformerFlow 的 decoder2 是「细节修正器」，不是唯一光流源；`preds.1` 已是合法粗流。预测：高相似帧 decoder2 周期降到接近 0，整网按帧混合可到 2×+。不相容：相似帧 AEE 明显差于全跑。负对照：随机跳过同样比例的块。

**O2. 早期 T 预测后期静默（C-STEP 思维 × T10 非因果）**  
非因果 T10 **不能** 因果早退整窗。可测：前几个 bin 的占用是否预测其余 bin 的 r0 通道静默。若相关弱则停。不要把非因果窗假装成 C-STEP 的 t=0,1,2,3。

**O3. 足够光流能量就停细化（Scrooge 思维 × 稠密回归）**  
注意力用 softmax 质量和；光流用 **已累积的运动能量 / 事件计数**。过阈停 decoder2。与 O1 相关但判定量不同（相似 vs 已经够）。

**O4. 弹性出流：显著运动块先完成（ELSA 思维）**  
不要整 19200 tile 同步。高事件 tile 先跑完 decoder 并写出；低事件 tile 拖后或跳过。首响延迟降，吞吐不一定 2×。质量：先出的块必须是任务相关块。

**O5. 位平面关键路径调度（BitL 思维 × 证书）**  
证书现在按平面均匀走；BitL 说该切方向。在 GROUP 内按 1 的密度选先走的平面，让界更快碰到 τ。预测：H12 粒度上比均匀平面多停。叶子正、H96 仍可能被长尾吃掉。

这些不是 7 分标题，是 **比再抄一次森林更可能成倍** 的差分。O1 与 COPY-1 是同一条线的抄+改。
