# 名义 MAC 跳零之后还剩多少（2026-09-16）

分母 596.5 G dense MAC。下面「省」= 全零行/元素不乘。**不是周期，不能乘起来当 FPS。**

| 段 | dense 占比 | 已测无损可跳 | 跳完还剩（约占全网） |
|---|---:|---:|---:|
| Patch r0 | 21.4% | 元素 nnz 3.6–4.4% → 约 96% 的 r0 | **~0.9%** |
| Swin MLP | 26.2% | 零行+相同行 25% 的 MLP = 6.6% 全网 | **~19.6%** |
| Swin 注意力线性 | 12.6% | 6.28% 全网 | **~6.3%** |
| Patch r1 / stem | ~19% | 未按行重测；r1 已低秩 | 大部分仍在 |
| Decoder | 8.1% | 级跳过不省成倍 | ~8% |
| 其他 | ~13% | — | ~13% |

r0+MLP+attn 三块 dense 约 60%。跳零后 **r0 几乎消失，MLP 仍是第一贵（约 20% 全网），注意力线性还剩约 6%。**

再叠 Jung：42% 的 SSA 块 Q 为空可关，质量 AEE 0.713 vs 0.716。SSA 本身比 linear 便宜，系统成不了倍。

**成倍需要动跳零之后仍贵的 MLP 非零行（以及 r1/decoder）。** 非零 FC1 行几乎互不相同，Phi 码本已伤 AEE。下一条硬实验应是 **MLP 非零行的同资源周期（AAC 已跳零之后）**，或训过的支持码，而不是再数 dense G。
