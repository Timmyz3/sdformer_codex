## 1. F1 — lifting 源活动 × 敏感 r1 结构剪枝（优先 #1）

### 1.1 一句话 B
在 patch r1 上，用完整 T10 门 + 真实 PED/门双消费者损失，在固定广播域内选可**共同删除**的物理源字（含 H 重排同步系数/阈值），使结果适合共享供数且保住隐藏通道。

### 1.2 同分母对照清单（必须齐）

| # | 对照轴 | 同什么 | 差分只允许什么 |
|---|---|---|---|
| C1 | ordinary dense-source/raw + **同预算窄稠密 / hidden50 式减宽** | 端口/状态/背压/训练域/恢复预算 | 无 lifting；仅宽度/容量 |
| C2 | 完整 **HiNM（含二阶）** / VENOM-CRISP 两级结构 | 同上 + 同等剪枝权限 | 结构剪枝族，非 lifting 源活动形状 |
| C3 | 幅值/活动感知 **C16**（若保留） | 同上 | 旧活动启发式，非 lifting 联合扰动 |
| C4 | **同 lifting raw 无剪枝** 端点 | lifting 图与消费者不变 | 仅有无本 F1 删字 |
| C5 | 开源 **2:4 / Wanda** 作表示对照（非标题） | 同等稀疏预算口径 | 借入底座 |
| — | **禁止** | — | 只回 s2b3 不敏感块打磨；改对照端口/背压；把 W² 下降写成物理源字下降 |

### 1.3 完整 A 继承（写入实验页时勾选）

- [ ] lifting 结构化 T10 PSN 执行对象与常量编译图  
- [ ] 残差链 source→…→双 PED 与 finite 端口/背压合同  
- [ ] Gustav NRV/源∩W/局部状态作供数分母（借入）  
- [ ] da4ml 整图 CSE 与普通 2:4/量化同等权限  
- [ ] Prosperity「产品费用」仅作 mask 选择强控制，不自称 X  

### 1.4 待证 X（一句话）
相对 HiNM/窄稠密：按 **lifting 改变后的源活动形状 + 非因果 T10×双 PED 联合扰动** 决定可共同删的物理字，而非只换损失名或砍不敏感 FC1。

### 1.5 固定杀门（任一即停该布局）

1. 同槽同训练预算下 **不胜** HiNM 或同服务窄稠密（C1/C2）  
2. 只降 W² / 参数量，**不降**物理源字、门活动或流误差  
3. valid 探索 AEE >1.259 或相对同预算强对照 ΔAEE >+0.005  
4. 并集仍读满，且 Stage B 分母下 **无** 周期/服务余量  
5. 为过门改 same-port/state/backpressure 合同  

**停什么**：该 r1 剪枝布局。**不停**：lifting 家族、Gustav、剪枝研究资格。

### 1.6 与 Stage B / Codex

- **现在**：只写本页；可准备捕获脚本规格，**不开训**  
- **Stage B 后**：若 lifting 相对 ordinary 无足够整段净服务潜力 → F1 改挂 **ordinary 敏感 patch** 或降优先，仍不抢 Stage B  
- **不接**：Codex「ready/完成依赖」主线；不解释为标题 X 已成立  

### 1.7 所需捕获 / 工具（纸面）

| 需求 | 说明 |
|---|---|
| 三源 gate 逐位置捕获 | ordinary vs F1-candidate vs（可选）HiNM，同帧同预算 |
| 物理源字计数 | 删后仍被读的字/行/广播组，不是逻辑稀疏率 |
| 双消费者误差 | 门 + 连续 PED 联合，禁止只报单消费者 |
| 供数并集 | 共享供数下是否仍满读 |

### 1.8 给管理 RTL 的接口提示（非本页交付）

F1 相关粗验若做：**删源字后索引/对齐税**、共同删字使能一拍控制——对应 MP3 方向。通过只说明「可表达」，不替代 §1.5 杀门。

**MP3 回写（2026-09-11 box，仅表达力）**：`mp3_shared_source_prune` — `make sim` **PASS**；`make synth` **PASS**（无 latch）。稠密扫描 W 拍且 emit=W；剪枝同扫描预算下 emit=popcount(mask)（例 W=8/keep=5 → emit 8→5），双消费者（gate XOR + cont ADD）重构与 golden 一致；重叠 start 可计 stall。yosys techmap cells：**W=8 → 887**；**W=16 → 1143**。**只说明**共同删字+双消费者+单端口扫描可 RTL 表达；**≠** F1 净服务 / Stage B PASS / 标题 X。

## 2. F2 — lifting 半步检查点 × 组有损共同完成（优先 #2）

### 2.1 一句话 B
在 lifting 半步写回 / 必要 RNE 边界设固定检查点：用已付费部分状态预测整组残差链 T10 门字；**一组接受则发预测 θg（含预测非零）并退休请求，否则继续原算**。

### 2.2 同分母对照清单

| # | 对照轴 | 同什么 | 差分只允许什么 |
|---|---|---|---|
| D1 | 完整 Gustav 式共享请求同步（**无预测**） | 组关闭逻辑、端口、背压 | 无有损预测 |
| D2 | SparseInfer/BitFair 式 **独立每神经元预测** + **相同**组关闭 | 预测权限与组尾语义 | 预测粒度，非半步挂点 |
| D3 | 同精度 **静态窄层** | 精度与服务预算 | 无运行时预测 |
| D4 | lifting raw **无预测** 端点 | 半步图与 RNE | 仅有无本 F2 |
| — | **禁止** | — | 用严格后缀界负结果冒充有损预测已死；接受后不评 AEE；预测开销不入账 |

### 2.3 完整 A 继承

- [ ] lifting 半步图与中间 RNE 语义（约 35 RNE 线索，≠周期）  
- [ ] θg / τ 分离；残差链真实消费者  
- [ ] Gustav 共享请求 / NR4 / 有限 S  
- [ ] SparseInfer「预测→跳权 / 未跳完整执行 / 真实零补跳」与 BitFair 学习终止链作底座  
- [ ] finite_service 事件依赖与单资源互斥边界  

### 2.4 待证 X（一句话）
相对「s2b3@C192 独立/组预测」：共同完成挂在 **lifting 半步自然边界** 与 **r1 多消费者并集费用**（借入预测链≠X）。

### 2.5 固定杀门

1. 净服务 **不胜** 同精度静态窄层，且不胜「独立预测 + 同组关闭」（D2/D3）  
2. 预测/摘要开销 ≈ 再做一次 PSN  
3. 接受后 AEE 破 1.259 或相对 +0.005  
4. 组尾仍被最慢消费者钉死，且请求数不降  
5. Stage B 分项表显示瓶颈在纯算术/RNE 而非共享并集/状态存活 → **降优先或改 F4**，不必强开 F2  

**停什么**：该检查点/组费用布局。

### 2.6 与 Stage B / RTL

- **第二队列**；不占用 Codex ready/完成依赖档期  
- **已有**：MP2 group accept/continue **PASS**（box）→ 控制通路可表达  
- **可续**：半步边界触发 + 接受/继续与 RNE 检查点对齐（管理 MP 线）；仍 ≠ service%  
- **MP4 回写（2026-09-11 box，F4 启发 / §2.5 杀门「改 F4」旁路粗验）**：`mp4_last_n_merge_cert` — `make sim` **PASS**；`make synth` **PASS**（无 latch）。对照朴素全合并 vs 末 N=5 + 证书/回退：accept 路径 **N+1=6** 拍；rollback **N+1+GATES=14** 拍；全合并对照 **GATES=8** 拍。cells（MODE=1 techmap）**2407**。软件历史上全合并为负——本探针**只验**部分合并+证书/回退控制可表达，**不**主张全合并或 F4 净服务，**≠** Stage B / 标题 X。  

### 2.7 所需捕获 / 工具（纸面）

| 需求 | 说明 |
|---|---|
| 检查点集合 | 哪些半步/RNE 边界允许预测发射 |
