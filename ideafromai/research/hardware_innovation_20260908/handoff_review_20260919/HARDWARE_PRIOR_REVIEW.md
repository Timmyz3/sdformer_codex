# 09-19 硬件交接与 CICC 先验独立复核

审阅日期：2026-09-19。范围：Claude T41/T47/T48、Grok 统一交接、sd5ai `SDformer/docs/HANDOFF_CODEX_20260919.md` 的硬件论断，以及本地已完成的真实 FC1→PSN 核。只读源资料；未运行 GPU、EDA，也未修改原报告或生产树。

**结论：接收已有实现和负结果，不接收“每轴支配”“全库无周期证据”“移植空间穷尽”“CICC 身份不明阻塞一切”等总括判决。** CICC 原始全文本机已有且确认为混合 SNN/ANN 芯片。现有门核仍缺足够新颖性和完整物理净收益，但不能用弱化/异资源对照证明整个家族不可能。

## 1. 先区分三个同名 C1

| 名称 | 实际对象 | 这次可使用的证据 |
|---|---|---|
| 生产 C1 / m935 | 瓶颈 Conv3×3 的有限父行乘积复用，九个 1RW 宏 | 同账本 CPU 周期模型、定向 VCS、后继 mapped PT/FM；不是注意力 QKᵀ |
| Claude C1 | 组级 BFP 位平面供数与 T10 门证书 | 多轮整数/Verilator、若干 FPGA OOC/实现结果，需各自绑定报告 |
| Codex joined FC1→PSN | 真实投影 g′ 输入→FC1 Y→完整 T10 PSN→H96 门 | 480 条完整命令、同 union 资源/端口/背压；normalized 版本功能扩至 496 条 |

三者不是同一模块。Claude 的 k=4 微调门不能代表原始 dense T10 PSN；Codex 投影学生不能借用 ep34 全头 AEE。工程规模、已有证据、性能应分别核对。

## 2. T41：强对照值得保留，但不是每轴支配

已读 `T41_REPORT.md`、`results/t41_ppa.json`、生成的 `t41_fused/t41_fused_gate.sv`。RTL 是 **Y 已完整到达以后**，硬编码 k=4 的 A，对十个 t 各做四项常系数乘积及阈值比较，输出十位。它没有 FC1 生产者、参数 SRAM 供数、输入 FIFO 或 out_ready 背压。

| T41 对照点 | LUT | FF | DSP | 4 ns OOC WNS |
|---|---:|---:|---:|---:|
| serializer + T39 A | 8,883 | 2,015 | 0 | 两个独立模块，不是整链实现 |
| serializer + T25 k4 | 5,526 | 2,020 | 0 | 两个独立模块，不是整链实现 |
| fused 默认 | 241 | 11 | 40 | −0.377 ns |
| fused 禁 DSP | 7,069 | 11 | 0 | +0.077 ns |

可以认定：完整 Y 已知、允许同侧门计算时，送最终十位是必须面对的直接对照；12M 算术判决和 80k RTL 判决零差支持其函数等价，不应人为规定必须传多位 Y 来保护串行器。

需要修正：

- DSP 版省 LUT 不等于省总面积；它多 40 个 DSP，并且 4 ns 目标未满足。
- 无 DSP 版相对 **T39 合计 LUT 少 20.42%**，相对 **T25 合计反而多 27.92%**。因此“每个面积轴都赢”不成立。
- 1 拍/组与 3.031 拍/组在同频、无限供数下是 3.031 倍吞吐；报告另写 2.1–2.3 倍，实际混入各自 OOC 频率估值。两者都不是同频整链实测。
- +0.077 ns 是 OOC setup 裕量，不是已完成布线时序。默认 DSP 点已经失败，不能同时声称“同一时钟”和无条件吞吐胜出。
- 10 bit 是输出负载。该 RTL 还假定每组 240-bit Y 与 640-bit 阈值端口已就位。允许融合是合理权限，但必须在共同供数、存储与消费者边界内计费。
- 零差只对指定量化 A、阈值及受测函数成立；不能将表内 `aee: identical` 解释为新网络 valid825 已联测。

**裁决：T41 是必要强分母，否定“只与 FX24 串行器比较”的标题；尚未证明所有端口/面积预算上门核无价值。** 新颖性不足与同资源性能失败是两个判决，不能互相替代。

## 3. T47：确有 RTL，但 4× 是明确弱基线上的槽位比

已核 `t47_deconv_walker.sv`、`t47_ppa.json`、`T47_REPORT.md`。H4×W5、Cin4、Cout1，三个用例，Z/P 各 2880/720 抽头槽位、逐值一致；FPGA OOC LUT 219/155，FF 170/172，DSP 0/0。这个实现证据应保留。

限制必须比“玩具规模”更具体：

1. Z 每输出枚举九个核位置，连结构性不合法抽头也消耗槽位；P 按相位直接枚举合法奇偶抽头。4× 是该两个控制器的比值，**不是对已有 input-scatter / 零跳过 / 合法抽头枚举强基线的新增 4×**。
2. 代码两臂都从原始 `CIN*H*W` 输入地址空间取数，Z 用逆映射产生零；并没有实例化四倍零插值 SRAM。因此“输入缓冲省四倍”是相对显式展开缓存的解析选择，**并非这两份 RTL 测得的容量差**。
3. 核外组合权重/输入接口，无请求响应握手或写回背压。`nslot` 可信，但全算子 latency、SRAM 服务、halo/多输出通道账未闭合。
4. 0 DSP 说明这里用二值输入选择权重，不是相位分解独有收益。
5. 浮点 `conv_transpose2d` 约 8.1e−6 差不能称 FP32 逐位零差；量化整数玩具用例的零差是另一条证据。

**裁决：纳入 decoder 的共同映射底座，暂不占 TCAS-II 主贡献。不能把“唯一闭合映射 RTL”误解成其他已完成 RTL 不存在。**

## 4. T48：适合做算术热点图，不是硬件成本图

从 `t46_zero_decomposition.py`、`t45c2_density_operand_width.py`、`t48_ledger.py` 和 JSON 核算：A=946.381824G，B=55.855957536G，A/B=16.94325665。B 是算子形状与 profile 活动率相乘的 **活动加权工作量估计**，不是逐项执行 trace、周期或存储访问计数。

| 可保留 | 不可继承 |
|---|---|
| 明确区分零插值结构零与输入数据零 | `measured=true`、成本 0 的“网络级 16.94×” |
| B 下 encoder/frontend/decoder/bottleneck 约 31.97/29.16/27.38/11.46% 的算术分布 | 直接按这些比例计算墙钟 Amdahl，或推出注意力能耗只有 3.7% |
| 原始 profile、40 样本捕获与 decoder payload 的交叉来源 | 将 55.856G 全部称“不可省真工作”——子集复用/因式分解可继续降低求值成本 |
| 修正 bulk=None 被归入二值的缺陷 | bulk≥0.99 自动证明精确二电平；它只表示非零幅值接近最大值，需要源码/逐值支持 |

最关键错误在 §6.2：**`SOP_B ≡ 权重 SRAM 字读取次数` 不成立。** 输入驻留只说明输入的位置，不决定权重在哪一级复用。一个权重可从寄存器广播给多个空间位置/多个 T，SRAM 还可一次读多个权重；反过来 metadata、重放、冲突也可增加事务。至少要分清 scalar weight uses、RF reads、SRAM words、DRAM bytes。`SOP/参数数` 可以命名为“平均标量权重使用次数”，不能命名实际 SRAM 读取放大，更不能从 34,932/301 两个比例证明“搬家最贵”“单数据流不可能最优”。

T48 还有三项应从投稿口径撤回：

- `17.03% × 34.86% bits = 5.9% 网络收益`：运算覆盖比例乘输出 bit 减少比例不是周期或能量收益。
- 1-bit 源不意味着所有相关多位运算都无位级优化空间：权重、连续 FC1 Y、PSN A 均仍多位。T45 抽头证书仅 sample0 两个 bottleneck conv1、48/768 通道、代理阈值；不能由此否掉全网所有表示接口。
- §8 写 `A 101.585G / B 55.856G` 与本表 A=946.38G 冲突，属于残留口径，不能作为“唯一权威表”直接进文。

**裁决：保留热点定位，将“成本/带宽/全网收益”降回待排程测量。**

## 6. CICC 2026：已查原始全文，不再是 ANN/SNN 未知项

原始四页 IEEE PDF：[/home/zhumd/work/papers/649/Zhang 等 - 2026 - A 28-nm Optical Flow Estimation Accelerator with Redundancy Speculation, Bit-Width-Aware Compression.pdf](/home/zhumd/work/papers/649/Zhang%20等%20-%202026%20-%20A%2028-nm%20Optical%20Flow%20Estimation%20Accelerator%20with%20Redundancy%20Speculation,%20Bit-Width-Aware%20Compression.pdf)。[IEEE DOI](https://doi.org/10.1109/CICC65509.2026.11509564)。本次已直接读取全文；在线 IEEE 页面被 JavaScript 验证挡住，结论来自本地原始论文，不靠搜索摘要。

1. **混合 SNN/ANN U-Net**：§I 明写 SNN 提取时空信息/下采样，ANN 生成实值光流/上采样；引用 [7] Spike-FlowNet (ECCV 2020)，不是当前 SDformer Motion-XOR。
2. **真实 28nm 芯片**：§III-A / Fig7 为 die photograph 与 FPGA/test-chip PCB 测量，die 1.45mm²、core 0.80mm²。不是“大概率硅”。
3. **三个联合手段**：DCF 按通道密度排序，达到 #CH 阈值后推测 MaxPool/ReLU 地址可停；BWAC 变位宽加 nonzero bitmap；DLSS 用特征相似度选择是否只执行 Level0。
4. **DCF 不是严格区间证书**：论文称 speculation，并以模型评测控制误差；不能因为后接 ReLU 就认定剩余带符号项不可能改变判决。
5. §III 报告总体 operations/EMA/energy/latency 约 0.20/0.08/0.12/0.19×，来自同论文三个机制相对其基线；不能套到本模型。MVSEC baseline 8-bit AEE 0.96，联合方法平均增加约 0.03。
6. **EMA-inclusive 14.07 TOPS/W 混有外存估算**：原文明确 EMA 使用 LPDDR3 **3.7pJ/bit、6.4GB/s**。芯片有实测不代表外存部分也由同平台实测；本工作不能拿某个无 EMA 组件估计直接排序。

本地 `docs/228_CICC2026光流芯片借鉴与FAED本土化设计_20260801.md` 早已记载上述混合身份与主要数字。因此新交接提出“先取得全文确认 SNN/ANN，阻塞一切”是知识同步遗漏，不是研究阻塞。该旧笔记也有需要纠偏的地方：把 DCF 描述为后续绝不改变输出的提前确定性，不符合原文的 speculative 有损机制；旧 AEE/no-budget/DATE 决策已过期，只借原文与迁移负结果。

这篇确属直接同任务先验，应放入机制差分表。重点是如何处理同类连续/脉冲混合算子、EMA 与近似质量约束；**它没有自动占掉所有 PSN/FC1 执行切口，也不能因工艺任务相同就要求整网芯片才允许继续组件研究。**

## 7. 本地真实 FC1→PSN 核的当前反证与限度

`support_source_execution_20260915/post_psn_subset/joined_fc1/README.md` 的共同 mode4 FC1、唯一90KiB Y、真实T10运算与门转排已经实现。32real 是 8 个投影源 tile×4 个 H96 函数，非32独立帧。

| 冷启动完整命令 | native | certificate | 周期降低 |
|---|---:|---:|---:|
| ready | 184,408 | 176,448 | 4.3165% |
| 固定背压日历 | 212,997 | 204,698 | 3.8963% |

480 条链命令完成，normalized 后扩至496条且同链计数不变。该核真实存在，不能写“全库只有一个 m935 island/没有周期数”；但 union 硬件包含额外宽加法、比较器、LUT mux，并不构成相对独立 native 的同面积同频证明。约4%周期收益容不下较大频率损失，也未闭 BN2/shortcut/整网 AEE。

`operator_timing/SUMMARY.json` 的**单判决 lane** 28nm DC 两点：面积 5293.26→5014.42µm²（−5.27%），最坏到达2.66545→2.49370ns（−6.44%）。这是局部常量组织改写的物理线索；无 PT/FM/CTS/功耗/整核Fmax，不能乘80或与4.32%拼成完整加速。该数据既不能被远端旧 m931 覆盖，也不能用来宣布主核 PPA 闭合。

## 8. 对下一轮的约束和可执行顺序

- **优先审计并落地一个 ep34 Stage0 FC1+PSN leftover 子链**是合理方向：LUT-GEMM packed 与合法 Scrooge 的 CPU KEEP 作为机会值，下一步量实际端口/组锁步/maxabs预扫/阈值/转排/背压成本。29%与60%只能在匹配算子按工作量相加，不能直接相乘或沿用41%为RTL预期。
- 复用现有强 AAC/native/真实Y控制经验，不从弱 FX24 或7-serial重建分母；但不得把投影学生输入、阈值或 frozen-BN 直接移作 ep34 live-BN。
- T47相位映射共同给候选与对照。已有合理decoder枚举不再支付稠密插零税；若做新decoder X，必须在该底座上产生额外访问/状态/调度收益。
- 不因 T41 宣称支配就停止全部门执行接口；也不因局部 proof/DC 通过恢复旧 C1 标题。保留实际问题：消费者已经只需离散门时，能否减少**最贵的生产和服务粒度**，而非只少发已有bit。
- 不启动全网剪枝/注意力/旧r0并行大扫；等主线程核对算法身份、remote变更后固定一份输入/阈值/整数顺序。对失败接口记录失败成本，未试家族仍单列，不写“穷尽”。

**本轮独立判断：现有完整门子链新颖性约3/10，T47映射约2/10；它们是有用且可复用的底座。LUT+Scrooge尚不能评分为强接受，值得一个有限资源完整子链试验。CICC确认使比较更具体，不构成停止研究的理由。**
