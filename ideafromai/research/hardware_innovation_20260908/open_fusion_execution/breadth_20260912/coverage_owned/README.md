# 覆盖补漏与一个新接口实测

**并没有把全部适配接口试完。** [覆盖表](COVERAGE.md) 把全部305个重叠候选视图逐行落入可执行接口，另列补文献/Grok接口；它们不是305个独立idea。[逐行CSV](coverage_all_views.csv) 保留原A/B/X、证据、身份/资料缺口和剩余项；[后续批次](REMAINING_BATCHES.md) 给出具体强对照与边界。

本轮实际补了 [NRV∩W 同址合并/共享缓存接口](NEW_INTERFACE_RESULT.md)，六臂同端口与有限存储，528次重放、118272个S和168960门bit全部正确。逐次NRV读口也计费后，最优index相对最优dense仍慢104.33% / 43.98% / 42.93%（原整数学生/row2of4/C16）。合并减少W字节，未降低dense完成槽；不把它包装为新性能胜出。

本次是CPU供数前端服务模型，使用原有16个真实捕获选取；S/PSN只做功能检查、没有新AEE或RTL/PPA。其4×4KiB、2R32源bank是新共同预算，不能替代旧4×1KiB RTL表。旧预重读NRV模型得到的dense改善已撤回，全部最终结果已用实际NRV响应重跑。
