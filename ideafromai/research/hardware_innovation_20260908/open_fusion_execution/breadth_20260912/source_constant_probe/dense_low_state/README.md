原596组验证检查RF逻辑tag、两槽就绪与数值。两真实halo的193,920个完整整数矩阵积及同量最终门逐值0差；四个RTL例（两窗×ready/stress）387,840个门位及1,003,536次向量RF写回全0差，SR64/SW64与完整CSE逐窗相同。源码实际调用已有`compile_fixed()`和`actual_window()`，公共RTL核对上级同一CPUgold，没有重新生成不同量化函数。

应保留两个普通选择：完整CSE用于最强已测串行源分母；13工作RF＋1门RF的合法程序为未来80消费者＋2供数RF交织提供同权控制。其新增周期须放进真正共享issue/端口执行后再评价，**本次没有执行交织或证明净收益**。40/61不能当dense的状态下界，RF减少也不是物理面积下降。
