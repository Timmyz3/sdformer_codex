# 唯一普通低状态源控制

B：新 dense 的公共 CSE 程序峰值为 61 个工作 RF，这不是 dense 时间矩阵的最低状态需求。后续若把 lifting40 的 13 RF 与消费者交织，必须面对也能压低 RF 的普通编译控制。

A：保留当前 stage320 dense 的全部 As、最终 RNE/sat 与 literal 发放阈值。按每行的 signed CSD 项展开，两条独立累加链交织；十个原始输入常驻 RF0–9，链在 RF10/11，最终相加在 RF12，门仍走 RF95。采用原双级指令、2R/1W 和 512×128 ROM，冷输入与提交语义不变。

X：本项没有新算法或标题增量，只补强普通对照。对比当前 dense CSE 与 lifting40 的同一源执行接口；不由源级费用推断完整局部链收益。

固定门：先完成实际两槽依赖排程，再检查 512 指令容量。插入的 RAW 和尾部排空 NOP 也占 ROM。若超过容量，仅停止这一固定逐行两链编译点，不扩 ROM、不改 ISA、不自动改做跨行调度或行 CSE。即使不准入，也保存未截断程序并核对标量边界、真实两窗的完整门前整数与输出门。
