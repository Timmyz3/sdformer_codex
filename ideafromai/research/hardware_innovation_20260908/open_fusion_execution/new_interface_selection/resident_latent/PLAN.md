# R24 潜变量留驻：执行前 B / A / X / 强对照

2026-09-12。固定两学生原interior P2：完整I24源位置(120,160)、(120,162)，全T10。只做CPU实际载荷与端口原型，不改系数、不训练、不评价AEE。

**B。** 原P2连续U→V把R24潜变量写入SRAM；V96按H32三块重新收集全部Z。低秩虽已减少算术，潜变量重读和寄存器预算仍产生费用。单遍统计等其他支路不在这里相加。R24原排列参数来自已有`original_ordered_U/V`前24维，RNE/sat边界仍为U右移16、V右移15，随后原bias/sat；不重定基或融合掉舍入。

**强对照先列。** 同一P2载荷、同一96×8RF / 128KiB state+128KiB coef / SR64+SW64+CR256 / 48位累加器 / 单发射。保留原R24、R32的P2驻源MAC，并给R32同样P1潜变量留驻权限：Z40RF+H32输出40RF，三块完成V。H40同样需要三块，反而把16位系数的32B字切开；因此选更合理的H32，不把R32强制溢出衬托R24。

**A。** 既有`ped_bitplanes/probe.py:resident_mac`的源驻留、标量lane选择与定点提交完整继承；普通循环分块、producer/consumer融合、低秩两阶段片上中间值均有强先验。独立新颖性审阅另核LoopTree、TwinQuant与LowRank-SSM；本页不称已完整移植其硬件。

**尝试接口。** R24每个P1独立处理T10：U结果30RF原位RNE/sat成Z；V每块H48占60RF，Z+Y共90，临时不超过既有6RF。两块V直接通过已付费`IMAC_INDEX(src,lane)`消费Z。每条MAC仍读源RF向量和目的累加RF向量；lane mux属于该既有指令，不新增第三读口或免费独立extract。原24-bit源收集、两次P1的权重CR重读、真实依赖等待和输出都收费。Z未写SRAM，也不能在V完成前回收。

**X未成立。** 若留驻有净收益，只能先保留为更强公共blocking底座。单凭R24能装进96RF或比R32便宜不能叫新机制；要看同rank布局差分及R32同样编译后的结果。固定ready和原32拍压力轨迹，不扫P/H/端口/缓存。若拆P2后净负，停这个布局；不由此否定低秩家族。
