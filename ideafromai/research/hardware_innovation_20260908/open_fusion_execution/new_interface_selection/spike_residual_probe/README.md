# 固定门字时间解码 + 精确 PED 残差：实际探针

2026-09-12。**整数功能通过；停止这个固定 D 编码布局。** 它几乎没有减少连续 MAC 必要工作，额外二值投影与解码反而增加计费算术。此结论来自实际捕获和完整 U/V 定点输出重构；费用是乐观发射/载荷模型，**不是逐周期仿真、RTL 加速比或 PPA**，也不否定经训练改变残差支撑的表示家族。

本次直接试了 [probe.py](probe.py)，无 GPU、训练或参数扫描。输入是原 ordinary/lifting 两学生同一捕获帧 **full_updated_I24 与其同生产者 full_proj_words**：前者供连续 PED，后者由 proj.sn 读取同一更新后的状态得到，未借 sn1/sn2 偷换生产者。每学生仅在预定 y/x=32:96:4 的256锚点拟合一个所有96通道共用的10×10 D，加10个时间偏置。LS系数一次RNE为整数状态单位；因此 b=Dg+c 是精确定义的整数预测，r=x−b 不裁剪。不扫 D、位宽、rank 或样本。两学生 D 均100项非零、系数实际需18位；常数偏置需16位。

强对照是原 raw I24，以及**同校准的逐时间均值常数残差**；所有臂用同一原 U32/V96、signed16权重、指数16/15、原 U RNE/sat24→V RNE/sat24→bias/sat。两个残差臂把 Ur 和 Ub 的原始48位累加在 U 舍入前合并，原 V 只跑一次。另以独立 Ug→D(Ug)+Uc 路径核对二值项，整数 D 无中间RNE才允许这一次交换。常数 Uc 可离线预计算但运行时读/加仍收费。现有 gate 的3×3权重不同，**没有抵扣任何 gate 卷积乘积**。

**功能范围。** 对整个捕获帧的 stride2 锚点，两学生共36,864,000个 D残差值 b+r=x，零差；这里仅做源重构/范围普查。原校准与两块不交叠留出窗执行完整 K96→U32→V96，D臂552,960个输出与原定点函数零差，其中留出61,440个输出也与原捕获逐位一致。三臂合计1,658,880输出核对通过；所有中间RNE、负符号位、24位饱和和48位累加范围都保留。校准帧没有变成独立测试帧，不把整帧源重构叫完整层周期重放。

**即使二值项和解码免费，窗口 Ur 相对 raw U 也仅多4、少8、相同、多4次 MAC8。** 因而现有24位MAC上几乎没有可供这层表示支付开销的省算空间。压位宽字段双方都按同一个P2×T10源字、1B宽度头计；节省仅0.50–0.69%，没有拿24位不压缩raw作弱对照。

**A/B/X裁决。** 这次借入的是预测值+精确残差、常量编译及线性分配，SymbolicLight式双路径也已有先验；只把门字用于预测连续源，本身不够形成标题。候选X原本是“已生成的同生产者门字，让连续消费真正少服务”。当前 r 几乎全密、位宽也基本不变，故该X在这个固定LS解码端点没有出现。创新性诊断3/10（表示探针，未有超出先验的有效差分），**不以此分数或算术比例推断录用概率**。

只保留一个不同的未试接口：在允许改变学生的条件下，训练连续状态/门字使残差以**真实物理源字**为单位零化或低位量化，再用同设置SDformerFlow baseline核AEE，并与普通结构剪枝/激活量化同训练预算比较。它改变支撑与算法函数，和继续调这个固定D是两件事；本轮未训练、没有精度或性能承诺。不因本负结果杀整个家族，不再为本布局扫D或写RTL。
