普通源驻RF已给双方完整整数消费者，使该局部消费者相对旧供数省15.28–16.16%；这是公共实现改进。真实U/V、RNE、BN2、raw I24和连续PED都保留。恢复后ordinary两窗口相位消费者636,220/677,356槽，全局636,224/677,294槽，均与各自新整数金值一致。

独立生产者+消费者串行收费和包含双方gate DMA：恢复相位比未剪枝公共底座省3.78–3.88%，全局省4.08–4.13%。这不是集成时间线、整帧或整网速度；新参数改变了projection gate，后续原生投影/动态BN费用未继承。

新行相位接口令同一水平P2共mask，生产费用已与全局mask相同，解决广播税。免训AEE ordinary/lifting为1.217386/1.247094，仍不达门；帧均值与像素均值比较方向不同，两种均保存。此结果限制本次mask选择，不否定布局接口。

## 连续PED与完整动态BN

[PED位面](ped_bitplanes/README.md)的32个case保持真实I24/U/V/RNE，输出0差。逐位校正仍太多。普通驻RF的叶收益26.84%不能推广全链，其完整消费者收益已单列。

[完整BN分项表](default_bn/README.md)覆盖每轴192000位置×96通道，保原分母、交错支路、256叶树、FP32 FMA和rsqrt。code0不能从BN分母删去，也不意味着后继PED为零。强默认控制/零叶复用为 ordinary107,236,936/106,649,070，lifting106,714,840/106,124,128槽；新增约0.55%。初版3.3%含对照未缓存−μ的遗漏，已更正，不再引用。

这里仍从全图投影捕获开始，规范化输出全部物化；未执行全域生产者、BN+PED相加或一遍统计强对照。与自身密集树位等价不代表已与CUDA BN位等价或新AEE。公共BN总费用改善约47.5%，不能全记新增X，也不能与其他倍率相乘。

## 后续按不同接口推进

1. 保留源驻RF、code0压缩和默认传播，接真实生产者与最后消费者；补投影融合统计首遍和FlexAcc式一遍矩对照。改变浮点函数时单独评价AEE。
2. 结构剪枝转向多帧真实任务敏感度或生产者支持改变，普通全局/减宽/2:4享相同训练；不继续扫本次mask或延长64步挑最好值。
3. 父复用下一接口先恢复原作合法K16分块对完整算子的覆盖及TCAM/重叠。M20/K864与更大M状态不可互代；已有列流RTL可复用。
4. [队列](EXECUTION_QUEUE.md)继续保留费用感知稀疏、权重/源交集、可学习时间结构、Motion-XOR行内复用与因果运动选择。一次失败只结束实测布局；新尝试先明确A/B/X和强对照，再直接做有界原型。
