# 同一生产者门字与连续 PED 输入的三种固定表示

本页仅解释本轮已排队的三臂；精度以 `representations/aee/` 的实际推理为准，CPU 源误差不能替代 AEE。未开训练、步长扫描、RTL 或 EDA。

**B 与强对照先行。** `updated_I24` 同时供给实际 proj 神经元和连续 PED 分支。AT-LIF 仍输出 `{0, θ}`，静态 θ 可折入后续权重；连续值来自神经元前的旁路状态，不是 AT-LIF 的第三种输出。旧精确 `Dg+c+r` 残差几乎全密；换成有损表示后，首先要击败普通同位宽 I24 量化，不能把量化本身的供数收益记到 Dg 上。共同底座是同学生的真实 R24＋单遍 BN，强对照同时保留普通 signed8 量化和不量化的完整 I24。

**A 与候选 X。** 借入的是预测编码、普通量化、低秩双矩阵及可交换的时间/通道线性算子。潜在增量只可能来自：使用原本已计算的同一生产者门，减少连续分支仍必须搬运或计算的内容，并在共享资源下超过普通量化。当前未证明这一点；不用新名称把这些公共底座包装为贡献。

令 `X[t,c,p]` 是 signed24、物理尺度 `2^-14` 的原始更新状态，`g[t,c,p]` 是本 helper 使用原时序排列、阈值和增益产生的实际 proj 门。`D[10,10]`、`c[10]` 是既有单帧 256 个 anchor 拟合后取整的常量，本轮不重新拟合。两学生实际 D 都有 70 个非零，最大绝对值分别 113220、111315；不能免费塞进 signed16 系数口。

三臂共同使用 `step=2048` 个 I24 单位（物理 0.125），RNE ties-to-even，量化码饱和到 `[-128,127]`：

| 臂 | 传给原 PED U 的 reconstructed source |
|---|---|
| `i24_q8_s11` | `sat24(step * Q8(X / step))` |
| `Dg_q8_s11` | `sat24(Dg + c + step * Q8((X-Dg-c) / step))` |
| `Dg_only` | `sat24(Dg+c)`，残差明确丢弃 |

以上 `Q8` 表示一次 RNE 后 signed8 饱和。解码后仍执行原实际 `U_q16 → RNE16/sat24 → V_q15 → RNE15/sat24 → bias/sat24`。普通学生选原排列 R24，lifting 学生选 activation-whitened R24；source temporal identity、真实 gate 支路和其不同的 3×3 权重保持原功能。

**门的时序与数值。** 原软件先在同一次 producer preparation 中生成连续 PED，然后调用实际 proj 神经元。本探针在 `U_ped` 挂点用同一个 predicate 提前求 g，并逐帧核对之后真实模块发出的门；它只是软件诊断安排。硬件必须明确重排、转发或支付重复 predicate 的执行，T10 非因果依赖不能当零延迟。g 不是 sn1/sn2 门，也没有使用当前帧最终 flow。

`Dg_only` 有一个可合法尝试的执行重排：D 作用在 T，U 作用在 C，因此完整整数累加 `U(Dg+c) = D(Ug)+U(c)`。四个既定窗口已核整数累加零差异；原 U 的 RNE 必须留在完整右式完成之后，不能在 Ug 或 Dg 中间插入 RNE。全二值 g 的 `|Dg+c|` 上界分别 214318、227973，小于 `2^23`；故这一臂的重建 sat24 在当前常量下对所有合法门冗余。右式累加上界分别 114447667740、137768526295，仍小于 `2^47`。这些是数值合法性，不是周期证明：D 位宽、临时状态、gate-ready 等待、广播口和归约口均须收费。

**当前 CPU 机会与去留规则。** 同一个既定首帧，普通 Q8 的零码比例约 3.2%，预测残差 Q8 约 4.1–4.3%；两者都没有空的完整 P2×T10 源字。不能据此预判网络 AEE，也不能声称可跳过共享源请求。无残差臂具有不同表示接口，局部误差较大仍照计划做真实推理。三臂只凭同帧 NB0 精度门决定能否继续；是否进入电路还要比较其完整代价与普通 Q8、固定 R24。一次失败只停止这个固定表示和参数点。

校准帧出现在 diverse10 中，所以同时报告排除该帧的 holdout9。十帧结果不会继承成 valid825；已有学生或公共 BN 的历史精度也不会与本臂相加。
