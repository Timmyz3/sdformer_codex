# 五候选独立复核（2026-09-13）

## 阅读顺序与预先准则

先写下本准则，再核查实现/原始结果和最强最近邻，形成初评；最后才打开旧 REVIEW / NOVELTY_REVIEW / NEXT_FAMILY 评分文件。入口 README 已包含部分作者结论，不能声称完全盲审；本轮不采用其中的分数或“可作标题”裁决作为评分依据。

新颖性 N（0–10）评已具体提出且有机制边界的贡献：①相对最强最近邻新增了什么可执行契约（0–3）；②结构、二值门与连续消费者是否产生非平凡耦合，或可泛化的独立调度/表示机制（0–3）；③能否被简单组合既有方法解释、是否有公平消融隔离剩余贡献（0–2）；④差异的可复用性和明确适用域（0–2）。普通 dense 也受益不是减分规则；需要判断机制本身是否新，而非必须 lifting 独占。区间表示证据与最近邻覆盖的不确定性，不是接收概率或统计置信区间。

性能证据 P（0–10）单列：相对同函数最强可执行控制的净收益、质量约束、工作边界及成本是否完整。不同函数只可报告质量/成本折衷；CPU 服务槽不写成 RTL 加速。新颖性高低不由速度正负直接决定。

完成度 C（0–10）单列：从数学/编译到实际输入、有限资源执行、消费者、数值核对、完整工作边界和硬件实现的覆盖程度。本轮不新增训练、实验或 EDA。A 移植完整度按实际借入机制分别报告，不因没有复现整颗既有芯片就抹去已完成的局部移植。

准入只采用同协议优于 NB0（完整 valid825 的帧均 AEE = 1.44535253468097），不恢复旧 +0.005；十帧只能和十帧同协议 NB0 比，不能替代 825。当前 AT-LIF 输出按 {0,θ}、固定 θ 可折入 W；连续 I24/PSN/PED 是另一个数值接口。

## 独立初评（在打开旧评分文件前固定）

### 1. learned lifting40：有结构差分，尚缺由双消费者带来的新执行契约

已实做的对象是四层配对、每层两个半步、每半步五次更新的40系数 T10 图。`source_execution/run.py::compile_graph/literal_gate` 明确保留逐半步 RNE/sat24；35个中间 norm 必须真实执行，末五个纯门出口允许精确 cutoff。这不是把一个实数等效矩阵直接交给稠密 MAC，也不能因“非线性舍入后不能合并”就自动授予新颖性。

最强先验是 [Dao 等 Butterfly，ICML 2019，§3.1–3.3](https://arxiv.org/html/1903.05895v2) 的可学习稀疏因子快速变换，以及 [Fang 等 PSN，NeurIPS 2023，§3.2–3.4、式9–10](https://arxiv.org/html/2304.12760) 的可学习全时间连接和二值门。前者直接覆盖“学习结构使时间矩阵乘更便宜”，后者覆盖“全T时间映射→阈值脉冲”。二者未在所核段落中提供本项目逐半步定点语义、T10小图和连续 PED 义务共同作用的有限资源接口；这是**可研究差分**，而不是检索未见就证明首创。

**A移植完整度：**PSN固定T时间映射/二值输出及替代结构已经迁入真实网络、编译和源RTL；稀疏因子思想迁入了具体40更新图，未复现Butterfly论文的排列学习、整个结构搜索族或原硬件。da4ml完整图CSE与普通两项量化权限都实用，属于已完成的公共编译基础。

性能证据来自新匹配320端点：dense/lifting/34的825 AEE为1.208329775/1.225494715/1.421461096。源RTL周期491→446，少9.165%；两项量化同权限后319→290。后者各自新825为1.209053834/1.235243345；lifting仍符合NB0准入，但与dense存在明确质量折衷。两项源的工作RF为40/10，另有门collector；普通低状态同函数路径也可13工作RF，但472周期。故不能声称dense至少需要40RF，也不能将活跃RF差写成物理面积差。[源结果](../../breadth_20260912/source_execution/summary.csv) · [常量结果](../../breadth_20260912/source_constant_probe/summary.csv) · [普通低状态](../../breadth_20260912/source_constant_probe/dense_low_state/README.md)

目前双消费者说明候选服务对象真实，尚未说明结构使某个只能靠该图实现的请求取消、共享值直供或完成时机出现。N=5认可这种结构/数值语义/负载结合的非平凡性；没有把9%源核优势或所有外围优化叠到N里。需要新接口后再决定是否晋级。

### 2. 同资源交错：公平执行是实质补强，交错原理仍很通用

`full_window/run.py`确实在同一个Machine中调用`execute_flows(source, all_ped, ...)`；source/PED具有明确RF区间并共享single issue、ready/pending、SR/SW/CR和DMA暂存。保存46,080B anchors、迁移sn2和真实输出全部被收费。它不是独立时间线相加再取max。完整A窗口＋B源ready相对强普通分别少0.681%/1.902%/2.613%，背压少0.545%/2.143%/2.694%。[实测CSV](../../breadth_20260912/hardware/actual_interleave/full_window/comparison.csv) · [代码](../../breadth_20260912/hardware/actual_interleave/full_window/run.py)

最强先验选 [LoopTree，TCASAI 2024，§III–IV](https://arxiv.org/html/2409.13625v4)：已系统处理跨层分块、保留、重算与流水组合。其原文§IV-C的时延分析采用隐藏阶段时延和带宽估计，而本项目逐issue/响应实际执行，证据粒度更细；**这提高可信度，不等于发明了新的交错方法**。当前固定双流轮转、互斥与手工RF划分，尚未给出可泛化的新调度准则、闭包算法或独特的producer-ready接口。

**A移植完整度：**有限容量分块/保留/交错的局部机制已完整执行；没有移植LoopTree完整设计空间搜索、分析器或能耗模型。B消费者、native、全域BN、上游整层缺席。C=5.5恰好反映“完整A局部链＋完整B源”而非整链硬件。

普通34受益更多只能反驳“lifting专属收益”的归因，**不能证明调度创新不存在**。N偏低的原因是当前机制被已有流水与保存/重算组合充分解释。保留为强底座，不因这一个布局小幅收益而关闭生产顺序研究。

### 3. commit摘要：应区分占用格式收益与形成时机收益

`metadata.py`确实从真实H8门commit的16B载荷生成H4摘要，后继用摘要与几何许可决定是否发SR请求，并清除缺席位置的缓存lane；普通扫描臂用同一个摘要原语并预取下一字。source与sn2两点摘要占最多1,616B的原状态池，没有引入免费门图。保留原c-major K864次序，也仍扫描K选择项。[实现](../../production_fusions_20260913/source_metadata/metadata.py) · [结果](../../production_fusions_20260913/source_metadata/summary.csv)

最强先验是 [GustavSNN，HPCA 2026，§IV-D/E](https://doi.org/10.1109/HPCA68181.2026.11408587)：本轮直接读本地论文全文`literature/GustavSNN_HPCA2026_public_mirror.txt`，核对NRV记录非零行索引和P位行向量、全零行跳过及fetch/execute重叠；第二先验 [LoAS，MICRO 2024，§II-D、§III](https://arxiv.org/html/2407.14073v2) 已将活动位图与双稀疏求交和全时间供数紧密组织。当前H4摘要不是这两文格式的逐位拷贝，但“元数据指示空组并跳过读取”属于明确强先验。

**A移植完整度：**有序NRV、物理H4读合并、真实源载荷和消费者完整K864已实用；并非完整Gustav CPTB局部膜状态、权重行分块、多PE和整芯片，也非LoAS完整FIRE/TPPE。这些缺项限制整架构比较，但不抹掉已经完成的局部NRV迁移。

对原目录少0.696%–4.234%服务；对同摘要且预取的普通扫描，两个commit摘要只再少0.110%–0.136%。因此正收益大头属于格式/空字跳过，形成时机只是小增量。dense/corner第二摘要反而比只在source形成多751槽，是有用反例。N=3的原因是当前新增的本质是已有格式的生产时形成，未取消目录物化或建立不同消费次序；不是因为“小于某个百分比就不新”。有功能SV原语但未迁36条CPU链到RTL，不能报完整RTL加速。

### 4. 门条件Q8/full-D/phase：接口比“普通量化”更具体，但已实现放置不合算

实际函数是`q=clip8(RNE((x-Dg-c)/s))`，再重建并送连续U/V；g来自已经真实生产的T10门。这里的“门预测”是**门用于预测连续x的基值**，不同于“提前预测门而停止PSN”。不能拿SparseInfer/BitFair的门提前终止直接当此函数的等价最近邻。

强先验选 [Jacob 等，CVPR 2018，§2.1–2.4](https://arxiv.org/html/1712.05877) 的仿射整数推理、尺度/常数外提，以及 [Phi，ISCA 2025，§3.1–3.2](https://arxiv.org/html/2505.10909v1) 的模式预计算和有符号稀疏修正。前者固定仿射参数，后者对象是二值模式并匹配模板；**本项目使用已存在的门作为连续残差编码条件**，不是两者的逐项相同实现，因此不能仅说“量化/LUT已知”就给零分。残余新意是同源异质输出之间的条件编码契约，而非Q8或查表本身。

**A移植完整度：**原U/V RNE/sat/bias次序、fixed/affine整数直消费、完整full-D CSE、真编码Dg、独立Ug、有限96RF spill与真实CR控制都已经完成。未复现Phi模式学习/匹配/架构，且本项目g并不需要额外Phi匹配器。现在可以停止说“full-D还没适配完”；已适配的这个放置结论为负。

fixed/affine码相对同函数展开少0.73%–1.34%，但比不同函数raw慢0.70%–2.06%；full-D码比自身展开慢2.41%–3.18%。质量只有该旧R24父的diverse10：ordinary full-D 1.168702647优于其fixed/affine；lifting普通affine 1.180753363优于full-D 1.203848848，不能继承新320学生825。[同函数比较](../../production_fusions_20260913/encoded_consumer/comparisons.csv)

**相位负结果的确切边界：**`phase_execution.py::encode_decode_h8/u_h8`先得到q，求z=q+floor(b/2048)，真实以16bit写读SRAM，然后恢复I24进入原U。它没有执行普查提出的`2048·(U z)+U δφ+常数`。因此2,095,499对2,057,099的+1.8667%淘汰的是这条额外spill边界；不能叫做“窄操作数分解已失败”。另一方面，商余恒等式及tie parity正确性本身不构成硬件主创新；`U δφ`、LUT、索引、额外MAC和宽度真实收益还未闭合。[代码](../../production_fusions_20260913/encoded_consumer/phase_execution.py) · [精确普查](../../production_fusions_20260913/encoded_consumer/PHASE_PROBE.md)

N=4.5在没有性能优势时仍保留条件编码本身的差分；P=2.5反映硬件正主张不足，C=5.5反映当前布局已完成而不同接口尚未完成。暂不把其列为唯一下一实做优先项：现有机器用同宽PE，即使数学上变窄，也不能免费减少MAC槽。

### 5. 物理源组剪枝与34：两件工作，不能合并证据身份

普通34是T10时间矩阵的3/3/4块结构；`source_execution/run.py`仍加载全部T10输入并产生全部T10门，源SR64/SW64基本义务没有因系数从100变34而整体消失。因此303周期、825 AEE1.421461096是**普通结构化算术削减**的有效性能/质量折衷，不能写成物理I24源字共同删除。34比NB0好0.02389，但18序列中仅14个均值更好；仍按用户整体NB0门准入，不追加逐序列门。

另一支真实物理实验是旧父sn2的global/phase/row-phase H8 mask及`pruning/source_address_iterator/execute.py`：共同H4读合并后，iterator确实能少发部分物理读，原raw I24和PED义务保留。对同mask最强predicate，净差约−0.025%至+0.123%，global/interior反而多168槽；不能用被删spike比例约14%冒充源事务或服务下降。[地址接口](../../pruning/source_address_iterator/README.md) · [该身份AEE](../../pruning/aee_results/README.md)

最强先验是 [Bishop，ISCA2025，§3.2、§4.1](https://arxiv.org/html/2505.12281v1) 的token-time组活动、组级跳过与BSA训练，以及 [DepGraph，CVPR2023，§3](https://arxiv.org/html/2301.12900) 的跨算子依赖组共同结构剪枝。两者分别覆盖“训练整组稀疏”和“把依赖绑在一起删”；本项目可剩的差分是**由二值门、连续PED、raw残差、回退及后续复用的全部需求决定一条实际物理请求可否取消**。仅加共同mask、或将逻辑依赖叫成物理闭包，都不足以构成新接口。

**A移植完整度：**固定H8分组、掩码恢复、共同地址迭代和两个真实消费者已经局部迁入；34本身已有匹配恢复、825、源RTL。没有Bishop完整BSA/ECP/异构核、DepGraph自动依赖图，也未完成Pro/Grok所提HiNM二阶＋双轴置换等强布局选择。这里不据此要求一次复现所有论文，但不能声称“完整强剪枝A已移植”。N=4承认物理需求目标的具体性；其尚缺实做接口，当前34与iterator均只能作底座。

## 原始Pro/Grok建议的有效部分和过期部分

已读两份Pro原文的对应F1/F2/F5段，以及最近相关Grok原文`survey_ab_fusion_20260910/f1_f2_paper_design.md`、`f3_f7_paper_design.md`、`FUSION_RTL_ROUND3.md`。采纳它们区分“门已定/连续值已就绪/状态可释放”、物理请求需全部消费者共同放弃、玩具RTL只验表达力、负结果只约束具体布局的要求。Grok MP3仍扫描W拍，只降低emit；MP5的8/11/16拍玩具不能裁决真实源图融合。

## ONE：最值得下一次实做的接口

**选择“真实source门commit → 保序K864供数 → 第一个preview-U消费者”的直接交接。** 目标是让已经生产的H4/H8门载荷在同一有限Machine内被第一次消费，删除目前仍存在的对应SR首读以及可合法消除的NRV目录写回/重读。它不是再生成一份占用摘要，也不是保存46,080B anchors后轮转。普通dense、lifting和34必须同样拥有该接口。

这是本评审的独立优先建议，**不要求打断root本轮已在执行的24项跨帧margin缓存**。缓存可按其既定边界收口；此处只选一个之后更直接回答“生产顺序是否能成为结构/双消费者接口贡献”的实做对象，不新增并行实验。

固定边界可用已有两项dense/lifting＋34、既有两个halo和共同96RF/128KiB状态/系数/原端口。在同一个执行器中把source H8实际commit载荷交给有容量限制的gather/保序入口，按原c-major K864次序发给preview-U；之后完整preview/sn2、updated门与连续PED继续原函数。只允许重排独立源pixel/H8的生产，**不改lifting内部半步或RNE、浮点preview的累加顺序、原门阈值**。若一个源字还供相邻anchor/后续消费者使用，它仍需保存；不能以首个消费者已用完为由删掉全部SW或raw I24。

三个固定强控制是：①当前完整CSE＋普通P1立即消费；②当前最强扫描/producer双摘要；③同生产顺序但仍真实物化/读回的控制。它们共同拥有直供、暂存、预取、重算等权限。第③臂隔离改变source顺序的代价与取消物化的收益，避免再次把更弱分母的差额算成X。

先在代码中明确每条可取消请求对应的真实使用者与缓存生命周期，再执行；若发现保序/halo复用迫使所有原读写保留，则这个接口本身就没有目标义务可删，不靠扫队列续命。若有实际删除，则看付完gather、RF保存、仲裁、目录、系数及真实外送之后的同函数总服务差，继续保留完整数值0差和固定压力。**不要求某个预设百分比，不将CPU槽称RTL周期，也不承诺标题。** 若收益仍被普通已知融合完整解释，代码留下作A；只有可解释的新保序/释放契约超出强普通控制，才重新评N和晋级。

优先它的原因是现有metadata已经证明了真实源字和完整K864入口，同时其commit增量被强扫描压到约0.1%；这暴露出下一条应改变的具体费用——首读和目录边界，而不是缺一份新稀疏率表。相位因子化更依赖尚未证明的窄PE收益，物理共同剪枝还需要新的布局/训练选择；本接口可以用现有函数先回答一个硬件因果问题。**该建议本身的概念新颖性仍只约3–5分，不能当成已找到高分X。**
