## 测量边界

1. 起点是完整native投影捕获、全K864源支持证明的tag和真实连续q24。源tag并非用浮点raw==0猜测；原始生产者整帧重放、tag/压缩形成吞吐仍不在本段服务内。
2. sum/sumsq使用原单遍两条带256叶配对树，方差为E[x²]−E[x]²；相比旧中心化两遍公式，FP32顺序已改变。这里只证与同公式参考逐位相等，**不继承旧AEE或CUDA位身份**。
3. 两个ready学生、一个ordinary固定背压构造而已；不是825帧/整网时间，未测RTL、DC/PT、Formality或PPA。
4. 先前default-reference第三臂与普通融合同价，本轮省去重复臂。此处35%–39%的基线改善不作为新机制增量。
