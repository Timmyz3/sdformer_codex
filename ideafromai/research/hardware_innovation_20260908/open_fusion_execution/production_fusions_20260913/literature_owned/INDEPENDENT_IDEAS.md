## I01 — Threshold certificate with consumer-selected evaluation order

- **Idea:** evaluate preview dot products in a fixed coefficient-block order and stop an output only when a remaining-sum interval proves the final sn2 bit.
- **Assumption:** enough outputs lie far from threshold to pay for bound metadata and branch/compaction work.
- **Prediction:** exact output bits with fewer issued weighted-source operations after counting interval tests and lane underfill.
- **Disconfirmation:** comparisons, bounds, and fragmented active rows consume the saving on the shared single-issue core.
- **Uncertainty:** prior coverage of threshold bounds and whether dynamic issue order is legal at this interface.

## I02 — Small binary-pattern lookup shared by downstream consumers

- **Idea:** encode 3–4 adjacent sn2 bits as a pattern index; a small coefficient-dependent table emits joint partial sums for Conv2/merge and binary projection, leaving continuous PED explicitly separate.
- **Assumption:** the 512×128 ROM/coefficient budget can hold useful table slices, and lookup extraction costs less than selected additions.
- **Prediction:** exact binary-path arithmetic savings after table fill, address, decode, and carry costs.
- **Disconfirmation:** coefficient-specific tables exceed residency or lookup gives no advantage over existing CSE/PoT.
- **Uncertainty:** substantial overlap with existing M4RM or neuron lookup controls is possible.

## I03 — Signed temporal transitions as an exact sn2 consumer interface

- **Idea:** represent consecutive sn2 vectors by a first vector and signed transitions in {-1,0,+1}; fuse Conv2/merge with a recurrence over time rather than independently applying it to ten bit vectors.
- **Assumption:** temporal transition density is substantially below absolute spike density after charging reconstruction and state.
- **Prediction:** exact output currents and fewer issued additions when successive spike frames are correlated.
- **Disconfirmation:** transitions are denser than spikes, or the output-state/replay traffic exhausts state and RF budgets.
- **Uncertainty:** delta encoding may already be covered; noncausality permits reordering but does not create correlation.

## I04 — Projection/PED common rowspace with explicitly charged residual

- **Idea:** factor the continuous PED operator into a component of an already needed pre-threshold projection current plus an explicit residual operator; retain useful currents until both consumers finish.
- **Assumption:** the operators have sufficient common or nearly common rowspace; exact residual can be low-complexity, or an approximate residual can pass the fixed student quality floor.
- **Prediction:** joint operator cost falls while PED error and full task quality remain acceptable.
- **Disconfirmation:** nonlinear boundaries prohibit sharing, or the residual is dense enough to erase common-component savings.
- **Uncertainty:** source tensor and operator compatibility have not yet been established.

## I05 — Pattern-complement duality for binary stencil accumulation

- **Idea:** per fixed input block, choose the smaller of the active and inactive bit set and correct with the coefficient block sum; share that block sum across Conv2/merge consumers where exact algebra permits.
- **Assumption:** blocks have skewed occupancy, especially near high-density thresholds, and polarity metadata is cheap.
- **Prediction:** exact min(popcount, block_width-popcount) weighted additions plus one correction beats both dense and spike-only controls on some real layer.
- **Disconfirmation:** occupancy is near half, sign correction dominates, or the strongest baseline already contains this identity.
- **Uncertainty:** this may be an implementation control rather than a new research contribution.
