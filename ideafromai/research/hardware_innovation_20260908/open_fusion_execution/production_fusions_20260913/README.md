## 目标成本与“借完整”的边界

这轮打在真实patch残差局部链的门供数和连续PED上。ordinary34/interior两目录占该局部链约14.02%；摘要能削掉其中一些空读，但不能删原PSN或连续PED。Q8入口直接改变真实连续U的输入读，而它的编码与后段仍未闭。没有把历史patch约35%套成这两个小窗口的整网收益，也没有用一张叶表证明系统加速。

完整复用的是本仓已有CSE程序、真实常量/原舍入边界、实际RF/SRAM/系数响应和局部消费者。Gustav、Prosperity、Phi、MiLo是比较来源和明确接口借入，**本轮没有完整复现它们整颗芯片、原模拟器或GPU内核**。每项最近邻和未借部分分别见子报告；改放置或改名本身不算X。

Pro两份报告、Grok F1/F2及F3–F7设计被重新读入。另核对七篇原始来源，覆盖CVPR、NeurIPS、ISCA、MLSys、TRETS等，见[来源与全文位置](literature_owned/PRIMARY_SOURCES.md)。这不是重新全文穷读775实体；总目录和未读/未试记录仍保留。[本轮方法与技能引用](METHOD.md)说明用了两科研技能哪些环节及其局限。
