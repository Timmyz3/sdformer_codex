# Patch r1：用有界神经元输入换取可取消的卷积生产

2026-09-08。本轮只保留这一条训练候选：**将固定 BN 后的 PSN 输入范围变成学生定义的一部分，以严格区间证明提前完成 0/1 门，再取消没有未定消费者的 Conv1 时间列。** 这比给 Conv2 块 OR 加一个损失项多了一种执行行为；现有数据尚不足以把它升为主贡献。没有启动训练或 RTL。

## 当前问题及完整先验

目标是昂贵的 patch residual r1，`conv1 → fixed norm1 → sn2 → conv2 → fixed norm2 + shortcut`。源与出口仍为 `θg`，连续幅值 θ 与判决偏置/阈值不同。共同四处 patch BN 固定学生 full825 AEE=1.203184；row34=1.203511。原 rank2/3 控制已真正按两因子执行，但把 R 移到 Conv 前会把稀疏权重加法变成连续源 MAC：真实源计数增加约7%–61%，不能只报时间维变小。

## 唯一候选及新增行为

定义一个新学生：`x_s=clip(BN(Y_s),l_s,u_s)`，`g_t=1[Σ_s A_ts x_s+b_t≥θ]`，出口仍为 `θg_t`。先保留 row34 的34连接和完整十个输出，训练 A、偏置及有限区间；不把原 FP32 模型宣称为无损。当前 CPU 初筛仅校准每时间列共享的上下界，未训练。

已生产列集合 S 的部分膜为 `m_t=Σ_{s∈S}A_ts x_s+b_t−θ`。剩余项的合法区间为

`L_t=Σ_{s∉S}(max(A_ts,0)l_s+min(A_ts,0)u_s)`，

`H_t=Σ_{s∉S}(max(A_ts,0)u_s+min(A_ts,0)l_s)`。

`m_t+L_t≥0` 即完成门1，`m_t+H_t<0` 即完成门0。未定门仍执行原完整函数。只有同一 P4×H8 请求组内**所有依赖列 s 的门**都完成，才取消该组的 Conv1 时间列；320门不必全部同时完成。θ 的幅值不参与“是否可取消”的偷换。实际定点实现须采用向外舍入的界，当前 Float64 校验不是该定点证明。

裁剪本身也收费。固定BN为 `a_hY+b_h` 时，可将区间反变换到rawY域后再折叠BN；负a交换端点，a=0作为常量。这避免新增动态除法，但需要每(t,h)两端点、每个实际生产值的比较/mux，以及相应定点范围和零值常量补偿。当前CPU表尚未计入这些服务，不能把clamp当免费。

这与 SpikeX 的实际区别是：输入仍有活动、权重仍非零，但其消费者已经不可改变，所以能停止生产。与 SnaPEA/BitFair 的区别是：停止对象不只是一个点积后缀，而是多门依赖并集解除后，一整列尚未生成的卷积结果。**普通逐门区间判断＋依赖短路也能得到相同语义，必须作为强实现控制；单有这一接口尚不是排他的电路新意。** 候选真正待证的是训练范围/裕量后，取消请求能否足够集中，值得有限状态实现。

例：两门为 `2x0+0.1x2≥1` 与 `2x1+0.9x3≥1`，所有输入限于[-1,1]。已知x0=1、x1=0.1时，第一门必为1，可取消仅服务它的列2；第二门仍需列3。普通整字同时判决此时尚不能退休两个门。将该例复制到请求组内32个 `(p,h)`，公共列2才真的可取消。反例是其中一个消费者落在阈值附近，公共列不能取消；逐门确认率很高仍可能几乎不省取权。范围过窄也可能裁掉少量但关键的光流特征。

## 一次训练的最低门与当前判断

有限valid10语义检查及四条已授权完整825比较均已完成。若进入训练，仅用共同train32，初次只开放34项A、10偏置与20范围参数，主干/Conv权重固定，使用真实Conv2及最终flow蒸馏。强控制至少是同参数预算的 PACT式裁剪恢复、同训练数据的 SpikeX块占用费用恢复、以及同裁剪模型的普通逐门严格界执行。候选额外目标应计**未定消费者保留下来的 Conv1 实际活项/请求＋PSN重复判断＋真实Conv2**，不能拿更低发放率冒充新增取消能力。

本轮主观概念潜力 **6/10**，当前净收益证据 **3.5/10**，均非录用概率。已有明确可测行为，但温和范围只省4.2%活项，强行裁窄又损伤稀有门；费用可能被比较、重算和普通裁剪/剪枝吃掉。只有相同精度下优于这些完整控制、并留下足以覆盖状态与供数的余量，才值得进入电路；否则停止本版本，不把未训练当作所有有界神经元思想失败。
