# R3Q06 — 训练时支持：改硬件必须产出什么（独立开题）

身份：AT-LIF 输出 \(\{0,\theta\}\)，层共享 \(\theta\) 吸入下一层 \(W\)；脉冲路径是 0/1 GeMM。残差 / PED / I24 是另一条连续张量。禁止不可吸收 int8 payload、禁止 MX3P / 换神经元。

预算：lifting 相对同预算对照约 +0.013，未过 +0.005；**唯一成对恢复留给 AEE**。本问所有候选不得把该恢复花在 FireFly 式二值支撑密度当标题。GrokBot train-binary-support 已是停标题类。SENECA 阈值+膜正则、DATE QAT 拉高发放稀疏、SpikePool 最大池化注意力（GPU 算法）都是必须抄全的 A，不是 X。

状态：candidate，无打分。学生允许改的东西写在每卡；未改 lifting 系数、未占用该成对恢复。

## R3Q06-I1 冻结 lifting 上的分型 last-use 证书

**主张：** 不重训 lifting，只训一个廉价辅助头，预测「吸完后的二值 GeMM token」与「连续 PED 张量」各自的 last-use 时刻；硬件必须产出两路 typed kill / last-use 标签，而不是默认双消费者共寿命。

**A：** SENECA 正则化阈值与膜电位以适配神经形态核；DATE 用 QAT 增加发放稀疏；FireFly 族训练二值/位图支撑密度；GrokBot train-binary-support 同类。它们都不产出**分型 last-use 证书**。

**B：** 吸 θ 之后仍可能存在二值门与连续 PED 的双 last-use。G1 在 8088 wait-class 未拆开前不得当标题。现有训练先验改的是发放密度或膜动态，不改两路寿命是否被绑在同一 wait-class。

**X：** 训练目标是寿命证书，不是稀疏率。辅助头读已冻结的门与 PED 轨迹，监督「此后无消费者」；λ=0 即退回今日双 last-use。不碰 40 个 lifting 系数。

**学生可改（不烧保留恢复）：** 只训辅助头 / 证书损失；主干、θ、W、lifting 冻结。证书错了只杀掉该头，lifting AEE 预算仍在。

**硬件必须产出：** 每 token 的 `last_use_bin` 与 `last_use_ped` 两比特（或两路计数器到期），以及允许单路 kill、另一路继续的握手。禁止写成「连续 AT-LIF 幅值被两个 MAC 共用」。

**禁止碰撞：** 不得把证书训练写成 FireFly 位图密度、不得用不可吸收 int8 幅值当 payload。

**杀掉：** 证书在冻结轨迹上若不能拆开 8088 同类等待，或 typed kill 不减少同资源净服务，停该头，不启动成对 AEE 恢复。

## R3Q06-I2 T 相位占用 / 展开模板（不是密度）

**主张：** 正则化的是 T10 **何时**发放，使占用落入可编译的 Spike-IAND / FireFly-T overlay 时间槽模板；发放率可以不变。硬件必须产出模板 ID 与槽占用，而不是更稀的任意 bitmap。

**A：** DATE QAT → 更高稀疏；SENECA → 阈值/膜；FireFly 训练支撑密度；Spike-IAND 的 T-unroll 是执行侧。把「再稀疏一点」当训练标题已被停。

**B：** 本网贵段是 T10 源与双消费者排程，不是分类网络的发放率。稀疏正则不保证 overlay 槽可静态展开；8088 长背压四臂持平说明 wait-class 与占用有关，与平均密度无关。

**X：** 损失惩罚的是「偏离合法 T 槽模板」，不是 \(\|s\|_0\)。同一密度、不同相位，硬件合同不同。

**学生可改：** 在冻结或近冻结主干上加相位对齐损失；若必须动 PSN bias，只允许短探针，且 **禁止** 为此调用 lifting 成对恢复。精度若掉，停相位损失，不拿保留恢复去救。

**硬件必须产出：** 每通道（或每组）一个小模板 ID + 槽掩码；执行器按模板展开 AND/累加，而不是运行时扫任意 0/1 向量。

**禁止碰撞：** 标题句不得出现「训练二值支撑密度」「FireFly-S 联合剪枝量化」。不得把模板 ID 做成不可吸收的幅值码。

**杀掉：** 同密度对照（只打乱相位）若精度/服务无差，或模板集大到退回任意 bitmap，停。

## R3Q06-I3 吸后双核路由比特（DATE 混合核的 typed 差分）

**主张：** DATE 的 dense/sparse 双核 + QAT 稀疏是 A。本网在吸 θ 之后，学生只允许再训一个 **路由比特**：二值脉冲去 0/1 GeMM 核，连续 PED/残差去稠密连续核。硬件必须产出 typed 分流，而不是「更稀所以走稀疏核」。

**A：** DATE hybrid dense/sparse cores，QAT 提高 spike sparsity。Prosperity/Gustav 的稀疏 GeMM 底座仍是对照，不当本卡标题。

**B：** 吸完后脉冲已是二值，DATE 的「靠 QAT 变稀再换核」不再是新合同。未解决的是连续 PED 与二值 GeMM **不同核、不同 last-use**，而不是稀疏度阈值。

**X：** 路由监督的是消费者类型（门 vs PED），不是密度分箱。λ=0 退回单核双消费者。

**学生可改：** 冻结 lifting 与 AT-LIF θ；只训 router（可从已有门/残差特征读出）。路由若伤 AEE，丢掉 router，不占用保留恢复。

**硬件必须产出：** 每包 1-bit `route∈{bin_gemm, ped_dense}`，两套端口与完成/ready；禁止把 PED 塞进二值核，也禁止把 0/1 脉冲再扩成 int8 payload。

**杀掉：** 若路由几乎恒为一路，或同资源相对「单核 + 普通稀疏」无净服务，停。不得为救路由去重训 lifting。

## R3Q06-I4 只正则连续 PED 轨（SENECA 的消费者差分）

**主张：** SENECA 的阈值+膜正则作用于发放神经元，是 A。吸 θ 后发放神经元已是 \(\{0,\theta\}\) 可吸收。把同类正则 **只打在连续 PED/残差消费者** 上，逼其动态范围/寿命变成硬件可杀的短整数轨；脉冲路径保持 0/1 GeMM。

**A：** SENECA threshold and membrane regularizers；DATE 稀疏 QAT。身份禁止把 AT-LIF 再改成不可吸收幅值或 MX3P。

**B：** 膜正则若打在 AT-LIF 上，最多再造 DATE/SENECA 稀疏，且容易滑向「保留 θ 当 payload」。真正贵且未训练的是连续 PED 的字宽、存活长度与 last-use，它不是脉冲。

**X：** 损失在 PED 张量上（范围、提前 last-use、与二值门去相关），不在 \(s\in\{0,1\}\) 上。脉冲轨合同不变，连续轨合同变。

**学生可改：** PED 投影/短读出头与其正则；**禁止**改 θ 的不可吸收性、禁止改神经元类型。尽量冻结 source lifting。若 PED 头是新函数，用 32/10 探针自带杀门，不用保留的 lifting 成对恢复。

**硬件必须产出：** 更窄/更早 kill 的 PED 字，以及与二值 GeMM 分离的 last-use；脉冲侧仍是 0/1 × W。

**杀掉：** 正则后 PED 范围/寿命不变，或门与 PED 仍同寿命；或为压 PED 而把误差赶到 lifting 上并要求动用保留恢复——直接否决该布局。

## R3Q06-I5 有限时间字母表（模板 ID，不是通道支撑字典）

**主张：** 每个通道的 T10 发放串必须落在很小的合法字母表（例如 8 个时间模板）。硬件产出模板 ID，按 ID 展开，而不是 LUT-NN/GrokBot 那种 **通道支撑码 → 部分和表**。

**A：** GrokBot train-binary-support（停标题）；LUT-NN / 有限二值发放字典；FireFly 位图支撑；Spike-IAND T-unroll 执行。DATE 稀疏不约束时间形状。

**B：** 已有「训练二值支撑」把空间/通道支撑变成可查表集合，标题级已停，且会诱使把唯一恢复拿去救密度学生。时间字母表未作为**不改 W 支撑密度**的训练合同试过。

**X：** 约束在时间轴形状，W 的非零模式可以不动。消费者仍吃 0/1 GeMM；变的是时间展开控制面。

**学生可改：** 对发放串加模板投影（硬前向/软反向）或 STE 到最近模板；尽量只动 bias/短时常数，不动 lifting 因子。字母表学生若掉点，杀掉字母表，**禁止**用保留 AEE 恢复去圆。

**硬件必须产出：** 每通道/每组 \(\lceil\log_2 K\rceil\)-bit 模板 ID 与只读模板 ROM；禁止把 ID 解释成幅值 payload。

**杀掉：** \(K\) 大到接近 \(2^{T}\)；或与「同密度、自由时间形状」对照无编译/服务差；或退化为通道支撑字典（滑回停标题类）。

## R3Q06-I6 冻结 lifting 的 preview-V 槽预算控制器

**主张：** Codex 观察：preview-V 微核普通角 10396 槽；推迟 V 直到 native BN 完成是整数 0-diff 且 `arithmetic_saving=0`。学生只允许训一个 **issue 控制器**：哪些 preview-V 活集可在编译槽预算内发出。硬件必须产出带预算的 V-issue 证书，而不是新算术。

**A：** DATE/SENECA/FireFly 都改发放或权重；SpikePool 改注意力算法。BN-before-V 本身是卫生/顺序，不能当算术标题。

**B：** 0-diff 顺序不产生算术节约；10396 槽是占用问题。未试过用训练（而非手工扫描 low8）把 preview 活集压进固定槽预算，同时保持 BN-complete-before-V 的 0-diff 身份。

**X：** 训练目标是槽占用证书 + 合法 issue 集合，不是稀疏发放。BN 顺序锁死为 0-diff，不另开 BN 标题。

**学生可改：** 只训控制器/门控读出；lifting、V 表达式、BN 仿射尽量冻结。控制器失败不影响保留恢复。

**硬件必须产出：** `bn_done` 再 `v_issue` 的握手，以及每块的槽预算计数；超预算则拒发而非改算术。

**杀掉：** 相对「固定 BN-before-V、无控制器」若净服务不降（与 `arithmetic_saving=0` 一致则停标题），或控制器改变数值函数却去要 lifting 恢复。

## R3Q06-I7 事件前端合同：学生改吃芯片已产出的计数/极性，不改脉冲幅值

**主张：** ASNA-Flow / ERAFT FPGA / SNE 等事件光流硅已产出事件计数、极性、时间面之类前端。学生只允许把浅层输入合同改成这些 **已存在的硬件前端量**，使本网不必先物化稠密帧再走 AT-LIF。吸 θ 后内部仍是 0/1 GeMM。不把唯一恢复花在内部二值支撑密度上。

**A：** 事件光流硅与 ERAFT/SNE 是任务/前端对照；SpikePool 是 GPU 注意力算法；DATE/SENECA 是核内稀疏与膜正则。

**B：** 本网冻结学生仍偏帧/体素链。内部 GeMM 稀疏训练不改变「硬件前端必须先变成稠密激活」这一产出。前端合同与内部 FireFly 密度是不同生产者。

**X：** 训练的是输入接口与浅层适配，不是 \(s\) 的通道支撑。内部身份保持可吸收 \(\{0,\theta\}\)。

**学生可改：** stem / 浅层适配层（32/10 或短预算）；主干 lifting 冻结。前端学生自备 AEE 杀门，**显式不是**那次 lifting 成对恢复。

**硬件必须产出：** 与对照芯片同类的计数/极性/时间面 token，而不是新的不可吸收 int8 事件幅值。其后 AT-LIF 仍吸 θ。

**杀掉：** 浅层适配代价吞掉前端节约；或精度只能靠解冻 lifting + 保留恢复才过 +0.005——该布局停，不挪用。

## R3Q06-I8 二值池化证书替换注意力式归约（SpikePool 的硬件合同，而非 GPU 算法标题）

**主张：** SpikePool 用 max-pool 做注意力是 GPU 算法 A，不能当硅标题。学生只允许训一个 **吸后 0/1 上的池化/argmax 证书**，让某路消费者 last-use 的是池化索引+二进制掩码，而不是再开注意力 GeMM。硬件必须产出比较树与一次 last-use，而不是新注意力核。

**A：** SpikePool max-pool attention（GPU）；FireFly 位图密度；DATE 稀疏 QAT。本网注意力行内复用/K=0 已有旁路边界。

**B：** GPU 上把注意力换成 max-pool 不规定双消费者谁 last-use 池化结果。吸 θ 后比较树是合法二值操作；未训练「池化证书作为 PED/门之一的最后消费者」这一合同。

**X：** 训练监督池化位置/掩码，使注意力式归约从必须产出的硬件集合里消失；密度正则不是目标。

**学生可改：** 只替换指定归约消费者的读出（池化头），冻结 lifting 与 AT-LIF 类型。该头自带 32/10 杀门。禁止为对齐 GPU SpikePool 精度去动用保留恢复。

**硬件必须产出：** 比较树、argmax 索引、二进制掩码的单次 last-use；禁止把池化改成携带 θ 的模拟幅值再入下一层（θ 只许吸入 W）。

**杀掉：** 相对「普通 0/1 GeMM + 不换注意力」无服务差；或池化头逼出不可吸收 payload；或需要重训 lifting 才能过相对 AEE 门。
