# 本轮执行问题与比较边界

先验底座：固定支持码/乘积预计算、宽广播、局部持久累加。待解决洞：已训练支持码减少逻辑加法，但表更宽，真实 bank 请求、暂存和完整 PSN 可能吃掉收益。

第一实验在同一个 RTL 中比较 direct bit / LUT16 / LUT10 / LUT10+零响应字目录。输入为已有学生投影后的原96bit g′，RTL 自己判码、处理逃逸；没有实现前级最近码投影。保留 P32 T10 H96，真实 W、完整 Q14 时间矩阵、48位阈值与正负/常量出口；Y、U 都在 RTL。直接模式也享有宽广播、第一次写零省清空、系数零 bank 门控。各模式同96路 ALU/MAC、8bank×128bit、24word(384B)预取池、4个描述符。模式共享实现不等于已经证明相同频率/面积。

计费：片内参数读取、源码输入、系数请求/返回、FC1流水、Y、完整PSN、输出背压。表在 SRAM 的首次外存装载、前级投影、四个H块之间的重叠、FC2/BN2/shortcut不在测量范围。SRAM布局不超过128KiB；参数端口装载也计入。debug Y/U 是测试观察端口，不计成应用接口输出带宽。

第一判断：真实32病例总服务、系数字节和队列峰值，不能把向量加法或旧CPU37.94%当本次RTL周期。零源/逃逸/负gain等5病例仅功能诊断。两种背压条件；数值独立dense整数参考，不跨原整数学生的比较边界。新颖性需在该底座以外给出差分；单独紧凑LUT与零目录不当新标题。

有损响应投影另由 probe_response_projection.py 比较普通同稀疏W剪枝和自由L，不共用未改变的gold，不声称AEE。光流依赖单独分析，不与FC1结果相乘。

在首轮完成后追加一个有边界的执行比较：响应等价投影 W′ 已由独立探针得到，新增 mode4 普通完整 H96 内容去重。编译器只根据真实 W′/D 生成 class map，RTL 读取48B当前H块映射并合并目的mask；不赠送运行时源统计。与同 W′ 的mode2比较，不与原函数借精度。四个H块的class map共192B，SRAM最高使用地址8161，仍在8192字内。没有把该通用去重算作原创X。
