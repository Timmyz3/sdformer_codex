R2最终版本也比416bit四P控制少4.802% / 6.073%服务；时间端点两域则分别慢1.167% / 3.373%。候选z口208bit、强控制416bit，但R2另有class/代表存储和地址mux，端点有第二z域，因此只能说**在这些显式资源点下的周期结果**，尚无等面积或能耗结论。不能只保留较弱双P分母。

静态metadata需要摊销：八个真实fixture各自重新冷配置时，R2最终版本116856拍仍慢于native114495拍，差2361拍。正收益目前来自参数只加载一次的连续64块；不是任意短任务都更快。相对同32bit count20，最终配对的计数读、写各由1348152降到1078416B（原64），但旧20bit count19到32bit count20曾增加字节流量；这些阶段不能拼成未经测量的能耗下降。

固定顺序`[8,2,6,3,9,4,1,5,7,0]`只用同帧输出tile0–31校准一次，后续不重选。128–191与校准虽输出tile不同，输入halo仍共享12480个源word；4000–4063的源行49–52与校准源行0–2完全不重叠。**两组仍是同一帧，不是跨帧/跨序列泛化。** 输出按原T恢复，TB没有重排source/gold或赠送中间结果。

## 2. 为什么这次是针对失败原因修改

**R2原迁移失败：计数化省去了重复z更新，却新增密集扫描、计数RMW和标量退休。** 原八块raw核心113475拍，比直接87599拍慢。实际适配链为：活动块遍历98767 → 首触/有效块95142 → 合并检查与读90483 → 复用原乘法器双P退休87198 → count8/psum复用84246。原对照始终保留，不能把修复稠密控制的全部收益叫新颖性。

count8由静态class频次≤255保证，超界类走原direct，不截断、不丢任务。Q1计数与后续Q2输出生命周期不重叠，复用原8bank×480×32的p_mem前160行；所有计数退休后才允许Q2覆盖，并由实际bank地址选择供数。原独立6400B计数阵列消失，但有效位、holding、地址mux与代表metadata仍收费；删除数组不是面积结果。

进一步融合的是**固定时间配对**：端点实验揭示已到齐的T10可以在线性层内部换执行顺序；R2无需使用有符号端点，只把共同活动的时间位置配到同一个计数字中。于是保留非负count8和单一z域，省掉更多计数RMW，不额外支付端点prefix/merge。原64块count更新52595→42026，退休读块6482→6195，实际代表退休19140和Q2 MAC198720不变；核心净少`2×10569 + 2×287 = 21712`拍，额外1配置拍后冷服务少21711拍。没有把两条百分比相乘。

这是具体多机制融合的正结果，仍不能称新代数。UCNN的sum-first、精确signed packing、存储生命周期复用和重排都已有先验；待证明的增量是这些表示与真实消费者完成边界的执行组织，而非替旧方法更名。该接口当前仍只到raw。

**时间端点原迁移失败：原T序中孤立脉冲多。** 本轮先实现每K双域选择，原八块仍94655拍；必要条件过滤/lazy clear降到87913，依然略慢87599。固定时间序改变这个失效条件，实际更新下降后两域成本才得以偿付。同排列的单域全端点也已实现，避免把排序收益全归给混合选择；但它尚未胜过较宽端口的原生四P，不能升为主标题。

**DA不是一看到慢就停。** 构表延迟、空/小rank旁路、付费位置选择、扣除已付选择费后的再决策均已写RTL。原八块100043→94823核心拍，仍慢直接87599约8.247%。真实开销由3072构表＋4920编码＋2796DA服务−3564免MAC=7224拍闭合。停止的是这个576B单N8表生命周期；跨tile驻留等其他接口继续保留，不默认免费增加12倍LUT。

**RR借宽链补的是必要强对照。** 完整raw→J20→I24、两context下，64块冷服务模数787603→借链786421，只省0.1501%。实际流没有宽链竞争；构造合法相邻异质tile后，固定consumer优先出现负例，一位组RR改善无BP，暖BP仍有8拍负例。保留它作为共同底座/竞争反例，不作调度标题。

## 3. 复审确实补回了遗漏

本轮补写的接口包括：R2稀疏控制与有界计数、psum阶段复用、时间配对；逐K直接/端点两域、固定顺序与同序单域控制；DA有费混合；RR借宽链及竞争下的适配。16个新执行变体为R2 mode16–21六个、DA mode13/12/11三个、RR mode3/4两个、端点mode1–5五个；强原生0/1/2是原RTL复用，不额外计新机制。

仍然没完成的明确接口：完整Gustav压缩NRV∩W地址/条带、保留原Prosperity森林的联合虚节点/部分lane图、CFMP同预算TC/TR与真实消费者、Q1生产期bitmap流水、真正`Uz+Uδφ`分域直达U、空间R16/Tucker窄整数连续后端、anchor整P启用成本、依据已有粗流/事件的decoder2前置wake。它们写进执行队列，**没有被一次不适配布局否定，也没有假装本轮都已实试**。

相反，完整Prosperity外层、Q8/full-D消费、旧U16端点、普通单遍BN早已做过，不能继续标成完全没试。有效普通迁移保留为A；尚未搬完原论文的组件明确叫补A，不把局部重写说成作者完整加速器复现。
