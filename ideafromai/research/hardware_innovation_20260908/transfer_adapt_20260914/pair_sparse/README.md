**资源与精确性。** 两臂共享同一union资源声明：八条32bit分段ALU、八个signed19×13乘法器，原208bit z向量口，原Q2缓存/psum。字典实际额外使用8bank×320row×20bit=6400B计数、2592B class和96B代表表。适配再用1280bit寄存器有效位以及活动位图/选择器。有效位在tile启动时并行清零，计数SRAM没有大批免税清零。银行每拍同一地址读或写；无效行根本不读。声明相同资源集合不等于综合后等面积，直接执行不需要这些计数存储。

双位置退休借用[ULPPACK式受界打包](https://proceedings.mlsys.org/paper_files/paper/2022/file/e09d45e14e9ece7142217550ddd3c4d0-Paper.pdf)这一类思想。令低计数a≤255、高计数b≤127，系数q∈[-4,3]，原signed19输入能表示a+2048b。乘积低11bit给出qa，高部分给出qb；q<0且a非零时，低字段借位使高部分少1，使用原分段ALU的高字段carry-in补1。两段均回到原13bit z。越过任一计数门直接恢复原标量退休；全864计数和边界128/256均实际走回退。没有新增乘法器、没有漏掉负号或用真实平均值替代范围判定。[RTL](decomp_core.sv)

验证包含20fixture×6模式×2背压×2无reset命令=480命令、1,843,200个实际raw输出；原14/15的128条历史记录逐字段复现。另有64tile×4模式×2背压×2轮=1024个tile命令、3,932,160个实际raw输出，其中动态source变化验证首次触及有效位。独立穷举数学式覆盖signed3全范围、计数合法域和六种z值；这3145728个字段比较是数学检查，不另称RTL穷举。真实source/weight/output背压由TB施加；外部配置口没有ready，其加载未模拟DDR停顿。
