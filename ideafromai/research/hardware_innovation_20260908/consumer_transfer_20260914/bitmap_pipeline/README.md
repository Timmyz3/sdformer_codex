# 位平面负迁移已通过实际适配转正

2026-09-14。当前R8整数学生的patch r0.conv2，native96×4×4门字，P4/T10/K864/R8/N96，全3840个raw输出。新增四个RTL消融：构造合拍、读执行流水、活动块遍历、单活动位回到原生AAC。原生14及旧位平面15保留并逐字段复现；没有把BISMO整个加速器移植完成。

## A、B、实际改变

A是[BISMO](https://arxiv.org/html/1806.08862v1)的AND/popcount、位平面加权和有界供数重叠。原文已有fetch/execute/result结构及转换单元；本地只移入当前算子需要的执行组织，未复刻其DMA/ISA/完整矩阵overlay。

B来自真实负结果：旧16K三plane映射需另花864拍/tile构造bitmap，所有40个P/T线性扫描54字，并让权重读和pop执行互斥。本轮用同一真实源加载生成bitmap，实际维护live图与一项plane holding流水，最后对单活动位bitmap直接取原Q1 signed3向量累加。单活动位选择在BM_SCAN读回的字上发生，未经TB预选；其余块仍执行三plane。此处是对已经暴露的供数和执行粒度问题的修复。

这四项是一个迁移过程的消融，不是四篇新idea。BM_PIPE有三plane槽和末项排空，空plane仍有判定拍；不宣称全部访存延迟被隐藏。完整bitmap产生后才消费，未实现全层DMA与消费重叠。

## 连续回放与费用

同一实例参数加载一次，每套64块连续两轮无reset，逐块换真实源与origin。冷服务含1824静态配置、每块1537源/origin配置、start、所有输出握手；暖服务只省首轮静态配置。`BP`是实际source/weight/output背压，非公式外加延迟。

10相对14净服务减少16.302%/18.848%。已有更宽416bit z原生四P控制为933565/996457，10在当前资源点仍少11.809%/12.237%；但有额外pop树/bitmap/系数副本，不能称同面积优势。两组仍是同一帧：4000集合与旧固定时间校准源不重叠，本路线本身没有训练或选择时间排列。

数据流量也没有自动变好。128集合10发出70383次128bit plane读、17984次24bit原生Q1读，另有6144次128bit Q2读；原生14只有25237次24bit Q1读和相同Q2读。10减少z向量读写，却增加系数位平面流量。`weight_words`混合不同有效宽度，不能直接当字节数或能耗结论。所有分支用同一weight grant，但低利用率的24bit原生读不能按128bit“实际有效字节”虚增。

## 有限资源与准确性

共享原8×32bit ALU、8×19×13乘法、208bit z服务、520B z和15360B psum。额外主数组为4320B source bitmap、2592B系数plane副本；13/10再有270B live位和54bit迭代状态，另计plane-valid/holding及八棵pop16。40路bit写和live更新是寄存器/位写组织需求，不假装SRAM宏免费支持。模式10增加onehot判定、位号与Q1地址选择，未新增数据ALU。

最终SV已显式把q_mem读合成一个地址mux和读表达式，bp_q每lane也只有一个受使能的读表达式；BM_SCAN的onehot和holding使用同一bitmap读。真实物理时序/面积仍未映射。同模块资源权限不证明各模式独立综合等面积。

Q1覆盖signed3全域−4..3。任意线性部分和界为−3456..2592，signed13可容；Q2 signed16，保守raw绝对界905969664，signed32可容。Q1/Q2间没有新增RNE或饱和。最终输出保持原T/P/N，AT-LIF静态θ已在部署权重中吸收。

[独立重算](verify.py)从source/Q1/Q2重建native和bitplane结果，同时逐条核原生issue、非空16K块、onehot、实际权重/状态工作量和全部FSM周期。2592命令、9953280个raw值通过；568320个不同fixture输出独立重算，50848项计数检查，3024个旧控制字段复现。[机器结果](verification.json)不把重复回放算成独立帧。短流额外覆盖非零→零→非零源，不靠reset清除live图；边界有signed3−4、计数255/256、全零W、padding污染及输出hold。

## 去留与下一接口

保留为有效执行底座，候选新颖性由[独立评审](../review/)另行判断。[BBS/BitVert](https://arxiv.org/html/2409.05227v1)已有位级补集求和与bit稀疏组织，BISMO已有位平面流水；onehot切回普通AAC也不是新代数。不能因为周期转正就换名字充当首创。

两项具体延伸已独立执行：完整FP identity→J20→I24消费在[bitmap_consumer](../bitmap_consumer/)，小位图驻留与额外z读写交换在[bitmap_block_resident](../bitmap_block_resident/)。各自实际测量，不把raw比例乘到完整消费者。

复现顺序：`implement.py`、`run.py`、`run_stream.py --stage short`、`--stage 64`、`--stage disjoint`、`verify.py`，均用Python3.12。Verilator结果属于组件周期；无VCS/DC/PT/FM、PPA、整网FPS或新AEE，生产树与稿件未动。
