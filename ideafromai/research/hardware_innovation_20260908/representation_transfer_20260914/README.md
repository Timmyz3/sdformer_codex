# 两路径继续实试：空间分解、快卷积和结构剪枝

2026-09-14。承接 [上一阶段](../consumer_transfer_20260914/README.md)，本阶段沿用户要求的两条路径推进：有效的借入继续接强后端；迁入效果弱的实现，定位具体费用后另写适配，再与更强普通控制比较。所有新增电路在本目录隔离实现，生产 nts07 与投稿稿件不动。

当前完成的是四条相连的机制线及其控制：位平面供数、空间低秩、连续级快卷积、结构剪枝。不能把十多个 mode/实现臂称作十多个新 idea，更不能说全部调研候选已经试完。[逐家族覆盖与未闭接口](transfer_coverage.md) 保留旧 Prosperity、Gustav、CFMP 等工作及尚未尝试的放置。

## 结果先看强对照

最终主表由实际组件收据与独立完整网络质量生成，见 [净结果](NET_RESULT.md)、[全部冷服务/BP/输入组](component_quality.csv)、[825质量](quality/QUALITY_REPORT.md)。周期终点为原生 source→raw→原 FP32 identity→J20→wide64→I24；AEE来自完整825帧网络，**两个覆盖范围不同**。

| 函数和执行 | 跨18序列36tile冷完整周期 | 完整825逐帧AEE | 留用判断 |
|---|---:|---:|---|
| Q11母体、普通因子 | 980690 | 1.254431 | 未剪枝强控制 |
| moment投影、三项 | 865250 | 1.296504 | 同硬件被自由U质量超过，降为约束消融 |
| 自由U零项、三项 | **865250** | **1.258343** | 保留为精度较好的性能底座 |
| 原生删tap、普通执行 | **849931** | **1.285953** | 保留为较快的竞争取舍点 |
| 同moment、源侧box2/两tap | 883130 | 1.296504 | 已完成强普通控制；比三项慢，状态较小 |

同环境SDformerFlow NB0为1.447937。自由U方案相对Q11母体普通执行少11.77%组件周期，逐帧AEE增加0.003913；这是**改变函数后的质量/服务交换**。它相对另一个moment函数的同三项硬件没有周期增益，优势是质量。三项对同moment通用Winograd的纯执行适配增益为4.75%，两个结论分开。

最重要的迁移结论是：原 Q11 通用 Winograd 在18序列36个固定 tile 上只少0.268%周期，背压时只少0.022%；这是真实负迁移线索。原因不是没有写完变换，而是每tile已实付2832拍变换/恢复/缓存等固定增量，几乎抵消有效MAC减少。根据这个问题，做了原生tap剪枝、保持普通卷积的moment投影、直接变换域剪枝三个不同函数，并写了三项执行器。其相对同moment通用实现每tile实少1192拍，首模型加载另少192拍。

新颖性仍须单独判断。快卷积、空间低秩、Winograd域剪枝、固定零项简化均有强先验；[独立评审](review_stage_final.md) 对目前算法组合暂评2/10、具体接口3/10。当前获得了可继续利用的性能与质量点，尚不能靠更名变成TCAS-II新机制。

## 2. 完整迁移空间分解，并补强直接执行

[空间R16普通RTL](spatial_r16_rtl/README.md) 实际接原生 `{0,θ}` 门源、竖3×1 Q1、Z、连续横1×3 Q2、完整I24。θ已吸入系数，前级保二值AAC，后级确实使用连续乘法。实际挂点是patch残差 `r0.conv2` 的stride1/pad1，不是旧stride2 anchor或注意力QK。

空间分解已经改变模型函数，导出Q13/Q11分别独立验证。**固定某一整数函数后**，再将因子展开成W32作为同函数直接AAC。最初逐event读改写psum控制偏弱，因此又实现 [output-stationary强控制](spatial_r16_direct/README.md)：同1280B中间存储放实际位图，付费构造，使用同ALU/权重服务。Q13因子raw冷服务相对强OS少10.94%/17.38%，原29.55%/38.44%仅属弱RMW对照，不作为主贡献。

双方不等面积：直接展开W32为331776B，普通因子表12096B；因子确有8个19×13乘法与Q2 cache。直接OS允许相同算术但没有用到乘法器。共同8ALU/256bit服务只是比较合同，不能推出同面积或同频。

完整普通因子实测Q2占其raw core约55%–56%，因此下一步针对连续Q2，而非继续只磨Q1跳零。这是**本组件**的计费份额；当前没有部署学生整网硬件份额表，不能拿历史patch约35%替代它。

## 3. 迁入快卷积效果弱，再按失败费用适配

[Q11普通/Winograd双臂](spatial_winograd/README.md) 保持同函数，经典F(2,3)仅放在已连续的Q2，避免把二值Q1直接变成多位乘法。D变换、原地Z读写、四M保持、恢复、跨stripe累加全部使用实际端口和ALU。无中间RNE；按固定界在原19×13乘法容器内选择一次Q11，另跑其完整825质量。

| 固定36tile跨18序列，冷完整服务 | ready | 有背压 |
|---|---:|---:|
| 同Q11直接OS | 1182084 | 1422253 |
| 同Q11普通因子 | 980690 | 1025097 |
| 同Q11通用Winograd | 978062 | 1024872 |

Winograd相对普通因子的17个tile赢、19个输；每序列两位置合计10赢8输。两套同帧64的6.47%/7.41%改善仍保留，但不能替代这张跨序列表。新增数据/支持状态2754B及控制代价显式列账，不借更大的状态称免费。

随后 [pruning](spatial_winograd_pruning/README.md) 固定三种新函数，各有独立整数gold和网络评估：

- `moment`：在原Q11整数系数上投影到一个变换项为零的约束。全部192个输出组最后选择同一关系 `g1=g0+g2`，不能说成运行时自适应多模式。
- `native_tap`：以同BN/输出尺度加权系数误差，删一个物理tap组。必须给它普通支持驱动执行，不强迫它走较慢Winograd。
- `unconstrained`：直接删同一变换分量U2而不投影。它是有效的两相位近似算子，p2不除二，scale减半并重构aQ40；保留原一次I24舍入。不能因它不再是普通卷积而排除。

这些选择不依赖验证集活动，无新训练、无剪枝比例扫描。它们是借入思路在当前粒度上的小范围迁移，**未完整复现WINS的训练、GPU分组平衡或原系统**。

[三项RTL](spatial_moment3/README.md) 把通用四项中的已知零分量落实到实际控制：3D/3M、24词cache、两次恢复。moment与unconstrained在同一可执行程序上所有周期完全相同，质量各自评估。因此“投影保持普通卷积”没有独占硬件收益。native_tap的普通臂在跨序列上还更快；最终取舍须把所有函数的AEE放在一起。

独立评审提出的强普通控制也已实际补完：[源侧box2→两tap](spatial_box2/README.md)。同moment系数可写成 `(1+x)(g0+g2 x)`，把共同相邻和移到Q1前，从原门字生成0/1/2，用W/2W选择而非额外乘法，E16占原1280B Z，后端仅两个普通tap。raw/full各716命令均通过同moment独立gold。它在跨序列比三项慢17880拍：前级多6344次更新、每次3拍，共19032拍；后级多64992个MAC拍；免去65952拍固定工作与192配置仍不足。两套64也分别慢7.24%/7.93%。因此这条普通控制已试，不能继续以“尚未写”为由放任三项对照薄弱；更小Q2表/cache也不自动代表吞吐更高。保留它的状态取舍，当前不取代三项执行。

## 4. 数字边界与复现

网络质量均为同A800/env312的825帧、18序列、48152523有效像素。NB0是本地原SDformerFlow PSN/SDSA ep29完整flow[-1]，候选保留已有matched-dense学生与粗头；不是冻结ep34的原始FP32网络。因此比NB0的整个差距不能只归给本次分解或剪枝。

组件输入包括同一首帧135真实tile、7合成边界、另外18序列首帧各固定边缘/内部2tile。各新函数在网络中实际注入I24并检查下一读取者，重捕的36记录与其独立CPU gold对照。完整825质量不等于825帧全部tile已跑RTL，更不等于整网硬件FPS。

采用Verilator4.028；原raw叶与完整消费者均单独回放，ready/BP、连续两遍无reset换source、冷加载/模型驻留分开计。每分支README列实际命令/逐值/状态验证，不累加重用控制臂的测试量包装覆盖。没有VCS/DC/PT/Formality、综合Fmax/面积/能量或PPA。本阶段不作ASIC加速比、整网周期或强接收保证。

源代码、脚本、配置和逐命令小结果入Git；编译目录、逐次logs与大数组留本机。主汇总入口为 `quality/summarize.py` 和 `summarize_stage.py`，只有相应完整结果存在后才生成最终表。当前所有模型/RTL均隔离；后续迁接前保留普通因子、OS、native-tap与自由U零项强控制。

本轮所有预定网络评估和上述组件回放已完成。下一步见 [NEXT.md](NEXT.md)：空间候选进入与R8相同的双context/总容量/消费者合同；另一条保留Gustav真实源bank生产到支持准入。当前单context空间与双context R8不能直接比倍率，不能用本表宣称生产C1/C2已经重构完成。
