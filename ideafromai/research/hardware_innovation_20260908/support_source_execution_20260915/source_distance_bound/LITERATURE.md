# 距离界源生产：先验与此次实际差分

2026-09-15。以下是有界定向补读，不是再次宣布文献穷尽。先写未解决接口，再做固定资源RTL；相关公式和搜索方法本身不作为新颖性。

| 完整先验 A | 核实到的机制与阅读深度 | 本次能借什么；未照搬什么 |
|---|---|---|
| [FPGA implementation of full-search vector quantization based on partial distance search](https://doi.org/10.1016/j.micpro.2006.02.014)，Microprocessors and Microsystems 31(8)，2007 | 出版者摘要/引言：子空间搜索、部分距离、多个系数并行和位平面压缩；已有实际FPGA实现。未取得足够正文核对每个模块。 | 部分距离淘汰、并行VQ电路都是旧方法。此次是精确Hamming和固定最低index tie，不继承其有损位平面压缩或性能数字。 |
| [LUT-DLA](https://arxiv.org/html/2501.10658v1)，HPCA 2025，§IV-A/B | 正文：CCM的距离PE流水维护最小距离/index，异步FIFO连IMM；查表模块与装载组织单独优化。 | 保留完整分类→索引→输出表的语义对照。本文已有输入向量，当前query bit却必须先做完整非因果PSN行归约；本地Hamming字典不是官方CCM的全量复现。 |
| [LUT-LLM](https://arxiv.org/html/2511.06174v1)，[FCCM 2026作者仓库](https://github.com/LUT-FPGA/LUT-LLM)，§4.2–4.3 | 正文：多个短距离流水与小归约树匹配加载带宽；激活/权重双索引表配合读取和累加。仓库目录/公开范围已查看，未复现代码。 | 有限并行数应由物理供数决定，不把大比较树当免费。它处理已加载向量，尚不能据此认定已解决昂贵源PSN的选择性生产。FPGA结果不转作本地28nm证据。 |
| [Greedy Miser](https://icml.cc/2012/papers/592.pdf)，ICML 2012；[Cost-Sensitive Tree of Classifiers](https://arxiv.org/html/1210.2771v1) | 本轮之前已读的费用感知特征/分类先验。 | “按特征代价少求输入”也不是新思想。本次必须在相同源MAC、X驻留和消费者语义上证明控制/状态实现的额外净收益。 |

**B：现有最强ROBDD源链在背压下只比static省约1.42%，图流量仍高；减少源乘积数并没有自动变成相同比例的服务减少。** 新试验用有限距离界比较器取代图读取。每个被查询的(t,c)仍由实际十项PSN计算，不把CPU已经知道的门送入DUT。

候选差分只写成待证命题：在“二值门需要连续源归约制造、后续仅消费码字或完整H384响应类”的接口上，以实际X驻留约束组织查询和取消，能否比静态完整分类和已优化图执行付出更少净服务。**PDE公式、nearest-centroid、响应等价、特征选择和resident调度分别都不独占新颖性。** 若有限比较税超过图访存，停止该比较器布局；不能把“16比较器不够快”写成全部源取消接口无效。

数值证明：令已知位的距离为d，未知码字分歧数为m，则所有补全下Dist(k)−Dist(j)的最小值为d_k−d_j−m。因此仅在d_k>d_j+m，或相等且j<k时删除k。d_j+m最大32，需要显式六位或更宽比较；全体剩余码字同canonical响应才可按类退休。独立未知补全是保守超集，不假设PSN输出统计独立。

本页不宣称新RTL通过，不把论文先验性能或CPU树节点/源任务数写为本地周期；实际结果由同目录程序和RTL报告补充。
