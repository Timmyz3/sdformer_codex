# 补齐普通批内参数驻留

独立审阅指出，同一个P32命令内source的A、τ、D/mask、rank与roots完全相同，却每P重复读。保持当前寄存器，在P0真实加载、P1..31直接复用，是所有执行臂都应拥有的普通权限。

本目录只增加source warm-start（同P32同mode内），保留活动前沿PF及统一root bank。每个新的top命令P0仍冷加载；不跨模式、权重函数或命令暗用陈旧参数。X槽、graph cache和所有动态图状态仍逐P清空。无新增参数容量，不削掉实际不变参数首次费用。

同五臂、同两权重函数、32训练P32＋2诊断、两BP。逐位Y/U/gate和全部partial生产检查沿用；每tile源配置应从static960/graph672字降为30/21字。将其作为最终强普通基线，不能把省去重复参数当作新颖性。
