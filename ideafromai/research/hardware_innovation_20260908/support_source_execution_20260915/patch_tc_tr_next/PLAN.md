# 固定整数学生与两种真实执行顺序

B先行：已有区域TC/TR只闭了NumPy地址，完整PSN仍在H96输出域执行；这不能代表因子化卷积已经完成硬件迁移。先补一个非退化八区域学生的固定整数函数，再让同一有限资源机器比较 U→Z→V→Y→A 与 U→Z→A→Q→V。不以普通dense原卷积当唯一分母。

A是ISSCC2025 [CFMP作者稿](https://arxiv.org/pdf/2512.17555)的预训练TC选择、紧凑中间量和同TC恢复TR；当前本地R96/active48、J4、八区域掩码及训练不是作者全部配方。额外结合完整非因果T10 PSN：本地mask跨T10共用且BN可折阈值，整数不含中间舍入，因此A可在R域先做。可交换线性变换不是新数学；待测增量是有限端口和中间位宽下，完整时间域生产与TR恢复怎样共同组织。

本步仅一次固定编译，不选精度最佳量化点、不重训：沿现有导出规则，theta折U→逐latent dyadic INT8，V投影sign×2^shift（shift[-15,0]），A RNE Q14，BN和PSN偏置编译成整数阈值。ordinary R32沿已有U8/VQ5学生编译、删除断开的尾部。TC/TR非退化学生另列新函数，不能继承原FP32或其他QDQ/整数学生AEE。

全部八个mask都给出任意归约顺序范围；用现有四份真实source_gate_words与group_ids生成新gold。三种参考必须相等：完整masked矩阵、实际TC/TR地址+紧凑Z、A→Q→V（不跨越任何原整数舍入）。记录量化后的局部门差，不能称网络AEE。源为水平P4，终点sn2；尚无后续18点halo/Conv2。

下步硬件至少比较同函数的dense-masked/TC跳生产/TC加A→V，以及普通R32的两顺序；所有臂同源口、状态容量、真实参数加载、背压和算术权限。A→V会放大Q的位宽，必须实付缓存和TR读取，不能由乘积数量直接算周期。若位宽/搬运吃掉省下的MAC，则停止该布局而保留已完成的CFMP迁移底座。
