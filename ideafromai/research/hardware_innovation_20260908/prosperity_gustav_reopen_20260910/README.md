# Prosperity / Gustav 重新融合：本轮已完成的探针

2026-09-10。三个固定CPU探针已完成；没有训练、RTL、EDA或论文修改。用户后续将 **lifting40 的 Stage B 同资源排程**指定为下一主实验，并允许先把本轮收完，因此本目录现收口为第二队列证据，不挤掉 Stage B。

**结论：** 旧G4失败没有否证Prosperity/Gustav家族；真实稀疏W确实改变了可共享关系。但现成W加部分lane继承，以及本轮共享mask选择，尚未形成相对强控制足够大的执行增量。完整联合共享图、有限状态下的计划选择和针对性恢复均未完成，不能把这些未试接口写成已失败。新颖性仍须在完整执行对照中证明。

## 2. 掩码选择已经与普通活动感知对照比较
