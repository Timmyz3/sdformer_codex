# C2 R-Sparse 式互斥两路（针对内部连续消费者的精细/近似分流）

## B（最强对照）

同函数完整 I24 消费者链（r8_consumer_fusion：固定R8→真实FP32残差→固定BN→I24，单go全层逐值通过），原生窗口与双P打包两个资源点（−3.58%/−3.56%）。两资源点不横比面积。

## A（完整继承）

R-Sparse (ICLR 2025) §3.2–3.5：大输入分量走原 W 精细路、小分量走低秩近似路，列布局 + 按层预算搜索；作者代码已开源，可作照抄起点。

## X（差分）

**互斥两路 + 源字退役的联合**：R-Sparse 分流的是连续 latent；本地连续量只有内部消费者（残差/I24/PSN）。X 把两路与**源字生命周期**绑在一起：
- 只被近似路消费的源字，可在精细路完成前提前退役（结合非 anchor 位置仅门消费者使用的事实）；
- 二值 g 本身始终走精确路，输出仍是 {0,θ}，不违反二值身份。
落在"减少了原来必要的供数/物化义务"上：精细路不必为仅近似消费者保持源字。

## 杀门

1. 静态（kill C）：非 anchor 位置的门保持率 r_gate 与 anchor 占比联合估计并集占用。若并集占用相对 ordinary 无 ≥15% 供给义务下降空间，此 X 的物理收益上限不足，停。
2. 照抄复现：R-Sparse 开源代码先在本地连续消费者（残差 I24 通路）原样套用（幅值分流 + 低秩路），AEE 须过 NB0 门（≤1.445353）。
3. 动态：互斥两路在同端口净服务 ≥15%（完整链口径），近似路不得再叠加已有 R8 分解分母（不能重复计费）。
4. 若照抄效果差 → 路径(b)：诊断"幅值分流在 I24 定点尺度下失效"的具体原因（如小分量在 f14 定点下量化噪声占优），该诊断本身可成为适配改进点。

## 两路径处置

先照抄（有开源代码）：本地连续消费者上跑原版分流 → 好则加源字退役 X；差则按路径(b)定位问题。

## 最近邻

R-Sparse（幅值两路）、UCNN/ISCA18（输入相似复用）、**APEX (arXiv:2608.19046)**（LoAS+PASC-IF 输入×权重双稀疏延伸）、**M-HySMap (arXiv:2608.26223) / SupraSNN (arXiv:2606.13354)**（多消费者脉冲路由）、本地 r0_source_retirement（两源父和 −4.92~−5.55%，同挂点强 A）。差分点：互斥消费资格驱动的源字退役（lane 粒度），而不是幅值剪枝或路由本身。
