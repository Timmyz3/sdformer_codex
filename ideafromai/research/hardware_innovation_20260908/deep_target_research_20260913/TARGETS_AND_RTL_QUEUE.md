# 具体目标与 RTL 验证队列

## 首工单：r0.conv2 普通稀疏底座与支撑选择

**B：**高分辨率 K864/N96/T10 卷积仍贵；旧公共遍历、H8 重放和元数据会吃掉加法减少。**A：**普通 2:4/3:4、完整源窗口、实际权重字和元数据、有限状态、独立稀疏 lane、RAW/背压。**X：**在同一付费 lane RTL 上，用实际字请求、尾长和阻塞共同选择支撑，超出普通活动度负载平衡。

先用既有真实 r0 W 和输入，明确共同定点常量及舍入。公共与独立 lane 先比较固定同一函数；新支撑与 Gram/旧 request/负载平衡目标再比较同一硬件。范围从原生源位图开始，到完整 Conv2 张量写出；K、N、T 和空间都不截断。norm2/identity 先有明确数值桥接，随后纳入 RTL 才称完整 block。

本工单第一张表至少包含 `RTL cycles / source bytes / coefficient bytes / metadata bytes / state bits / RAW stalls / input stalls / output stalls`。一次先写一套资源点，按实测瓶颈决定下一接口，不能只增端口制造收益。细节见[稀疏 RTL 工单](sparse/rtl_workorders.md)。

**停止条件：**独立 lane 的普通收益不归 X；在同一独立 RTL、同样优化预算上，联合目标未胜强控制则停该目标。保留底座与其他稀疏表示。

## 分解工单：r0.conv2 有限整数 Winograd

**B：**普通低秩产生连续 latent；普通 Winograd 在低事件密度下扩展有效项。**A：**WINS-R/C/B、数字变换、精确有限域编码、零跳过、融合、相同码缓存与位宽分析。**X：**候选原生码流联合剪枝消费者与幅值类，让仍付费的物理访问或串行执行减少。

导出一组具体 `Û/m/B/A` 和同函数 4×16 展开。无剪枝端点可用于功能和税额基线；WINS 训练/拟合另开一组明确模型，真实前向评价。不能从已有低秩 AEE 推定 WINS 也过门。

先调试小运算单元，再扩到完整 C96/O96/T10 和相邻 tile；只有完整归约、输入重叠与最终输出均纳入时才出性能表。控制包括普通有限域 WINS、同函数直接事件展开、同质量普通 2:4/低秩。后两种比较不得混成同一个“加速比”。

**停止条件：**相同有限域与布局给足后，X 若只剩普通使能而无实际访问/周期增量，停该码流；无剪枝输给 bit-skip 不直接否决有损 WINS 家族。数学与首模块细节见[分解报告](decomposition/REPORT.md)。

## 任务工单：decoder2 事件可观测性细化

**B：**decoder2 在稀疏后仍值得测，且所有区域不必需要相同细化。**A：**已有 preds.1、WaveletVFI/EEMFlow 的粗细分工、去插零多相执行、普通置信度和 group 稀疏。**X：**事件可观测性决定保留/刷新，并与整 T10/相位请求组的服务费用共同优化。

先导出真实 decoder2 输入、preds.1、事件摘要和当前 norm 配置。算法控制为 preds.1 直接早退、均匀窄 decoder、flow 梯度、高频阈值、密度、不确定性及新选择器。保留当前完整预测对照；不要求 +0.005，探索门是优于 NB0。

硬件范围包括可部署 mask 生成、支持反推、相位地址、有限缓存、全部输入通道归约、norm、pred 神经元和最终 flow 合并写出。离线 GT mask 只能标记为诊断上界，不能成为硬件输入规范。首条链完整之前只称模块验证，随后完整层回放记录实际周期。

**停止条件：**没有比简单早退/阈值更好的质量—服务曲线，或展开后请求几乎不减少，则停该选择器/粒度。保留粗细分解家族及 r0 扩展位置。见[光流报告](flow/flow_task_native_report.md)与[decoder 源码核查](integration/DECODER_TARGET.md)。

## 共用交付边界

本目录为研究和设计交接，本轮没有执行上述 RTL 工单。后续原型进隔离目录，生产 nts07 和 `paper/tcasii/main.tex` 继续只读。每个工单至少保留一个固定函数的数值对照与一个同任务质量的强算法对照；默认定点并不继承 FP32 质量。

Verilator/VCS 的实际周期、逻辑综合结果、DC/PT/Formality 的同负载结果和真实 SRAM 下的物理结果分别标注。开始写原型不以已知赢家为前提；“可以尝试”也不等于能把尚未测量的速度写入论文。
