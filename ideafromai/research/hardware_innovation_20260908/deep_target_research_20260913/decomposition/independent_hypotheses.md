# 本轮检索前的四个表示假说

2026-09-13。先读了指定 profile、current_bottlenecks、decomposition README 与 catalog/COVERAGE 的相关记录，再写下以下假说；已受这些历史记录启发，并非盲法或独立于项目历史。随后会查 primary 文献，允许修改或降级。

1. **列原型→整数事件直方图。** 将 96×864 卷积权重拟合为小原型矩阵 C 与每列只有一个/少数 ±2^e 的指派 D，先对原脉冲位做有界整数分桶，再按 C 展开。与连续低秩的区别在 D 的有限字母表；假说是按真实活跃源形成 prototype 请求，能压掉低秩连续 latent 的全宽 MAC 和无事件 prototype 的取数。需要面对稀疏发放下聚桶碰撞少、指派误差、整数位宽增长和 LegoNet/权重聚类/SmartExchange 碰撞。

2. **事件条件的 Kronecker 切片收缩。** 把 96 通道拆成 12×8，将核写为若干 A[a,c1]B[b,c2,δ] 的和；先只做有事件 c1 的 B 收缩，按同一位置的实际 c1 支持压缩第二次 A 展开。假说是编译选择通道拆分与收缩次序，使物理 latent 按事件片段出现，避免普通低秩全域连续 latent。需要支付 latent 连续化、跨片归约、支持目录及最强稀疏 Kronecker/TT 控制；不能把 Kronecker 名称当 X。

3. **二值支撑驱动的精确 Winograd 双路径。** 对二值 4×4 输入块，Winograd 输入变换保持有界整数；用原块支持及变换零值决定 direct-event 或整数-transform 路径，融合输出逆变换并统一累加。假说是某些有符号抵消/重复空间形状让 transformed 路径真正少常量加法，而非只少密集乘法。需要完整双路径参数、分支/编码/缓存、边界与原事件卷积强控制；低 p 下全局 Winograd 很可能不适合，不能据此杀掉按支撑挑选的整个家族。

4. **局部支撑的集合多项式/决策图分解。** 将四至八个输入脉冲位的局部线性映射编成共享 decision DAG 或差分表，节点同时输出多个输出通道，并只沿实际支持走。假说是把输出块、空间 tap 和十时刻的相同 support 合并成一次原子 table/vector 请求，可以减少权重读与宽加法，而非重复旧 pair-ID 或泛称 CSE。需要和完整 LUT-GEMM、LUT-DLA、共享子表达式、无损事件跳零的最强控制比较；查表容量与地址生产可能完全吃掉收益。

以上都未做新数值实验、训练、RTL 或 EDA。后续报告将区分外部先验 A、当前 r0 昂贵余洞 B 和剩余可检验 X。
