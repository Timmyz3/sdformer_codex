# 逐卡审阅规范（2026-09-11 接手 Codex）

审阅对象是卡片本身，不是独立开题。禁止把卡内自评分、OpenROAD 完整度或 iverilog PASS 写成 TCAS-II 录用证据。

## 网络身份
- 任务：事件相机二维光流，主评 DSEC valid825 AEE
- 冻结学生：Motion C12 / H67 / ep34；ATLIF 输出连续阈值幅值 θg，不是二值发放
- 当前主研究线：patch r1 上可学习 T10 lifting + 完整常量编译 + 真实双消费者
- 精度门：绝对 AEE≤1.259；相对同预算强对照增量≤0.005
- 服务门：完整目标链同资源净服务至少少 15%，状态/系数预算不增加
- 生产 C1/C2 与 `paper/tcasii/main.tex` 只读；Yosys/OpenROAD ≠ ASIC PPA

## 每卡必须填
A：完整先验（必须抄全的那篇/那族）
B：本网未解决洞（用已有负结果或费用账证明 A 不够）
X：相对 A 的真增量句；写不出就写「无标题级 X」
强对照：必须同时给普通压缩/剪枝/供数，不能只比稠密或串行
缺证据：全文未迁、训练未做、消费者未接、同资源未比
决定：保留完整迁移 / 保留强底座 / 保留对照 / 纠正后保留 / 停止该布局 / 旁路低适配 / 待核全文
novelty 0–4：0 无；1 仅先验；2 有洞但 X 未定位；3 有可测 X 但未闭环；4 标题级（卡面几乎达不到）
fit 0–4：与 θg / T10 / 双消费者 / patch 贵段的贴合
evidence_depth：`card only` 或 `card+local experiment` 或 `card+rtl tb`

## 硬规则
- 停布局，不杀家族
- 二值 ATLIF / MX3P 岛 / 空泛 CIM 不得当主贡献
- 不得把组件倍率相乘，不得报整网 FPS
- grokbot RTL 树是隔离草图，功能 TB ≠ 同资源加速
