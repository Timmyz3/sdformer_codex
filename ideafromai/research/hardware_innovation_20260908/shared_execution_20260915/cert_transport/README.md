本实验把 Claude T5 的整数门证书迁到实际供数接口：原始 Y 字进入 RTL，硬件生成共享有效位宽和位平面，逐词读取阈值，最后完成 ready/valid 门结果退休。保留原整数函数；这是 **post-Y、阈值已生成** 的局部执行实验，尚未覆盖 FC1 生产 Y、动态 BN 统计或连续消费者。原 Claude 文件只读。

新 RTL：[cert_transport.sv](cert_transport.sv)。独立全深整数点积与边界 TB：[tb.cpp](tb.cpp)。执行入口：`/opt/anaconda3/bin/python3.12 run.py`，需要本地 Verilator 4.028 和原 `claude_fusion_trials_20260914/results/t5_rtl/` 的四份捕获。详细数字见 [RESULTS.md](RESULTS.md)、[summary.json](results/summary.json)。

实际比较的是同一个电路的四种供数策略：

| 模式 | 完整/提前终止 | 初始供数位置 |
|---|---|---|
| FX full | 完整 | signed24 的符号头 + bit22…0，共24拍；删除原25拍对照中重复的符号位 |
| FX cert | 区间锁定后全组结束 | 同上 |
| BF full | 完整 | 硬件算 `e=bit_length(max(abs(Y)))`，符号头 + bit(e−1)…0 |
| BF cert | 区间锁定后全组结束 | 同上 |

这里沿用原文件的 BF 模式名，但它保留全部低位，属于无损整数有效位宽组织，并非固定尾数位宽的有损块浮点量化。e=0 只对应全零组，补一个零平面做精确阈值判决；signed24 最小负数在25位 abs 中处理，e=24 合法。未使用可能把 −1 编为 e=0 的另一套最短指数约定。

每组共用一个64位请求/响应口，一次只允许一个在途请求。五次读入10个 signed24 的 Y，每个64位传输放两个源字；随后十次读入本组 `(t,h)` 的阈值及比较方向，每词64位。Y 的共享指数在响应到达时生成，寄存器中的10个字按位形成平面，不由 TB 预先提供指数或平面。十个阈值到齐后，符号头初始化；之后每拍计算十个判决，全部锁定后停止，输出背压时保持结果直到退休。全部模式付相同的原始字、阈值和输出协议费用。

零外部停顿时，每组周期恒等式为：

`1 command + 15 request + 15 response + 1 sign header + planes + 1 retirement`

即 `32 + header_planes`。另外记录请求拒绝、响应等待和输出停顿，满足完整周期和。背压用固定日历：请求在周期模7为0/1时拒绝；响应比最早下一拍额外延迟1/2/3拍；输出在周期模5为3/4时拒绝。它是明确的压力情景，不是实际系统总线测量。顺序采用原T5采样记录，不能冒充完整层的 h-major 调度。

| 资源 | 本实例实际合同 |
|---|---|
| 外部供数 | 一个64位口，最多1在途；源40B传输 + 阈值80B传输/组 |
| Y 缓冲 | 10×24 = 30B |
| 本组阈值 | 10×64 = 80B；不再在门核里免费声明十个3072深度阈值表 |
| 位平面累积 | 10×48 = 60B，另有锁定位、判决及控制 |
| 常量配置 | A=100×16=200B，P/N=20×48=120B，通过readmemh预装常驻，**未计配置服务** |
| 算术 | 十路10项条件加和、十路前缀更新、二十路区间界及比较；N/P×(2^m−1)实际改成移位减法 |
| 时序边界 | 长组合链尚无综合、Fmax或PPA；full/cert是同电路消融，不是最优完整点积硬件的面积对照 |

本接口读取了完整 Y，所以提前停位平面 **没有减少这些原始源字或阈值字节**。有收益的是本组门判决的服务时间。阈值对同一 BN epoch 的同 h 可跨位置复用，但当前没有阈值缓存或生产顺序重排；不能把每组冷读成本外推成所有设计的不可避免下界。反过来，也不能在动态 BN 下无条件跨帧复用旧阈值。若进行缓存适配，键及失效必须覆盖阈值 epoch。

验证覆盖四trace各20,000组×4模式×2背压情景，6,400,000个捕获判决；另有每trace35组零、最小负数、正负幂、混合符号和逐判决V/V+1阈值边界，共11,200个判决。逐组比对完整有符号点积、供入平面数及RTL生成的指数，并检查读数和输出保持。边界阈值采用明确的signed48+比较方向合同，不是在声称已修好原浮点BN负gamma转换。原脚本的负gamma和signed49保存问题见[独立审阅](../claude_review/README.md)。

当前保留这个原语，但尚不把它叫作 C1 的最终形态。T5 使用的 S0/S3 FC1+动态BN图边，与当前空间 r0.conv2→I24 图边不同。下一步若扩大，首先要选定真实 BN 身份、阈值生成/可用边界，以及该 Y 是否还被完整值消费者需要，之后才比较全链。四份f12/f14整数捕获的门精确性不能继承 R8、ep34浮点或空间学生的valid825 AEE。
