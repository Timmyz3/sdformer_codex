# CPTB/NRV 类别执行：本轮完成的有费用参考

固定 `v000_zurich_city_09_a_0001` 的六个 S2 块，均完整 P1200/C384/H1536。下表是 **CPU 服务模型**，已包含有限源补给、FC1、同学生全部 T10 输出的非因果 PSN 消费及输出总线；不是官方 GustavSNN 工件、RTL 层周期、PPA 或整网加速。当前 B/τ 已训练且 D 限制时间子空间，不声称秩10或原 ep34 算术等价。

| 整数三判决学生 | 117.191999M | 100.120080M | **99.915785M** | −14.7418% |

`class_best_tail` 使用普通“类别和→原位共享加法恢复 Y→A_eff”或直接 B 中较便宜者。整数学生 b0/b4 选恢复；rows3 b0/b3/b4/b5 选恢复，其余等成本点保留直接 B。整数学生另付 9.216M 次 LOAD、12.9024M 次 add_store，没有冒算为 CSD；源缓存单读口、U24→缓存写回 mux 明确计入共同结构。恢复后的 Y、CSD 与直接整数 U/门值均用实际 W、code、τ 核对。这证明前端按类别发事件的收益，不能将全部差额归为“永不恢复 Y”。

参考依据是 [GustavSNN, HPCA 2026](https://doi.org/10.1109/HPCA68181.2026.11408587) 全文 §IV-C/E、§V、§VII-A；全文来自公开读书仓镜像。承接了列分区 PE、权重行 tile、NRV、NR4 零权重压紧、L1D/merger 每 PE 每拍选一个事件、fetch/execute 双缓冲、共享双口 W 及同 k-ID 同步。原作实际实现 LIF。本地明确另加非因果 T10 的类别/时间部分和与消费接口，不自称完整官方硬件复现。

`packed_class` 和 `packed_time` **都一次扫 D、读相同 W、使用相同三位码输入**。time 用 P-bit L1D 加 code→time 游标，没有虚构 P×R 平铺 L1D。每个原始 NRV 行以所有同 ID tile 的 ready 广播，两路公平 W 仲裁；该具体时序是本参考的选择。末包 flush 与下一包首事件重叠需要独立 state-adder 和同址旁路，尚未以 RTL 验证。

共同物理点为 8 tiles×8 PE、P8、W8；每 tile 8KiB 双口 W、128KiB 全局 W、8×1KiB 源 bank。每 PE 一律分配 **7×8×15bit S/Y＋valid、2×7×15bit 源缓存、U24**；τ、微码和译码按两轴最大上限，输出共 640B。time/rows3 可闲置或钟门多余空间，没有让类别路径免费多容量。一个原 partial-adder 明确扩为24位，另有15位 state-adder；不额外给乘加阵列。这里是裸资源及端口约定，不是 SRAM 宏/PPA。剩余空间用于别的位置预取尚未优化。

有限输入每次处理 D128：384B dense codes 先放源 bank 低地址，反向读 d=127→0，再从1KiB高地址反向写64bit NRV；最终顺读恢复原 D 顺序。全活128行和所有真实记录均验证不覆盖未读输入。每 ID 每拍编码一行，零行也付费；1R1W/64bit 是本参考的端口选择。执行时 NRV 与 W 各一拍，跨三块保留宽部分和。全部输出位先存共同640B，再传出。

全局只有一条总线，每32B事务付5拍；**W/τ装入→代码装入→编码→执行→输出**采用明确的保守串行排程。整数学生两轴均读199.0656MB代码、3.538944MB权重、0.27648MB阈值，输出13.999104MB（含波次描述符）；不是八个 ID 各享6.4B/拍。原 Gustav 分块、W缓冲的多行利用和装入/执行重叠仍可继续改进，因此这些流量和服务不是理论最优下界。

源生产算术、FC2、BN2 和 shortcut 仍不在上述端点内。按根代理已验证的整数 source leaf，64 PE 串行复用可另拼接3.6864M源计算＋6.48M输入传输＋0.162M code写回；加同一10.3284M后，整数学生为 **110.244185M 对127.520399M（−13.5478%）**。这是阶段模型组合，仍需源配置装载少量费用及宽输入/控制 mux 改造，不是已连线的层 RTL。

结果：`gustavsnn_reference_finite_supply.json`（整事务24点）、`gustavsnn_reference_best_tail.json`（追加12点）。更大范围 `gustavsnn_reference_teacher_bits3.json` 为120个完整捕获的四轴突触端点；`gustavsnn_reference_with_consumer.json` 为三模型各60捕获的 ready-source 消费端点。它们的边界与有限总线表不同，不能混比。脚本与 C++ helper 均在同目录；这份硬件参考未运行 EDA、额外训练或修改生产树；本轮算法训练和完整验证见上级 README。
