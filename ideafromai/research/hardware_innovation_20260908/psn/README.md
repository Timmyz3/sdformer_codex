本轮已运行参数检查、真实输入核对、付费运算计数、一个有限 RF 服务模型及一次已完成行见证探针。**修正静态常数折叠后，低秩方案输给普通范数基线，本轮停止该版本；已完成行见证只留下很薄的局部机会，不晋级大 RTL。** 连续输入上的满秩时间混合没有因为输出发放稀疏而自动变成稀疏点积。

主入口是 [screen_psn_residual_bound.py](screen_psn_residual_bound.py)，结果是 [result.json](result.json)。最后一次有限探针为 [screen_completed_row_witness.py](screen_completed_row_witness.py) 与 [witness_result.json](witness_result.json)。没有改生产树、训练、EDA 或哈希封存。

## 数据与真实语义

三个位置分别为 `patch_embed.head.sn`（T10）、`layers.0.swin_blocks.0.mlp.sn2`（FC1/BN1 后 T10）、同块 `attn.sn_k`（T2）。矩阵秩分别为 10、10、2；上三角未来项分别有 45、45、1 个非零。前端 A 的前五奇异值为 1.888、1.715、1.508、1.445、1.436，并不接近秩一。

- FC1 后：用 ep34 sample0 的真实完整源和冻结权重重建 32 个均匀输出通道，BN 统计使用每通道全部 192,000 行。6,144,000 个输出位与已有捕获一致。费用探针选 16 个均匀空间包，每包 32 位置，保留完整 T，共 16,384 条轨迹。这是 float64 重建，并非新捕获的原始 GPU 中间张量。
- 前端及 T2：根代理从真实 ep34 前向取得 `zurich_city_09_a_0001` 与 `interlaken_01_a_0000` 两帧，每模块均匀选 128 个 32 列包，每列保留完整 T。四份真实 FP32 输入对应的 98,304 个输出位，与原 A 的 float64 重算全部一致。不是全帧或 valid825 评价。
- 输入是连续值；输出为发放标志乘阈值幅值 \(\theta g\)。脚本读实际 θ、bias、center；不把 θ 的通用语义改成 1，也不引入逐事件任意幅值。

## 被测方法与费用

保留原满秩 A，取静态 SVD 因子 \(A_r=L_rV_r\)，\(E=A-A_r\)。在完整 T 到齐后计算 \(z=V_rx\)、\(\|x\|^2\)、近似判定值。原界为

\[
|(Ex)_t|^2\leq\|E_t\|^2\|x\|^2。
\]

正交界利用 SVD 正交性，把右端的输入能量收紧为 \(\|x\|^2-\|V_rx\|^2\)。实现额外收费 r 次平方、能量归约与相减，并加收费的 `1e-10*norm2` float64 数值余量。比较平方量，**不需要根号**。该余量不是原 GPU FP32 算序的通用误差证明。

能证明判定结果的输出提交 θg；其余按原 A 行重新计算。强对照包含完整 A、**rank0 范数直接判定再回退**、单纯低秩近似新模型。还单列了事后已知 `abs(E@x)` 的免费 oracle；它只显示理想机会，不能当可实现收益。没有用这两帧拟合 basis。

**rank0 必须做静态折叠。** 令 \(m_t=b_t-center_t-\theta\)，离线生成 \(\kappa_t=m_t^2/\|A_t\|^2\)。运行时只计算一次 \(q=\|x\|^2\)：静态负侧用 \(q<\kappa_t\) 证明不发放，正侧用 \(q\leq\kappa_t\) 证明发放，零行单独作为常量。逐输出不再收 margin 平方或行范数乘法。本次三模块的静态 margin 都为负，按 κ 排序还有普通的 T+1 嵌套掩码译码对照；不把它当新增机制。

修正后的 rank0 付费乘法比例为 `1+1/T-cert_rate`。r≥1 原界为 `1+(2r+3)/T-cert_rate`；正交界另加 `(r+1)/T²`，其中一项是数值余量乘法。所有投影、范数、判定及失败回算均纳入。T2 的 rank1 即使全部认证，也至少需要原完整 A 的 2.5 倍乘法。

JSON 另外给出加入正常 IEEE FP32 范数/点积误差余量并向下舍入的 κ 常数，用顺序 FP32 平方归约复查。五组数据的认证掩码变化与认证位错误均为 0。这是当前数据和注明算序的敏感性检查，不是 TF32、溢出、次正规数或任意 GPU 归约实现的完整证明。

## RF 生命周期与完整强比较

有限模型每块 32 列，16 个共享标量 MAC、16 bank 1R1W、合计 512 个字的 RF；同地址读可广播，系数为局部静态表。直接完整 A 和失败回退使用同一普通可压紧行任务引擎。每次最多 16 个任务持有累加器，不为全部失败输出分配另一套 T 行宽状态。

rank0 的 32-bit 载荷方案占 **1,524 B**。rank1 占 X 320 字、latent/norm 64 字、结果/失败掩码及两波描述符 29 字，共 **1,652 B**；rank2 为 **1,780 B**。另有两边共同的 16 个 MAC 累加寄存器。完成判定后 latent/norm 生命周期结束，失败清空后才释放 X。**块内无 X 溢出，额外 X 访问属于 RF，不能写成外存流量。** 位宽尚未成为冻结部署合同：若 X 保持 32 位、工作数值使用 64 位，rank1 为 1,908 B，rank2 为 2,164 B；JSON 同时保留全 64 位容量。

FC1 后 rank1 正交界在 512 个块上的服务槽为 **101,432**，输入驻留完整 A 为 **112,640**，修正后的 rank0 为 **85,544**。这些数已计任务尾部空槽、RF bank 冲突、比较和未重叠 dispatch。相应 RF 读数分别为 **373,860、245,760、363,806** 字，候选没有获得 RF 访问下降。

更强的输入流式 A 可把同容量用作 T 行 partial sums，省掉 X 保存；其 MAC 槽下界为 102,400。本探针尚未关闭真实生产者供数、比较流水与系数分发代价，所以 0.900497 不能推广为“已胜所有强基线”。本模型中的普通掩码压紧、RF 生命周期复用和 ready/valid 不是新增原语。

## 一次有限重构：已完成行的连续值作为见证

按 A 的行相关性静态编译互不重叠的行对：只接受 \(|cos|\geq0.8\)，从高到低最多五对，不足不补；较大范数行为锚。前端得到两对，FC1 后得到一对，T2 得到一对，均没有用这两帧拟合。先执行静态 rank0；只有同一对的两行都未决，才在计算本来就必需的锚行后尝试证明其伙伴。

令 \(a_j=c a_i+e\)、\(u=a_i x\)。锚行在提交自己的 θg 之后，连续值 u 暂不丢弃，用于另一行的界：

\[
|e x|^2\leq\|e\|^2\left(\|x\|^2-u^2/\|a_i\|^2\right).
\]

证明失败仍按原 A 计算伙伴。使用静态常数可把判定折成二次式 `F=(alpha*u+beta)*u+gamma-lambda*q`，符号由 u 与另一静态常数比较。每次尝试实际收 **3 乘、3 加、2 比较**；普通逐式实现的 6 乘也列在结果中。原始锚点积可以用静态阈值比较完成自身发放，不另收一个低秩投影。这个代数折叠和正交界本身不是新发明。

| 位置 | 尝试数 / 省掉的伙伴行 | 乘法数 / 静态 rank0 | 最有利服务估计 / 静态 rank0 |
|---|---:|---:|---:|
| FC1 后 sample0 | 11,005 / 6,988 | 0.962911 | 0.996715 |
| 前端 Interlaken | 3,984 / 2,374 | 0.963332 | 0.990436 |
| 前端 Zurich | 5,052 / 3,430 | 0.948227 | 0.977288 |
| T2 Interlaken | 1 / 0 | 1.000321 | 1.003541 |
| T2 Zurich | 0 / 0 | 1.000000 | 1.000000 |

此表服务轴比上面的 RF 模型更乐观：在每个 32 列块内先合并已知任务数，按完美压紧发射，尚未实现“锚完成→判定→失败伙伴”因果排程，也没有计 bank 冲突；对照采用相同假设。每次尝试另列锚值一写一读、norm 一读；16 个锚值暂存可放入 2 KiB RF，但未证明理想发射次序能在这 16 个暂存项下实现。因此不能把该轴称为真实周期，不能与上表混作同一服务模型。

所有认证位与原 A 一致，二次式与显式正交残差界也逐位一致；仍是 float64 机会模型，没有给见证判定构造冻结 GPU FP32 的普适证明。观察到的是 FC1 后最多约 0.33%、前端两帧约 0.96%/2.27% 的乐观服务余量，真实依赖与容量调度可能吃掉它。**保留“复用必需输出幅值”这个局部观察，本轮停止扩展，不据此启动大 RTL。** 这不等于证明所有已完成行见证或另模型共设都无效。

## 先验与判断

[Davis 与 Arel，2013/2014，§3.1–3.4](https://arxiv.org/pdf/1312.4461) 已用低秩预判激活符号，再条件计算原矩阵；原方法允许预测误差并主要跳过预计被 ReLU 置零的项。这里值得区分的适配是：θ 已知时，正反两侧均可直接提交 θg，使用可证明的剩余界并在不确定时回算原 A。**低秩先判再算不是本轮新想法，Cauchy 界和正交投影也不是。** 当前可研究的剩余问题只是：判定余量、完整 T 消费与有限 RF/失败服务能否共同形成稳定净收益。

[MFPSN，NeurIPS 2025，§4](https://proceedings.neurips.cc/paper_files/paper/2025/file/5f40a99efedc1148a061d80201949c84-Paper-Conference.pdf) 已有通道化因果时间卷积与二幂系数；本地 M29 也已有低秩 PSN。它们是另模型竞争者，不是冻结 fullrank A 的等价替换。本轮没有训练这些模型。

当前判断：**普通低秩＋标准界＋通用压紧回退，在本次冻结数据上输给静态 rank0，停止这个版本；见证方案也尚不足以独立担当主贡献。** 范数基线保留为后续 PSN 的普通强对照。若通过训练约束行残差或增加判定 margin 改善，则明确另开算法身份及 AEE；本轮没有修改 A，也没有用两帧拟合投影或行对。
