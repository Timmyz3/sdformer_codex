# Gustav 指导的最小连线切片

已实现并通过 Verilator 的 **2 tiles×4 PE、P4/F_live1、完整 C384→全部 T10 门**。这是论文指导、针对当前整数学生的功能实现；不是官方工件、完整 GustavSNN 或完整 FFN。生产 nts07、主稿及旧叶未修改。

```text
4 个已驻留 code3 源 bank：RTL 64bit 地址读取→128bit 跨字提取→空行扫描
  → 每 tile 两个 W8 地址/返回口、4-ID 仲裁、独立返回所有权
  → 每 PE 私人 W=0 压紧→双 NR4→P4/R 目的合并→持久 S15
  → 同 source-ID 两 tile 全 C 完成屏障
  → 读 S、标量 CSD、独立 τ→完整 T10 门＋原样 θ payload
  → 输出握手后释放，下一任务可不复位运行
```

`gp_slice.sv` 实现真实地址生成、返回仲裁、跨 tile 屏障和输出口；`gp_slice_pe.sv` 实现私人压紧、双包、局部部分和与非因果 T10 消费。选择/CSA/Acc24 逻辑承接旧 `gp_temporal_pe.sv`、`shared_fc1_psn.sv`，此次将消费链连在同一顶层，未直接并挂旧的七 bank×96 lane 阵列。

两表示共同使用：每 PE 声明 56×S15＋valid、两包各四个 `(code12,W8)`、七个 S15 消费缓存、U24、十个门位；每 tile 两个 W8 读口与 10×τ24；每 source-ID 一份 256×16 程序，向两 tile 广播。源码 bank 为四个 1 KiB、64 bit 单读接口（每个任务实际读取72字＝576 B）；每 tile 驻留一个384 B密集W行。初版地址空间512 B，文末双指针对照统一扩为每 tile 2 KiB；原 `result.json` 保留初版口径。W口每口仅一个事务，外部行为存储有一个 W8 返回保持寄存；owner/code/地址保持在 RTL。原样传递的每 tile θ 为32 bit，与24 bit τ是不同字段。

P4/F1 下只有前 `4×R` 个 S 字使用：s2b3 的时间路线 R6 用24字，类别 R7 用28字。56字是共同声明容量，综合可能裁去不可达的高28字，**不能把声明容量称宏面积**。标量路径有一个 W10 包内部分和加法器；成员路径另有真实四输入 CSA。两者的 S 提交与 PSN 共用一个带溢出观察的 Acc24 加减器，同 PE 突触与 PSN不重叠。成员归约不是与最小标量电路等面积。

验证命令：`/opt/anaconda3/bin/python3.12 -B run_functional.py`，使用本机 Verilator 4.028、`make -j1`。[结果](result.json)为 **144 次完整任务，46,080 个门位比较，0 差异、0 溢出**。其中12个真实 capture 来自 v000/v006 的六个 S2 块；每个抽16位置和两个真实隐藏通道、保留完整 C384，分别运行 class/time、scalar/member、正常/有停顿四配置。NumPy 用稠密整数点积独立构造 S 和门，C++再次按完整 C 循环核对。C++只响应 RTL 地址读取原始源码/W，并检查黄金结果，没有向 RTL 灌预拼 NR4。

每个源 bank 的地址0–71恰读一次；每个非空源行对每 tile/ID 恰发一次 W 地址。另检查私人包数与尾包长度、事件/提交守恒、S 的有效零、同 ID 屏障及最后输出握手。定向任务包括空源码、全零 W、不同 tile 的1/3行尾包、−128/127、相消为有效零、S15两端、满双包以及合法非1θ：`θ_source={0.5,1.5,2}`、量子0.5、`Wq=2θ_source·baseW`，独立 `θ_output={1.25,0.75}`。该有理数任务是接口诊断；真实所选参数 θ恰为1，不能把诊断冒充检查点数据。

运行中双包占用峰值2、四个物理 W 口曾同拍接收请求，累计9,149个 W 返回等待拍；两种 tile 完成先后均出现。输出与 done 的 valid 在背压期间保持，所有任务间改变程序、rank、W与源且不做全局复位。[逐任务计数](results.tsv)从接受 start 到最后门握手，包含局部取数和 T10 消费；程序/τ配置显式执行，但不在该端点内。12个真实 case 的无停顿平均最后输出为 class scalar 2492.67、time scalar 2473.25、class member2491.25、time member2460.67拍，**仅为该有限功能切片的观测，不是已准入的 RTL 加速比**。

两条接口与比较边界：当前顶层等待最后 W 返回并推进源结束状态，保证 PE 的最后一次 `row_valid && row_ready` 与 `end_valid && end_ready` 不在同拍。**PE 独立接口要求这个时序**；若外部另接时把二者合在一拍，封尾会看到旧 `packet_count`，该用法不在本次合同内。压力配置的随机数流连续使用，且任务 tag 会改变较慢的 tile，所以不同 scalar/member/表示的 stalled 轨迹并不相同；这些结果只验证压力下的功能，不能据此归因周期差。仅 ready 配置使用相同的固定存储服务来观察该切片计数。`real_group_totals` 中所有 `_peak` 字段按任务最大值汇总，不累加峰值。

当前每 W 口在请求与返回之间只允许一个事务，有周转空拍，尚非每拍持续接新地址的流水 SRAM 口。未接外部冷装入/DMA、F_cache多行、8×8阵列、完整 P1200/H1536层，以及源生产量化、FC2、实际 BN2 域和 shortcut；尚未做 VCS/DC/PT/Formality 或宏映射。源码/W行为存储由 C++有界响应，S与程序是 RTL寄存数组；不得据此写 SRAM PPA。双指针跟进如下，仍是有界功能切片。

## 双指针交集：已连线，真实 W 上保留负结果

按 [GustavSNN §VII-B](https://doi.org/10.1109/HPCA68181.2026.11408587) 增加 `start_intersection`：比较实际源扫描产生的非空 NRV 行号与有序非零 W 索引，小者前进，相等才读 W 值。两模式使用相同每 tile 2 KiB、两个8 bit读口；压缩行格式为 `uint16 nnz + nnz×{uint16 index, int8 W}`，最大1154 B。头、索引和值都经实际地址请求/返回，C++仅返回所请求的存储字节。每 PE 另保留 count9、pointer9、index9、phase3、inflight1；含端口地址/类型扩展和模式位，共新增269个声明控制位及比较/地址逻辑，不据此估面积。

运行 `/opt/anaconda3/bin/python3.12 -B run_intersection.py`：[结果](intersection_result.json)为 **352 次完整任务、112,640 个门位、0 差异、0 溢出**，NR4峰值2，四个W口曾同拍接收请求。原12捕获之外加入真实训练 `row_2of4_trained`、`broadcast8_C16_half_trained` 各两个s2b3捕获，使用其各自 W、codes、B/τ；没有用人工mask替代真实稀疏模型。每例都跑两种 W 寻址、class/time、scalar/member、ready/stalled。检查器独立推导每 PE 双指针的完整地址序列，并核对私人包/事件/S提交不变和全部 T10 输出。

当前字节口实现中，索引读取超过省下的值读取。约50%密度的压缩行仍占约566–578 B/行，大于密集384 B；原整数行约1134 B。全零W、约1–2%非零的定向任务能减少事务与完成拍，但只能证明边界功能和机会，不能覆盖真实负结果。C16与2:4的时延差尚未做前端等待细分，不能仅凭此表归因于最终完成屏障。

**共享驻留不等于一次局部读取。** 原文§V-A/图11已让同 h 的多个 PE 共享一份双口W行，并只导入一次；本件每 tile 也只存一份。§IV-E描述各 PE 按自己的NRV顺序读取W，§VI-B报告共享buffer的读冲突。但§VII-B没有给索引头缓存、同址合并/广播或索引具体布局，所以本件四ID私人游标重复读取字节索引**不是原作必须付的代价**。有费用的同址读合并/广播、共享索引头或有限索引缓存/位图，仍应作为普通强组织补齐，不能包装成新机制。

本件还采用较保守的共同源行桥：两个tile均消费/跳过当前行后才前进，未复现原作全部包级供数时序。动态NRV确由RTL实际源码读取产生，但仍完整扫描C384，每源bank72次读取；静态W/索引导入、压缩构造与冷DMA均未计时。程序/τ配置也在当前计时端点外。这些数只比较本切片的功能和端口事务，**不能当完整Gustav性能分母或已准入RTL加速比**；后续补普通共享控制属于完善借鉴底座。
