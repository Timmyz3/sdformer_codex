## 先写 B 和强对照

**B：** 普通稀疏卷积之后，多个时间、位置、通道消费者仍要求同一个未生产值；单门提前完成不等于取消一次 P4×H8 生产或共享取权。旧持续严格检查输给一次许可；旧固定 A 的 γ 校准增量薄。尚未做的是在相同训练权限下同时恢复时间结构、改变完成相关性，并回到完整物理成本。

**强对照：** row34 与 common3-private34 都得到预测器、量化、相同训练预算和普通依赖短路；除最初共同前缀外，已给每个结构从训练集自行选择最优前缀的权限。普通逐消费者费用与实际组需求费用交叉比较。完整十 Y 共取权、一次严格许可、原稀疏卷积是后续硬件对照，不由训练代理取代。Conv2/BN2/shortcut 不因省 Conv1 自动免费。

**A：** Gustav 的共享稀疏供数；稀疏 PSN 的受限时间图；CGNet/TermiNETor 的部分计算与共同完成；DynConv 的真实前驱需求费用；CFMP 的生产/消费掩码和索引转换。已读方法范围及缺少的原训练 recipe 见 [直接先验评审](../../../literature/direct_priors_20260909/review.md)。完整 CFMP 和 CICC 动态剪枝均未被冒称复现。

**待检验 X：** 是否能训练出一种非因果 T10 依赖，使相近精度的提前完成真实取消更多尚未生产的 Conv 列；与完整常矩阵求值叠加后，是否还有同资源净增量。这是待检假说。

## 本地先行试验边界

等待 A800 SSH 地址/端口期间，用现有 `partial_completion/capture.pt` 做一次有明确身份的训练诊断。它是 **train16、valid4，各帧64个原生P4位置，全部C96/T10**；Y 为固定 BN 后、整数化 Conv1 之前的真实 FP32 捕获。不是拟定的 integer train32，也不是新的全网 AEE。现有 checkpoint/config 只在远端记录路径，本地未找到对应文件。

先跑四轴：`row34/common3-private34 × individual/group-demand`。支撑 E 在每轴固定，更新其34个非零系数、偏置和γ；本轮没有学习支撑选择。保留全部10输入/输出及θg幅值；A 使用 Q14 直通估计，偏置和预测系数仍为浮点训练参数，本地诊断不称整数 RTL 合同。固定公共前缀 `[2,3,7]`。预测仅用已生产前缀与训练均值/协方差；未来完整 Y 只作监督和完整回退参考，不作预测输入。

预测形式为已有部分和加剩余均值；`abs(predicted_margin) ≥ gamma[t] * residual_std[t,h]` 时接受，否则完整计算。A、偏置及10个γ共同训练，输出θ保持。独立费用按各消费者所需列计费，组费用用未完成度的确定性 `max` 形成 P4×H8 列需求，硬0/1端点与组OR一致；不把边际独立假设当真实请求概率。

`source_words` 只有P4 OR，所以组列费用是保守包络，未含精确lane交集。time-major列访问和多个时间共取一次W分别统计；不能相加列费用冒充共取权请求。真正的服务/状态费用由 [hardware/](hardware/) 补齐。

训练固定400步、batch64、Adam学习率0.002、同随机种子和批次、同损失权重；仅最终valid4评价，不用valid调γ或挑中间检查点。局部蒸馏损失与门错误分开报告，不能由此宣称任务精度通过。失败只说明这一预算与表达方式；若有可解释的新组合可继续试。

正式推进仍须真实网络 AEE、完整 Conv1→PSN→Conv2 费用与最强同资源控制；旧15%整链门用于晋级电路，不将小样本训练代理当门。保持生产树和投稿稿只读。

## 新整数桥与真实网络入口

`compile_integer_bridge.py` 已用 `full_capture4` 的真实 W1、固定 BN1 与逐 p 源编译共同 W8，并为自选前缀 row34／common3-group 分别生成新 Aq14、逐 `(t,h)` 完整阈值及前缀正负阈值。原 θ 幅值保留，`theta_decision` 与 `theta_amplitude` 分字段；新训练的负侧接受条件是 `pred ≤ −radius`，没有套用旧严格小于的表。BN 常数已折入整数比较，零原始卷积和仍可能产生非零门。

`integer_bridge_r1/result.json`：首四个 **train16 捕获帧**、每轴983,040门，整数比较与直接同学生函数的 full／conditional 均0差；精确有理数边界检查分别12,864／14,400例。相对各自 FP 学生，完整函数改变358／344个门，提前函数改变354／334个门；这只量化本次模型变化，不能当 AEE。共同 Zi 静态范围 `[-15540,16695]`，Ui 需30个有符号位，阈值需27位；接口仍保 INT24／INT48。每轴直接表有2,880项，按48位存为17,280 B，尚未计读口或实际时序。

`evaluate_integer_bridge.py` 已提供 `--modes full conditional`、`--split diverse/valid`、`--count`、`--capture` 与 `--stop-at-block`。它按行条带计算整数值 Conv1，避免全图 im2col；norm1 wrapper 不重复施加 gain，实际 Conv2／固定 BN2／shortcut 和 CoarseReady 后继照常执行。CPU 上，两轴各983,040门的原生布局、接受掩码、完整／提前输出与编译参考全部0差；另用真实完整源图的局部窗口验证了 W1/channel/kernel/条带索引。默认后继保持母模型的真实 FP Conv2／BN2；网络 AEE 由单独 GPU 评价结果给出，不由这些 CPU 数字推断。

整数版捕获沿用完整 source/output 门图、need_column 和小窗口接口，另存逐 lane `accepted.npz`。`conv1_Z_int32` 是实际整数状态；`conv1_raw=scale·Zi`、`norm1_Y=scale·Zi+offset` 是明确标记的等价仿射窗口（Float64），不是声称硬件另存这两份张量。

FP 与整数的 conditional 捕获现在都直接保存本次判决的 `accepted_gate_bits/accepted_gate_shape`（`gates.npz`，T/C/H/W C-order little），并兼容 `accepted.npz`。exact 的 `prefix_acceptance_evaluated=False`，不产生假早接受位；这些位只记录已有预测，不另算一遍 PSN。

普通双卷积量化控制已加入为 **`--quantize-conv2`**。两学生共享同一份 W2／θ／固定 BN2 折叠规则，按 H 取 dyadic scale、W8 round-even；整数 Z2 经 `scale·Z2+BN2_offset` 转为 FP32，再执行原 shortcut。全零源仍输出 BN2 常数，未偷删支路。新学生另存 `conv2_integer_control.npz`、`_w1w2` 轴和独立 AEE，不能沿用只量化 W1 的结果。CPU 用每轴245,760个真实捕获衍生门检查：整数卷积、仿射输出和零源常数均0差；共同 Z2 静态范围 `[-15864,17457]`，W2 零率1.5613%。完整825精度已补齐，尚无该W8控制的完整硬件性能。

普通接口控制 `evaluate_boundary_control.py` 使用train16、两结构与两执行模式的共同逐H二幂尺度，将shortcut缓存和相加输出存为Q16；源神经元仍读取原输入。BN2偏置保留8个保护小数位，26位有符号内部界足够，最后round-even到Q16。192万实际窗口输出与独立整数移位/RNE计算0差；90个符号和中点定向例0差。四轴diverse10 AEE为row34完整／条件1.127440／1.141005、common3为1.140893／1.128014。各轴身份缓存裁剪35次，输出裁剪8–10次，均已在AEE里；不是无损模型。见 `boundary_q16_calibration/`、`boundary_q16_valid10/`。这里只闭合普通数值接口，尚无825或时延收益，不当新机制。
