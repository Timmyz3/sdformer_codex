# 昂贵 patch：先定位不可廉价删除的计算，再测生产与消费

本轮使用既有整数源码学生、原完整 T10 PSN、θg 和粗头；没有套用上一轮 s2b3 剪枝。十帧母模型精确复现 1.114212。以下首先是零训练敏感性，不能把掩码失败当成训练路线失败。生产 nts07、主稿未改。

## 挂点敏感性

`patch_embed.residual_encoding.resblocks.{0,1}` 每块为 `sn1→conv1→norm1→sn2→conv2→norm2＋identity`，每个卷积为 C96/H96/3×3。这里属于旧40帧粗头后较贵的 patch；不把那份工作量代理当本轮周期比例。

|---|---:|---:|
| 母模型 | 1.114212 | 1.114212 |
| 分支不生产，保留真实 norm2(0)＋identity | 2.424371 | 1.859643 |
| 中间隐藏通道减半，W1行与W2列同时删 | 1.266880 | 1.233490 |
| 仅conv1逐行2:4 | 1.121754 | 1.119848 |
| 仅conv1共同展平16项、8输出一组、保留一半 | 1.102031 | 1.300903 |

半宽影响两层，约删整对卷积50%连接；后两轴只影响conv1，约删整对25%，不是同预算对照。展平16项跨 `C×kh×kw`，不等于原生源字，不能据此算物理取数节省。半宽和删分支保持真实 BN/PSN/shortcut；软件仍执行被零权重屏蔽的路径，运行秒数不作硬件结果。

这与 s2b3 全隐藏删除仍满足 full825 预算不同：patch 值得继续研究稀疏生产，但普通2:4是很强的控制。[完整结果](valid10_summary.json)、[脚本](run_patch_probe.py)。

已按全域动态 BN、完整时间矩阵 A 检查

`A(aY+b·1)=a·AY+b·A1`。

20个真实conv1场景、9,830,400个保留全部C/T的采样，Float64最大误差3.56e−15、门差0；这些位置与原FP32路径也门差0。空窗处原始Y确为0。它是实数代数及采样数值检查，未部署全网重排，也不是定点/RTL等价证明。[消费结果](zero_column_consumer.json)、[脚本](consumer_probe.py)。

两块本次所有场景的默认T10门均为0；不能把非零默认和负例外包装成当前检查点已展示的必要优势。τ与θ仍不同，其他参数/场景的非零默认需要正确处理。

最贵r1.conv1在32bit表示下，Y从294.912MB降至约208.076MB（含共享有效图和逐行偏移）；完整PSN从737.280M降至519.948M乘加项。24bit仅作尺寸扫描，为221.184→156.081MB，未准入该位宽。这些值仍很大，未消除动态BN等待；掩码生成、打包、端口冲突、真实BN归约和conv2均未闭合，不能称净收益。

普通“压缩Y＋同一零掩码＋BN补偿＋PSN零列跳过”已可得到该行为，故保留为强底座，不称独立创新。[先验逐项分析](../../literature/patch_background_followup_20260908.md)核对了 Graham/SBNet/SSCN/DeltaCNN/MEET 的背景、索引、halo和归一化边界。

## 同步检验更简单的固定 BN

用原train32全域一、二阶矩校准，只换四处patch残差BN，不使用验证集拟合。十帧：仅r1 norm1为1.095979，两块norm1为1.118428，全部四处为1.120722，母模型1.114212。[十帧表](fixed_bn_valid10_summary.json)。全部四处已完成 [full825](fixed_bn_valid825_summary.json)：825帧/18序列/48,152,523有效像素，帧均AEE **1.2031838444**，像素均值1.1700342948；同父1.1653991651，帧均增加 **0.0377846793**，通过1.259预算。这是仅校准的新模型轴，没有与生产mask或剪枝联合跑full825。

固定BN已通过精度预算；接受这一精度代价即可移除四个全域统计等待点，但仍需实际卷积、T10神经元、缩放/偏置、halo与shortcut。不能再把可校准消除的全域屏障写成必须设计复杂电路的理由；同样的零列消费也须给固定BN控制。保持完全原函数的任务仍可采用动态BN压缩路线，两者不能混成同一个精度结果。

## 下一判别：少生产，而非重新编码已有零

## 完整借鉴所需的更强控制

因当前T10输入已经齐备，普通masked PSN应允许静态重排；普通分组也应允许输入组与输出标签独立分配。已做两项训练集CPU搜索，均保留原输出t标签和34项：

- [重排k4](reordered_masked_probe.py)：子集＋末三列DP精确覆盖10!个共同输入/输出排列。训练膜MSE从自然k4的0.210544降至0.136874。
- [输出分配分组](reassigned_group_probe.py)：在每个3/3/4输入分区内，用Hungarian给原输出行分配3/3/4个名额；固定连续输入组MSE为0.153397，全2100分区最优0.143349。此控制不要求原对角保留，不能把更宽松约束的收益称为新机制。

独立审核分别用前向DP、容量DP和normal-equation solve复核，系数及偏置的FP32重建一致。[审核与状态](dependency/strong_controls_review.json)。三轴Y均为4；重排k4的推送U为3，分组为4。它们是更强普通控制，不能按膜MSE直接选网络赢家。

另外恢复了[普通低秩控制](dependency/lowrank_controls.json)：rank2/3使用40/60个因子系数与乘积，训练膜MSE为0.110836/0.067459。需等待全部十个输入，保留2/3个连续latent，另需输入/串行输出工作位置，不能称同34项算术预算。此前无损SVD预测的负结果不适用于本次允许改变A的有损学生。

[训练门诊断](dependency/train_gate_summary.json)比较了train32每帧512个完整C96/T10空间采样。自然k4总门差1.83%，却漏44.40%教师非零门；sliding总门差3.25%，漏99.74%；row34/连续组漏21.68%/44.51%。大量静默样本使总体门差不够判别，膜MSE也未随AEE单调变化。诊断用保存的真实FP32门作教师、NumPy Float64求值，仅是训练样本误差，不能代替完整光流精度。

## 低秩前移：取权变少，连续幅度算术变多

另补42帧[单位置时间模式](dependency/source_element_histogram.json)，每帧66,355,200个`(C,kh,kw,y,x)`单元。`Σhist×popcount×96`恢复valid10平均2,982,223,315.2次conv1活跃贡献，与原统计均值一致。

固定BN下可以在实数代数中将R移到卷积前：

`R(a_h Conv_W(θg)+b_h·1) = a_h Conv_W(R(θg)) + b_h·(R·1)`。

随后仍需L、导出低秩学生的校正偏置b_r、未改的center/θ与真实消费者。不能换回原稠密PSN的bias，也不能把潜变量上的BN偏置误写成原b_h；尚未实际运行该重排网络来验证FP32/定点差异。

[源费用脚本](lowrank_source_cost.py)用保存的R及真实模式计数，得出：

| 输入组织 | conv1有效数值项/帧 | 数值动作 |
|---|---:|---|
| 原θg源 | 2.982223G | 预折θ后的权重加法 |
| rank2连续源 | 3.197648G | 连续幅度乘加，数量比原加法多7.22% |
| rank3连续源 | 4.796471G | 连续幅度乘加，数量比原加法多60.84% |

两个R都没有把非空时间模式完全消零。若一个P4上下文内向所有latent共享同一权重向量，逻辑取权使用为7.838010M；这是取权与连续算术的取舍，不是加速比。R查表/形成、源驻留、位宽、乘法面积能量、其余L和conv2尚未计入。[结果](dependency/lowrank_source_cost.json)。因此“十步压到两三步”不能直接做硬件倍率或主贡献。
