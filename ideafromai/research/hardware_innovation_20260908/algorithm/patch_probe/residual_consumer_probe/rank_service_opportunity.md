# Conv2 普通低秩/连续旁路控制的实际费用机会

2026-09-09，加入已通过 valid825 的普通空间剪枝。**非 anchor 整个 BN 分支置零是现在必须保留的强控制：没有非 anchor Conv2/U/V，仍保原 identity 和连续 anchor 路径。** 相对它，R16 的低系数字供给量需与新增连续乘加权衡，不能再只和全空间原 W2 比算术余量。K 旁路没有独立的费用优势。这些均为普通控制，不增加机制新颖性分数。

`nonanchor_norm2_branch_zero` 的完整 825 帧 AEE 为 **1.2196337149**，48,152,523 个有效像素，见 `branch_control_valid825/nonanchor_norm2_branch_zero_summary.json`；共同 R32 父为 1.203043065。只置 Conv2 raw 为零、仍保 BN2(0) 的另一函数为 1.2626667877，略超 1.259 预算，不能与本控制混称。新控制在非 anchor 连整个 BN2 分支及其 shortcut 加法一起删除，proj.sn 直接吃 identity；anchor 的原数值与 Wres 路径不变。sn2 输入未改，因此以下四帧源捕获可直接复用；不是拿不同学生的源密度拼表。

输入为 `capture_train4_ped` 的四个真实训练帧、每帧原 64 个水平 P4，完整 T10/K864/H96。共有 279,601 个非零源位，密度 3.1603%；10,240 个时间/位置中 6,237 个源非空。源实际为 θg，此次 θ=1；这不改变一般接口的连续 θ 语义。F/G 直接读 `rank_control_parameters.npz` 的同一次 FP64 SVD 导出 FP32 系数，R16 取共同前 16 项，没有另行拟合。

## 同一有限供数合同

每个原 P4 内按 K 顺序，当前 40bit 源词供全部合法 T/P 使用；mixed 的 anchor 只走原 W2，非 anchor 只走 F→G。空间剪枝控制只有 anchor 走原 W2。全部 Z 保留至 V 阶段，V 仅跳过由源空/静态 F 零证明为空的 Z，不用未来数值抵消作先知。W2、F、G、K、Wres 各自分区；系数存储地址按 `input_index × output_count + output_index`，真实 FP32 系数按 64bit/H2 或 256bit/H8 字合并。每个字在当前 P4 内充分复用，组间没有额外热权重副本。共同固定描述符循环扫描 221,184 条；40bit 紧凑为 1,105,920 B，按 64bit 补齐为 1,769,472 B。空间剪枝还可静态省掉全无 anchor 的 P4：本范围仅 128 个 P4 含 anchor，可降至 110,592 条/884,736 B，但该源排程尚未实现。anchor 的 3×3 邻域仍需真实 sn2 源，不能按输出位置直接删除对应上游位置。

**算术门。** 只比较被改变的 Conv2 部分，令一次 FP32 MAC 更新成本为一次 AAC 更新的 `q` 倍，不含存储/供数/控制，则全 R16 需 `q<2.334865`，混合 R16 需 `q<2.300772`，全 R32 需 `q<0.933946`。把首项装载也给普通控制后，R16 的乘法单元成本需小于 1.345282 次加法成本才有纯标量算术余量；R32 的加法数量本身已超过原轴。这些是成本交叉条件，不是时延预测；专用 MAC 的并行度、共享端口与合法重叠均尚未计。原轴还有同样的 2,359 万连续 PED 乘积，不能隐藏这一剩余贵处。

上段只说明相对旧全空间原 W2 的界。**改用已通过精度的空间剪枝分母后**，全 R16 要 `q<0.301686` 才有这一路纯更新算术余量；给双方首项装载后，即使不收乘法，R16 的 U/V 累加加法也多于空间剪枝。它仍有 40.54% 的本地系数字节差额，需要实际带宽/连续乘加资源模型才能判断；这不是 40.54% 时延收益。混合 R16 相对空间剪枝增加 3,246,320 次 U 更新和 7,054,848 个 V 乘积，是另外一个精度/费用取舍。空间剪枝在本范围少 72.57% 的 Conv2 AAC、但合并 Wres 后系数字节只少 49.98%；都不是按 75% 几何位置推导的周期。

## K 控制与存储边界

`K[o,k]=Σ_h Wres[o,h]·BNgain[h]·W2[h,k]`，固定 BN2/conv bias 编入 value 常数。它在实数代数中使 value 支路保持原函数，但 FP64 构造、FP32 存储和原 CUDA 求和次序不是同一数值执行；本轮没有为融合 K 声称精确 GPU 等价或通过 AEE。K32 最大系数舍入差约 2.78e−8，不能据此推断输出无差。K 贡献若直接加进已有 identity value，首项也需要相加；若另开 K 部分和并首项装载，最后的合并加法抵消该项节省，计数已保留。

原路径的单次 Wres 已同时处理 identity 和 branch，所以 `原 gate＋K value` 多做 anchor K，不能省掉一条不存在的第二投影。`R16 gate＋K value` 比混合普通控制多出 anchor 的 **1,227,296 次 U 更新与 2,525,184 个 V 乘积**，K32 下系数字节也增加 637,632 B；mixed 的 anchor gate 保持原函数，而全空间 R16 gate 会改变它，因此两者仍须独立测 AEE，不能由此断言精度优劣。

K64 将该列增至 663,552 B；K 常数另 768 B（FP64）。每个 P4 的 identity 与完整 Conv2 输出各 15,360 B；全 R32 的 Z＋两者共 35,840 B，再留偶数行两个 anchor 的 PED value 为 7,680 B。空间剪枝仍保 identity，但其 Conv2 输出逻辑峰值只需 anchor 的 7,680 B（全无 anchor 的组为零）；公共分配上限与实际活用量在 JSON 分开列。首项 valid 位最多另 640 B，仍需上下文/坐标/完成元数据。这里给出的是一个有限、可排列的裸 payload 方案；H8 分条消费可能省状态并增加其他重读，尚未比较。K64 的累计精度/状态位宽未准入，不能免费套用 FP32 状态数字。

原 W2、F/G 与空间剪枝的稀疏更新、系数字请求已用独立稠密矩阵闭式计数逐帧核对；原 W2 计数与已有 count-bound 普通分母一致。这份 CPU 计费未额外训练、运行 GPU、RTL 或 EDA，825 精度来自上述独立网络结果。未计完整 BN2/shortcut/proj.sn/脉冲 proj.conv 的费用、状态流量/RAW、银行仲裁和冷 DMA；空间剪枝省下的非 anchor BN2/branch-add 也未暗自折为周期。系数字节是本地使用量，不是片外流量。普通 parity 重组及跨 P4 缓存尚未测。下一步必须以已过精度的空间剪枝作普通强底座；本表不能支持新机制或净加速结论。
