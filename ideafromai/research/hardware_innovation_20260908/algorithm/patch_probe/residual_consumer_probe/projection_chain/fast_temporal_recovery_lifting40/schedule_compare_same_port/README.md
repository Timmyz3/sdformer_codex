## 做了什么

* 同一首帧zurich_city_09_a_0001，两轴实际参数和旧同帧AEE完整复现；完整三处gate、θ、坐标布局与小块I24已取回。本轮没有新的valid825。两学生原有825 AEE分别为1.219801338与1.232979368，+0.013178030的相对精度红灯仍在。
* 源核把35次中间round及35次sat24分别收进同一算术通路；普通十门与lifting末五门均给精确阈值前推。程序逐槽执行真实RF值、装填I、收集门与有限FIFO，每种场景192个真实门字零差；原I到源结束仍保留。
* 后端执行完整U16/F、BN2常量和I合并、PED U32/V32及门比较。独立整数公式与实际模型的每轴61440个门、15360个连续输出均零差；服务Engine逐项发出地址和依赖请求，尚未逐指令执行SRAM payload。它没有给FP影子Conv2重复收费。
* 后端用共同自然T10-word输入，避免拿debug bitplane的零碎访存当主分母。184320B的完整I块按P2外部读取；32KiB状态总峰32576B，Z与PED U按真实最后使用复用。权重池128KiB，实际使用44096B；阻塞入口和出口均计费。

## 新颖性与唯一后续接口

借入部分仍是完整CSE、常量阈值前推、SIMD、Gustav供数和低秩消费者。候选X是**可学习lifting时间结构在真实连续输入、θg出口与双消费者残差链上，经同等编译之后留下的净服务及状态优势**。这次72→12的程序存活压力是可用的结构证据；10.76%源服务及5.78%后端服务尚不足以承担强接收结论。

按灰区规则，只保留一个下一接口：**带明确费用的两级RNE/sat写回**。当前模型将每次round与sat串行发射两次；下一次可检查一次复合规范化写回是否保住结构优势。普通图获得相同指令、流水延迟、寄存器/读写口与合法排程权限；新阶段寄存器、RAW等待和写回冲突全部计入，不把规范化当免费操作，不承诺维持原时钟。这个复合操作本身归已有定点执行方法，不能单独当X。

完整r1服务仍需在同一资源合同上连接FP32 preview U32/V、完整sn2、源核和整数后端，并补原生proj spike conv与PED末加；本轮不把局部槽数填成该总表。当前学生的FP32 preview不能偷换成旧signed24 V图。未闭之前不开精度恢复、性能RTL或主稿贡献改写。本次没有新增资源扫参，也没有对lifting家族作淘汰判决。
