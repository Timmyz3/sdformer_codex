# 固定全合并纯门图：第一次 CPU 费用筛查

仅使用 lifting raw 的 stage320：从实际 q12 半步以 Python Fraction 组成无 RNE 的 B，再折入真实 IEEE source gain 和 P；没有读取 export FP32 source_A。按既定每矩阵 signed16 规则得到 exponent=15、100 个非零系数、范围 [-20511,10545]，无裁剪。该近似矩阵不是已验证825的逐步 RNE/saturation 函数，不能继承其 AEE。

| 每 T10 向量 | 原精确 lifting raw | 固定全合并近似图 |
|---|---:|---:|
| 完整 da4ml 加减 | 159 | 241（add 148 / sub 93） |
| 中间 RNE 条件增量 | 35；末5已折门 | 乐观按0 |
| 精确节点位宽和 | 5143 | 7984 |
| 覆盖移位操作数/结果的算术位和 | 5144 | 7987 |
| 加上原35个RNE增量的算术位和 | 6031 | 7987 |
| 原 guard/sticky/饱和 | 35 guard、333 sticky输入位、35饱和选择 | 额外guard/半径比较/fallback均按0 |

完整合并图有 67 个直接共享节点、147 个跨最终输出祖先节点；最长加减依赖 10，最大实际算术位宽 41。唯一末端负号可静态翻转门比较方向和cutoff，无须物化连续负输出。完整官方顺序/固定 last-use 压力顺序的临时峰值分别为 2048/1734 bit（69/58 个数），另有共同 I24 的240bit和两个至多41bit转发寄存器；输出sink假定及时接收。这是静态压力统计，未闭端口或峰值物理RF，更不是周期。

位宽口径：此表双方都取移位后两操作数及结果所需位宽的最大值；原lifting图按同一规则重计为5144bit。早先常量编译报告的5234bit用了更保守的进位预留，不能混入本表计算比值。

全合并图单看算术就比原159+35次增量多 24.23%；同口径算术位和比原加减及RNE增量之和多 32.43%。故本次停止**这个固定全合并布局**，不追加误差界/回退扫描。尚未综合原RNE的guard/sticky/saturation，不能将上述比值当成面积或物理严格支配证明；部分合并/其他纯门证书仍未被该结果否定。

新 q16 图在完整符号系数、全部1024个signed24域角点、1024个固定整数向量及21个基向量/零向量下，与独立整数dot和官方DAIS共 20690 个输出零差。这里的零差只对应新矩阵，未与原lifting门比较；没有网络实验、GPU、RTL、格式或分组搜索。
