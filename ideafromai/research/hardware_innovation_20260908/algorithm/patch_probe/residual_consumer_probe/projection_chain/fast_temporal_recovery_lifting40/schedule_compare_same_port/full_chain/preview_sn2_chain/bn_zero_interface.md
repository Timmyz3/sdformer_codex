# 新观察：零投影跨动态 BN 的消费者边界（机会探针）

**B在前：** 已执行的全域BN逐学生读取18432000个原生投影值。对首个既有帧的探索性检查发现约57.5%–57.8%的位置在96通道同时为零，但动态BN不能直接把这些位置从均值/方差分母删掉；随后仍有连续PED。这是已有空源跳过尚未消掉的搬运，是否占足够服务须在同一完整层里测。

**A与最强对照：** Gustav的NRV能提供完整K864的空输入证明；[Finch，OOPSLA2025](https://doi.org/10.1145/3720473)已处理非零fill与重复值结构，[MLSys2019 BN重构](https://proceedings.mlsys.org/paper_files/paper/2019/hash/9db64c20dee0011899dfdf200e61ef35-Abstract.html)已拆分统计/规范化并与前后层融合。故“位图+默认值”“把BN分两段”都归公共底座。另将[FlexAcc，ISCAS2025](https://jiemingyin.github.io/docs/ISCAS2025_FlexAcc.pdf)的BN数据搬运分解作为比较对象，不照搬其GPU/FPGA平台倍率。

**候选差分，尚未证明：** 从实际二值投影生产者的空输入证明出发，保留动态BN所需的零位置统计质量，在连续PED之前维持一个随本域统计更新的默认向量，而非重新物化96路零或默认输出。必须给普通模型同样的默认值编译和融合权限；若特殊零标签只等同通用Finch式fill表达，则只留实现，不作X。更严格的FP32重复更新/舍入处理是未试接口，不能用实数计数公式假称位等价。

**本次固定探针：** A800只推理原ordinary/lifting两学生、原预选一帧，补完整I24/updated I24、三份T10门字和连续PED；用实际3×3/C96门域重建原生投影空源标签。检查标签推出的零、BN后的非零与连续PED义务；同时列“active-only BN”及漏掉零位置中心化方差项的错误控制。捕获不是硬件回放；约57%仅是先看原数值得到的探索性观察，不能外推825。

**晋级/停止：** 若生产者标签无法解释零，先修接口，不以输出零倒推免费许可。若只能省传输但不能胜过普通默认值+最佳BN融合，停该贡献句。端口、元数据、动态统计、FP32差异与PED全部计完前，无净服务百分比、训练或RTL许可；不启动剪枝/阈值扫描。BN孤立算子的改进也不能自动满足整链15%门。

本轮文献边界：核上述主来源摘要、Finch格式说明及FlexAcc前向/数据流章节；未复现完整Finch编译器或FlexAcc工件，不声称没有先验。这个接口保留在原有浅层统计/消费者完成队列，不另起Card名。

**下一固定实现界面：** 先给双方同样的“生产者空标签+普通默认值BN融合”控制；全192000位置、原256值树归约顺序和PED均保留，先只免去有来源证明的零载荷读写。严格FP32统计/最终输出及元数据实价通过后，才判断跨消费者边界是否还有超出该普通控制的增量。没有额外增量则该项留作底座，F1的表示/共同需求研究仍保留。
