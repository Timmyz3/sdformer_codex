# 完整动态BN的下一完成边界

B：局部原生投影已能写出，但eval下BN没有running statistics；每通道必须等192000值。用捕获μ/var直接归一化不能闭合硬件。

固定公共实现：同128KiB状态、128KiB系数、96×8 RF、1R64/1W64、1R256系数、32B/5槽DMA。FP32四条交错部分和；一遍均值、一遍中心化平方和、第三遍规范化。每个实际32B数据通过SRAM/RF。rsqrt使用整数初值和三次FP32 Newton，无免费sqrt/SFU。固定背压沿用前表。该稳定两遍统计是共同控制，尚未与最佳一遍Welford做完整实现比较。

数值修正：四条长链仍有约48000项累加，方差最大误差约1.4e-5、输出约0.0026。因此在相同资源内采用固定256值叶块、四条局部部分和、10层SRAM树归约（3840B）。不是扩大RF或引入FP64。修正后输出最大误差为3.8147e-6/4.7684e-6，普通/背压输出逐位相同；仍非CUDA位等价或新AEE证明。旧长累加只作失败的数值控制，不晋级。

本次数据边界：真实完整捕获的原生投影输入域→自行计算统计与全部规范化输出。外存可持完整域，片内不持整域；所有外存读写计费。不会将其槽数加到4×4局部表，也不声称已经重算其余全图投影。FP32归约与rsqrt函数差异单列，不沿用AEE。

后续接法：完整层投影发射→同域统计屏障→保留U32/延后V的同资源两臂→最终PED合并。只有整个函数和时间线都闭，才能改Stage B状态。BN本身是必须完整借入的算子，不作为新增标题。

实测：每学生18432000值（192000/通道），均值/方差最大差均7.450580596923828e-9。树归约控制正常203297841槽、固定背压234061322槽；两学生同量同槽。外存读221184000B、写73728000B；统计与规范化是串行公共算子控制，不能与4×4局部链相加成整帧表。运行`run_global_bn.py --pairwise`与`--pairwise --stress`，详见global_bn_pairwise*.json。
