## 延迟与容量已收费

8 lane、每lane 96×48位2R1W RF、512×128位组合ROM、5760B持久I和16项有限FIFO，四臂完全相同。流水A执行加减／RNE／比较／LOAD，流水B执行signed24饱和或48位直通。槽t发射读旧RF，t末进A/B寄存器，t+1末写回，t+2才允许读；LOAD和gate也遵守两槽延迟，无旁路。每槽最多一条SIMD指令、每lane一次RF写。gate-valid只在B写回时出现，COMMIT等该批流水排空，再逐lane交付。

新增中间流水态为8×48位载荷，加共同valid1、写回类型3、目的寄存器7、输出时间下标4，共399bit，按**50B共同分配**。无跨批并行，不需要额外批标签；没有运行时scoreboard或未计价的pending队列。宿主RF逻辑标签仅核验提前读取／活值覆盖，不参与执行选择。全部中间寄存器只留一项，饱和器与两级延迟同样配置给ordinary；未证明该硬件与旧单槽核等面积或等频率。

排程器显式收费NOP及ROM读取。两臂选定程序均只有一次末尾流水排空NOP；lifting的另一个压力策略虽把峰值降至13字，却多两次RAW等待，按预先约定选了更短的15字程序。旧单槽模型的12字峰值不能混入本表；实际RF分配均为96字，没有面积下降结论。
