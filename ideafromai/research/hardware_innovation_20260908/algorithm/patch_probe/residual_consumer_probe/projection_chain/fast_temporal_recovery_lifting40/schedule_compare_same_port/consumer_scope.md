# 有限整数消费者切片（2026-09-10）

本次完成同一真实帧 `zurich_city_09_a_0001` 左上角的 **sn2 已就绪＋外存 I24 → Conv2 U16/F → anchor 合并 → PED U32/V32 连续口和 proj 门口**。16 个 even/even anchor 均执行完整 K864，输出 T10×C96×4×4 连续值及 T10×C96×8×8 门。普通 dense-source/raw 与 lifting raw 是各自已评价的不同学生，本表比较其实际捕获负载。

`consumer_service.py` 的 NumPy int64 逐个执行已保存的 RNE/sat 边界：两轴各 **61,440 门和 15,360 个真实连续输出均 0 差**。这是独立公式核验；Engine 目前排实际地址/依赖，但未逐指令执行 SRAM/累加载荷，不能把公式 0 差扩大为地址载荷回放通过。连续 gold 来自实际绑定 fixed helper 的 `proj.conv_res` 返回值，未使用 FP 影子。U16 的 θ 已折权；F 已折 BN2 gain，BN2 常量在 anchor 加一次。非anchor 的整个 BN2 branch 已由共同父删除。当前两轴源/输出 θ 都为 1，但十个 signed cutoff 独立保存，未令 τ=θ。各矩阵完整合法输入域的累加界均落在 signed48，最宽界约 ±4.656×10¹²；最终各级状态仍按合同落 signed24/f14。

共同资源是一个明确的服务点，不是工艺时钟：8 个共享算术 lane，16×24→48 MAC 结果延迟 2 个服务步，AAC、RNE、sat、比较分别占 1 步；一个累加向量串行保持依赖。state 为独立 64-bit 读/写口，系数为 256-bit 读/写口，均每步一字、读延迟 1；当前 W 字和输入字各仅一份。MAC、转换和这些端口是相对 source-only 加法核的额外能力，不能把两份步数直接相加或称等面积。所有输入/输出共用 32 B/5 步事务流，每个 32 B 块即时进入/离开本地存储，64 B staging 有界。

Z 在全部 F 消费完后才释放给 PED U；没有额外主机驻留态。整个 8×8 I24 共 184,320 B，按 P2 分批从外部读入一次。四个 signed16 矩阵占 43,008 B，BN2/PED bias 与 cutoff 配置占 1,088 B，冷填共 **44,096 B**，全驻共同 128 KiB 系数池。后续系数字读取是片内使用，不能写成片外流量。

320 B 已分配为累加48、operand 收集48、W字32、state字8、DMA/output64、源与门收集器各16、源元数据8、地址/控制80 B；48 B operand 区复用承接 H8 I/gate 和跨64-bit的24-bit标量，不依赖一个8 B缓存承载完整向量。

K-major 保留全 T 部分和，同 k 的活 T/P2 共取当前 W 字；time-major 保留工作累加向量，支付重复 K 扫描、源读和取权。没有逐阶段拼最小值。两轴均用强 source-empty 控制：完整源扫描确定空的 anchor/time 后跳过 F，仍支付 BN2 常量；分别有 43/56 个空点。完整非零产品数与独立源×真实非零 W 计数相等。真实四矩阵没有全零 H8 系数组，因此本次没有借免费静态零目录跳过取权；将来若启用该分支须补元数据供数。

主结果以普通 source 可直接生产的 **自然 T10 uint16 词**作输入：12,288 B，搬入 3,456 步。保留的原生 TCHW debug 重放因 8 bit 行跨全幅地址而取 245,760 B、47,616 步，仅作输入格式对照，没有放进主分母。两轴共同外部事务合计 314,432 B（包含冷填、I、源词和两类输出）。lifting 的该切片步数少 **5.784%**；其中 U16 少 36,088 步、F 少 7,800 步。共同 PED 连续路径约占总步数 52%–55%，不能只凭源加法减少宣布完整链获益。

**范围尚未闭合：** 本模型不包括 source DAG、当前仍为 FP32 的 preview U/V＋完整 sn2、原生 FP32 `proj.conv`、后续 norm/PED 两支合并，也未把已有 integer CMVM 强行接到 FP preview。新保存的原生投影 W 可供下一次接入，参数可读不等于该算子已调度。当前是一个左上角边界块；内部块 halo、更大的串行块交接、完整 Gustav NR4 广播/流水、CMVM 和合法多累加流水均未最优化，不能乘块数宣称整帧周期，更不能与 source-only P2 数字拼成全链 PASS。
