**继续保留整残差链前投影。** 源码和四训练帧实捕证实，C(x_stem+Y0+Y1)可以在实数域展开到三个真实θg源，不再遗留旧局部方案的Cx。当前直接96路展开需24.879840M额外源加权项，原C是23.592960M连续乘积，另有三核、动态stem BN及跨阶段状态；这些不同算术不能直接作加速比。普通门链仍须保留，X12总和舍入不满足分配律。普通投影R32的10帧AEE1.205744、825 AEE1.224500均已完成。同50%源组的W删除／核空间／仅投影K删除，经相同四训练帧顺序均值校正后，10帧AEE为1.589146／1.565390／1.394170，未达到普通R32；这仍是未恢复训练的学生，下一步准备同预算真实GT恢复并保留独立稀疏L强控制。[校正结果](projection_chain/consumer_bias_corrected_diverse10/run.json)、[完整先验与控制](projection_chain_prior_review.md)、[捕获与费用](projection_chain/README.md)。

**B：普通底座之后还剩什么。** 前一轮恢复后的普通 R32，在完整 valid825 上 FP AEE 1.201095、U8/VQ5 解量化 AEE 1.203043。旧 private56 相对同样条件执行的 shared56，在完整一帧的 256bit U 权重字上只多省 0.03999%。因子分解和移位消费值得保留；继续增加该固定私有尾的控制逻辑没有足够的净收益依据。本轮转到仍为 96×96×3×3 的真实第二卷积，检查其消费者是否真的需要全部连续结果；这一步不是重测旧 C1。

**A 与拟融合的 X。** 残差后的发放、膜 shortcut、范围提前终止、低秩/低位因子及空间剪枝均属于继承方法。当前待研究的接口是非因果 T10 PSN 与实际 PED 双消费者：同一连续残差结果，有些位置必须保留幅值，有些位置只被后续发放门消费。先建立普通删除/重算/区间对照，再判断是否需要联合训练消费者依赖、不同精度的计算或便宜的膜复用。不能把“跨层”“绑定矩阵”或多篇论文组合本身算成 X。[先验与独立概念审阅](novelty_review.md)、[硬件消费者与状态审阅](hardware_review.md)。

**实际拓扑修正。** 首次运行发现 `proj` 是 `SpikingPEDLayer`，并非最初按通用类阅读的单支 `SpikingEmbeddingLayer`：先 `conv_res(x)`，再 `sn(x)→conv`，最后相加。连续 `conv_res` 是 1×1、stride2、padding0，使用 even/even 位置。四分之一是空间位置比例，不是可跳过工作量；该部分不能只凭 `proj.sn` 门已定就删除。普通奇偶重组也应给双方，不能借水平 P4 中 anchor 保活而否定其余位置。间隔列 P4 的 halo 较大，尚未采集、排程。

**已完成的精度工单。** `evaluate_branch_control.py` 的普通删除已取得上表完整825结果。`evaluate_rank_control.py` 的四轴diverse10分别为：uniform R16 1.140892、R32 1.124674、nonanchor R16／anchor原W2 1.147966、仅门消费者用R16且连续支路保原值1.133398；其中只有uniform R16另跑了825，不能替其余三轴补全量。软件仍执行稠密算子，只评AEE；墙钟和75%的位置比例都不作为速度。

门／连续分离与线性核收缩保留为待改进思想。此前仅r1的局部K合成没有消除原来的96×96连续投影：原来算一次C(x+Y)，新路仍算一次Cx；在anchor还增加了门用R16支路。这个负结果仅约束该局部方案，上述三源完整展开已另测。无论哪一种，都必须超过普通空间删除、低秩和完整编译，允许普通流式消费与H8分块。

**固定停门与保留项。** 不给上述全K数量界、现成廉价M或旧private56继续扫参。保留完整θg、低位因子、真实消费者域和另训练的结构化近似；新融合只在普通同函数编译/删除/同训练预算控制下评增量。当前两处采到θ=1，并不改变全项目对连续幅值θ与发放g分开建模的约定。
