# r1 → proj.sn 默认膜复用：硬件边界与强控制

2026-09-09，按 A800 实际 PED 拓扑修正。**该挂点可定义、可公平对照，但默认膜许可只覆盖没有连续旁路消费者的位置；目前不能认定有净硬件收益。** 本次仅读源码与捕获接口，没有运行模型或建立周期/PPA 结论。它改变的是 Conv2 之前能否取得便宜的后继判决依据，与上一条 private latent 请求差额没有推导关系。

**B：实际有两个消费者。** A800 的 patch 是 `MS_PED_Spiking_PatchEmbed_Conv_sfn`，proj 是 `SpikingPEDLayer`，不能用普通 `SpikingEmbeddingLayer._forward_MS` 代替。`Spiking_modules.py:817` 的真实前向先算 `x_res=conv_res(r1out)`，再算 `proj.sn(r1out)→proj.conv→norm`，最后相加；`conv_res` 是 1×1、stride 2、padding 0。因此 r1out 在 `(y mod 2,x mod 2)=(0,0)` 的 **anchor** 有第二个连续消费者，其余位置只被 proj.sn 消费。原评审中整体 sole-consumer 的推断撤回。首轮探针因 proj 无 `use_MS` 停止，只说明该类型检查不适用于 PED，尚未给出消费者机会数字。

普通 R32 已降低 Conv1，新的目标仍是完整 96×96×3×3 Conv2。`ATLIFTernaryPSN.forward:344` 的连续 `h_seq` 只是临时计算值，现有硬件没有免费持久副本。

令固定 BN2 为 `a₂·Conv2(θ₂g₂)+b₂`，sn1 内部膜为 `u₁=A₁x+b₁−c₁`。正向二值门的下游裕量是

`m = m₀ + Aₚ[a₂·Conv2(θ₂g₂)]`，
`m₀ = M(u₁−b₁+c₁)+Aₚb₂+bₚ−cₚ−τₚ`，仅当 `Aₚ=M A₁`。

绑定为同一算子或明确便宜的 M 才省投影；一般 `AₚA₁⁻¹` 不保证存在，也通常是稠密计算。θg 的幅值和判决 τ 分别保留。当前 identity-only 捕获删去整个归一化分支；真正只跳 Conv2 时仍有 BN2(0)，必须编入 `m₀`。若实际神经元是绝对值双边触发，许可要覆盖两个阈值区间，不能直接套单边公式。线性重排首先是实数恒等式，FP32 加法顺序或后续定点编译需另核。

**必须同给的普通控制。**

| 控制 | 隔离什么，不能收弱 |
|---|---|
| 原算子、直接计算 `Aₚx`，完整稀疏 Conv2 | 普通固定 BN/shortcut 融合、T 共取权、源/权重零、最佳合法分块均保留。 |
| 同一个绑定学生、复用 u₁，但无预判 | 权重共享/CSE 与省中间写回的独立收益；不能全归取消机制。 |
| 同学生、直接 `Aₚx` 或复用 u₁ 取优，加相同残差界及普通提前终止 | 最强执行控制；候选若只是这一组合，本身不足以构成新电路机制。 |
| 简单残差门控/旁路、同训练预算与 AEE | 检验绑定或学习许可是否只是普通有损 block/局部门控；与严格证书分开。 |
| 按 stride 消费域分组，anchor 与非 anchor 分开调度 | 双方同给，避免混合 P4 中 anchor 人为保住全部共用 W 字；取权、halo 与源银行冲突仍计。 |

**因果执行。** ① sn1 生成 θ₁g₁，同时保存目标位置的 u₁，随后就地换成默认裕量；② Conv1/sn2 生产 Conv2 所需的真实 3×3 邻域 T10 支持目录；③ 仅利用该目录、静态 W2/BN2/Aₚ 和已经计算的部分和生成保守剩余界 `[L,U]`；④ `m_partial+L≥0` 或 `m_partial+U<0` 才退休对应门，后续请求按未决消费者并集决定，**其中包括 anchor 的连续 conv_res 依赖**。anchor 的 proj.sn 门即使全部已知，只要 conv_res 仍需要该输入通道，Conv2 的真实 T10 数值仍必须完成；不能把门确认当数值确认。真实 conv_res 零列若存在可按静态依赖删除，双方同给，不能先假定它存在。最终 branch 只能作答案核验。支持计数/分块界的目录读取、表访问、符号传播和比较要收费；精确求和所有活 W 得到“界”可能已经付完 Conv2。普通先算时间域 Conv2 再作 Aₚ 的路径同样允许；每个 Conv2 更新都重新投影 T10、或把 `Aₚ·W2` 当免费常量，都不是合法省费。

**状态和释放。**

| P4 内部示例（裸 payload） | 必须说明的寿命/费用 |
|---|---|
| u₁/m₀：H8×T10 共 320 个数，FP32 为 1,280 B；H96 为 15,360 B | 从 sn1 到邻域 sn2 就绪。不能同时免去存膜和重算。允许原位替换，不强制保存 u₁、m₀ 两份。 |
| Conv2 时间域部分和：同 H8/T10 为另 320 个数 | 和默认裕量是否同时活着取决于检查排程；尚无该新学生合法定点位宽。 |
| 目标 P4 的 sn2 邻域：3×6=18 位置×96×T10，位图 2,160 B | 这是内部窗口并集；逐 offset 展开会重复。普通三行缓冲可共享 halo，但全宽三行需 115,200 B 位图，容量/端口与分块择优均给双方。 |
| H8/P4/T10 未决位＋输出位：80 B，另加上下文/源进度/last-use 元数据 | 分开的 H8 若进度不同，不能共享一份剩余计数而不保存游标或快照。 |

连续目标 P4 若连 Conv1 一起融合，还需 5×8 的 sn1 支持覆盖；这不等于必须保存所有邻域位置的连续默认膜。**非 anchor** 在改为 `m₀+r` 后可不物化 r1out，并以 u₁ 替换旧 identity；若 fallback 仍调用原始 `x+branch→Aₚ`，原 x 仍不能释放。**anchor** 需保留原 x 至残差/conv_res 消费，或先收费产生 `conv_res(x)` 并保存该连续贡献，再加分支贡献。后一种是普通线性融合控制，也给双方；未验证精度/算术费用前不能以可逆 A 恢复 x 为由免存储。proj.conv 的门分支可以独立启动，但最终 PED 输出须等连续 conv_res 分支，两支局部结果/完成标志不能免费。

**最强普通 stride 分组。** 240×320 中 anchor 占 1/4，非 anchor 占 3/4；这只是几何比例，不是实测请求取消率或活动加权上界。连续水平 P4 在偶数行混入两个 anchor，在奇数行没有 anchor；因此“任一 anchor 保住 W”只约束前一类组，不能推成全部位置无机会。明确可执行的普通排程是：anchor 单列；奇数行用连续 P4；偶数行的奇数列按四个间隔 2 的位置组 P4。后一类组的 sn2 halo 是 3×9=27 位置（3,240 B 位图），融合 Conv1 时覆盖 5×11；不是原来的 3×6/5×8。逻辑位置可按组内序号分 bank，并保留实际坐标；若沿用 `x mod 4` 银行映射，会有二路同 bank 冲突，需付读排程或同等重映射接口。源行缓冲可跨两类任务共享、同 W 可广播，但跨组热权重/halo 驻留必须受共同容量约束。该调度是常规消费者域分块，不算候选独有增量。

**真正待证的增量与最小门。** 可争取的是训练使“早已必算的膜”成为后继足够便宜且有用的许可，并让它在 W2 请求发出前撤销整组真实依赖。稠密 Aₚ 下，一个未决 t 往往仍需要所有 s；P4/H8 共取权中一个消费者存活也保住该字。先把 anchor/非 anchor 分开报告，普通与候选采用相同 stride 分组，再算实际字请求取消、最慢消费者完成、新增宽状态/界供数，以及未省的 conv_res。全 T 默认门一致率即使很高，也不包括 anchor 连续分支的正确性许可。若普通复用＋提前终止已达到相同费用，保留它作强底座，不再给组合换名。已有 [膜 shortcut/残差后发放](https://arxiv.org/html/2307.01694v1) 与 [剩余范围提前终止](https://arxiv.org/html/1906.03180v1) 的完整借鉴边界见本目录 `novelty_review.md`；当前缺的是实际 PED 两消费者条件下可支付的取消证据。
