# 真实 PED 96×96 连续投影：完整 da4ml 基线

2026-09-09。**整矩阵与十二个H8完整图已编译并核对整数函数；尚无有限端口时间线或PPA。** 这是补齐普通强底座，不是新增硬件机制。未训练、捕获、生成RTL、跑EDA或修改旧／官方源码；CPU编译及核验总用时62.15秒，不是推理性能。

输入来自 [projection_control_parameters.npz](../projection_control_parameters.npz) 的真实 `conv_res`。Wq为输出×输入的96×96、每行dyadic W8；Xq为连续r1out的全局dyadic X12，合法范围 **[−2048,2047]**。实际函数为 `Iq[h]=Σc Wq[h,c]·Xq[c]`；输出恢复为 `Iq·input_scale·row_scale[h]+original_bias[h]`。`input_scale=2^-6`，row_scale为2^-9或2^-8，原bias为0。恢复缩放／偏置不在本整数DAG中；新量化学生的网络AEE由独立评价确认，不能说编译PASS证明FP32网络不变。

采用 [da4ml官方0.6.0与完整算法](https://calad0i.github.io/da4ml/cmvm.html)：图分解、带位宽费用的跨输出有符号移位CSE，以及官方内部的分解搜索。唯一固定求解设置为 `wmc/auto, hard_dc=-1, decompose_dc=-2, search_all_decompose_dc=True`。没有把逐常量CSD替代完整方法，也没有搜索额外延迟／分块参数。全图和H8均独立调用同一官方求解器。

| 同一Wq整数函数的组织 | 加减节点 | 最长加法依赖 | 官方节点顺序的临时峰值／一个(p,t) |
|---|---:|---:|---:|
| 独立常量CSD＋各行归约 | 23,337 | 本轮未排程 | 本轮未排程 |
| 整96×96 CMVM | **9,527** | **12** | **39,919 bit，4,989.875 B** |
| 十二个H8 CMVM串行 | **11,320合计** | **14最大** | **4,325 bit，540.625 B最大** |

Wq共有9,162个非零系数。普通字MAC同样可跳这些静态零、用相同X12/W8和合法输出位宽；不能以23,337个CSD加减作为唯一速度对照。整图的4,600个算术节点最终服务于多个H8组，直接有多个消费者的算术节点为2,599；两者定义不同。H8图间另有77种相差符号／二次幂尺度的相同中间线性形式，仅作潜在共享计数。整图比H8少1,793个节点也包含官方分解选择的变化，不能全部归为一种排他跨组机制。

**整数与解释器核验。** 每个节点保存完整96维整数系数、父节点／移位／加减、严格X12域范围、最小有符号位宽、深度、扇出和最终H8消费者。所有输出符号重建严格等于对应Wq行，覆盖整个合法整数输入域。四个已捕获训练帧，各T10×64真实anchors，共 **2,560个输入向量**；整图及H8合计各核 **245,760个真实输出**，0差异。官方C++ DAIS解释器另外各核64个均匀真实向量及195个静态域角点，也0差异。真实图输出范围[−1,079,243,965,589]只是观测；合法域上界11,444,224需signed25，普通MAC获同样位宽，不以样本范围縮位。

继续使用原 [PSN适配](../../../../psn/cmvm_20260909/README.md) 已解决的C连续矩阵绑定和级联scale/sign别名问题；本轮只读导入，官方源码未改。新增X12非对称域按正／负系数精确求上下界。若官方DAIS为了移位指令顺序存储相反符号，区间随之翻转，float32不能表示的区间端点向外取；5个整图节点的解释器声明宽于其数学最小位宽，分别记录，未隐瞒解释器放宽。

**状态与费用边界。** 本图实例是一个(p,t)的96通道向量，通道彼此参与归约；不能像旧PSN图一样乘“96个独立h lane”。两种组织均另有 **1,152bit驻留X**、**50bit两操作数寄存器**；如果输出不能即时消费，还需最多 **2,367bit** 的96个输出收集状态（未含随后FP/定点转换格式）。P4复制示例明确乘4，未假定SIMD资源免费。临时峰值包含新结果产生、旧操作数最后使用前的瞬间，但只是合法官方节点顺序，不是最小状态调度。

在该折叠RF读取模型中，整图18,873次读取（其中X读取2,741），H8合计21,903次（X读取6,466）；X驻留只读回RF，不等于DRAM流量。充分展开的电路可以用连线／流水寄存代替这些RF访问，却必须付移位、扇出、配平和面积；不得强迫它按此串行执行。反之H8控制也可以使用公共X缓存、跨p流水和输出背压。这里未将节点数、抽象FPGA cost或合法RF顺序写成周期。
