# ZPS 显式 S6 普通强控制

已完成十二个官方两级 da4ml H8 图，使用现有 `zero_point_shift.npz`，没有新增量化或训练。对剪后的 64 行，`core=group_shifted_pruned`、`D=-group_constant`；保护的 32 行 `core=Wq,D=0`。逐元素证明 `Wq=core+repeat16(D)`。每个 `(p,t)` 先生成六个 `Sg=Σ16 Xc`，再由 H8 图消费 `[X96,S6]`，S 生成一次并保存供十二组复用。

X 是连续投影输入的 signed12 编码，合法域 `[-2048,2047]`；S 范围 `[-32768,32752]`，需 signed16。官方编译输入明确区分这两种域。每个 102 维节点另保留折回原 X96 的完整整数系数，并利用 S/X 相关性求严格范围；保护行和每个输出与同一 ZPS Wq 完全相等。全部 2,560 个真实向量、245,760 个输出 **0 差**；官方解释器另核每图 64 个真实向量和 195 个合法角点，0 差。局部节点最大需 25 bit；输出 scale/bias 保持原包定义，不等同原 FP 网络。

| 同一 ZPS 权重，每 `(p,t)` | 直接整图 | 直接十二 H8 | 显式 S6＋十二 H8 |
|---|---:|---:|---:|
| 加减节点／操作 | 7,855 | 10,141 | **9,393**（含 S 生成 90 加） |
| X/S 输入读 | 2,246 | 5,872 | 5,742（X 5,495＋S 247） |
| 临时读／写 | 8,529 / 4,384 | 7,591 / 5,453 | 6,728 / 4,996 |
| S 最终写 | 0 | 0 | 6 |
| 全部逻辑读写 | 15,159 | 18,916 | **17,472** |
| 临时 RF 峰值字数 | 1,428 | 184 | 184 |
| 按实际位宽求和的临时 RF 峰值 | 21,447 bit | 2,791 bit | 2,791 bit，另 S 96 bit |
| 统一 25-bit 字的临时容量上界 | 35,700 bit | 4,600 bit | 4,600 bit，另 S 96 bit |

同一普通输出依赖 DFS、两个旁路寄存器、最后使用释放、延后写回；十二 H8 串行执行，空间取最大值。公共 X 缓存为 1,152 bit。S 生成明确计 96 次输入读、90 次加法、六次 S 写，16-bit 工作累加器可以复用已有 25-bit 结果寄存器。这里先生成六个 S，普通还能延后至首个实际 D 消费者并复用释放的临时槽，未声称最小状态。局部图深度最大 12，尚未包括组和生成的数据依赖，不能拿它与整图深度 11 直接作端到端时延比较。

显式已知分解相对直接 H8 少 **7.38%** 加减、**7.63%** 逻辑读写，小临时峰值保持不变；相对直接整图仍多 **19.58%** 运算和 **15.26%** 访问，换取较小的临时容量。它是 ZPS/BBS 组和复用的普通强控制，消除部分原先的状态问题，不作为新机制。数值均为标量逻辑工作/状态，未计指令、地址/shift 控制、RF 延迟与端口冲突、输入 DMA、输出 scale/bias 和背压服务；不是 RTL 周期、实际 SRAM 或 PPA，也不是完整 BitVert 硬件复现。

入口：[compile_explicit.py](compile_explicit.py)；结果：[result.json](result.json)；分解：[decomposition.npz](decomposition.npz)。十二组的官方 pipeline、`.dais` 和含原 X96 系数的 DAG 均在本目录。沿用 `psn/cmvm_20260909/.venv/bin/python -B compile_explicit.py` 可复现。本轮未改 RA、其他已通过图或生产文件，未运行 GPU、RTL 或 EDA。
