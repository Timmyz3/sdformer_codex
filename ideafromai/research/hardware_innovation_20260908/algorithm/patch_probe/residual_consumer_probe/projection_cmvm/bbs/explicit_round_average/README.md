# 显式组和的 RA 普通强控制

已完成同一 `round_average.npz` 的十二个官方两级 da4ml H8 图，不新增量化或训练。对每个 `(p,t)`，先计算六个 `Sg=Σ16 Xc`，再依次执行 `[core8×96 | D8×6] × [X96,S6]`。`Wq=core+D` 逐系数相等；384 个组常量按 `pruned_rows[64]×6` 绑定，保护的 32 行 `D=0`，其 core 保持原行。剪后 core 仍精确含各组的 `2^low` 因子，不把它误称统一 INT5。

X 是连续投影输入的 X12 编码，合法域 `[-2048,2047]`；S 合法域为 `[-32768,32752]`，需 signed16。102 维局部图保留官方运算与原始系数，同时每个节点折回独立 X96 的完整系数求严格区间，保留 X/S 相关性。全部 2,560 个真实 X 向量、共 245,760 个输出与直接 RA Wq 整数点积 **0 差**；官方解释器另核每图 64 个真实向量与 195 个合法角点，0 差。所有局部节点最大需 25 bit。外部输出 scale/bias 原样保留，未声称原 W8/FP 网络等价。

| 同一 RA 权重、每 `(p,t)` 的逻辑工作 | 直接整图 | 直接十二 H8 | 显式 S6＋十二 H8 |
|---|---:|---:|---:|
| 加减节点／操作 | 7,785 | 10,098 | **9,038**（含生成 S 的 90 加） |
| X/S 输入读 | 2,415 | 5,922 | 5,526（X 5,397＋S 129） |
| 临时读／写 | 8,232 / 4,316 | 7,479 / 5,430 | 6,473 / 4,812 |
| S 最终写 | 0 | 0 | 6 |
| 全部逻辑读写 | 14,963 | 18,831 | **16,817** |
| 临时 RF 峰值字数 | 1,402 | 184 | 184 |
| 按实际位宽求和的 RF 峰值 | 21,003 bit | 2,791 bit | 2,791 bit，另 S 96 bit |
| 统一 25-bit 字的临时容量上界 | 35,050 bit | 4,600 bit | 4,600 bit，另 S 96 bit |

双方采用同一普通输出依赖 DFS、两个旁路寄存器、按最后使用释放和延后写回；H8 图串行，临时空间取最大值，输入 X96 的 1,152 bit 公共缓存独立列。S 用一个 16-bit 工作累加器逐组产生，首次 X 作种子，付 96 次 X 读、90 次加法和六次 S 写；工作累加器可复用已有 25-bit 结果寄存器。这里保守地先生成所有 S 并留到消费者完成，没有让这 96 bit 或 S 读写消失。普通还可推迟至首个实际使用 D 的 H8 才生成 S，或复用已释放的临时 RF 字；本表没有声称这是最少状态。读写是逐标量逻辑访问，未包含实际指令字、地址/shift 存储、RF 延迟与端口争用、输入 DMA、scale/bias 和输出背压服务，**不是周期或 SRAM/PPA**。

显式已知分解比直接 H8 少 **10.50%** 加减和 **10.70%** 逻辑读写，在几乎相同的小临时空间内收回一部分全局共享收益；相对直接整图仍多 **16.10%** 运算和 **12.39%** 访问。因此普通 RA/BBS 的组和复用已经吃掉部分原先观察的容量问题，不能把本实现命名为新机制；剩余是全局 CSE 与局部小状态的具体权衡，不是已证明的新电路收益。这里也不是 BitVert 完整位串行硬件复现。

入口为 [compile_explicit.py](compile_explicit.py)，结果为 [result.json](result.json)，完整分解为 [decomposition.npz](decomposition.npz)，十二组各保存官方 pipeline、`.dais` 和含原 X96 系数的整数 DAG。复现使用既有 `psn/cmvm_20260909/.venv/bin/python -B compile_explicit.py`。本目录独立写入，未改原编译器、原图、生产 RTL，也未运行 GPU 或 EDA。
