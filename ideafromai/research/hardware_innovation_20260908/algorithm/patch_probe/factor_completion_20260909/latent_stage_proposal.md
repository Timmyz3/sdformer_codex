# 用潜变量阶段替换时间阶段：一次结构试验

## B 与最强对照先行

已测时间前缀／尾部反复请求同一个第一因子 U 的系数。原 hybrid 加入指定费用项后请求只额外少约1.267%，并增加恢复误差；原布局的完整T共享对照仍更省取权。另一方面，连续 Z×V 会引入原 θg 卷积没有的乘法，必须保留这一成本。这些结果支持改变生产依赖，不能推出残差计算家族无效。

强控制为：原未分解卷积、已有普通 shared_compact R48、同总活跃R56的普通共享两因子，以及给普通R56同样的CGNet式32＋24分片/许可/回退。所有轴均可在第一因子前回推需求、在存活系数上复用全部T10，并选择A与V的较便宜合法次序。新旧学生各自执行真实Conv2、BN2、shortcut与粗头；未匹配AEE的工作量差不作净性能结论。

## A、继承边界与待证 X

A 是 CFMP 的因子化生产/消费链、CGNet 的基础/条件分支、TermiNETor 的共同完成，以及完整T稀疏供数。原文已覆盖部分计算、完成反馈和供数优化，均不称首创。现有本地CFMP只迁入作者三页稿公开的功能链，未冒称完整官方训练复现。

X 假说：共同训练跨通道预览与消费者局部残差，使非因果T10神经元的完成结果，在第一次取私有U系数前取消该生产；共享和私有系数各自完整时间复用。与旧方案的差别是**切开潜变量依赖**，不再将同一系数切成两个时间阶段。该差别能否留下净收益尚未知，独立概念评分暂5.5/10。

## 只做一个固定结构

`Y = (gθ U_shared)V_shared + (gθ U_private)V_private`。共享R32，12个H8组各私有R2，总活跃R56；私有因素只连接本H8。普通控制R56全共享，分片同为32＋24。二者无空间mask、新增层名或秩扫描。先用完整T10共享部分产生全部预览，再按未决门及A的真实依赖回推私有源时间需求；同一U系数在对应阶段只发一次请求。一个近阈值门仍可能保留整个私有包，需实际统计。

两结构同train16、固定256步重建，再同256步混合完成训练；第二阶段各做既定λ=0与0.10，其他条件相同，不用valid挑超参。A/b/θ保持当前common3合同。均值/半径只从训练集拟合。完整私有Y仅作监督/回退，不能进入许可。先做实际源的局部完整数值和成本，再接网络AEE。

## 判别与停止条件

先报告实际U请求、U加项、连续V乘加、A求值、源码重复读取和峰值活状态，保留不同算术单位；再纳入同资源服务。必须胜过自身全算和普通共享分片，且最终825帧AEE≤1.259、整链服务改善至少15%，才考虑主机制RTL。未过只停止此固定结构；新结构须指出修复哪项实测瓶颈，不能靠继续扫秩或γ维持它。

DeepShift-Q的独立量化数学与同预算恢复已实际迁入：三结构×FP/U8+VQ5六轴各完成64步真实GT更新，随后只用train16全空间重校统计。U8吸收实际θ，V的32种非零幂次码保留连续Z消费。移位是继承项，完整服务必须收费。SmartExchange使用小基和稀疏幂次系数重构W；不能把本激活因子路径说成已完整实现SmartExchange。

恢复后的必要控制再加一次**预览单独执行**：六轴都直接删除尾V，不重新训练、不扫描rank，数值仍用同调用布局，普通编译可删尾U/V到R32。先测实际光流；不能让精度已足够的普通R32缺席，再把可直接删除的尾包装成精巧完成机制。

位宽核算提示另一项待测B：U8累加、V幂次对齐和Aq14后，完整裕量需要约46–47位，原FP32工作状态布局不能直接沿用。只在同一结构内考察**H8局部非因果T10完成与状态退休**是否减少活状态或重算；尚未实现或宣称收益。强控制必须含普通共享的最佳H条带、先产完整tail再消费、以及保留32位Y再用单个48位工作裕量的V→A路径；禁止强迫普通方案同时存全部H96的48位裕量制造优势。是否还有X由同容量完整服务和预览单独执行控制共同决定。
