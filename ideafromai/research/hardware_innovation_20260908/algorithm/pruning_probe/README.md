# 单层 s2b3：50% 剪枝与实际消费者短探针

普通隐藏通道减半和逐行 2:4 均已完成固定检查点的完整 valid825，精度接近同父整数源基线，必须作为后续机制的强控制。隐藏通道减半还能删除一半对应 PSN 和 FC2 输入列。共同 H8×C16 块剪枝仍有组内供数价值，但这次十帧精度较差，尚不能凭共同支撑宣布其优于普通减宽。

## 掩码与微调方式

掩码仅由原整数 W² 决定，同值按较小下标选取，训练后不重新选择：每行 C4 留最大的两个；每连续八个 H 对 24 个 C16 块的 W² 求和并保留 12 块；普通隐藏控制按整行 W² 留 768 个 H。三个剪枝轴都保留 294,912 个 FC1 系数槽，占原槽位一半；原零权重使实际非零数略有差异。三个初始掩码分别保留 86.721%、55.368%、61.168% 的原 W²，这只是选掩码的代数量，不能代替精度。

训练复用已有 train32 的完整 C384、T10、P4 相邻输入：每帧 32 个 P4 块，每步相同的四块，每轴 256 步。W 以固定 signed8 网格直通量化，Adam 步长 0.03；τ 用训练膜标准差归一化的偏移参数，步长 0.003，前向和导出都量化到整数。损失为保留神经元的标准化膜 MSE，加 0.1 倍完整 FC2 输出 MSE；它是局部蒸馏，没有用小批次近似替换真实 BN2。参数、步数、掩码和最终检查点均没有用验证集选择。

隐藏留半按升序保留索引实际计算较窄的 FC1/PSN，并只使用相应 FC2 权重列。不能用“整行 W=0，仍保留原 τ”的网络替代：后者可能继续发出 θg 常量门。本实现没有保留这部分输出，也没有给剩余 FC2 权重重新训练的额外自由度。

核对结果：不剪轴的 W、τ 和 AEE 完全不变；所有剪去位置保持零；所有掩码、B 和 θ 不变；导出 W/τ 有整数实现，静态 S/U 前缀界满足 Acc24。每轴保存了全六块的新源 codes，包含 s2b4/5 经真实剪枝网络传播后的变化。

硬件比较应读取训练后的实际 W、τ 和隐藏保留表，分别计算源读取、权重压缩及元数据、NR4 分发、PSN 和 FC2 的费用。共同 C16 支撑可减少单个 H8 组的源读取；跨多个输出组缓存时，支撑并集未必仍只有一半。此目录只提供精度与可执行参数，没有报告周期、面积或功耗。

- `run_pruning_probe.py`：可重复的掩码、初始验证、四轴等预算训练、最终验证。
- `summary.json`、`*_valid10_frames.json`：总体及逐帧精度。
- `*_initial.npz`、`*_trained.npz`：`weight_int8`、`threshold_int32`、`hidden_keep`、`hidden_indices`、`B_int8`、`E_int8`、固定 `weight_mask`。
- `codes/<variant>/<frame>/s2b*.npz`：八轴各 60 个完整 `[1200,384]` code 数组，字段 `codes`。
- `initial_masks.json`、`final_parameters.json`、`training.json`：选取规则、实际非零数、整数界和训练过程。

运行：`env312/bin/python run_pruning_probe.py --root <研究根> --steps 256 --weight-lr .03 --threshold-lr .003`。
