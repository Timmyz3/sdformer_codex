# 广播域剪枝：实际五轴结果与下一道门

当前 H8/C16 版本没有证明新增联合消费者目标的优势，暂不进入机制 RTL。已完成真实 W8/τ 微调、完整网络 valid10、十帧完整目标 FC1＋PSN 服务回放，以及独立审阅；不是仅凭“已有先验”降级。另行接通的 [2×4 PE 硬件切片](../../psn/rtl/gp_slice/README.md)是执行底座，不是本剪枝机制已经成功的证据。

## 挂点与实际借鉴

对象是当前整数码学生的 s2b3 FC1，完整 `P1200×C384×H1536`，保留连续幅值 θg、独立 τ、非因果全部 T10。该学生沿用 ep34 训练来源，但已改变源表示、量化、BN1 与读出，不能标成原生 ep34 算术。粗头后的全部 FFN 约占点积工作代理的26%，六个 S2 FC1 约11.4%；本次只改其中一块，不能占用全部份额或称整网周期比例。

实际移植了 [HiNM](https://arxiv.org/html/2407.20496v1)及 [FlexHiNM-GP 的 Gyro 分组流程](https://proceedings.iclr.cc/paper_files/paper/2026/file/9e33fdc35b68781132e836964a326bf3-Paper-Conference.pdf)：等量采样、平衡聚类、完整候选组的实际剪枝代价、Hungarian 指派。共同搜索序列为 `(8,1,4,1,2,1,1)`；为匹配搜索预算，所有轴运行完整序列、保留最佳解，不使用原文遇到不改进即停止的规则。相同轮数不代表相同离线计算量。

本地格式只使用输出分组分支：每八个物理广播消费者共同保留24个 C16 块中的12个。未复现完整 HiNM 的输入重排、内层2:4、区域搜索，亦未复现 VENOM 的 OBS 保留权重补偿、FlexHiNM 的 Hard Concrete 渐进训练。因此这是有明确边界的迁移对照，不能声称优于完整原作；负结果也不否定其完整方法。

## 新增轴与公平控制

每轴从同一 W/τ 开始；同 train32、同256次更新与小批次顺序，只训练保留 W8 和 τ24。B、E、源生产者、θ、FC2、BN2固定。全部 H 排列同步作用于 W1行、τ、σ、θ和W2列，未剪模型的完整 T10 门与 FC2 映射检查通过。

- `gyro_membrane`：删除一个 C16 块的标准化膜重建二阶代价，包含块内相关项。
- `gyro_fc2_separable`：加入 ATan 代理导数及实际 FC2 列范数；不是在零蒸馏损失上计算零 Fisher。
- `gyro_fc2_exact_diagonal`：使用全部被删块合并后的真实硬门变化，但 FC2 Gram 只留对角项。
- `gyro_fc2_joint`：同样硬门、同样样本、同样掩码选择，增加 H8 内 FC2 贡献交叉项。

联合代价为 `δy_G = Σ(h∈G) W2[:,h] θ_h δg_h` 的平方误差。候选组内相消真实计入，但搜索仍按组求和，不含组间交叉项，也没有直接搜索所有共同掩码。最终局部 FC2 指标重新计算全部 H，整网验证另经过真实 BN2 与 shortcut。

二阶分数使用4096个训练位置；两个精确门轴共同使用每帧八个均匀 P4，共1024位置、全部 T10。首轮只用角落 P4 的结果放在 `corner_probe/`，不据此选择赢家。局部拟合用 FP32 矩阵计算；整网验证恢复母模型的 TF32 设置。`summary_fp32_inference.json`及中止的全量 FP32 验证只是数值设置诊断。恢复后普通控制精确复现此前 valid10，五种目标捕获的全部十帧 C384 源码也与原控制一致。

## 同预算结果

AEE为相同十帧的逐帧均值，覆盖516,735个有效像素；不足以宣称细小差异显著。最后一列是十帧完整目标 FC1＋PSN 的 CPU 服务模型平均百万拍，不是 RTL 或整网加速比。各 C16 轴使用相同8×8资源、P4、F_live1、F_cache36、双口W与NR4归约；普通隐藏减半按自己的合法容量和真实 H768 执行。

| 未剪学生 | — | 1.114212 | 13.414754 |
| 普通逐行2:4 | — | 1.108800 | 11.117950 |
| 普通隐藏通道减半 | — | 1.113059 | **6.721455** |
| 连续 H8、W²共同 C16 | 0.416104 | 1.130192 | 7.989401 |

新增完整 Gram 比精确对角的局部误差高约2.76%，服务也没有减少；相比普通隐藏减半仍慢约19.1%。两种结构共同省掉半数权重，但隐藏减半还删除了半数 PSN、门输出和 FC2 列，C16 保留所有消费者。这解释了为什么省共同源字不足以超过它。

单块全部隐藏删除已完成 [valid825](valid825/summary.json)：825帧、18序列、48,152,523有效像素，AEE **1.183003**；同父基线 **1.165399**，增加0.017604，仍通过既定1.259门。普通隐藏减半的既有full825为1.164732。因此删除不是“精度完全无损”，但它是必须纳入的低成本精度折中；当前复杂分组尚不能超过更简单的隐藏减半，不能只凭AEE过1.259晋级。联合分组只完成valid10，未冒充新的full825。

## 由此推进什么

1. 已全量验证单块删除，下一次挂点先做敏感性与实际剩余费用检查。删除保留真实 FC2 偏置、BN2和外部残差，不等于随意把整个残差块换成零，也不证明全部S2/全部FFN都能删除。
2. P0-1保留成强对照，暂停当前分组目标的更多搜索及机制 RTL。不能将此次结果写成“所有广播结构剪枝无效”；更完整剪枝方法、其他精度预算与更敏感算子尚未检验。
3. P0-2已经补了[完整 C384 输出机会](../../psn/group_completion_opportunity.json)和[实际前缀识别](../../psn/group_completion_prefix_probe.json)，下一步须回写预测门、验证AEE并收费。C192、k=1只能接受13.77%组，且必须先执行检查；单凭完整计算后66.91%的静默组不能推出可实现收益。
4. 全量单块删除仍满足精度预算，先重新定位敏感且昂贵的挂点，包括第一大头 patch residual；不要在同一块继续磨分类器。硬件只保留已接通的2×4底座，待新增轴出现净收益再扩展。

运行：`run_group_pruning_probe.py --root <隔离根>`；仅重测部署用 `--stage eval`。`evaluate_controls.py`重测三个旧强控制和全隐藏删除；`evaluate_fixed_825.py --record <固定pt>`只做全量验证。主生产仓和投稿稿未修改，无新增EDA或PPA。
