# 2026-09-14 阶段结果：从八块走到整层，并实际筛选两条分解

**本阶段实际补齐了完整层连续RTL，新增窄整数R8分解核和单方向Winograd核。R8值得保留，单方向变换在当前真实稀疏输入上失利；新增标题机制尚未成立。** 本次没有把实验换成更多命名卡，也没有因普通分解已有先验而停止实现。

计算对象仍是当前matched-dense模型的patch残差r0.conv2：Cin96、Cout96、3×3、T10、240×320输出。它是已定位的高成本卷积之一；本轮没有重新测全网络算子份额，局部改善不能换算整网速度。当前不是原ep34未经改造网络，具体模型、源、Q16/新因子身份见各数据定义。

## 1. 已完成整层RTL，输入与最后输出都计费

此前父和模式在八块上约5%的收益，现在扩大为同一SV实例、一次go完整执行19200个2×2 tile。新wrapper自行计算原生全帧源地址、边界padding和tile身份，先装一次W/mask，再逐tile装入源、执行、接受480个输出beat、退休；TB只供存储响应和检查gold。

|---|---:|---:|---:|
|dense|1437874585|1361527081|5.310%|
|普通块幅值剪枝25%|1110577614|1053569256|5.133%|
|整Cin费用剪枝25%|1094526589|1034824441|5.455%|

这是六个完整帧RTL作业，每作业73728000个输出全部比较一致；另有24个跨行64tile作业检查源/参数/结果背压及第二次启动，共448266240个输出通过。整帧运行无外加背压，实际带背压覆盖是跨行64tile，二者不混写。计数与源几何另经独立复算。

完整冷作业共同装载/控制成本29559457拍已经包含于表内；每臂外部源请求29276544次。整Cin只降低leaf内部读取，当前wrapper仍装全部源，不能说已取消上游PSN生产或外部halo流量。数据和证据见[整层报告](stream_rtl/REPORT.md)、[独立审阅](data/REVIEW_STREAM.md)、[根审阅](stream_rtl/ROOT_REVIEW.md)。

这个结果保留了既有product reuse执行底座A，也暴露了仍贵的部分：dense内部psum读写合计519864960拍，权重读取153790128拍。增加输入双缓冲只能处理当前约2.17%的装载/控制份额，不应优先包装成主要创新。

## 2. 新整数R8分解：已测性能和新链质量，未借旧SVD结果

将已存R8浮点因子的第一因子固定为[-3,3]小整数Q1，尺度吸入后因子后量化成signed16 Q2。SV真实执行 `g→z=Q1g→p=Q2z`，中间无RNE；raw p之后的输出缩放及真实浮点消费者用于独立质量评价。

同函数expanded E=Q2Q1需要signed21，直接控制保留其真实宽度和父和复用。三个模式共同拥有八加法器、八乘法器、同源/系数许可及全部状态预算；不是拿原8加法器Q16核与新增MAC硬比同面积。

|真实八块，同函数与共同预算|核心周期|含每块新源/原点装入|
|---|---:|---:|
|expanded21，原生父和直接|370240|382536|
|窄整数R8，后因子V驻留|173739|186035|
|窄整数R8，输出psum驻留|180651|192947|

V驻留相对expanded控制，核心少53.07%，含新源装入少51.37%。psum驻留虽然减少psum访存，却重复读取Q2，在当前完整排程中慢3.98%；不是加法/字节少就认定更快。新量化链diverse10 AEE **1.353326**，优于历史NB0 **1.454603**，未训练或扫格式。

168条实际RTL命令、645120个raw输出通过，两份独立源码/函数/绝对周期审阅无阻断发现。来源：[新核与结果](integer_factor/REPORT.md)、[新链AEE](data/integer_factor_diverse10.json)、[独立审阅](novelty/REVIEW_INTEGER_FACTOR.md)。

边界：这是新有损函数与同函数直接控制的局部周期，不是原网络无损加速；未计p*scale及后续BN/PSN/残差，不是完整r0 block，也未完成因子链valid825。RTL源来自3090固定捕获，AEE在A800；八块源有19/122880 bit差异，不能称跨环境全链bittrue。

**新颖性判定：保留强A，X未立。** 当前做的是完整小整数因子执行，没有实现D1中按系数码分桶。UCNN、SmartExchange、StrassenNets及普通SVD/驻留是明确先验。后续任何新归约、分组或退休必须对比当前更快的V驻留模式，而非继续只比expanded；51%的优势不能归给尚未写出的机制。

## 3. 新单方向变换：真实RTL负结果，不停整个分解家族

沿横向做F(2,3)，纵向保留直接归约；完整包括源变换、signed18紧排系数、256bit跨字读取、两行中间状态、逆变换及精确/2。它改变了此前二维Winograd的表示接口，不是同布局扫缓存。

同模块、共同八加法链/有限缓存/静态零半组控制下，真实八块direct **178948**拍，一维变换 **305875**拍，后者慢 **70.93%**。CR256读取11790→20580；累加发射77172→75180，仅少2.58%，不足支付变换、重新聚集和宽系数读取。原始W16系数165888B，变换后18bit系数248832B。

13fixtures、两模式、两背压共52runs、199680个输出通过。此核资源与原生mode6不同，不能横比其178948和上一表370240/整层周期。即使更强pair控制尚未放入本核，候选已输给现有较强direct，足以停止该固定布局；不是挑弱direct来声称胜利。见[实现与结果](one_axis_transform/REPORT.md)、[独立审阅](novelty/REVIEW_ONE_AXIS.md)。

全一输入的合成例反而从442283降到100070拍，说明该表示确有依赖输入模式的适用区间；它不能覆盖当前真实稀疏源的负结果，也不应据稀疏源负结果淘汰整个变换家族。

## 6. 下一阶段顺序

1. **先把整数R8强A推进到完整消费者。** 复用已完成的连续tile wrapper，计入新因子的输出scale、真实固定BN2和下一边界；补本链自己的825。这样才能判断51%局部下降在完整支链剩多少。资源点保持明确，先不写生产PPA或稿件贡献。
2. **围绕实际余项只选一个新接口写RTL。** 当前因子第一阶段存在按K/P重复读源，第二阶段逐位置扫描/连续latent累加仍贵。优先比较UCNN式码归约、原生卷积源复用与真实T10完成边界的组合；共同零跳过和普通调度先给强A。若只是同一请求序列的改名，继续归入底座。不得把尚未尝试的整字退休预写成收益。
3. **剪枝保持普通块与整Cin两个控制。** 只有约1.8%的额外局部性能空间时，先看完整825质量取舍，再决定是否值得一次针对真实物理源义务的恢复训练；不从原始稀疏率重新造标题，不扫大量比例续命。
4. **新分解继续有界实跑。** 先读本次失败原因再换真正不同的表示/消费者接口，保留同资源对照。当前1D/2D Winograd布局停止；不是禁止分解研究，也不重做已经负过的相同端点与配对。

本阶段完成的是隔离Verilator、完整层gold/功能/周期和相应质量筛查，尚无VCS+DC/PT+Formality、同Fmax PPA或整网FPS。独立审阅没有给出TCAS-II强接收结论。下一轮应沿性能已成立的强A找可测X，而不是把本阶段的普通分解改名宣称创新已经解决。
