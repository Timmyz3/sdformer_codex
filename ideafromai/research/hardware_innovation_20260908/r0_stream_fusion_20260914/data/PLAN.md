# 固定整层源与质量扩展

2026-09-14。旧目录与生产模型只读；所有新增输出在本 data 目录及远端同名 owned 镜像。Python 3.12，不训练、不重选掩码、不哈希。

固定 zurich_city_09_a_0001.npy，沿上一轮 matched-dense stage320 ParentNetwork、原 scalar YAML 和同一 checkpoint，捕获真实 r0 sn2→conv2 输入 `[10,96,240,320]`，验证静态 theta 和 0/theta 幅值后存二值与低10bit时间字。三臂固定 dense Q16、普通块幅值25%、完整Cin费用25%，系数与上一轮逐值一致。

整层19200个2×2输出tile，id行主序：`oy=2*(id//160), ox=2*(id%160)`，4×4源origin为 `(oy-1,ox-1)`，图外为0。首64tile固定id128..191，含输出tile行边界；随后硬件决定是否完成全部。输出gold为 `.npy int32 [19200,10,96,2,2]`；读取部分时用mmap，避免巨量文本。整数gold由二值乘Q16完整K864累加，和原FP模型区别明确；无需中间舍入。

A800授权mux已可用且GPU空闲，远端现有env312为Python3.12.3/Torch2.2.2+cu121，与前轮3090环境不同。先在同一旧合法模型配置上做协议/速度探针，再固定三臂valid825；必须实际确认825帧列表和文件齐全，不用diverse10冒充。若环境导致数值不同，记录真实baseline，不重新调参追旧数。quality输出保持浮点消费者，不称全网整数bittrue。

额外统计完整源spikes、T10端点（边界约定分开）、连续固定Cin4/Cin8支持频度、时间冲突直方图，仅描述已有数据，不根据统计预选赢家。
