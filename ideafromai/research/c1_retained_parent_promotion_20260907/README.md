# C1 保留父值原位提升：筛查未晋级

**新增部分仅减少 1.58% 加法，停止这版扩展，不开 RTL 或 PPA。** 此结论针对明确的完整叶子消费者组规则，不是所有因式分解方法的上界。

对 Prosperity 原森林中的父 P，若所有直接消费者都是叶子，则沿 child 链求交集 Q。先计算并提交原行 P，再将寄存器中的 P 加上共同残差 `Q\P`，供整组孩子复用。Q 不获得新 SRAM 地址，不进入全局父森林。整个过程保留 `phi=theta*W` 的阈值幅值。

例如 P={a}，三个孩子是 {a,b,c,x}、{a,b,c,y}、{a,b,c,z}。具有同样父值保留能力的基线要做 9 次加法；将 P 提升成 {a,b,c} 后只需 5 次。三次孩子 seed 复制和四个真实目的提交均保留。一般增量节省 `(孩子数−1)×共同残差元素数`。

这继承 [SumMerge 的共享因式分解](https://cwfletcher.github.io/content/research/2021.ics.summerge.paper.pdf)、[Prosperity 的原父森林](https://arxiv.org/html/2503.03379v2)、[TA 的中间结果复用](https://arxiv.org/html/2504.16339v1)。本地 M2268 已提出父值保留、child 链与连续服务；这些能力全部给基线。可讨论的新增部分仅是依据完整消费者组提升保留值，概念独立评分 **6/10**。

| 同一已查看 cohort：192 tile、11,904 原行 | 同样保留父值的基线 | 增加原位提升 |
|---|---:|---:|
| 向量加法 | 6,662 | 6,557 |
| 源系数读取 | 8,747 | 8,642 |
| 相同连续服务参考的父读／父写 | 1,892／924 | 1,892／924 |
| 新增全局共享节点地址 | 0 | 0 |

323 个完整多叶组中只有 65 组能提升，分布在 44 个 tile。每组新增值不写回的好处成立，但共同残差稀少。相对基线省 105 次加法前，还要付出候选扫描：11,904 个行头、3,538 条子边及叶子检查、847 个孩子掩码读取、524 次 AND。它们只是逻辑次数，没有伪装成已隐藏的时钟周期。

父保留能力使普通原森林的父 SRAM 事件从 5,584 降到本地连续服务参考的 2,816；**这部分不是原位提升的增量**。具体调度、其它分支的缓存容量、提交背压尚未实现，不能把 2,816 当已测访存或周期。

参考对 95,232 个原行 lane 值及 1,640 个提升相关 lane 值进行非 1 阈值的整数分子检查。不是冻结 FP32、旧 96×12 物理位宽或 AEE 证明。样本继续使用已看过的 3/6/8 同序列小样，不是新盲测。
