# 对照 GrokBot 后的推进计划

2026-09-09。只投 TCAS-II。本轮完成文献复核与计划，不启动训练、RTL 或 EDA；两份原盘点目录保持独立。

**决策：维持昂贵 patch 第一顺位，把 Grok 的“少生产”和“共同完成”合为一个尚待证明的新机制问题；连续 PSN 排第二，先补完整常矩阵和状态基线。结构剪枝融入 patch 的训练与强对照，不另设同名主线。运动保留有条件的低成本探针。新增电路文献用于加深这些方向，不再开更多 Card。**

当前仍没有足以宣称强接收的贡献证据。C1/C2 的生产创新重构未完成；但已有功能原型和负结果应继续作为底座，不重复制造它们。

这次最应优先承接的不是题名里的 TOPS/W，而是：

- **patch 少生产的强近邻：** Zhang CICC 2026、CICC 2025 样本自适应神经元剪枝，再加 JSSC 2021 conditional computing。它们提高了对新预测/终止机制的要求。
- **稀疏供数完整性：** HIRB、SIMO SPad、Fang CICC 2024、SparseTrim、SP-IMC。借鉴必须包含索引、元数据、解压、bank、恢复，不能只取“跳过”二字。
- **连续 PSN 的物理基线：** ROM-LTE、OS-CIM、DNC，以及完整 da4ml 常矩阵图。局部状态和切换能量有研究价值，但零模式、驻留部分和、查表不能重新包装为独创。
- **C1 乘积缓存：** Pro-Cache-CIM 是直接待补原文，不再只列 Prosperity。其具体缓存语义未核，不能仅凭题名提前否定或恢复 C1。

数字 CIM 的调度/存储方法可借；定制 ROM、8T/3T 宏或保留触发器的 PPA 不赋给当前普通 foundry SRAM。没有本文所需宏，也不妨碍先审阅外围方法。

## 3. 先把“贵在哪里”落到同一边界

现有约 34.8% patch、26% FFN 是旧粗头后**点积工作量代理**，不是当前学生周期。若只做 patch r1，旧代理中 Conv1 约 6.71%、Conv1＋Conv2 约 11.07%；不能领取整个前端的份额。PSN 连续矩阵另计，不能与点积百分比直接相加。

第一张需要补齐的表按同一个学生、同一输入列出：源读/解码、Conv1、归一化、连续 T10 PSN、门判决、Conv2、输出与 shortcut、索引/halo、状态读写、端口等待及重叠。先给操作量与有限服务模型；未跑同负载 RTL 就不标 RTL 周期。上游相同的源生产边界说明清楚；任何候选新增源预测/参考生成均入账。

已有几个不能跨边界使用的锚点：

| 结果 | 能说明什么 | 不能说明什么 |

| r1 零训练 valid10：删分支 AEE 1.859643；半宽 1.233490；Conv1 逐行 2:4 为 1.119848 | r1 相对 s2b3 更敏感；简单稀疏/窄层是必要控制 | 三者并非同预算；不能叫 full825 已过统一精度门 |

## 4. 第一顺位：非因果 T10 能否真实释放昂贵 patch 生产

### B 与强对照先写

**B：** 在当前稀疏引擎之后，消费者的单门稀疏并不能有效取消 Conv1：多个时间输出、多个空间邻居和多个通道仍可能需要同一个物理源字/中间值。旧 mask、持续检查和普通分组已证明“门更稀”或“更勤检查”不够。

但这个 B 尚未证明有 15% 的整链可回收空间。先在最强普通执行上测可取消的尚未生产工作，不能用总零率、未来已知结果或单输出终止比例代替。

**最强对照名单：**

1. 同学生的普通稀疏 Conv1→Norm1→PSN→Conv2→Norm2＋shortcut，以及一次严格许可；时间顺序、P/H、Y/U 驻留和端口选择权相同。
2. 普通逐门预测器＋相同的组退出、训练预算与检查位置，不能只和“预测全零”比较。
3. 完整 DynConv 的 mask 训练、前驱膨胀和残差执行；TermiNETor 的共同终止校准与有界进度；取得 CICC 动态神经元剪枝正文后补相应功能。
4. 同挂点、同预算的半宽、逐行 2:4、完整 HiNM/VENOM 代表方法。不同学生画精度—费用前沿，不拿 s2b3 数字搬到 patch。
5. 若采用 CFMP：其两因子训练、tiled mask、索引转换、稠密恢复均承接。当前带 PSN 非线性的两 Conv 不能直接充作它的两因子。

### 完整借 A 的范围

“完整”指当前比较边界内的全部相关功能、费用与原算法训练权限：不能省略索引/校准/恢复，也不要求先为一张机会表复制原论文整个 SoC。先依据全文形成函数与数据流对应，再做行为模型；架构变体和物理工艺分别比较。

Gustav 的 GP/CPTB/NRV/局部状态可作为供数底座，且双稀疏、分块、多输出驻留、重叠应同时给基线；它不是 Prosperity 的直接升级，也不能因为把它搬全就得到新 X。规则二维 3×3 先用固定偏移和普通行缓冲；只有真正坐标稀疏的版本才承担完整 HIRB/SBNet 索引生成。

### 待检验 X，以及为什么不能只说“共同退出”

假说是：**同时训练时间依赖与共同完成，使少量已经得到的连续响应足以给出整组 T10 门，并取消剩余尚未计算的 Conv 时间列；取消要跨真实空间/通道消费者落实到物理请求。**

这仍未证明新颖。TermiNETor 已有共同终止，DynConv 已罚膨胀后的前驱费用，BitFair 已有学习终止及数据控制。需要区别的是“部分实际连续响应→非因果时间消费者的剩余依赖→未生产卷积取消”这条具体接口，以及它相对同权限普通预测/编译为什么有额外收益。换名字、软 OR 或 θg 都不构成差异。

对物理字 r，费用应依据所有真实消费者的并集：

`need(r) = OR_i(active_source(r,i) AND nonzero_weight(r,i) AND dependency(r,i) AND unresolved(i))`

该式用于计费，不是新的代数。不能假设消费者独立，再把边际概率乘积当真实请求概率；也不能再次计入基线本来会跳过的零源/零权。

### 只做一次有判别力的训练探针

先计算免费判决/取消、但保留完整依赖及同资源强基线的**整链乐观上界**。若连此上界都不足 15%，停止这个速度 X，不启动 A800 训练。

有足够空间且原文对照没有覆盖拟议差异时，仅预先指定一个 2×2：

| 因素 | 水平一 | 水平二 |
|---|---|---|
| 时间支撑 | row34 | common3＋private34 |
| 同权限训练目标 | 普通逐门/组终止费用 | 实际物理请求并集费用 |

固定连接数上限、完整 10 输入/10 输出、非因果语义、检查位置、总状态、P/H、训练样本/更新数、预测器容量和参数权限。保持 θg 与当前固定 BN 合同，τ单独处理。两种支撑都获得两个目标；未来 Y 只能作训练监督，不能作推理输入。使用已有 train32 与独立 valid10；不在失败后另扫支撑、检查点、γ 或种子。

**判别结论：** 若 row34＋相同目标已经吃掉全部收益，不能把 common3 称新架构；若所有收益来自普通预测训练，也不能算硬件 X；若只省活跃项而计入 Conv2/halo/预测后服务不降，则停止该版本。

最终晋级须：完整目标链净服务至少减少 15%，总系数/预测器/状态容量不增加，valid825 AEE≤1.259 且相对同预算最强学生不劣于 0.005。此为项目筛选门，不是 TCAS-II 录用标准。先 valid10 只作筛查，不能替代 full825。

## 5. 第二顺位：连续 PSN 的完整编译与物理成本

### B、A 与现阶段交付

连续 T10 中间量是实际算术对象；完整矩阵非因果，不能借普通逐时刻 LIF 截断。旧通用 MAC 服务比例不够证明新的电路问题，所以先补 **完整 da4ml CMVM/CSE＋普通缩位/流水＋严格判决**。

选择一份已有 S0 学生的固定 10×10 Q14 矩阵与已捕获 Yi，保持输入、整数函数、源端和系数预算一致。本步骤不改模型、不训练、不新捕获；逐系数 CSD 不算完成。比较内容包括全图公共子式、符号、位宽、深度、扇出、节点保存与重算、可选端口、跨 p 流水及消费者按位懒求值。合法普通优化双方都有。

新增阅读优先级为 ROM-LTE、OS-CIM、DNC：分别补零模式切换、驻留部分和、同一算术阵列跨阶段状态。完整方法尚未取得时，不凭摘要补想象电路。定制宏能力与普通 RTL 实现分开。

第一份交付只有一张同函数归因表：完整 MAC、完整 CMVM、CMVM＋普通判决各自的最长依赖、端口冲突、状态位数、位活动代理与完整 FC1→PSN→θg 服务。**它是补 A、寻找 B，不作为新机制结果。**

### 新 X 的准入

只有完整基线之后仍存在可指认的物理损失，才写一页 X。例如共享中间量为少数未完成消费者保留而造成宽状态读写/切换，是否确有比普通按需求值、驻留和时钟门控更好的组织。这个例子是问题，不是已经成立的创新；普通完成后关钟或复制公共子式不够。

旧速度版本继续按原 ≥15% 完整链门，不重跑“门确定就停 U”的改名版本。

**本轮新增一项筛选原则：** 若发现的是独立的状态/切换问题，可以在实现前另立能量主指标：完整链同 AEE、同吞吐/时序、同总面积/容量约束下，目标能量至少减少 15%。这是新的预先定义问题，不能在旧速度 X 失败后换指标续命。位活动、字节和寄存器数只筛机会；正式能量必须通过同工作负载、目标库和真实活动的功耗分析，包含时钟、控制与存储。若资料/库不足，保持模型标签，不给省电百分比。

此线可以独立产出有价值的电路机制，但目前 X 未找到，不预设它一定会晋级。

## 6. 剪枝、运动与其他候选为什么没有一起启动

| 项 | 处置与具体理由 | 恢复资格所需的新证据 |
|---|---|---|
| HiNM/VENOM/CRISP、量化剪枝 | 保留并纳入敏感 patch 控制；旧 s2b3 共同块不胜简单半宽，不代表完整方法失败 | 完整重排/内层 N:M/恢复训练和真实 Conv2 计费后，仍有普通方法吃不掉的洞 |
| S3Net/原生稀疏 stem | 排第二队列；真正改变网络和索引，不是给现有密集 stem 加零 mask | 同 AEE 下足够整段上界；固定偏移、完整稀疏坐标两种控制均计费 |
| 因果运动/残差主调度 | 保留最多一日机会探针；旧固定 tile 差分为直接工作的 1.52929×且参考状态很宽，当前版本停止 | 固定 BN 新学生中，事件/前帧输入和全部 warp/参考/halo/状态后仍有 ≥15% 整段机会；对照 DeltaCNN/MotionDeltaCNN/MEET、无 warp 差分和简单事件计数 |
| F_live>1 | 给双方的资源优化，不算创新线；有上界依据才做一次有限对照 | 在相同总容量/带宽中纠正原 F_live=1 限制；不能借多资源优势当新机制 |
| C1 Prosperity∪APEC 当前融合 | 停止：完整算子服务已慢16.44%，大缓存仍慢2.96% | 必须有新的构造/散播交互假说，且 Pro-Cache-CIM 等完整先验后仍有增量；本轮不重开 |
| C2 静态共模归约 | 停止：同结构直接时间并行更快，加法减少没有转化为周期 | 完整 LoAS/真实消费者可补，但不能再给当前归约加槽扫参 |
| HBG 幅度双轨 | 保留适配审查；静态 θ 可折权时没有凭空出现的逐事件乘法瓶颈 | 真实不可折叠的幅度、非线性或消费者成本，及相对 C-DNN 等混合架构的差异 |
| Motion-XOR K=0/行内复用 | 无损机会保留为旁路，K=0 只可跳相应输出乘积 | 当前同账本份额和合法分母；不能把少量注意力工作夸为系统主贡献 |

一条支线排队靠后不等于被证伪。缺全文、缺完整迁移、短训未拟合、模型收益不足、功能失败、同资源失败分别写明。

## 8. 每天的挖点与审阅方式

沿用用户指定的一页格式，顺序固定为：**B和强对照 → A的完整方法 → X差异句 → 一次判别 → 杀门**。每天只围绕当前真实洞补直接先验，不再无限关键词扫卡。

三类 skill 的用途分别是：grilling 追问分母、完整迁移、简单控制和版本级失败；brainstorming-research-ideas 检查前提变化、极端负载和正交组合；scientific-brainstorming 保留假设、竞争解释与反对意见。代理审阅是有上下文的独立意见，不冒称盲法。评分只辅助比较，不能将数个主观分数相乘或换算录用率。

每个将进入实现的 X 给两类审阅：一份查最邻近原文是否覆盖，一份查同资源执行是否有净空间。允许审阅支持“思想仍值得试、当前实现应停”，也允许结果推翻原评分。最终交付应是一条比强底座更好的可测机制；若尚未得到，明确报告未得到，不用扩 RTL 或重写标题代替。
