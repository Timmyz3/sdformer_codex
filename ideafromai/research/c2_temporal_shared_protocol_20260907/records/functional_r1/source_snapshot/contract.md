# C2 有界时间共享部分和：隔离协议原型

日期：2026-09-07。状态：已授权研究实现，非生产 RTL、非性能或 PPA 准入。此前研究解释见 [融合机制报告](../fusion_delivery_20260907/report.html)。

## 算术与继承边界

输入为完整 T 的发放签名 `sigma[c]` 和有效贡献 `phi[c,h]=theta[c]*W[c,h]`。ATLIF 完整数值是 `z=theta*g`，连续值阈值幅值保留。本原型使用有符号整数分子表达诊断用有理数贡献，不证明冻结 FP32 重排、Acc24 位宽或 AEE 等价。

同一签名的多个源先构造共享部分和，再向签名中每个时间消费者提交。完整 T 来自 LoAS 的时间组织，分组求和来自共享归约/RSR 一类先验；LRU、ready/valid 与多播确认均不单列为创新。这里检验保留源顺序的有限部分和能否正确连接累加与释放，尚不代表该组合具有充分发表新颖性。

## 唯一执行合同

- 参数：默认 `T=10, SLOTS=8, LANES=8, VALUE_W=48`。48 bit 是精确诊断载荷宽度，不继承旧 C2 的 24 bit 面积与时序。数学整数精确性要求每个部分和及消费者 Y 均在有符号 48 bit 内；电路溢出会按位宽截断，未实现饱和或溢出恢复。C++ 参考对所有实际累加检查范围。
- 每帧是一处空间位置、一个输出通道切片。输入按原通道 `c=0,1,...` 顺序，`last` 标记最后一个源。合法帧非空、长度不超过 `2^INDEX_W`；到最大索引时必须为 last，否则内部期望序号将自然回绕。帧内 `frame_id` 不变。输入有效而未接受时，正常生产者保持所有输入字段。
- 单个源事务在途；字典和 LRU 一次处理一个源。没有 8-bank 同时请求、乱序返回、生产者直连或免转置声明。
- `sigma=0` 不分配；单比特签名直接分发；多比特签名命中则更新，未命中分配，满则完整排空 LRU 槽后复用。
- 每个时间消费者独立 `ready`。只有 `valid[t] && ready[t]` 才清除其待交付位。其它消费者接受后，仍未接受的消费者看到的值和帧身份不变。
- 共享槽即使部分和值为零仍有效。槽被驱逐后同签名再次出现形成新段，不能免费合并过去的段。
- 所有输入处理完并排空字典后发布 `done_valid`；其在 `done_ready` 前保持。不得提前接受下一帧。复位取消当前帧，消费者必须在同一次复位清空对应累加状态。
- 输出是对 T 个消费者的增量服务。消费者的 Y 与有效位跨单源旁路、驱逐和最终排空持续存在；所有增量完成后才消费最终 Y。
- 非法输入的 frame/index 不在本叶数据域内；`in_ready` 对当前期望身份门控。仿真会验证错误身份不能被接收；负测撤销非法 valid 一拍后才重新发起正确输入。不提供超时、丢包恢复或系统故障处理接口，不能声称拒绝所有违反长度合同的序号回绕。

## 显式状态与端口预算

| 状态 | 默认数量 | 用途 |
|---|---:|---|
| 字典宽值 | 8 个向量 | 同签名的部分和 |
| SRC 宽值 | 1 个向量 | 已接受源；等待 victim 完成时保留 |
| WORK 宽值 | 1 个向量 | 正在分发的旁路或排空值 |
| 消费者 Y | 10 个向量，位于测试消费者 | 持久输出累加值，另有 10 个有效位 |
| 窄状态 | 单独计费 | 标签、有效位、LRU、源签名/last、待确认位、帧和源序号、状态机 |

宽工作状态为 `D+2`，不含 T 个 Y。消费者采用可直接读取的寄存器阵列，每时间消费者最多一次更新/拍；这是明确的测试合同，不是 1RW SRAM。若改成同步 Y SRAM，额外读返回/写回状态必须另计。若支持一个 8-source bundle 的乱序返回，保守需另加 8 个输入重排向量，不能仍声称工作区仅 10 个向量。

字典当前为寄存器数组、全标签比较，每次最多一个宽槽更新或排空读取。宽加法器数、组合扇出、寄存器开销尚未映射；逻辑操作数不能替代端口周期或能量。

## 预声明验证

使用系统 Verilator 4.028 和 C++ 独立直接求和、LRU 分段参考。默认配置以及 `T=2,D=1`、`T=10,D=4` 覆盖边界。输入使用 8 lane 的有符号 48 bit 整数分子。

定向覆盖：全零、单时间旁路、同类重复、D+1 类抖动、末源为零、符号抵消但有效零、各消费者独立长背压、输入保持、done 背压、错误帧/序号拒收、排空中复位后的新帧。

真实发放支持验证只取既有封存 sample0 的 stage0/3 block0 真 FC2，每层预定 16 个位置 `floor(i*(P-1)/15), i=0..15`，不是新盲测或新捕获。每源诊断系数：

```
W[c,h] = ((c+3)*(h+5)*13)%256 - 128
W[:,0] = -128; W[:,1] = 127
theta_numerator[c] = 999883 + 17*c
phi[c,h] = theta_numerator[c] * W[c,h]   # common denominator 1e6
```

实际 checkpoint 权重不用于上述数值测试。每个分发段及消费者接受事件都对照独立软件参考，不能仅依靠最终和相等掩盖重复/遗漏的抵消。

## 通过之后仍缺什么

本轮通过仅证明隔离整数协议及所测背压轨迹，不产生 RTL 加速比。下一次性能比较必须统一 bank、输入暂存、源顺序、Y 存储、背压和位宽，纳入直接完整 T FTP、平坦共享归约与 LoAS/RSR 近邻。VCS、DC/PT、Formality、生产者集成、真实数值与光流评价均未由本轮授权结果自动完成。
