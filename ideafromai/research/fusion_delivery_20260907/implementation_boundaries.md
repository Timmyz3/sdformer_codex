# 本轮参考到硬件的明确边界

本文件补充已封存收据的实现费用，不修改任何既有统计。2026-09-07。

## C2：不能遗漏的费用

1. 完整签名参考中的 `head[1024]+next[C]+valid[1024]` 最低状态为浅层 **13,696 bit = 1,712 B**、深层 **50,176 bit = 6,272 B**。这是单位置的头/链/叶有效位，未含控制与内部前缀信息。
2. `present[level]` 不是免费硬件服务。可由叶有效位的范围 OR 实现并计逻辑/查询，或另外保存 T=10 非零签名森林的 **1,013 个内部有效位**，并计构建、清零、查询。包括叶在内满森林有2,036个节点；数据有效与数值是否为零不同。
3. 一个 `next` 单链在同步单口存储上有地址依赖。按类统计的 bank 请求轮数下界未必可达到，需要预取队列、连续成员数组或按 bank 分链。新增存储、端口和读取都不能隐去。
4. 上游若按 hidden-channel 块遍历全部空间位置，生产者直接建立成员表就要同时保留多位置状态，或者先保存完整 G/σ 后另行分类。一份单位置表不能自动消除转置或预处理。当前参考不计其重叠收益。
5. 后序遍历的样本峰值为5个工作向量，通用配置仍按理论 **T=10** 计，已用全部1,023个非零签名达到峰10。这里已经含当前叶/运算寄存值；另需10个输出向量。
6. 递归分发只比完整平坦共享归约再省1.78%/1.28%加法。主要收益来自同签名归约；不能把全部22.94%/50.56%算给新栈调度。

## C2：源顺序变体如何解决已暴露的问题

源顺序变体从完整T源标志按原通道序读入，直接维护D=4/8个有界共享部分和，不需要上述成员链或内部树有效表。单时间签名直接累计；多时间签名命中则加到对应槽，满时先把旧槽完整分发后再复用。驱逐后又出现的同签名是新段，全部重复分发已经收费。

D=8留8个宽部分和，加两个明确预留的输入/排空寄存值，共10个工作向量；另有T个输出向量。88bit只包括8项10bit标签和有效位，**不包括宽数据、LRU、输出有效位或控制**。

源取数身份顺序未被重排，因此没有被强迫变为逐类串行访问；但尚未证明一周期并行收8个源。真实K8要解决同槽多源更新、不同槽多端口写、排空输出竞争、返回乱序与背压。CPU串行事件正确性不是这些事务性质的证明。该变体是已有选择性部分和/RSR的实现路线，不单独当第三个新代数。

## C1：端口证书与理论释放

所有原始目的保留。相对原森林，V为存活虚拟节点数，q为其中有父者数，r为由根变成非根的原行数，D为取消全部消费者的旧捕获数，U为新加入捕获的原行数。当前一父边一读、有消费者节点一写的合同给出：

`Δ读 = r+q`，`Δ写 = V+U−D`。

总1RW服务不增需要 `D ≥ V+U+r+q`。这只约束读写事件总量，不证明请求位置、等待时间、分配或时钟。完整消费者集合必须在检测期已知；不能把信息当作免费预测。

当前图参考允许最后消费者后的理论释放；旧m935没有任务内回收。因此17个理论峰活结果不能直接套用原生产岛的16/64槽合同或旧面积。九宏旧父槽为96×12bit，与Acc24不同；本轮非1阈值INT64分子诊断不证明该旧位宽继续适用。

所有C1/C2的源读取单位均为该权重/阈值身份下的系数向量行，不是外部字节流量。没有新增VCS/DC/PT/Formality闭环、物理PPA、整网FPS或AEE结论。
