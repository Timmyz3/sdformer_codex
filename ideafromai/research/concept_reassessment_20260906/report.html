先理解想法：ATLIF 幅值语义与 C1/C2 构想重评

2026-09-06｜给课题负责人的概念解释与取舍材料｜唯一投稿目标 TCAS-II。

本轮只判断“想法是什么、能否借来、迁移后哪里可能有新意”。上轮 T 分混入了实现成熟度，不能直接当作构想新颖性分。没有 RTL 或 PPA，不是这一阶段的淘汰理由。

主要改判：ExSpike 的共同贡献复用恢复为 C1 重构底稿；运动残差驱动的计算选择恢复为可改模型的方向；ATLIF 按“发放标志＋连续值阈值幅值”理解。 本轮不替用户决定生产设计。

ATLIF：发放标志与数值幅值分开

当前这类神经元可简写为：

g = 1[u >= θ]
z = θ × g

g 表示是否发放，z 才是软件输出。θ 是连续值参数，不能把 z 随手改成 g。固定 θ 时，输出为 0 或 θ；这也不表示每个事件都有一个任意变化的连续幅值。两个事实应同时保留。

源码实际返回 out * thre，thresh 定义为浮点可学习标量，见 ATLIF 实现。本轮只读同 SHA 的 ep34 检查点，105 个 .thresh 均为标量，其中 10 个不等于 1，最小值为 0.9998828172683716。这不允许近似当成 1，也不证明 θ 会随推理事件变化。

forward 累积阈值更新量，实际修改参数在外部 threshold_update 中进行；训练期的手动 homeostatic 冻结也不自动等于冻结梯度更新。相关实现为 installer.py 和 h28_optimizer.py。

在某个合法线性段，若 θ 对该输入通道固定，可代数上写成 W(θg)=(Wθ)g。这意味着幅值换一个地方表示，不是幅值消失。量化是否能容纳 Wθ、分支和非线性是否允许搬移，需要按路径判断。本轮不把“全图幅值都可免费折权”当研究前提。

H67 中，分数的部分运算读取发放模式；value 路径仍执行 attn = k_orig.mul(gate)。学习阈值 θ、注意力 gate、宽位中间数值不能混成一个概念。见 bsa_attention.py 的 _ternary_alpha_xnor_token_scores 与 tx_qkselector_shiftmax 分支。

ExSpike：为什么应该恢复讨论

ExSpike 的 APEC 将相邻位置的活跃通道集合分成共同部分和各自剩余部分。共同部分只算一次，各位置仍有自己的完整输出；它不是把多个原始事件坐标合成一个坐标。ExSpike，§III-A2、图 5

用适配我们阈值幅值的例子解释。Φ(c) 是通道 c 在同一权重身份下的有效贡献，允许 Φ(c)=θ_c W(c)：

位置 A 需要：a、b、c
位置 B 需要：  b、c、d

共同计算 U = Φ(b) + Φ(c)
A 的结果 = U + Φ(a)
B 的结果 = U + Φ(d)

对 Conv3×3，Φ 可以表示对应核偏移和输出通道的贡献向量，最终仍送往各位置的输出邻域。若 θ 是同一模块固定的阈值，θ 不等于 1 并不妨碍复用。若未来幅值随位置或事件变化，则应比较有效贡献是否相同；只看“都发了”不够。这是面向我们网络的迁移推导。

旧 C1 借用真实父行的结果，要求相等或包含关系；A、B 互不包含时，未必有可借的父行。Prosperity 原文明确讨论过需要新建交集行的情况，随后没有采用它。Prosperity，§III-B

所以 APEC 确实是更宽的复用起点，应恢复讨论。但它的基本方式已经属于 ExSpike；更一般的虚拟交集构造还有 SumMerge 等先验。“比旧 C1 完整”与“相对全部先验有新意”需要分别回答。SumMerge，§3.3.2

一个值得讨论的改造是：从整组的一个公共交集，走向不同消费者子集的多个共同贡献。 四个位置分别需要 a+b+c+d、a+b+e+f、c+d+g+h、e+f+g+h，总交集为空，仍能共享四组两项和。这连接本地 selective-shared-reduction；相对旧 C1/APEC 有明确区别，相对 SumMerge 等仍是有条件的改造空间。

目录 MW-ΔBuf 还启发另一种分组方式：沿运动对应关系寻找可复用贡献，而不限于固定空间邻居。不过 MotionDeltaCNN 已研究运动对齐后的增量推理，“对齐后复用”本身不应算作我们的发明。MotionDeltaCNN，§3

独立重评结论是：直接 APEC 的适配高、属于我们的新增概念低；多消费者子集共享值得研究，但已有公共子表达式先验。未完成 RTL 不应扣构想新颖性。

我之前提出的三条，分别在解决什么

晚知判定分界下，提前压缩中间结果

宽位中间值最终经 BN、PSN 决定神经元输出 0 或 θ。BN 使用当前输入域统计，某些等效判定条件要稍后才能确定。

例如中间值 [1,2,9,10]，先按分界 5 保存候选发放标志 [0,0,1,1]。只要最终分界落在 (2,9]，标志不会变，可以丢掉多数原数值。靠近分界的少量值保留以便修补；超出可确认范围再重算。输出时仍恢复 θ 幅值。

θ 是 ATLIF 参数及输出幅值；τ 是把 BN、PSN 后的发放条件换算到前级数值后得到的等效分界。 “晚知”主要说 τ，不是说 θ 随每个事件随机变化。

可争取的新意是利用后继脉冲消费者的要求，提前丢掉宽位值，再用最终条件确认结果。压缩、预测 BN 和回退分别已有先验。Gist、预测 BN 技术、OPN

它贴合现有归一化—神经元边界，风格偏数值表示和存储消减，光流辨识度不强。已有 CPU 筛查支持两个选定层的适配，不替新颖性加分。

先从发放模式求统计，再生成宽位输出

通常先算全部线性层输出，再求均值方差。这条想法先统计输入各通道发放次数与共同发放次数，推导输出统计；归一化参数齐全后，再正式产生宽位输出。

对阈值幅值输入 X=S Dθ，可以完整保留幅值：

V = Dθ W
G = SᵀS，k = diag(G)
sum(Y_h) = kᵀV_h
sum(Y_h²) = V_hᵀG V_h

前提是这个域内 Dθ 固定。若幅值逐位置任意变化，必须改用加权统计，普通共发放次数不再足够。协方差传播和 AND-popcount 是已知工具；新意候选在源统计替代宽输出统计遍的组织方式。AVP、BISMO

用投影筛运动候选，再查二维事实

先看横向、纵向简化证据，筛掉不可能胜出的速度；存活候选再查真实二维事件轨迹。两条投影可能来自不同物体，不能直接拼成二维运动。

它适合作为另一种事件运动组件，与当前 H67 关系较远。投影上界和候选消除已有先验，保留备选，不为凑三条而优先。EventShiftFlow、GCK

ideas 包的主要方向怎么重新取舍

重复命名按思想家族归并。“需改模型”是迁移类别，不是新颖性扣分。本表覆盖 R1–R4、G/H/I 和 Grok46 中本轮争论的主要方向，不把每个名字计作独立创新。

方向 思想是什么 当前构想判断
AdjEvt / ExSpike 多个位置的共同贡献算一次，各自补齐 恢复 C1 底稿。 保留 θ 幅值；坐标合并误读应修正。
OP-STW / PRRC / OGEC / CFP 用粗运动与可信程度，决定哪里继续精细计算 恢复讨论。 低置信遮挡可能更难，不能机械等同少算；改变执行函数需另评模型。
MW-ΔBuf / Δ-MaskPipe 先用运动解释变化，只对剩余变化更新 值得讨论。 光流适配强，视频增量已有；阈值幅值、PSN、动态 BN 是迁移差异。
ECP-QKV / BUI 在昂贵计算完成前判断后继决策是否已确定 保留。 可面向发放及幅值确认重构；与晚知分界方案重叠，不算两条独立创新。
WinTok / HeatFlow / TokMerge 选择窗口和 token，或合并冗余 token 恢复改模型方向。 Swin 适配好；检测显著性应改成光流剩余运动需求，并保留稠密输出。
STH-Gate / SinkSparse 区分时空计算需求，并保留参考信息 可借，直接新增概念有限。 当前没有这些 head 分型与保留策略，需要模型设计。
TDE3 / BL / BitHyp 用事件先后顺序或简单方向检测给粗运动线索 可作前级先验。 detector 已有；它怎样改变后续工作更值得研究。
TMA / BiSAT / MFBD / Motion-TTB 对齐多时刻证据，让一致运动证据共同作用 可借，原版需改模型。 仅给普通上下文改名为运动包不增加新意。
TID 过去运动先对齐新事件，再估计未解释的运动残差 恢复为新模型来源。 当前 bin 置换没实现原思路，不说明思路无价值。
EDC 多时间尺度的特征差异与匹配信息结合 保留。 原版有相关体和迭代器；也可只借差异作为计算需求线索。
ResHTR 主体运动较低频更新，中间时刻由残差细化 保留，迁移跨度较大。 高时间分辨率不是现有多尺度头的同义词；训练噪声不是推理机制。
SCI / NL-STMFA 检查对齐质量，或为非匀速运动补充修正 保留为模型来源。 SCI 是学习纠错输入，不自动产生清零/停止指令。
HBG-RP / SMAM-RP / ADP-MAC 分开组织发放控制与幅值相关数值计算 按阈值幅值语义恢复审视。 不预设幅值为 1，也不认定 ep34 已有每事件任意 int8 载荷。双轨/bit-skip 本身已有。
ARM-Acc 对局部纹理不能区分的运动保留多个假设 概念可用，需真实运动假设。 多 head 或多 Acc 上下文不自动具备几何含义。
MX3P＋脏分数复用 利用共同发放、共同静默、时间变化，复用没变的分数 恢复算法原生候选。 三个 popcount 单独新意有限；低性能份额不直接否定新颖性，gate×K 数值仍需保留。
混 T / VGTS / ReMem / 提前停止 减少时间展开或复用神经元内部信息 保留可迁移部分。 当前完整时间 PSN 不能套普通 leak/reset 停止规则，这是函数差异。
NPU 端口、VFS、队列、广播 更合理地分配资源 可作工具。 直接作为标题新意偏低；任务信息怎样决定分配才可能形成特色。
CIM / 近存状态 把状态留在计算附近，减少搬运 近存思想可借。 当前工艺与用户范围不支持的模拟位线、多行宏操作不能直接搬来。

SAST 的窗口/token 选择还覆盖稀疏 MLP，不只影响注意力叶；把检测选择准则改为光流准则是我们的迁移假说。SAST，§3.2–3.5

TID 的先对齐再纠正、EDC 的对齐后差异，可以启发计算选择，但原模型不是 H67。IDNet，§III-B–E、EDCFlow，§3.1–3.3

另补正两处概念：BAT 的 backward 并不一概要求等待目标窗之后的未来事件，论文也展示只用过去事件预测未来流；SCI 图是网络的学习纠错依据，不是自动的停止/清零指令。BAT，§3.3、§4.4、SciFlow，§3.1

供用户比较的三种创新风格

共同贡献复用： 从 ExSpike 出发，讨论比真实父行或整组交集更灵活的共享。最接近替换旧 C1，保留 θ 幅值；先验压力主要来自公共子表达式研究。

运动解释后的计算选择： 从 TID/EDC 借“尚未解释的变化”，从 CFP/WinTok 借“选择值得细化的区域”。高速平移的墙可能事件很多，但粗运动已解释得很好；刚出现的小物体事件不多，却更需要计算。以此决定重训后的 Swin/MLP 或解码细化工作，比仅按非零率分配更贴光流。这是组合假说，仍要承认运动增量和动态推理先验。

后继脉冲语义驱动的表示： 保留最终消费者需要的发放标志和 θ 幅值，减少等待统计时的宽位中间存储。贴现有神经元接口，光流辨识度弱于上一条。

这三种都不需要现在拿生产 RTL 才有资格讨论。直接换名字、把已有方法改个输入接口或读错算法，仍不能增加新颖性。先根据思想差异取舍，再决定进入哪些设计与实验。
