# C1/C2 重构研究：从二值消费者和真实归一化依赖寻找新电路

2026-09-06｜唯一投稿目标：TCAS-II｜状态：研究筛查，尚未形成两至三条已证明有净收益的强机制。

**当前建议：主攻“晚知阈值下的二值提交”；保留“二值源统计驱动前馈执行”作为竞争路线；“二维见证约束的运动搜索”降为独立组件备选。** 三者不拼成一座加速器。旧 C1/C2 的存在不构成保留理由，也不以换名字补足创新。以下明确区分可证明的数学、真实输入机会统计和仍缺失的电路证据。

这轮最有价值的变化，是把研究问题推进到一个真实且可检查的矛盾：**H67 的前馈输出最终只有一位，但 no_running BN 的最终判定阈值要等全域统计完成。** 因而宽位中间值的保存、重算和提交方式，值得独立成为电路研究对象。当前独立评分仍集中在 5–6 分；这些是研究潜力判断，不是录用概率。

**冻结身份与本轮证据**

模型为 Motion C12/H67 ep34，完整检查点 SHA 为 `4bbaf7fc9fa48e6efd46898e40a05ca6f5c606d4497551394caf2885b394ca48`。量化关闭，Motion α=0.125，K 作为 V；冻结 AEE 1.199514 和全局发放 5.6709% 不用于给新整数合同背书。ATLIF 是 `{0,θ}`，库存口径为 105 安装、12 个 sn2_q 不调用、93 调用、12 个 attn_sn 死结果、81 个有消费者。

源码显示 PSN 使用可正可负的 fullrank T×T 矩阵。BN 在评估时使用当前域统计；checkpoint 内仍有 running_mean/var，并不意味着实际前向使用它们。前馈主路径是 `sn1 → FC1 → BN1 → sn2 → FC2`。因此“直接静态折 BN”与“把 PSN 当普通 leak/reset”都会把新机制建在错误模型上。

本轮从本地系统交接区找到同 SHA 检查点，使用白名单 NumPy 读取器读取其张量；没有安装 PyTorch、执行 pickle 任意全局对象或启动远程捕获。机会检查预先固定 sample0、stage0/block0 与 stage3/block0 两个 FC1 层，空间包 B∈{16,32,64}、边界保留 K∈{0,2,4,8}，全部行与输出通道均纳入。两层真实形状为 `(N,C,H)=(192000,96,384)` 与 `(3000,768,3072)`，N 包含 T=10。

检查了捕获哈希、帧 CRC、行序、二值代码和参数形状。NumPy float64 重建共 **82,944,000 个输出位，与对应封存 FC2 输入零差异**；独立的“先 BN 后 PSN”参考也零差异。此结果是两个预设层的单样本数值筛查，不是所有输入的浮点等价证明、valid825 精度评价或定点硬件合同。BN epsilon 在该筛查中按源码默认取 1e−5；运行对象的完整属性仍需单独导出核对。

可复查：[预声明方案](records/threshold_packet_screen_plan.json)、[机会结果](records/threshold_packet_sample0_screen.json)、[脚本](scripts/screen_threshold_packets.py)。原捕获是间隔采样，不把 sample0→sample1 当相邻视频帧。本候选使用同一 epoch 内的前缀预测，不依赖这一跨帧假设。

**候选一：晚知阈值下的二值提交**

问题在于统计尚未齐全时，FC1 已经产生大量宽位数值；下游真正消费的却是经过 BN 和 PSN 后的二值结果。传统融合实现可以保存 raw Y，也可以只求统计后把 FC1 再算一遍。候选要探索第三种表示：先保存候选脉冲、一个可验证区间以及少数靠近阈值的数值，待最终统计到齐，再决定提交、局部修补或回放。

令 `Y_sph=(S_s,p θ_source)·W_h`，`U_tph=Σ_s A_ts Y_sph`，`R_t=Σ_s A_ts`，`d_h=sqrt(var_h+eps)`。当 γ_h>0 时，最终二值判断在实数算术下可改写为：

```text
bit_tph = [ U_tph >= τ_th ]
τ_th = μ_h R_t + (d_h / γ_h)·(θ + center_t − bias_t − β_h R_t)
```

γ<0 时同时对 U 和 τ 反向；γ=0 单独走常量判定。这个代数本身不主张新意，也不自动保持原 GPU 浮点重关联顺序。

具体电路流程如下。

1. 首遍完整执行 FC1，并融合当前域的统计归约。当前空间包完整 T 的 Y 到齐后，计算 U，固定这个包的预测阈值。预测可使用已经完成的同域前缀统计，不能偷看未来包，且包内不能继续改变预测阈值。
2. 生成候选位，保留 K 个最接近预测阈值的 U 及其位置。其余宽值丢弃；只保留候选 0 一侧的最大值 a、候选 1 一侧的最小值 b。空侧有显式标志。流式 K 集合使用固定距离和位置打破平局；被逐出值折入 a/b。
3. 最终全域统计封存后，如果真实阈值满足 `a < τ <= b`，所有已丢宽值的候选位都正确；仅用保留的 K 个值修补边界位，随后提交。
4. 区间未通过时，对失败的 `(空间包,h)` 重放所需完整 T，生成最终位后提交。未证明的候选位不得提前送给 FC2。epoch、层、权重身份与尾包长度进入描述符。

小例子：U=[−9,−2,4,8]，预测阈值 1，K=1，保留 −2。其余值给出 a=−9、b=4。最终阈值若为 −3，证书成立，只需将 −2 对应的位从 0 改为 1。无需保留其他三个宽值。K=0 是纯证书，K=B 是全值保存；它们属于同一个容量旋钮。

本轮完成 378,125 次小域阈值决策检查与 1,200 次有理数 BN/PSN 代数检查，覆盖符号、阈值相等、空侧和 K 单调性。这些小域样本的通过比例不能当作 DSEC 命中率。[数学检查](records/threshold_packet_toy_check.json)

**可以争取的新意**是“最终统计晚到时，仍可在丢掉大部分宽值后保证最终二值消费者正确”的表示与提交电路。Gist 已提出面向消费者的低位编码；公开的预测 BN 技术已有统计估计和回滚；OPN 已在 TCAS-II 做抽样归一化和单遍访存。因此不能把压缩、预测、回滚、单遍 BN 或稀疏消费者单独叫作新机制。[Gist，ISCA 2018](https://www.cs.toronto.edu/~pekhimenko/Papers/ISCA18-Gist.pdf)、[预测 BN 公开技术](https://patents.google.com/patent/US20200160123A1/en)、[OPN，TCAS-II 2024](https://doi.org/10.1109/TCSII.2024.3354738)

OPN 使用抽样 range normalization 提前确定统计，并为反向计算恢复部分输入。本候选保留最终全域统计，靠晚到的精确判定确认已压缩二值结果。这是需要证明的具体差异，不是“第一个做 H67 硬件”。OPN 原文方法及 FlexAcc 的原值保存流程已补读，记录在[先验缺口补查](records/root_bn_prior_gap_closure.json)。

**真实输入给出的机会与反证**

以下只展示预设 B=32、K=4，全部 24 个层/参数组合均保留在交互页与 JSON。加权回放比例按原二值源的活跃权重加项计数；首遍 FC1 一个也没有省略。

| 同一预设配置 | stage0/block0 | stage3/block0 |
|---|---:|---:|
| 证书失败包比例 | 0.2693% | 1.1680% |
| 跨 T 合并后，按 h 精确回放的 FC1 加项比例 | 2.4554% | 8.9066% |
| 固定 96 输出通道组回放的 FC1 加项比例 | 63.7489% | 85.4740% |
| 32 位 U 假设下的裸编码载荷 | 70.272 MB | 9.3696 MB |
| 完整 U 的 32 位载荷 | 294.912 MB | 36.864 MB |

上述载荷不是 SRAM 面积或实测访存；未包括描述符、补丁队列、局部宽值缓冲、源数据、宏对齐及端口。CPU 用 float64 审计数值，表中 32 位仅是待定义部署合同下的容量例子，不能声称该宽度已经等价。

固定 96 输出通道回放会把少量失败扩散成大量重算，这是当前最明确的电路矛盾。按 h 聚集可减少加项，但若每 h 独立重读 S，两个层的逻辑源读取分别为约 **20.767 MB、72.315 MB**。后者是原二值源大小的约 251 倍。这不是外存下界：按空间包保留 S，再遍历失败 h，可以共享源；相应代价转移为权重行重读、索引和缓存端口。

空间并行也不能免费实现理想稀疏吞吐。逐 c 扫描、把 W_hc 广播到空间目的时，零输入仍可能占用 lane；必须计入目的压缩或空 lane。由此，**低回放加项比例目前只支持机会存在，尚不支持周期/能量优势。** 真正要设计的是编码、补丁、有限存储下的失败集合调度及原子提交链路。常规广播和循环换序是配套实现。

强对照必须取下列实现中更优者：融合 FC1 求统计并保存 raw Y，随后融合 BN/PSN；融合首遍求统计、丢 Y、再完整重算 FC1。两者都允许合理分块、现有稀疏执行和广播。候选的额外编码、第一遍 PSN、源重读、补丁及完整 T 回放全部收费；不能只对稠密张量落盘程序比较。

最小下一门：冻结一个有限位宽合同；完成包含源/权重地址、读写端口、背压和 lane 占用的同资源服务模型；再扩大预声明样本覆盖。只有在此门通过后，才值得生产 RTL。新整数合同要另开 AEE 评价；冻结浮点路线需要原算序误差包络和失败回退，单样本零差异不能替代它。

**候选二：二值源统计驱动的前馈执行**

这条路线从另一端消除同一个等待：先在二值源空间构造当前域统计，得到 BN 参数后才正式产生宽位输出。对于二值 S、固定 W、且线性层与 BN 间没有舍入/饱和的合同：

```text
G = SᵀS，k = diag(G)
sum(Y_h) = kᵀw_h
sum(Y_h²) = w_hᵀG w_h
```

统计完成后，读回一位源 S，执行一次正常 FC1→BN→PSN。代数属于协方差传播；本轮不把它当新公式。二值矩阵乘、AND-popcount、转置和计数驻留已有成熟结构，必须与通用 Gram 核直接比较。[AVP](https://arxiv.org/html/1803.10560v1)、[BISMO](https://arxiv.org/html/1806.08862v1)、[Bishop，ISCA 2025](https://arxiv.org/html/2505.12281v1)

这次给出了一份比“加个 Gram 模块”具体的浅层组织：128 行源位转置双缓冲；固定 i 列驻留并广播；j 按 mod 8 分 bank，8 路 128-bit AND-popcount；G(i,j) 归 j 所在 bank。18 位计数每 128 位字装 7 个，整字暂存后连续更新不同槽，再写回，避免把 1RW 当作每拍任意计数读改写。

stage0 的行对齐遍历需要 **936,000 个设计推导发射批次**，不是 VCS 周期。G 计数可放入 8 个 128×128 宏；源转置双缓冲裸数据为 3 KiB，但若也用该深度的列 SRAM，会分配到 32 KiB。寄存器方案又有列选择、时钟与布线成本。原始二值源为 2.304 MB，wide Y 为 294.912 MB，二者是载荷，不能直接换成芯片面积比。

后面的 `wᵀGw` 必须在线算，不能免费放下 C²H 权重外积 ROM。以 16 个共享乘法 lane 的明确排程估计，stage0 需要约 0.226M 个乘法资源槽，stage3 则约 113.54M；槽数尚未含依赖、装载及统计标量单元。旧 Acc24 也不能充当大域矩统计累加器。这条路线只适合先筛浅层，不能把局部好处推广到所有 FC1。

**可以争取的新意**在完整统计生产链如何适配二值源、稀疏线性层与 1RW 存储，以较小额外电路消去宽位统计等待；单个 popcount 阵列和归一化重排不够。最强对照仍是融合输出统计保存/重算二选一，另加通用二值 Gram 核＋在线收缩。若整链不优于它们，则淘汰本候选。[BNFF，MLSys 2019](https://mlsys.org/Conferences/2019/doc/2019/18.pdf)、[FlexAcc，ISCAS 2025](https://jiemingyin.github.io/docs/ISCAS2025_FlexAcc.pdf)

独立评审为 **N6/F5/H5/T5**，保留浅层研究资格，暂不升为第二条强主创新。[完整电路评审](records/source_gram_circuit_review.json)记录了端口修正、位宽、所有阶段几何和强基线；OPN/FlexAcc 的后续原文补查另见上述缺口补查。

**候选三：二维见证约束的运动搜索**

这条是独立的离散事件运动组件，不能直接替换 H67 并沿用 ep34 AEE。给定双极性二维占据历史 O(x,y,h)，构造横、纵投影 X、Y。对速度候选沿时间路径访问：真实二维命中 R 的上界是同位置两轴投影命中的交集计数 U，满足 `0 <= R <= U <= H_valid`。

先用投影上界淘汰不可能超过当前最好候选的速度；存活者必须读取真实二维坐标形成见证。边界有效时间不同，要比较归一化命中率的整数交叉乘积，并明确平局规则；所有可能胜出的候选处理完成后才提交。目标是避免两轴各自选出不同物体的运动，再错误拼成一个二维速度。

EventShiftFlow 提供两轴时间占据与移位搜索的直接启发，但其二维组合存在关联问题；该文是 2026 ICRA workshop 预印本，不是 ICRA 主会。投影上界、分支限界和精确候选消除也已有直接先验，不能称它们为新原语。[EventShiftFlow](https://arxiv.org/html/2605.28312v1)、[GCK，TIP 2009](https://cs.haifa.ac.il/hagit/papers/TIP09-MosheHelOr-VideoCodingGCK.pdf)、[GOCM，TPAMI 2022](https://arxiv.org/html/2206.05127v1)

**可以争取的电路余量**是上界查询、二维见证读与窗口退休之间的共同存储组织。全局投影可能很快饱和；局部投影更紧，却可能丢失横纵独立查询的共享。480×640、双极性、16 个历史 bin 的完整二维位历史已需 1,228,800 B，另有新 bin 写入、退休和查询端口。必须比较位打包二维穷举、逐候选部分轨迹退出及分层占据索引，而不只比较浮点光流网络。

小域上界与 winner 检查通过，但没有真实事件吞吐/PPA/AEE。独立分 **N5/F组件8/F冻结ep34=2/H5/T5**；当前降为备选，不能凑作第三条强创新。[候选与公式](records/event_flow_candidates.json)、[独立评审](records/event_flow_independent_review.json)

**GrokBot 新 G/H 包：逐项读后的可用程度**

本轮复核了 `20` 入口、`04→09→12→14`、`15/16`、`18/19` 与 pointer，以及轻量镜像里的新叶、TB 和集成关系。首轮检查时的 G/H 七叶没有接进现有 front/back/top 消费链。末尾指纹核对发现 GrokBot 又同步了 Card I：回归收据从25项变成30项，wake_merge和部分文档/TB更新，另有5个新叶。对应版本和补审分开保存；本报告的最终代码范围固定到43份文件的只读内容快照，不覆盖之后的外部同步。[首轮逐项记录](records/gh_rtl_audit.json)、[并发更新补审](records/gh_concurrent_update_review.json)、[最终审阅快照](records/gh_final_scope_snapshot.json)

两批回归都是定向控制脚本的收据；peak、warp、上下界等关键输入由 TB 给出，不能据此认定原论文机制已经数字映射完成。新增局部 glue 不等于完整算法或原有 top 已集成；本轮不把作者声称的30/30冒称为自己运行的回归。

| 条目 | RTL 实际完成 | 迁移判断 |
|---|---|---|
| G：TDE3 prior | 一维左右 age 比较、conf 与 wake | 没有时间戳/速度编码、gain reset 或真实纹理抑制；可借运动线索，不能借其算法名当已实现 |

| G：TMA | 一维历史查找、相等计数、零值填充 | 缺二维对齐/采样/注意力及退出消费者；不是论文 TMA |
| H：BiSAT | 外部正反向特征比较、均值融合 | 缺相关性和偏移生产器；均值表达式还有窄位加法风险 |

| H：SCI | 外部 warp 特征差与 hold 标志 | 冻结 U-Net 没有对应迭代消费者；无完整恢复/前进协议 |
| H：BUI | 外给上/下界、启发式 gate | 未决区间仍能丢弃，没有 refine/replay；H67 的零 K 分数也会影响 Shiftmax 分母 |

两个算术风险是静态代码推导，未冒称本轮 VCS 反例。源级后端还有“pass-through＋计数器代替实际 MAC”、未连接的原始启发式开关等缺口。本轮未修改这些镜像文件。G/H 中有价值的是对运动和局部不确定性的观察，生产器、状态、精确失败路径必须补成真实电路。

对并发到达的 `research/21–23`、Card I 两份说明以及 BL/NL/TID/EDC/glue 五个新叶也完成了定向补读。TID 当前把时间bin循环置换，没有二维空间坐标或运动补偿；置换前后总和不变，N_ITER也没有驱动内部迭代控制。EDC是邻tile绝对差、外给correlation与固定3:1融合；没有产生低分辨相关性或学习融合器。BL的veto会抑制已有wake，但没有“该工作可精确省去”的证明；NL的主要算术为缩放绝对差与max。它们能做控制草图，不能因为引用了IDNet/EDCFlow并接出信号就得到完整算法的硬件身份。

这些淘汰有具体原因：如运动 sketch 每次加入和退休都要展开多个速度与 hash，低位逻辑状态又不能省去输入量化与门网代价。不是要求绝对首创。借用已知机制可以成立，前提是能指出它在本问题中新增了什么可执行结构，并胜过直接移植的强基线。[SHT，ICIP 2018](https://arxiv.org/html/1811.06287v1)、[事件窗口 Hough，ICRA 2020](https://rpg.ifi.uzh.ch/docs/ICRA20_Sugimoto.pdf)、[DMP](https://arxiv.org/html/2512.07602v1)、[WaveletVFI](https://byjiang.com/assets/pdf/WaveletVFI.pdf)

另有两项数学错误需要留档：一般非对角时间矩阵的逐分量阈值，不能靠把矩阵逆折进常量阈值来消除历史；横纵投影同时命中，也不能证明同一二维像素命中。记录中的反例只否定相应一般推导，不宣称相关论文全部无效。
