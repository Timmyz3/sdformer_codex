## 4. 第二批：E1，动态 BN 屏障是否值得消除

只改一个已确认仍有全域统计的投影归一化挂点，其他配置和参数起点相同。

| 臂 | 算法 | 要回答的问题 |
|---|---|---|
| N0 | 当前 onepass 动态 BN | 同批真实对照 |
| N1 | 只用训练数据校准的固定统计/仿射，不额外恢复 | 普通固定 BN 已能获得多少质量与部署收益？ |
| N2 | N1 + 同预算恢复训练 | 简单方法是否已经足够？ |
| N3 | 借鉴 IS-SNN 的拓扑感知权重标准化/残差稳定化，在该子块去掉动态 BN；同预算训练 | 相对 N2 是否有额外质量或结构收益？ |

IS-SNN 的公开模型页面标注 ECCV 2026 接收；本轮只核对了作者页面和摘要，没有完成其全文公式/完整代码移植。实现 N3 前须补原公式，不能只把 BN 替换成 Identity 就称复现。

### 必测

- 帧等权/像素加权 AEE、按序列误差、输出门密度、饱和和阈值翻转、不同事件密度下的稳定性。
- 完整投影输出的统计扫描、重读、存储寿命与 reduction barrier。
- 相同 SRAM/RF 容量、端口下，原有融合实现与去屏障后局部空间流水的服务和峰值活跃存储。
- 局部空间流水保留完整 T10 输入依赖及 3×3 halo。不得声称非因果 PSN 变成逐时间步因果网络。
- 连续 PED 路径仍须产生正确值；去掉 BN 不等于整网只做加法。
- 删除一个 BN 屏障不代表删除整网所有全域屏障。

### 取舍

若 N2 已获得 N3 的全部收益，保留 N2 作为部署底座，不能把已有的固定 BN/普通融合包装为独占电路创新。若 N3 使精度、可用块大小或存储容量出现有意义的新权衡，再进入完整子链硬件试验。

## 5. 第三批：E2，r0 大卷积的真实整数强对照

固定挂点：`patch_embed.residual_encoding.resblocks.0.conv2.0`，原 96×96×3×3；完整 K=864、T=10、输出96。先一层，不同时修改全部网络。

| 臂 | 表示 | 必付成本 |
|---|---|---|
| C0 | 原结构 W8，脉冲输入跳零 | 权重、实际非零输入、累加器、输出完成 |
| C1 | 普通 2:4 W8 | 压缩元数据/解码；另给同值 dense-zero 存储执行选择 |
| C2 | 输出组对齐的 2:4 W8 | 同组掩码约束导致的精度变化；真正 SRAM 字布局 |
| C3 | 已过小集质量门的 flat SVD R8，整数两级 | U/V、连续中间量、输出 rescale、残差/神经元 |
| C4 | 已过小集质量门的 spatial R16，整数空间分解 | 后级是 1×3，不是 1×1；行缓存与连续乘加 |

初轮不再做几十个 rank/码本扫描。C0–C4 相同校准、恢复训练预算、可训练权限和评价样本。

### 重要数值边界

flat8 可从既有规格起步：每 rank 量化 U 到 INT8，将其静态 scale 折入 V，再按输出量化 V。第一段输入只传脉冲位；第二段真实消费有界整数。

- `|z| <= 864*127 = 109728`，最坏需 signed18。
- `|p| <= 8*127*109728 = 111483648`，最坏需 signed28；Acc32 可覆盖该界。
- U/V 系数共 7680 B，另收取 scale、仿射等常量。
- 不能把后级输入当成 1 bit，也不能直接假定旧 Acc24 可以装下 p。
- 最终 gain×p 可能超过现有 16×24 乘口；拆分执行或新硬件均须收费。
- 所有 RNE、饱和与输出单位必须和实际整数金标相同；普通 FP32 的 fake-quant 前向不是完整整数核验证。

现有640行采样的记录为：flat8 约222.1125次选权加法+768次稠密后因子MAC/位置；普通2:4为1391.5172次选权加法。若只按这个后级稠密执行模型比较算术，设连续MAC/选权加法的单位成本比为β，则算术盈亏点约为β=1.5227。它不包含存储和控制，不是整个芯片胜负条件；压缩权重可能另省带宽，后级跳零也可能改变模型。延迟β、能量β和同面积吞吐不能混为一个数。

返回：每臂新 AEE、真实整数逐端点差异、范围/饱和、系数与状态实际字节、完整局部链周期/服务及分类停顿。

## 6. 第四批：E3，PSN 与连续残差共同感知的结构选择

这是一项新研究假设，不是已发表机制或已证明收益。SBC 原论文给出的时序压缩目标针对其神经元模型；不能把 LIF 的时间滤波矩阵直接套到本网的非因果 PSN。

### 最小推导与可实现版本

对一个输出通道，在一个空间位置收集 T×K 的真实输入 X。固定 BN 的线性系数并入局部映射。卷积权重变化 δw 造成 δu=Xδw。令 A 为真实 PSN 时间矩阵，D 为冻结参考膜值附近的阈值敏感度对角矩阵。

考虑局部近似：

```text
L_local = λg ||D A X δw||² + λc ||X δw||²
H_local = 2 Xᵀ (λg Aᵀ D² A + λc I) X
```

第一项保护时序判决，第二项保护仍供连续残差消费的数值。也可以用真实连续消费者的局部 Jacobian 替代 I，但会增加耦合和存储，首轮不需要把它做复杂。

这只是局部、固定参考的二阶近似：不能保证经过舍入/饱和/阈值后的逐位等价，也不能保证整网光流误差。真实硬前向、实际任务损失和最终 AEE 才是验收依据。

### 四个算法控制

1. 权重幅值/普通结构剪枝。
2. 普通激活重构误差/二阶目标。
3. 只保护 PSN 门/膜的目标。
4. 同时保护 PSN 与连续残差，并加入实际存储字/发射组代价的目标。

同一权重稀疏比例，既比较普通独立支持，也比较输出组共享支持；共同提供量化、再拟合和同预算训练。进一步比较近似同 AEE 的点，防止用更差精度换性能却不披露。

### 硬件代价目标

不要仅罚权重个数或平均 spike rate。估计并最终验证：实际读使能的 SRAM 字数、活动 RF 更新数、发射向量数、状态 spill 和输出事务。费用选择器只能用训练/校准统计和已到达输入，不可窥视未来样本或免费金标输出。

举例：一个真实权重字包含8个输出系数。若各输出独立保留一半连接，在独立假设下该字至少有一个保留系数的概率为 `1-0.5^8≈99.61%`。因此50%权重稀疏不必然使该字的读请求减少50%。这只是解释粒度问题的模型，不代替实测。

### 与已有工作的差别如何验证

H8共掩码、前置跳读、权重广播、请求感知选择本身都不是新机制；工程中也已有这类试验。需要证明新的时序/残差目标在同质量下产生更可执行的结构，并在物理事务上胜过拥有相同编译优化的普通2:4/组剪枝。若强对照已得到全部收益，把方法作为底座，不继续包装成新标题。

## 7. 第五批：E4，小硬件探针与完整子链

先综合少数决定取舍的原语，不直接重做整颗加速器。

- 脉冲选权加法单元与后因子有界整数 MAC：同工艺、时钟约束和输入活动，区分能量、面积、延迟/吞吐。
- 普通和组对齐稀疏前端：包含位扫描、元数据、地址发生器、跨字提取和累加器清零。
- 原动态 BN 完整后段与去屏障局部后段：计入真实存储生命周期、连续 PED 和最终输出。

当前 Python Machine 的单发射、8 lane、96 RF 是既有探索资源点，不是不可改变的芯片定义。基线和候选先在同资源点比较，再允许少量同面积/同容量设计点，验证结论是否只是特定调度器的产物。

完整子链至少覆盖真实输入到真实 gate 与连续输出，明确 3×3 gather/halo、完整K、完整T、输出通道、输入/系数加载、冷启动与稳态、输出写回。局部链不能免费继承整帧 BN 金标统计再称完整链。

验证分层：CPU整数金标 → 实际参数/活动RTL回放 → 综合后映射等价 → 时序 → 活动驱动功耗。改变模型的两个方案不做跨模型形式等价；应分别验证各自 RTL 对其金标，再核合成前后等价。没有布线寄生的结果标为预布局，不称芯片实测。

比较对象至少包括优化后的普通稀疏实现，以及与机制最近的公开方法适配。新结构必须给强对照同等驻留、广播、融合与地址预编译权限。

## 9. 回传格式与推进顺序

优先回传 E0 和 E1 的结果，E2 同步完成普通2:4和flat8整数端点。E3 在干净基线形成后启动。不要先跑十几个新RTL再找创新叙事。

每个实验臂至少包含：

```text
experiment_id,parent,checkpoint,output_head,numeric_function,
train_split,calibration_split,evaluation_split,frame_count,
AEE_frame_mean,AEE_pixel_weighted,delta_parent,
weight_bytes,metadata_bytes,peak_state_bytes,
AAC_count,continuous_MAC_count,cycles_or_service_slots,
SRAM_read_bytes,SRAM_write_bytes,RF_updates,stall_breakdown,
area,energy,physical_evidence_scope,correctness_status
```

未知字段留空并说明，不用名义MAC推算填入周期或能量。报告每臂是否完整、分母、失败原因、是否需要进一步恢复训练。

开发阶段可预设“相对同质量强对照，完整子链周期/能量或面积—能耗权衡存在足够余量”作为推进目标，例如希望收益达到两位数；这不是TCAS-II的录用门槛，也不是一次小样本负结果永久否定方法家族。

最终论文只保留一个有清楚因果链的中心机制，其他已有优化放入公共底座。TCAS-II官方指南规定总长5页，其中正文至多4.5页、最后一整栏为参考文献；不要把几百个原型拼成多条薄弱贡献。
