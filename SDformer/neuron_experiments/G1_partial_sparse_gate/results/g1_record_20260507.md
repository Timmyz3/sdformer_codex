# G1 Partial Sparse Gate Record

Date: 2026-05-07

## Goal

G1 tests the local-sparsity direction suggested by the PSN baseline sensitivity analysis. Instead of replacing every neuron, it wraps only six layer0 Swin spiking nodes with hard straight-through scalar gates.

Baseline files under `third_party/SDformerFlow` were not edited.

## Mechanism

Each target `Spiking_neuron.spiking_neuron` is wrapped as:

```text
output = base_psn(input) * hard_gate
hard_gate = STE(sigmoid(gate_logit) >= threshold)
```

Initial G1a policy:

| item | value |
| --- | --- |
| init checkpoint | `experiments/checkpoints/bs4_resume_epoch15_to60_20260424_163657/checkpoint_epoch59.pth` |
| `init_logit` | -2.0 |
| initial probability | about 0.119 |
| threshold | 0.5 |
| initial hard gate state | all 6 closed |
| trainable parameters | 6 gate logits |
| frozen backbone | true |
| gate regularization | `0.02 * mean(sigmoid(gate_logit))` |

Important correction:

The first short run let the frozen backbone remain in `train()` mode, which updated BatchNorm running statistics even though the weights were frozen. That checkpoint family is invalid for judging G1 and its large checkpoints were removed. The entrypoint was fixed so `sparse_gate.freeze_backbone=true` keeps the model in eval mode during gate-only training.

## Conclusion

G1 is the first successful sparse story: local gating of six sensitivity-selected layer0 Swin nodes reduces SOPs by about 25% while keeping AEE within about 1.3% of PSN baseline and improving AAE. Full neuron replacement was too disruptive; local sparse gating is the better direction.

Next recommended branch:

G1b should keep the same six target layers but compare closed-gate no-training, gate-only BN-eval training, and a tiny partial-unfreeze run where only layer0 block0/block1 normalization plus gates are trainable.
