# E4b Official-style TS-LIF Record

Date: 2026-05-04

## Purpose

E4b keeps the E4 official TS-LIF neuron dynamics but changes the training
protocol toward the official TS-LIF repository style:

- Adam optimizer.
- `clip_grad: 1.0`.
- Separate optimizer parameter groups.
- Low LR for the PSN-pretrained SDFormer backbone.
- Higher LR for TS-LIF dynamics parameters:
  `alpha_s`, `alpha_l`, `decay_factor`, `kk`, `yy`.

Baseline files under `third_party/SDformerFlow` were not edited.

## Decision

Do not launch full E4b training from these settings.

Reason: E4b successfully reduces firing/SOPs, but the optical-flow accuracy collapses in both short runs. This suggests the official-style optimizer groups alone are not enough for a useful TS-LIF transplant into the PSN-pretrained SDFormerFlow baseline.

The next worthwhile direction is not a longer full run with these settings. It should instead change the TS-LIF integration itself, especially the scalar `alpha_s/alpha_l` approximation and the blanket replacement strategy.
