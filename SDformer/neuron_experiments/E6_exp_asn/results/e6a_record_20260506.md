## Source

Paper:

No official GitHub repository was found during the initial search. This E6a implementation follows the paper-level NASN equations rather than copying upstream code.

## Mechanism

E6a implements the normalized ASN training-time equations:

```text
U[t] = H[t-1] + X[t]
S[t] = clip(round(U[t]), alpha, alpha + D) / N
H[t] = beta * (U[t] - S[t] * N)
```

Default E6a config:

| item | value |
| --- | --- |
| neuron type | `exp_nasn` |
| `D` | 4 |
| `N` | 4 |
| `beta` | 0.5 |
| `alpha_init` | 0.0 |
| `alpha_grad_scale` | 0.25 |
| alpha shape | scalar per spiking module |

## Initial Assessment

E6a is implemented and mechanically runnable. The first smoke profile is not a quality result, but it shows that the default NASN window `alpha=0,D=4,N=4` is not immediately sparse in SDFormerFlow. A proper short run should monitor whether `alpha` moves enough to lower firing without causing the accuracy collapse seen in ATLIF/TSN branches.

Relative to PSN baseline, E6a final has about 36.8% higher AEE, 11.5% higher AAE, and about 9.2x firing/SOPs. The final checkpoint is better than epoch30 on accuracy and slightly less dense, but both are far too dense to be useful as a sparsity-oriented neuron replacement.

Conclusion:

E6a NASN is runnable and reaches reasonable optical-flow loss after PSN initialization, but the current blanket replacement drives the spike activations into an almost dense regime. It should not be selected as a sparse replacement in this form. If NASN is revisited, the next attempt should add explicit firing regularization or partial insertion, instead of replacing every `Spiking_neuron` node.
