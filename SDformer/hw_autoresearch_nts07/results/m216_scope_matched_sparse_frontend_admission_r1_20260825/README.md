# M216 admission index

M216 is admitted as a standalone sparse-FC2 frontend milestone.  The index
binds exact Synopsys VCS, same-script frozen-H67 K1/K8 replay, matched
logic-only DC subruns and the independent 91/100, P0-free hammer review.

The allowed result is 4.764209x always-ready frontend cycle reduction, with a
4.577773x lower bound even against a zero-control-overhead K1 event-service
oracle.  At the matched pre-macro DC point K8 adds 0.737379% logic area and the
conditional matched-resource frontend throughput/logic-area ratio is
4.729336x.

The failed r1 DC parent receipt remains uncitable.  The r2 recovery is an audit
of its two completed exact-SHA subruns, not a replacement synthesis run.
Weight SRAM, response latency, accumulator/commit, native cropped-K1 area,
complete FC2/FFN, physical PPA and system speedup remain outside admission.
