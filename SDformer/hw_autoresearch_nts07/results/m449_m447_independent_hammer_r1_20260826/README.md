# M449 independent hammer evidence

This directory contains a full-population independent reconstruction of the
M447 correction-fold DSE.  The recomputation is formed from frozen M40 packed
payloads and the frozen M430 q32 catalog; upstream M430/M447 derived artifacts
are used only for post-derivation mismatch checks.

Primary review: `m449_m447_independent_hammer_review.md` and
`m449_m447_independent_hammer_review.json`.

The result is scoped to four frozen H67 bottleneck Conv3x3 operators.  It is
not a system, RTL-measured, resource-normalized, PPA, power, energy, or DATE
headline result.
