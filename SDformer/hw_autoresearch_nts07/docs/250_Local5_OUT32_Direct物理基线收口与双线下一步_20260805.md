# Local5 OUT32 Direct 物理基线收口与双线下一步

## 本轮唯一闭环对象

本轮只闭合上一轮 DATE 评审指出的最高优先级缺口：Local5 Direct 等宏物理基线。没有同时修改 Local5 架构 RTL，也没有冻结 Motion。

## 完成结果

Direct 在 `OUT_DIM=32`、32 个 SRAM 宏、5 ns Nangate45 开放物理代理下完成 detailed-route `0 DRC`。原先 63 个残余 M3 spacing 被消除；20 个 Acc 宏统一为 `MY`，所有 32 个宏零重叠。

后布线 RC/STA 显示 setup `0` 违例、最差余量 `+0.9305 ns`。但仍有：

- global-route overflow `33`；
- hold 违例 `1`，约 `-0.07 ns`；
- max-cap 违例 `245`；
- 60 个结构性宏 padding endpoint 告警；
- 默认 VSRC 下无效的 IR-drop 代理；
- 未闭合的天线与 KLayout 版图规则检查。

因此只能写成 `[open-pnr][代理] detailed-route clean`，不能写成 DC/PTPX PPA、STA signoff、版图 signoff 或 tapeout-ready。

## 两项负结果

1. 修改错误的 `fakeram45_256x16` LEF OBS 不改变 63 个 DRC，已恢复。
2. 扩展正确的 `fakeram45_128x256` LEF OBS 仍不改变 63 个 DRC，已恢复。

这两项负结果排除了“只扩 obstruction 就可收口”的解释。最终有效的是保持原 bbox 的宏朝向约束，但它同时使 global overflow 从 9 增至 33，说明局部 pin access 与全局通道之间存在权衡。

## 约束审计结论

60 个告警的精确来源为：

`5 role bank × 2 depth slice × 6 padded bit = 60`。

10-bit relation payload 被零扩展到 16-bit FakeRAM 端口，只有 `wd_in[15:10]` 被列为未约束宏端点。没有发现额外的未约束功能端点；但工具告警未消失，论文中必须保留该事实。

## 对 DATE 完成度的影响

本轮提高的是实现可信度，不提高架构新颖性。它回答了“Direct 是否能在真实宏边界下完成详细布线”，但没有回答：

1. Local5 attention-to-projection 是否端到端 RTL-exact；
2. 多样本真实 trace 下吞吐、p95/p99 stall 和能耗是否成立；
3. Motion T450 的 HIFP/新机制是否仍有收益；
4. 目标工艺 DC/PTPX 与真实 SRAM 宏 PPA 是否闭合。

## 双线策略

Local5 仍是当前主线，下一轮进入 `theta/定点/invalid-candidate mask/接口` 合同审计，然后按顺序闭合 12-block 调度、`score/Shiftmax5 → relation transpose → source-major term → TCFM5 → Acc32`。

Motion 继续实质推进：维护 SCS/NMF/DCTF/HIFP 回归，等待/检查 T450 full-resolution profile，并对 TTB/STT、自适应 issue、exact temporal quotient、跨窗口 gate-class persistence、Prosperity 风格 exact reuse 做真实 trace 上界筛选。每次只选择一个有足够收益的机制进入 RTL。

## 下一轮唯一最高优先级

审计并冻结 Local5 的数值和接口合同。Motion 在同一轮只做 profile/模型/回归旁路工作，不扩第二套顶层 RTL；若 T450 profile 已完成，则输出 Motion 新机制的排序和淘汰理由。

## 独立 DATE 评审

评分：`3/5`。

推荐：`Reject（大修后重审）`。

评审认为本轮相对上一轮有实质实现改善：Direct 已从“残留 63 个详细布线 DRC”提升为“开放代理 detailed-route 0 DRC”，但没有提高架构新颖性，也没有达到物理签核。

可进入主文的限定声明：

1. OUT32 双类 SRAM 宏绑定和三模式 RTL/macro 等价；
2. Direct 在固定 Nangate45/FakeRAM45 代理下实现 32 宏零重叠和 detailed-route clean；
3. 宏 pin access 与全局拥塞的 trade-off；
4. Issue/DS 的等宏综合负结果和候选裁决。

只能进入附录或限制章节的内容：setup 余量、线长/via、60 个 padding endpoint 清单、OBS 负结果和宏朝向调试过程。

禁止使用的声明：ASIC PPA、STA signoff、tapeout-ready、DS 功耗/EDP 优势、三候选公平物理 PPA、默认 VSRC 的 IR 结果。

评审建议下一轮转向 Local5 端到端 RTL-exact 合同与集成，不再无边界优化开放 P&R。Motion 可以继续 T450/full-resolution profile、回归和候选机制上界分析，但每轮最多晋级一个新 RTL 机制。
