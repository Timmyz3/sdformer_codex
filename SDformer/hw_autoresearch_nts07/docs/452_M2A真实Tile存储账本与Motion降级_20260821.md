# M2A 真实 Tile 存储账本与 Motion 降级（2026-08-21）

## 决策

M2A 用 A800 从冻结 checkpoint 直接抽取 chunk-complete 真实 bitmap，并生成确定性地址与
压缩 timestamp 事务。打铁评审给出 `54/100 CONDITIONAL`，并发现 v1 对 Motion 重复收取
Acc32 状态写回。该结论已撤回并用公平的共享/复制双模型重算。修正结果仍不支持 Motion
默认常开，同时支持把 Local 主创新改为 banked multi-source issue：

- Motion 默认 state hardware 暂缓，只保留候选层及共享状态的可选消融；
- Local 继续推进 2/4/8 source/cycle frontier extractor、weight gather 与 Acc32 adder tree；
- 下一阶段 RTL 不再扩大 1-source/cycle 的 output lanes，而是压低 source/command 地板。

## 真实 tile 身份

| 身份 | checkpoint SHA256 | operators | records | row/chunk identities | Motion records |
|---|---|---:|---:|---:|---:|
| H67 ep35 | `4f33e086...6158` | 31 | 45,600 | 4,560 | 4,742 |
| Local ep44 | `19820bec...4f57` | 36 | 51,600 | 5,160 | 5,418 |

每个采样 row 包含全部 256-bit input chunks，并对同一 row/chunk 连续导出 t0--t9。NPZ
保存 current/previous packed bits，CSV 保存完整 row selector count、tile 正负 transition、
valid bits、source base、fanout 和确定性 state identity。manifest 同时绑定 config、checkpoint、
profiler、writer 及 CSV/NPZ SHA。

这批证据已超过每线 10,000 个真实 tile 的 M1 gate，但只含 bitmap，不含 checkpoint INT8
weight/Acc32 oracle；因此其正确性级别是 descriptor/schedule，不冒充 full-chain miter。

## sampled address/timed ledger v2

96 output lanes、5 cycle/command、32 B/cycle bitmap、64 B/cycle Acc32、每 source 读取一个
96-byte weight segment。v2 同时报告：

- `shared-output-state`：前一 timestep 的 activation/output buffer 延长生命周期，作为
  previous bitmap/Acc32；不重复写一份状态；
- `explicit-copy-state`：previous bitmap/Acc32 写入独立状态区；最后 timestep 不再写无消费者
  状态；
- Local-only 不再分配任何 Motion state object。

Local+Motion 相对 Local-only 的 cycle change：

|---:|---:|---:|---:|---:|---:|---:|
| 1 | 6,439,747 | -3.5596% | +3.0537% | 10,789,938 | -2.9721% | +2.4730% |
| 2 | 4,111,394 | -1.7420% | +8.6166% | 6,643,077 | -1.5676% | +7.2764% |
| 4 | 2,947,686 | +0.2470% | +14.6950% | 4,571,878 | +0.1064% | +12.9571% |
| 8 | 2,369,227 | +1.9584% | +19.9339% | 3,539,630 | +1.6499% | +18.2483% |

公平结论不是“Motion 总会变慢”，而是它高度依赖状态生命周期：共享已有 buffer 时 p1/p2
有约 `1.6%--3.6%` sampled-cycle 收益，p4/p8 接近持平或小幅变慢；显式复制则从 p1 起就有
额外代价。两者都未达到“候选层 ≥10% cycle 或 ≥5% energy、全系统 ≥1%”的生存门槛，
所以不进入默认 datapath，但保留 layer-selective ablation。

v2 p1 ledger 输出约 98 MB `compressed_memory_transactions.csv`，包含 Local-only、共享状态
和显式复制三种 variant。每条记录给出
variant、cycle start/end、R/W、base address、bytes、object id、operator/row/timestep 与
bitmap-indexed weight address pattern；summary-only DSE 不重复保存大 CSV。

最坏 sampled row 的 retained prior bitmap+Acc32 为 H67 6,192 B、Local 12,384 B；共享模型
的额外复制容量为 0，显式复制模型的额外 state 容量分别为同样的 6,192/12,384 B。这里只是
单 row 生命周期上界，不冒充 timestep-major 全层峰值 SRAM。

## Local multi-source 收益

相对 1-source/cycle Local-only sampled schedule：

| sources/cycle | H67 speedup | Local speedup |
|---:|---:|---:|
| 2 | 1.5663x | 1.6242x |
| 4 | 2.1847x | 2.3601x |
| 8 | 2.7181x | 3.0483x |

这组 `2x--3x` 是真实 sampled tile schedule 的 Local-engine 候选收益，不是全系统 speedup。
它假设 weight SRAM 带宽随 source issue 扩为 `sources_per_cycle × 96 B/cycle`，因此 M2B 必须
以 bank 数、端口、adder tree、面积、时序和 PTPX 证明这个带宽可实现。

## correctness 与调度边界

完整 row 决策与 256-bit tile 执行不能混为一谈。全层精确调度必须：

1. row-level 统一选择 Local 或 Motion；
2. 按 input chunk 累加同一 row/output segment 的 partial Acc32；
3. Motion 若保留，previous bitmap/state 必须由按 row/chunk 寻址的 state table 提供；
4. 当前 one-slot stateful top 只作为单 tile miter，不代表全层 state capacity。

v2 validator 进一步 fail-close 检查 schema、checkpoint load audit、checkpoint/config identity、
source/chunk geometry、valid extent、tile→row count conservation、selector 公式、t0 previous=0
及 t1--t9 previous/current chain。针对缺 chunk、row conservation 和 checkpoint audit 的负向
测试已通过；memory/vector focused regression 为 `6 passed`。

## M2A 打铁评审闭环

独立 subagent 评分为 correctness 66、innovation 62、performance 55、DATE completeness 34，
总分 `54/100`。其 P0“output/state Acc32 双写”与 Local-only state allocation 已关闭。仍保留
的限制是：当前 operator 顺序是 sampled synthetic ordering，地址 pattern 尚未展开到逐 bank
尾段，phase 未建 serial/overlap/conflict 三界，peak capacity 也尚不是全层 live-set。因此这些
项进入 M2B/M2C gate，不用 v2 结果冒充 full-network memory simulation。

## 声明边界

可声称：真实 checkpoint bitmap、chunk-complete sampled schedule、公平的共享/复制状态地址
时间事务、同一 sampled population 上的 Local-only/Local+Motion 交通比较，以及 2/4/8
source/cycle DSE。

不可声称：full-network latency、DRAMsim3/CACTI 数字、macro PPA、2x/3x 系统加速、真实 weight
Acc32 bit-exact 或 Motion 已有能耗收益。
