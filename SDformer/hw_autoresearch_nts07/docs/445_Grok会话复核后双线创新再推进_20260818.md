## 2. Local5：最后一个 exact 所有权轴被数据否决

候选是在同一空间坐标的两个时间平面间合并完整 source payload：

`{K[31:0], valid[4:0], gate[0:4]}`。

只有两边都有 term 且 payload 完全相等时，才可能计算一次 `gate×W` 并向两个独立 plane accumulator 发射。独立脚本：

- `scripts/profile_local5_cross_plane_descriptor_merge.py`
- `tests/test_profile_local5_cross_plane_descriptor_merge.py`
- `results/local5_cross_plane_descriptor_merge_20260818/report.json`

在 ep44 post-G0 4800 group 上：

| 指标 | 数值 |
|---|---:|
| plane pair | 1,080,000 |
| 双 active pair | 135,666 |
| 双 active 且 payload 相等 | 590 |
| active-pair equality | 0.434892% |
| baseline source term | 2,683,574 |
| 理论可省 term | 1,154 |
| term 降幅上界 | **0.043002%** |
| term-only 加速上界 | **1.000430×** |
| 相等命中中双空比例 | 99.920577% |

双空命中已经被 Query-Silent 消除，不能重复计收益。若串行平面需要保留一整个 payload plane，裸缓冲下界为 18,450 bit，是现有 3,465-bit FCSR ring 的 5.325×。预注册门是 term 至少下降 10%，实测低约 233×，因此不写 RTL。

Local5 冻结算子的 exact 所有权轴现已覆盖：

1. Q/score：Query-Silent；
2. relation 生命周期：compiled inverse-stencil/FCSR；
3. source 内相等 gate：source-owned unique-gate；
4. destination 冲突：TCFM5；
5. 跨 source/product：W4/DQFS/Memo/Prosperity 等已负或冻结；
6. 累加换序：coefficient fusion/late-gate 同端口负收益；
7. 跨时间平面：本轮 0.043% NO-GO。

因此 Local5 若要继续提升创新，必须先有新的算法算子合同；继续拆 ep44 数据流只会改名。

## 3. H82：比 H86 更干净的 conditional support object

H82 的一类一票归一化满足：

`Z = Σ_{c in occupied} exp2(c-row_max)`，禁止乘 multiplicity。

这允许把 C7 的 count histogram 替换成 513-bit occupied-class bitmap。再接 temporal quotient descriptor：

`(class_id[8:0], k_mask[1:0], pair_last)`。

执行为：

`CLASSIFY occupancy+quotient → REDUCE row_max/denom → EXPAND descriptor→K`。

两种实现点：

1. compact gate file：每 occupied class 写一次 gate，descriptor 读取 gate；
2. denominator-only：只存 `{row_max, denom_shift}`，expand 按 class_id 重算 exp2，完全不存 class/token gate。

脚本和证据：

- `scripts/h82_multiplicity_free_quotient_model.py`
- `tests/test_h82_multiplicity_free_quotient_model.py`
- `results/h82_multiplicity_free_quotient_model_20260818/model.json`

敏感度点（不是 H82 rank-1 证据）：

| occupied class | equal pair | descriptor | fused pair-gather | quotient+gate | denom-only |
|---:|---:|---:|---:|---:|---:|
| 64 | 212/225 | 238 | 5,364 bit | 3,945 bit | 3,383 bit |
| 128 | 212/225 | 238 | 5,940 bit | 4,521 bit | 3,383 bit |
| 192 | 212/225 | 238 | 6,516 bit | 5,097 bit | 3,383 bit |

### 强基线修正

不能拿“物化 450-entry token-gate SRAM”当唯一基线。真正强基线是同一 H82 one-vote 数值语义下：固定 pair record、读取 K 时在线 gather compact class gate，不写 token-gate。

class-stationary CSR 也不能免费假设已排好。任意 score 到达顺序需要二遍 count/prefix/replay，或 linked-list 指针与随机写；模型已经计入至少一遍 descriptor reorder，因此当前不推荐 class-stationary 生产路径。

denominator-only quotient 避免 CSR 重排，仍按 pair 顺序恢复 destination；代价是 expand 每 descriptor 重算 exp2。它是面积/活动 Pareto 候选，不是天然周期加速。

### 准入门

rank-1 profile 必须同时满足：

- 513 档 `occupied p95 <= 192`；
- quotient descriptor/token `<= 0.60`；
- 相对 fused pair-gather 总状态下降 `>= 20%`。

通过后也只允许 sidecar RTL。生产准入还需要：

- 与 fused token-major H82 bit-exact，随机反压 0 mismatch；
- score→projection 周期改善至少 10%，或组件动态能量改善至少 15%；
- builder metadata、descriptor SRAM 和相同端口全部计入；
- 逻辑+宏面积增加不超过 10%，Fmax 损失不超过 5%。

当前状态为 `CONDITIONAL_PROFILE_GATE_SUPPORT_ONLY_NO_RTL`。它不是 H82 4.0，也不替代 H67/Local5。
