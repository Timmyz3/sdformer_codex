- Fixed：`slots == 2*pairs`
- RQTB：`slots+equal == 2*pairs`
- `Fixed.equal == RQTB.equal`

| 周期 | 112589 / 94891 = **1.1865×**（与封存逐拍相同） |
| Shared+Skip | 87034 |
| pair | 31050 = 138×225（含空行） |
| RQTB slot / equal | 34099 / 28001 |
| slot 减少 | **45.09%** |
