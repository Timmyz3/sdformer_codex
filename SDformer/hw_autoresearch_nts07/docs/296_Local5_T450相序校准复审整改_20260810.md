# Local5 T450 相序校准复审整改

## 1. 复审裁决

独立 DATE 风格复审给出 `2/5、T450 calibration DENY、formal DENY`。核心意见
成立：旧版 `busy_cycles/fill_end/execute_end` 是 TB 对 RTL 接口的观测变量，
不是 RTL 内部相位计数器；旧四段又用总周期差构造，`execute/drain` 可同步挪动
而不被发现。

本轮没有修改算法数据通路，只修 TB 探针、严格解析器、runner 和中文证据边界。
新结果位于：

```text
results/local5_erep_t450_phase_calibration_v4_reviewfix_20260810
```

状态仍固定为 `PASS_RTL_CALIBRATION_ONLY`，formal adapter 固定为 `DENY`。

## 2. 五段边界观测

TB 现在记录五个实际接口边界：

1. 第一条 relation 接受 cycle；
2. 最后一条 relation 接受 cycle；
3. `relation_seal` 撤销后采样的 execute begin cycle；
4. `projection_close_ready` 对应的 execute end cycle；
5. `projection_done` 对应的 done cycle。

解析器只由这些原始边界重新计算：

```text
prepare         = first_relation_accept - 1
relation_fill   = last_relation_accept - first_relation_accept + 1
relation_commit = execute_begin - last_relation_accept
execute         = execute_end - execute_begin
compute_drain   = done - execute_end
total           = done
```

首组观测为 `1/450/452/866/869`，对应五段
`0/450/2/414/3`。这揭示旧口径把 relation 之后的两拍 seal/commit 错写成
`prepare=2`；新口径将其单独记为 `relation_commit=2`。

总周期与旧回放相同，改变的是可审计分账，不是性能数字。证据明确写入：

```text
measurement_method = testbench_observation_of_rtl_interface_boundaries
independent_cycle_predictor = false
group_row_is_independent_cross_evidence = false
```

`GROUP` 和 phase 行来自同一 TB 与同一组 `perf_*` 信号，只能作兼容性和一致性
检查。active/term/update 另与 hash-bound vector manifest 对账；SRAM 与 stall 尚无
第二独立计数源。

## 4. 其余整改

- `memory_wait` 及全部 GROUP 计数必须非负；
- terminal PASS 后必须存在唯一 Verilator `$finish`，截断日志拒绝；
- 结果哈希新增覆盖 compile log、关闭探针后的 trace 和仿真 binary；
- 探针关闭兼容日志仍逐字一致，`compatibility.diff` 为 0 byte；
- parser/破坏性测试 `5/5`，新增“原始边界不变、只同步挪动 execute/drain
  派生字段”、负 memory wait、缺失 finish 等变异；若原始边界和派生字段一起
  自洽修改，解析器会接受，因此本包不是独立周期预测或外部防篡改设施；
- `result_sha256.txt` 全部通过。

## 5. 证据限制

1. 当前只运行 4800-group vector 集的前 4 组，且 `OUT_DIM=2`；
2. 文件仍处于 dirty/untracked 工作区，SHA 能绑定字节，但 Git commit 不能恢复；
3. 尚无 epoch capture/replay、OUT_DIM32 common drain/serializer 或 1200-window
   command ledger；
4. 本包不构成 EREP G0、候选 RTL、DC/STA/SAIF 或 ASIC PPA 证据；
5. 独立复审接受后，本包仍只记为有限范围 `[rtl校准] ACCEPT`，不晋级 formal。
