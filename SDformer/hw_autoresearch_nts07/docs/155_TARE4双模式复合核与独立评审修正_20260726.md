# TARE-4 双模式复合核与独立评审修正

## 0. 本阶段结论

Motion 与 Local5 双线已经从“共享两个叶模块”推进到**共享一个物理复合核**
的 RTL 原型：

- H67 使用 temporal anchor 和 Motion-XOR bias；
- Local5 使用固定 Q 的 topology anchor；
- 两种模式共用 32-lane alpha-XNOR、0/1..4/>4 classifier、signed delta4、
  dense exact replay、最终 RNE 与 ready/valid 控制；
- mode 可以逐事务交错，不需要分别实例化两套 core。

完整结果见：

`results/tare4_dual_mode_rtl_20260726/report.md`。

当前阶段仍不能把该核叫作完整 attention producer。H67 尚缺 T0/T1 双 score
原子提交，Local5 尚缺一次 self anchor 服务整行 2/3/4 个邻居的 context
协议和 Shiftmax5 row。

## 1. 为什么双线共享成立

两条算法线共同满足同一个 lane-local 恒等式：

```text
target_score = anchor_score
             + sum(updated lane contribution delta)
             + mode-specific bias
```

模式差异被压缩到 descriptor 合同：

| 字段 | H67 Motion | Local5 |
|---|---|---|
| anchor | Q0/K0 | Qself/Kself |
| target | Q1/K1 | Qself/Kneighbor |
| Q 是否变化 | 可变化 | 禁止变化 |
| bias | `16*popcount(K0 xor K1)` | 0 |
| dense fallback | direct Q1/K1 | direct Qself/Kneighbor |

因此共享的不是“两个相似模块的代码”，而是一个实例化一次的
`tare4_residual_composite_core`。`dual_mode_tare4_composite_top` 只增加
mode 选择与 Motion bias 生成。

## 2. 与已有工作的关系

| 工作 | 借用机制 | 本轮修改 | 不声称 |
|---|---|---|---|
| Prosperity | exact temporal residual/reuse | anchor 由 T=2 或固定 stencil 静态给出，不做在线 TCAM 关系搜索 | exact reuse 原创 |
| Phi | pattern/residual 两级执行 | 不学习 codebook，使用真实 temporal/topology anchor 和 direct fallback | pattern residual 原创 |
| Bishop | density stratification、TTB 思想 | ZERO/SPARSE/DENSE 精确分层，dense replay 复用同一核而非复制异构双核 | stratifier 原创 |
| FireFly-T | 多 lane 稀疏 decoder | 对 alpha-XNOR lane contribution 做 signed delta 重建 | decoder/overlay 原创 |
| 复旦 ISSCC 蝶形网络 | compact/重排范式 | 保留为 linear/prefix/butterfly PPA 对照，当前未采用 | 蝶形网络原创 |

可辩护的新意不是任一单独子模块，而是：

> 静态时间/拓扑锚点驱动的 exact residual execution，在同一物理核上将
> zero bypass、bounded delta 和 direct replay 统一，并把模式差异压缩为
> 可验证 descriptor。

该表述仍需同约束 PPA 才能晋级为 DATE 主贡献。

## 3. 独立审阅与修正

第一轮审阅结论为“不冻结”，新颖性 `2.0-2.5/5`。主要问题及状态：

| 严重度 | 问题 | 修正/状态 |
|---|---|---|
| P0 | Local5 TB 同时改 Q/K，不是 Local5 语义 | 已修：结构固定 Q，TB 只翻 K |
| P1 | 两个 wrapper 各自实例化 core，不是物理共享 | 已修：新增单实例 dual-mode top |
| P1 | bias 10 bit 与 raw<=2560 合同矛盾 | 已修：接受时断言 bias<=512 |
| P0 | Local5 每 edge 重算 anchor | 未修：下一步改 ANCHOR_LOAD/PROBE |
| P0 | H67 只提交 target，不是完整 T0/T1 packet | 未修：下一步改双 score packet |
| P0 | Local5 G0/G1 与 post-G0 trace 缺失 | 未修：不得冻结 Local5 主线 |
| P1 | operand SRAM latency/replay queue 缺失 | 未修：当前只证明零延迟算术核 |

因此本轮通过的是 **edge/pair target-score 复合核准入**，不是 full attention
或 DC 准入。

最终独立复审确认 mode sideband、Local5 operand isolation、Q7-RNE、
replay blocking 和 input-stall SVA 均正确，未引入新的 High/P0。当前
DATE 综合新颖性仍约 `2.5/5`，原因是行级调度/存储与目标工艺 PPA 尚未完成。

## 4. 结果摘要

全流程入口：

```bash
./sim_delta/run_delta_bounded_classifier_checks.sh
```

结果：

- H67 小样本真实 trace 3,645 条，raw/Q7 零失配；
- Local5 固定 Q 合成向量 12,000 条，覆盖 count=0..32，raw/Q7 零失配；
- 双模式逐项交错 6,000 条，Motion/Local5 各 3,000，零失配；
- 上述三个顶层均通过无反压和固定随机反压；
- Verilator `--assert -Wall` 零 warning/error；
- Erie 对 7 个相关 RTL 文件均为 0 error/0 warning；
- Yosys 三个顶层均 `check: 0 problems`。

开放映射 hierarchy generic cells：

- Local5：980；
- H67：1075；
- dual-mode：1108。

dual-mode 相对 H67 多 33 cells，约 3.07%，增量包含 mode sideband 与
Local5 模式的 Motion popcount operand isolation。该结果仅作统一化税的
开放代理，不作工艺 PPA。

## 5. 对主线选择的影响

### Motion

当前仍是硬件证据主线：

- 有 profile100；
- 有 hardware-order Q/K 小样本实迹；
- W4/T4 的 ordered replay 和复合顶层都已实现；
- 真实 trace 周期满足 `N + dense_fallback + 2`。

### Local5

已从“只有公式/DSE”推进到固定 Q edge-level RTL，但仍是候选线：

- pre-G0 的 exact-K 和低 XOR density 支持继续做 row-context RCSD；
- 合成 TB 证明算术恒等和 mode 共享，不证明真实 throughput；
- 在 G0/G1、post-G0 trace、ANCHOR_LOAD/PROBE 之前不能替换 Motion 主线。

因此继续双线的正确形式是：

```text
Motion：真实证据与主架构闭环
Local5：共享核 + row-context 增量开发
```

不是立即复制两套完整硬件。

## 6. 下一步接口

Local5 下一版必须从 edge 接口升级为：

```text
ANCHOR_LOAD(ctx, Qself, Kself)
PROBE(ctx, direction, Kneighbor, valid, last)
RETIRE(ctx, degree, row_score_packet)
```

最少需要：

- 1 至 2 个 anchor context；
- `ctx_valid/qself/kself/anchor_raw` 驻留；
- direction uniqueness 与 corner/edge/interior degree 合同；
- context 覆盖保护；
- dense replay 与下一 probe 的仲裁；
- row-end 原子提交。

H67 下一版接口应输出：

```text
PAIR_SCORE(tag, raw_t0, raw_t1, motion_count)
```

并由共享单 RNE/Shiftmax 后端按 descriptor 顺序消费，避免为双 score 盲目复制
RNE。
