## Motion

可逆时间 score-class 合并把一对时刻的 Q7 分数合成带 multiplicity 的 slot，并在 gated-K 边界按 active mask 展开。公平对照是同一 LFSR、同一接口的 Fixed2S。

ep35 sample0/window0、138 个真实 T450 head-row：Fixed2S 112589 → RQTB2S 94891，**1.1865×**，gated-K 与 synthetic Acc32 零失配 `[rtl]`。这是主结果。同一 LFSR 公平包在 ep30 held-out 上是 111807 → 94348 = **1.1850×**，单独一列，禁止平均。

与 1.1865× 同一 LFSR 公平包上，TESC 账本现已是硬件计数：138×225=31050 pair，RQTB slot 34099 / Fixed 62100 = **−45.09%**，equal 28001 且 Fixed.equal==RQTB.equal `[rtl]`。occupancy-gated 密行另一列是 23625 pair、slot −43.61%；不要两列合成。

密行里 37.7% temporal pair 双侧 K=0。directory 用 temporal_mask 写 class multiplicity 并更新 row_max，与 active_mask 无关，因此行内 pair skip **不是** bit-exact。

## Local5

固定五邻域 inverse-stencil 把 destination-major 的分数变成 source-major 投影。Query-Silent 是相对**密封 QFSA residual leaf** 的 early-out：Q==0 时 AXNOR 即 `32-popcount(K)`，有效邻域 K 全同时一次 `raw16(Q,K)` 广播。这是一条数据流，对照不是组合稠密 AXNOR，ident-K / Q==0 也不是并列「首次」。

所有周期数字默认 **`OUT_DIM=2` score+projection tile**，不是 encoder，也不是 OUT32。

100-group 真实切片：Q==0-only 封存快照 TCFM5 L1 **1.6957×**。现行 RTL 以 `IDENTK=0, overlap=0` 精确复现该列。同一向量、关闭 overlap 的级联 RTL：184632 / 324605 = **1.7581×**。Python Q==0=40257、ident-K=3396 与 RTL 一致。1.7581× **不覆盖** 1.6957×。

sample0 十二块各一张完整 window，合计 482520 → 272624 = **1.770×**。这是 12 次独立 window 的 `projection_busy` 之和。S2.B5 = 1.561×（Q==0 99.6%、ident-K 0）；S2.B1 = 2.127×。不要用 S0.B0 的 2.00× 或四行 B0 当 stage 代表。

十二块 leftover 2014；4/5 K 相同 18%；分数全同 63.5%。仍否决第三条路径。成对最小 Hamming 的 `"0"` 不是 ident-K 漏网。

十二块实测已经证伪用 B0 均值克隆同 stage 全部 block 的旧外推，论文不再引用该模型。

## 不能写

端到端 / full encoder / OUT32 加速；Yosys 或 OpenROAD 当芯片 PPA；把 skip、ident-K、共享后端拆成并列首次；用 S0 全空 Q 的 2.00× 代表 S3；继续引用已证伪的 B0 均值外推。
