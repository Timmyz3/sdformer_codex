## 是不是旧对象换名

**是现有 source-owned unique-gate 包的 2 路展开。**  
现行 builder 已经按相等 gate 合并成 `{gate,mask}`，并串行每拍一个。
TCFM5 着色已经保证五邻域无冲突。候选只是每拍发两个已有包，共享 source/lane/weight。

DATE 审稿人会写成 generic 2-wide unroll。冲突免费不是新引理，是 TCFM5 旧合同。

## 回答

1. 精确等式/下界：term-phase 下界成立；不含 score/relation/握手/额外 2-wide 控制。
2. generic 2-wide：在**同一** TCFM5 + unique-gate 流上，它就是这个候选，没有多出来的机制。比「两 dest + replay」好，是因为旧的 merge+着色，不是新发射器。
3. 加训练：只有 exact-equality QAT 真的改了 valid825 的 C 分布且不掉点，才可能谈 3.3–3.5；单靠 32.8% profile 不能到 3.5。禁止写成 Bishop 式 pruning。
4. 最小门槛：同 2-mul、同 1RW Acc；对照串行 TCFM5 **和** 2-wide+replay；报面积/关键路径；term 减少不得当周期。未过门前 **NO-GO 创新**，359 不动。
