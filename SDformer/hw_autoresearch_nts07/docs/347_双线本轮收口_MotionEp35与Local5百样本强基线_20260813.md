# 双线本轮收口：Motion ep35 与 Local5 百样本强基线

> 日期：2026-08-13  
> 范围：Motion/H67 与 Local5 两条独立 DATE 候选线  
> 原则：不以 Motion 替代 Local5；每个结论绑定证据等级和作用域。

## 1. 本轮结论

两条线本轮分别关闭了一个关键缺口：

1. Motion 将公平 RQTB 主锚点绑定到最终 rank-1 ep35 checkpoint，并用强 class-cache
   基线撤回了不成立的 `exp -22%` 独立创新归因。
2. Local5 首次得到跨 100 sample、真实 checkpoint INT8 权重、同步关系 SRAM 合同下的
   TCFM5/Linear5 公平 RTL 周期主表。

这不代表只剩 DC：两线都仍缺目标工艺 PPA、系统级连续调度和完整端到端能量；Motion
还缺真实多样本 RTL 与 RQTB-to-real-projection 联合路径，Local5 还缺 score/Shiftmax5
前端并入部署周期和 Gate D phase ledger。

## 2. Motion 收口

### 2.1 当前唯一主贡献

Motion 的核心贡献保持为一条：

> 相对于冻结 hardware-order 定点部署语义 bit-exact 的可逆时间 score-class 合并。

TESC 与 RQTB 不拆分；SCS、Shiftmax、FIFO、双 bank K、ZKQI 和 TTB8 均作为实现组件
或消融，不单列架构首创。

### 2.2 最终 checkpoint 公平锚点 `[rtl]`

证据包：

```text
results/h67_rqtb_strong_baseline_2s_ep35_t450_v2_final_20260813
```

作用域为 ep35、sample0/window0、12 block、138 个真实 `N_tok=450` head-row：

| 指标 | Fixed2S | RQTB2S | 结果 |
|---|---:|---:|---:|
| cycle | 112,589 | 94,891 | 1.1865x，-15.72% |
| slot | 基线 | -45.09% | descriptor 流量下降 |
| gated-K | - | 21,073 | 0 mismatch |
| synthetic Acc32 | - | 4,416 | 0 mismatch |

138/138 行均加速。该数字不是 full encoder 或多样本部署加速。

### 2.3 class-cache 强基线与负归因 `[rtl派生模型]`

证据包：

```text
results/h67_class_gate_cache_strong_baseline_v3_final_ep35_20260813
```

Fixed2S 与 RQTB2S 的唯一 class transaction 均为 1,317。163-entry direct-index cache
可以令两边 exp LUT/gate quant 求值都退化为 1,317 次，因此：

- `exp/gate -22.22%` 不再作为独立创新；
- 不能在无 SAIF 时把该活动代理写成节能；
- RQTB 的 1.1865x RTL 周期仍成立，其来源是 slot、descriptor、FIFO/issue 压力下降。

### 2.4 新候选裁决

**class-wise K count folding：否决。**

证据包：

```text
results/h67_classwise_k_folding_go_nogo_v2_final_20260813
```

当前输出保留逐 token destination。把同 class 的 K 压为一个 lane count 后写一个
accumulator 会删除 token 轴。更严格地，两个输入具有同一 count `[1,1]`，却分别产生
`[8,12]` 与 `[12,8]` 的 token 输出，因此 count representation 信息不可逆。保留
destination bitmap 的 algebraic form 与既有 FCIP representation 相同，不重复包装；
这不表示 FCIP 已有端到端 RTL/PPA 证明。

**base-delta score：不重复实现。** 既有 TARE-W16 已覆盖该思路：138 行周期约退化
0.2%，开放映射面积代理增加约 51.8%，面积归一吞吐约 0.657。它是负结果，不是 PPA。

## 3. Local5 收口

### 3.1 数值覆盖 `[rtl]`

累计只读审计：

```text
results/local5_numeric_coverage_audit_sample0_99_v4_final_20260813
```

- 100/100 sample；
- 1,200 个 canonical block-window；
- 198,720,000 个 Acc32；
- mismatch=0；
- 边界为 pre-bias/pre-BN/pre-requant/pre-residual；
- Gate D phase ledger 未完成，内部 formal G0 仍为 DENY。

### 3.2 百样本公平强基线 `[rtl]+[profile-qualified-trace]`

最终封存包：

```text
results/local5_joint_ep29_tcfm5_linear5_realw_sample100_population_rtl_v5_final_20260813
```

选择合同：100 个 sample 各一组 qualified T450 group；选择不依赖运行结果；stage
配额 `4/9/52/35` 按来源总体 `600/1200/7200/4800` 通过最大余数法确定。

公平合同：

- 相同一个 K bank + 五个 gate/valid relation bank；
- 相同同步 1R1W 目标端口合同；
- 相同 frontier、term builder、真实 checkpoint INT8 权重；
- 相同五个单写 Acc bank 和 readback；
- 对照仅改变 destination bank mapping/replay 策略；两后端为独立 RTL 实现。

| 配置 | TCFM5 cycle | Linear5 cycle | 加速 |
|---|---:|---:|---:|
| SRAM L1 | 132,388 | 198,108 | 1.496x |
| SRAM L2 | 135,936 | 199,327 | 1.466x |

逐 group 的 L1 `p50/p95/p99` 加速为 `1.252x/1.760x/1.831x`。L1 stage 结果为：

| Stage | group | 加速 |
|---:|---:|---:|
| S0 | 4 | 1.051x |
| S1 | 9 | 1.003x |
| S2 | 52 | 1.445x |
| S3 | 35 | 1.587x |

这说明当前收益主要来自 S2/S3；S0/S1 不能宣传显著收益。四配置分别归档 90,000 个
actual Acc32，合计 360,000 次比较零失配；TCFM5/Linear5 × L1/L2 四配置均通过随机
输入/读 gap 的 Verilator+SVA 压力回归。最终 `complete.json` 封存 49 个报告、日志、
RTL/TB/SVA/source 文件，报告器会对 live source receipt fail-closed 校验。

边界：每 sample 仅一组，不是全 13,800 group RTL；slice 从 post-score relation 到 Acc，
不含 score/Shiftmax5、bias/final、full encoder 和 foundry SRAM/PPA。

### 3.3 full-profile exact-port 模型 `[prof]+[模型]`

```text
results/local5_joint_ep29_tcfm5_full_profile_exact_port_model_v2_final_20260813
```

13,800 group、6,210,000 descriptor 上：active source rate 为 26.32%；同五 bank 的
active Linear5/TCFM5 exact-port 模型为 1.932x。它用于说明 100-group RTL 方向与完整

payload、checkpoint、config 和 selection-plan SHA，以及 Python/NumPy/平台 receipt。

### 3.4 模型到 RTL 分账 `[rtl]+[exact-port-model]`

```text
results/local5_tcfm5_model_to_rtl_calibration_v1_final_20260813
```

同一 100-group cohort 上，active exact-port 模型为 1.963x，实际 RTL L1/L2 为
1.496x/1.466x，即保留理想加速的 76.21%/74.68%。RTL 相对模型的固定开销为：
Linear5 L1/L2 49,612/50,831 cycle，TCFM5 56,757/60,305 cycle。当前只把差额归为
relation build、同步读、clear、frontier 与控制开销，尚未进一步拆到每项。

### 3.5 完整输出 tile 高负载回放 `[rtl]`

```text

```

四个 stage 各选 full-profile 中 product-term 最大的 group，回放一个完整 32-channel
output tile。四配置各比较 57,600 个 Acc32，合计 230,400 次比较零失配。该包只用于
关闭 `OUT_DIM=2` 的参数化风险，不作为无偏性能样本或跨 head 最终输出。

### 3.6 新候选负结果 `[prof]+[模型]`

静态 source projection hoisting 不晋级：相对 DQFS 多 19.8% weight-row，同时增加
13-bit vector add 与 13x9 wide product。动态 hybrid 仅在同约束 PPA 显示正收益时再做。

## 4. 当前可以写入 DATE 的硬件贡献

### Motion

1. 可逆归一化域 temporal score-class coalescing：multiplicity 保持分母，mask 恢复 K。
2. 双 slot、公平 backpressure-safe 微架构是上述贡献的实现，不单独宣称创新。
3. 当前性能锚点为单窗 1.1865x `[rtl]`；多样本约 1.17x 仍是 RTL 校准模型。

### Local5

1. 固定五 offset 的 inverse-stencil source-major 生成，避免通用关系 materialization。
2. 受限端口合同下的 affine five-color destination mapping，以五个单写 bank 消除
   Linear5 的 exact conflict replay。
3. active-source quotient 与 TCFM5 组成同一 post-score 投影数据流；当前百样本 RTL
   证据为 1.496x/1.466x。

普通 banking、FIFO、ping-pong、定点化、验证框架和 Relation Memo 均不单列贡献。

## 5. 下一轮优先级

### Motion P0

1. 冻结并写全 H67 score、Shiftmax、gated-K、round/saturation 的精确算子合同。
2. 把 RQTB 接到真实 checkpoint INT8 projection，形成同一 trace 的联合 Acc32 miter。
3. 将真实 RTL 扩到多 sample，报告 mean/p50/p95/p99/worst。
4. 在 DC 服务器上用同 SDC/SRAM 规则做 Fixed2S/RQTB2S 的 STA/SAIF/PTPX。

### Local5 P0

1. 将 score/Shiftmax5、relation build 纳入现有 TCFM5/Linear5 部署周期边界。
2. 建立 12-block 连续 job/tag 调度和 full encoder Amdahl 分账。
3. 扩大真实 RTL cohort；13,800 group exact-port 模型继续只作外推层。
4. 在 DC 服务器上以相同 SRAM macro 规则综合 TCFM5/Linear5，报告面积、频率、功耗、
   energy/group 与面积归一吞吐。
5. Gate D phase ledger/admission 继续推进，但不以验证工作替代性能和创新。

## 6. 投稿成熟度

本轮使 Local5 从“只有数值正确性、缺公平性能主表”晋级为“有跨样本组件级 RTL 强基线”；
Motion 则关闭了最终 checkpoint 身份和弱 exp 归因。两线仍都不是可直接投稿的完整 DATE
硬件论文，主要共同缺口是目标工艺 PPA、系统边界和可外推的真实 RTL 分布。

## 7. 独立 DATE 审稿

Local5 主证据包本轮复审为 **4.2/5，Weak Accept / Conditional GO**；若把 post-score
slice 单独当完整 DATE 论文则约 **3.4/5，Borderline**。审稿确认 P0 的抽样独立性、
公平基线、Acc32 一致性和封存链均关闭。其 P1 中的模型封存、四配置随机 gap、完整
32 输出通道和模型到 RTL 分账已在本轮继续关闭；剩余主要门槛仍是同约束 PPA、完整
score/Shiftmax5 边界、连续 12-block 系统占比和更大真实 RTL cohort。

Motion 的 class-wise K count folding 候选复审为 **候选 1/5 REJECT、筛选包 4/5 GO
作为负结果**。审稿确认逐 token destination 使 count folding 不 exact，bitmap-preserving
形式与既有 FCIP representation 相同，base-delta 属既有 TARE。审稿后已补两个不可区分
输入的信息不可逆证明、TARE 适用边界、producer/dependency 快照和 sealed complete；该包
不增加 Motion 正向贡献，也不降低 TESC/RQTB 主线评价。
