# 双线 Synopsys 交接 P0 复审闭合（2026-08-14）

## 1. 裁决

本轮不增加 Motion 或 Local5 架构机制，也不修改 `docs/359` 封存主表。工作对象是独立评审指出的 DC/Formality/PT/SAIF 交接缺口。

- Motion 冻结列仍为 `112589 -> 94891 = 1.1865x [rtl]`，slot `62100 -> 34099`。
- Local5 封存 Q==0-only 列仍为 `324605 -> 191424 = 1.6957x [rtl]`。
- Local5 十二窗仍为 `482520 -> 272624 = 1.770x [rtl]`，严格限定为 `OUT_DIM=2 tile`，不是 encoder。

## 2. 已关闭的 P0

### 2.1 网表与 SPEF 身份

`run_ptsta.sh` 和 `run_ptpx.sh` 现在只要读取 `SPEF_FILE`，就强制要求显式 `NETLIST_FILE`。该网表必须来自产生该 SPEF 的同一次 P&R，禁止继续使用默认 DC 网表与后布局 SPEF 混搭。

每次 DC/Formality/PT 运行归档输入文件 SHA、git commit、库、角点、网表、SDC、SPEF、SAIF 和 trace manifest 身份。

### 2.2 PVT 与多角边界

PT STA 强制要求 `OPERATING_CONDITION` 和 `CORNER_ROLE`；PTPX 强制要求功耗角。setup、hold 和 power 必须使用对应库/角分别运行。单一 `.db` 同时报 max/min 只算单角检查，不写成 MMMC。

### 2.3 SAIF 身份与注释覆盖率

新增 fail-closed SAIF manifest，绑定：

- 冻结设计名；
- SAIF SHA 与原始 trace SHA；
- 仿真器与 `strip_path`；
- warmup、测量周期和 trace 范围。

PTPX 工件审计默认要求可解析的 SAIF annotation coverage 不低于 `95%`。报告中没有可识别覆盖率也会失败，不允许默认为通过。DC 若读取 SAIF 同样要求 manifest，但论文功耗仍以 PTPX 覆盖率门槛为准。

### 2.4 宏库与 PPA 准入

DC/PT/Formality 支持通过 `MACRO_DBS` 链接冒号分隔的 SRAM/RF `.db`。`PPA_ADMISSION=1` 时强制要求：

- `OPERATING_CONDITION`；
- `MACRO_DBS`；
- `EXPECTED_MACRO_REFS`，并在 `report_reference` 中逐项核验。

当前三个冻结顶层仍使用推断数组，尚无目标工艺 SRAM wrapper。因此目前即使逻辑 DC 完成，也只能称为 pre-macro logic PPA；目标宏映射前禁止称最终 ASIC PPA。

### 2.5 Local5 PPA 对象与 lint

Local5 PPA 顶层继续冻结为手写 cross-r1 FCSR：

```text
RELATION_SCHED_MODE=0
BACKEND_KIND=0
ACC_BACKEND_KIND=0
ACC_MEMORY_IMPL=0
OUT_DIM=2
```

拓扑编译生成器只作为 208 退休合同的验证证据，不属于当前 PPA 对象。TCFM5 未启用的 vector-read 输入已显式绑零，输出显式 open，不再依赖缺失端口连接。

## 4. 验证分和完整度仍差在哪里

不是只差 DC/STA/SAIF/PTPX。

Motion 仍缺：

1. 多样本真实 Fixed2S/RQTB2S RTL，而不是 100-sample 校准模型；
2. 冻结 wrapper 专用真实 trace SAIF testbench 与层次映射；
3. 超过当前两输出通道真实权重投影的更完整输出路径；
4. 目标 SRAM/RF wrapper、DC/Formality、setup/hold PT、PTPX；
5. 12-block/full-encoder 周期与能量 Amdahl，不把 row slice 冒充 encoder。

Local5 仍缺：

1. OUT_DIM=2 population 之外的高 OUT_DIM 多样本周期/能量证据；
2. 真实多 window、多 sample 的 score-to-Acc32 回放；
3. 12-block 调度与完整数据通路联合，而不只是 scheduler 控制统计；
4. wrapper 专用 SAIF、目标宏、DC/Formality/PT；
5. 将生产手写 FCSR PPA 与拓扑编译合同的角色在论文中继续分开。

## 5. DATE 独立复评

本轮 P0 改动提高的是实验可复现性和工程完整度，不提高架构创新分。当前保守评分：

| 维度 | Motion | Local5 | 说明 |
|---|---:|---:|---|
| 架构创新 | 3.5 | 3.7 | 仍取决于 TESC/RQTB 与 QS+拓扑转置+TCFM5 本身 |
| 工作量 | 4.5 | 4.9 | 双线 RTL、验证和交接较完整 |
| 验证 | 4.0 | 4.5 | Local5 真实向量/SVA 更宽；Motion 多样本真实 RTL 仍缺 |
| 实验完整度 | 2.8 | 3.1 | 缺目标工艺、宏、SAIF/PTPX及系统端到端 |
| 工程 | 4.3 | 4.4 | fail-closed 交接提升，但不等于签核 |

因此当前仍不能称 DATE Best Paper 水平。下一阶段的最高价值动作是在有 Synopsys 和目标库的服务器上完成同对象 DC/Formality/PT/PTPX，同时本机继续补双线多样本与系统 Amdahl；不再用新的小机制掩盖实验完整度缺口。
