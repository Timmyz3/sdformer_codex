## 2. 覆盖

真实 ep35 full-resolution inference 对十个预注册 valid 样本各采集一个 all12
窗口：

| 项 | 数量 |
|---|---:|
| sample | 10 |
| block / sample | 12 |
| head-row / sample | 138 |
| 总 head-row | 1,380 |
| token / row | 450 |
| gated-K 输出检查 | 190,434 |

Icarus 与 Verilator+SVA 使用同一 Q/K/gate 向量、同一固定反压合同和同一冻结实现
快照，逐行账本完全一致，Acc32 checksum mismatch 为 0。

样本选择为同一 DSEC scene `zurich_city_09_a` 中按 stride 10 取得的
`0001/0011/.../0091`，每个样本只取首个 all12 窗口。它是预注册序列，不是按事件
密度或 score 等价率分层抽样，不能外推为整个 DSEC 分布。

- min `1.169380x`；

## 4. 恢复与身份

GPU 阶段已完成十样本 profile、120 份 NPZ trace 和 1,380 行向量。首次 RTL
编译失败不是数值失败，而是 live top 加入 generate 后，旧 TB 的层次账本路径

## 5. 仍缺

1. 多样本真实 checkpoint INT8 全输出 projection；当前多样本 Acc32 是 synthetic
   lane-weight checksum；
2. bias/BN/requant/residual 与完整 attention block 输出；
3. 更多空间窗口或按事件密度、等价率分层的真实 RTL，而不是每样本一个窗口；
4. full-encoder operator/IO shell 与实测 Amdahl；
5. 同库、同 SDC、同宏、同公平活动的 DC/STA/SAIF/PTPX。

因此这轮提高的是验证覆盖和实验完整度，不改变 Motion 的单条 DATE 架构贡献：
`MSSB5 score-front CSE -> Q7 pair-local reversible descriptor -> weighted Shiftmax -> ordered K recovery`。
