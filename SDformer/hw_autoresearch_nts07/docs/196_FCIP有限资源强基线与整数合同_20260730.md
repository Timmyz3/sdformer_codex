## 2. 整数合同

覆盖：

- `T=162`、`T=450`；
- 32 lane；
- K-zero class count；
- 多score class映射同一final gate；
- S16 fast path；
- 超过16个active class的whole-row replay；
- INT8权重和宽整数Acc。

结果：

| 指标 | 数值 |
|---|---:|
| cases | 504 |
| fallback cases | 50 |
| accumulator values | 1,185,408 |
| Acc mismatch | 0 |
| class-count mismatch | 0 |
| fast-path delivery | 712,439 |

该结果证明给定class与gate后，FCIP因子交集和算法级整行fallback等价。它不
证明hardware-order Shiftmax、逐拍abort、SRAM、背压或PPA。

## 3. 三个比较对象

### B0：当前定长路径

```text
162-token G1 build + 4x32 directory scan = 290 cycle/row
```

这是现有RTL/ledger形状，但对大量空row偏弱。

### B1：强稀疏回放

逐row按：

```text
active token + occupied final-gate/lane term
```

计数。它代表active-member sparse replay和occupied term扫描，不支付固定
162-token建表，是FCIP必须超过的强基线。

### B2：联合关系平面

仓库已有 `gatestack_transposed_bitmap_bank`，物化：

```text
relation[class][lane][destination]
```

FCIP物化两个因子：

```text
class[class][destination]
K[lane][destination]
```

并在读取时做AND。T162逻辑状态：

| 结构 | bit |
|---|---:|
| 当前SCS+G1 | 30,163 |
| S16联合关系平面 | 88,806 |
| S16 FCIP因子平面 | 13,638 |

因此FCIP相对B2的优势是容量，代价是双读和AND。

## 4. 有限资源结果

旧ordered trace没有segment identity，因此报告fragment上下界。共同
normalization和共同projection backend不计。

### 4.1 相对B0当前定长路径

所有配置在均值上均有较大上界收益，但这不是主结论，因为B0较弱。

### 4.2 相对B1强基线

| AND | fragment出口 | product出口 | aggregate speedup区间 | p99 speedup区间 |
|---:|---:|---:|---:|---:|
| 1 | 1 | 1 | 0.495x–0.987x | 0.301x–0.837x |
| 4 | 1 | 1 | 0.495x–0.987x | 0.301x–0.837x |
| 4 | 4 | 1 | 1.550x–2.249x | 1.146x–2.716x |
| 4 | 4 | 4 | 1.759x–3.157x | 1.146x–2.895x |
| 8 | 4 | 4 | 1.759x–3.157x | 1.146x–2.895x |
| 8 | 8 | 8 | 3.058x–4.970x | 2.157x–5.000x |

关键负结果：

> 增加AND宽度而fragment出口仍为1时没有收益。单出口FCIP相对强基线整体
> 可能退化，不能进入RTL。

第一候选不是32路全展开，而是：

```text
4 x 64-bit AND
4 x internal fragment service
1或4 x product service
```

但4路fragment不能假设下游DCTF免费接收。下一步有两种物理选择：

1. 四路fragment在FCIP内部按 `{final-gate,lane}` 组装成一条完整term，再以
   单term接口接现有后端；
2. 扩展后端为四路segment sink，并把端口、FIFO和Acc冲突全部计入。

优先选择1，因为它保持现有后端边界并减少架构变量。

## 6. 下一最小实现

先做CPU逐拍模型：

```text
one token/cycle factor writer
  -> S16 slot allocator
  -> occupancy RMW
  -> final-gate alias mask
  -> 4-way 64-bit intersection
  -> per-{gate,lane} segment assembler
  -> one-term ready/valid sink
  -> abort/epoch/replay
```

必须加入随机sink backpressure，并对最终Acc、term、delivery、abort和跨row
隔离做exact检查。逐拍模型通过后，才写该最小RTL。
