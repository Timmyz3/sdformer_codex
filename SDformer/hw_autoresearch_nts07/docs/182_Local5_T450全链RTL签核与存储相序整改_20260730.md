# Local5 T450 全链 RTL 签核与存储相序整改（2026-07-30）

## 1. 本轮结论

Local5 默认 Direct self-K 路径已补齐 `MAX_DEST=450`、`DEST_W=9` 的全链定向验证。最高合法目的地址 449 能够穿过：

`score/Shiftmax5 -> MFEP term -> multiset bridge -> bank-local projection -> Acc readback`

Verilator 与 Icarus 均得到：

```text
PASS tb_local5_window_t450 dest=449 gate=128 cmds=32 cycles=485
```

地址 449 的正负权重累加与独立 golden 一致，地址 0 保持为 0，未发现地址截断或回绕。

## 2. 发现并修复的硬件问题

原 `local5_banklocal_projection_top` 在 reset 和每次 `run_start` 时，以嵌套循环单周期清零全部 `MAX_DEST x OUT_DIM` Acc。小规模仿真可以工作，但在 `MAX_DEST=450` 时出现两个问题：

1. Verilator 拒绝展开大型非阻塞二维数组清零；
2. 单周期全阵列写不符合常规单端口/双端口 SRAM 的实现相序。

本轮新增 `ST_CLEAR`，每周期清零一个目的行，状态流程改为：

`ST_LOAD -> ST_CLEAR -> ST_RUN -> ST_DONE`

效果：

- `run_busy` 覆盖清零与运行阶段；
- 清零期间 `cmd_ready=0`，上游通过 ready/valid 自然反压；
- 最后一行清零后才允许命令进入；
- 清零周期被显式计入窗口延迟，不再隐藏为零成本操作；
- 数组索引去除 Yosys 不支持的 `int'(...)` 强制转换，功能不变。

## 4. 新增动态断言

`local5_banklocal_projection_assertions` 检查：

1. `ST_CLEAR` 时 `run_busy=1`、`run_done=0`、`cmd_ready=0`；
2. 非末行清零时，目的地址每拍递增 1；
3. 末行清零后一拍进入 `ST_RUN` 并开放 `cmd_ready`；
4. 命令在反压期间 payload 保持稳定。

这些断言验证控制相序，但不等于形式化证明，也不覆盖真实 SRAM 返回延迟。

## 5. 周期影响与架构启示

逐行清零是正确的物理相序，但会引入与 `MAX_DEST` 成正比的窗口启动成本：

- T450 单目的定向测试为 485 周期，其中清零阶段占 450 周期；
- window16 Direct 从原约 1662 周期变为 1679 周期；
- window16 TARE 从原约 1896 周期变为 1901 周期。

该结果说明，Local5 的下一项高价值硬件优化不应继续堆 score 算术，而应研究无损的 Acc 初始化消除：

- epoch-tag / generation-tag 惰性清零；
- 首写置零与读改写融合；
- epoch 回绕时执行低频 scrub；
- 将 tag 开销、wrap scrub、窗口周期和动态功耗一起评估。

这项机制仍是存储微架构优化，单独不足以构成 DATE 主创新，但可以明显增强 Gate-Stationary / deterministic term schedule 的完整执行故事。

## 6. DATE 证据边界

本轮实质关闭了一项窄范围 P1 实现风险：Local5 不再只有 T450 计数器或窄地址测试，而是具备 449 号目的 token 的完整累加读回证据。上一轮定义的真实 fullres/post-G0/ordered-trace P0 仍未关闭。

仍未关闭：

- fullres ordered trace 的 450 目的完整回放；
- `MAX_DEST=450`、真实 `OUT_DIM` 和 SRAM 宏的 PPA；
- 多窗口 Acc 初始化开销与 overlap；
- 随机 SRAM latency、final backpressure、coverage；
- Motion 全链同顶层；
- Central/Independent/DCTF/Local5 同 SDC、同 SRAM 规则的 DC/STA/SAIF；
- full encoder 系统吞吐与带宽。

因此当前状态仍是 `RTL_SUBSYSTEM_PARTIAL_SIGNOFF`，不能直接表述为可投稿或可流片签核。

## 7. 下一轮优先级

1. 实现并验证 exact epoch-tag Acc，和逐行清零做同顶层周期/面积对照；
2. 等 Local5 fullres hardware-order trace 后，回放多样本、多窗口并统计 mean/p95/p99；
3. 补 Motion T450 同顶层链，避免双线证据不对称；
4. 冻结 SRAM 端口、延迟和容量合同，再进入 DC/STA/SAIF；
5. 独立 DATE 复审只允许基于上述真实证据更新评分。
