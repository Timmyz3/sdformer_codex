# M510｜H67 反卷积覆盖缺口与 Event-Polyphase Decoder 立项裁决

日期：2026-08-27

## 结论

裁决为 `CONDITIONAL_GO__EXACT_TRACE_AND_A1_FASTKILL_BEFORE_RTL`。

旧 `620,302,905 cycle/frame` 是 96-lane activity-weighted **included-scope**
envelope，不是严格 full-network envelope。冻结 profiler 只 hook
`Linear/Conv2d/Conv3d`；H67 配置却令四层 decoder 实例化为
`ConvTranspose2d`，所以四层 decoder ATLIF 已被统计，而紧随其后的四层反卷积
算子没有进入 operator ledger。

旧 ledger 内已经统计的分子、模块周期和局部倍率不因本发现自动失效；失效的是
“full-network”标签及所有直接以 `620,302,905` 为完整分母的 Amdahl 结论。论文
系统表必须在 exact decoder trace 后统一重算。

## 2. 四层真实拓扑与无 trace 分析界

H67 的模型名为 `MS_SpikingformerFlowNet_en4`，它将
`transpose_type` 绑定到 `MS_SpikingTransposeDecoderLayer`。该层的实际 forward 顺序是
`x = sn(x); x = deconv(x)`，所以冻结 `atlif_activity.csv` 里这四个 ATLIF 的
binary output 才是紧随其后的反卷积输入；不是根据名称猜测。四层均为
K3/S2/P1/output-padding1：

| 层 | 输入 T×B×Cin×H×W | Cout | frozen S100 activity |
|---|---:|---:|---:|
| D0 | 10×1×1536×15×20 | 384 | 17.9766% |
| D1 | 10×1×770×30×40 | 192 | 18.4184% |
| D2 | 10×1×386×60×80 | 96 | 17.2754% |
| D3 | 10×1×194×120×160 | 96 | 28.1026% |

这里特别纠正初审笔记：D3 的 `Cout` 是 **96**，不是 48；冻结 decoder3 输出
shape 是 `[10,1,96,240,320]`。

不生成插零张量时，K3/S2/P1/output-padding1 的 source 映射为
`o=2i-1+k`。因此只有 top/left 被裁掉 tap，bottom/right 完整；单个
top-left source、top/left 其余 source、其他 source 分别产生 `4/6/9`
个合法 spatial tap。只用已冻结的 S100 总 active count，按这三类容量
做最紧装填，可得到 aggregate-count 分析界：

| 量 | 下界 | 上界 | 身份 |
|---|---:|---:|---|
| 四层 active product/frame（S100 均值） | 16,379,262,935.04 | 17,613,185,495.04 | aggregate-count tight bound |
| 同 96 product lanes cycle/frame（S100 均值） | 170,617,322.24 | 183,470,682.24 | ideal product issue；非 RTL |
| 修正 envelope | 790,920,227.24 | 803,773,587.24 | old included scope + omitted decoder |
| decoder share | 21.57% | 22.83% | sensitivity only |
| decoder 免费 ceiling | 1.275× | 1.296× | 非可实现 speedup |

四层 exact dense polyphase work 为 `78,848,509,440 product/frame`，即
`821,338,640 cycle/frame @96 lanes`。因此 dense-to-bit-sparse 的分析机会约
`4.48--4.81x`，但这是标准 activation-zero skip 相对 dense 的 opportunity，
不是本项目新 RTL 的创新倍率。

## 3. 唯一允许立项的新模块：EPD

最小边界：`Event-Polyphase Decoder (EPD)`。

1. 直接消费 C2 同族 `{valid,t,y,x,cin}` binary source descriptor；
2. 按 K3/S2 的 `4/2/2/1` output-parity phase 分解合法 taps，不物化插零；
3. phase-balanced bundler 在同一个 96-product-lane pool 中混排多个 source 的
   tap/channel slice；
4. deterministic destination/parity banking 与 completion scoreboard；
5. weight SRAM 与 psum SRAM 只暴露 request/response 接口；不做 DRAM、全网
   scheduler、BN 或完整 decoder top。

论文新意不能写成 polyphase、event queue 或一般 OOO：

- transposed-conv decomposition 已有直接前作；
- sparse event queue / memory interlacing 已有 SNE；
- multi-spike decode、bank-aware dispatch 与 OOO 已有 FireFly-T；
- ESDA 已给出 event vision 的统一 sparse token-feature interface。

只有“binary ATLIF stream × K3 4/2/2/1 asymmetric phase balancing ×
deterministic conflict-free vector-psum banking × 与 C2 source protocol 共享”在
强 A1 之上仍有独立收益时，EPD 才能作为贡献。

直接相关一手来源：

- [Transposed-conv decomposition（ISCAS 2020）](https://arxiv.org/abs/2205.02103)
- [SNE sparse event convolution（TCAD 2022）](https://arxiv.org/abs/2203.12437)
- [ESDA event sparse token-feature dataflow（FPGA 2024）](https://arxiv.org/abs/2401.05626)
- [FireFly-T multi-spike decode/bank-aware dispatch](https://arxiv.org/abs/2505.12771)
- [Prosperity official cycle artifact](https://github.com/dubcyfor3/Prosperity)
- [FEATHER two-tier verification artifact](https://github.com/maeri-project/FEATHER)

## 4. 公平基线与快杀门

必须同 top、同 96 lanes、同 weight/psum SRAM 端口、同 output commit：

- A0：dense polyphase，不物化插零，但不跳 source zero；
- A1：exact bit-sparse、in-order polyphase，消费同一 descriptor；
- EPD：在 A1 上只增加 phase-balanced multi-source issue/banking。

相对 A0 的约 `4.5--5.1x` 只写 activation-sparsity opportunity；论文硬件创新只
报 EPD/A1。

快杀门：

1. exact S10 trace 加回后 decoder share `<15%`：停止 EPD；
2. A1 96-lane useful utilization `>=85%`：停止新 scheduler，复用 C2 简单模式；
3. EPD/A1 同资源 cycle `<1.30x`：不做 RTL。按当前 decoder share，1.30x 约只
   对应 `1.05x` 系统 sensitivity；
4. 要进入主性能贡献，EPD/A1 至少需约 `1.66--1.80x`，才能支持约 `1.10x` 修正
   envelope sensitivity；
5. EPD added logic area `>20% A1` 或 3 ns Fmax 降低 `>10%`：停止；
6. 若差异最后只剩插零跳过或通用 OOO：降为 completeness，不列创新贡献。

   weight identity、每 sample/module shape 与 exact active coordinates；
2. 用整数 scatter reference 精确重放 PyTorch K3/S2/P1/output-padding1 的边界、
   destination multiset 和 product count；
3. 建 A0/A1/EPD 同资源 cycle simulator，先过上述 fast-kill；
4. 只有过门才写 standalone RTL，随后 VCS reference miter、3 ns DC、Formality、
   SAIF/PTPX 与 SRAM 收费；
