## 一句话

把 DATE 主表缺的三块补齐：**宏映射后的诚实面积列**、**S0–S3 各一张完整真实 window**、**剩余 residual 的书面或 RTL 裁决**。双线都要动，创新只允许 exact。

## 为什么够终局

355 已经有共享+skip 和 S3 非平凡 window。审稿还会问三件事：

1. ANT 0.90 是 flop directory，宏之后还成立吗？  
2. S3 一窗是否特例？S1/S2 中间分辨率呢？  
3. Q≠0 里那 37.7% 非 identical-K 还藏着第三条 exact 吗？

答完这三问，硬件故事可以停，剩下只有 DC/SAIF/SRAM 真库。

## 验收

### M1 fakeram K 宏 `[rtl]`

`h67_sync_dual_bank_k_store` 增加 `MEMORY_IMPL`（默认 0=flop，不改 sealed 路径）。  
`=1` 时每个 bank 绑 `fakeram45_256x32`（225<256，1 拍读，与现时序同）。  
共享后端 138 行 ready=1 **K bit-exact**，wall 与 flop 包偏差写明。  
Yosys **blackbox 宏**：报告 logic cells + 宏个数（共享 4，单核 2），ANT 只除 logic。  
禁止把宏功能模型展开后的 flop 数说成 SRAM 面积。

### M2 skip 启动序 SVA `[rtl]`

Verilator+SVA：skip/emit 互斥、`retire_count≤2`、空行不吐 token、`last_row_done` 只退休队头。  
至少跑通 138 行或 ROW_LIMIT 覆盖空行串 52–77。

### L1 四 stage 完整 window 表 `[rtl]`

sample0 每个 stage 的 B0 完整 window：

| stage | heads | 已有 |
|---|---:|---|
| S0 | 3 | 2.005×（全 Q==0，引用 352 包） |
| S1 | 6 | **本轮新跑** |
| S2 | 12 | **本轮新跑** |
| S3 | 24 | 1.5824×（本轮复跑打 RTL 计数） |

GROUP 日志必须有 `qsilent_rows` / `identk_rows`。Acc32 0 mismatch。

### I1 剩余 residual

在 S3（及 S1/S2）上统计「Q≠0 且非 identical-K」：

- 几乎全同（4/5 K 同）  
- 仅 1-bit 残差  
- 不同 K 但分数仍全同  

有结构性收益且能 bit-exact → 最小 RTL + miter。  
否则 **书面否决**，写进终局表，不进贡献列表。

### D1 12-block 真 window 模型 `[rtl校准模型]`

用 S0/S1/S2/S3 **完整 window 均值** 外推 21600 / 1320，替换只靠 100-group stage 均值的旧账。  
旧 1.81× 包不动。
