# Local5 统一数据流强基线与拓扑退休物理代理

## 1. 本轮问题

本轮只闭合一个 Local5 缺口：在真实 `score -> Shiftmax5 -> relation ->
TCFM5 -> Acc32` 边界上，把 Query-Silent score 快路与三行在线关系转置组合，
并用同 K-active 过滤边界的 Dynamic/Stripe 调度器攻击 FCSR。

不改 `docs/359` 封存主表，不产生 full-encoder、DC、SAIF 或 ASIC PPA 数字。
Motion 的 `112589/94891/34099/28001` 保持不变；MSSB5 仍只是 RQTB 的
score-front CSE 支撑。

## 2. 生产边界修复

### 2.1 Active-Rolling FCSR

- 三行 relation/K 状态替代完整 T450 image；
- K-zero filter 前移到 closed-form retirement event；
- 补齐最后一行 self、跨行 K `0 -> 1`、空 plane 无泄漏定向测试；
- 修复 `retire_ready -> in_ready -> write_fire` 组合环；
- 将 sidecar 的层次内部引用替换为显式 debug 端口；
- 当前源码 Verilator lint 不再出现 `UNOPTFLAT`。

该工作是 `docs/208` 的生产集成，不新增贡献名。

### 2.2 公平 Dynamic 基线

Dynamic 模式现直接消费已有 `in_active_candidate_mask`。inactive K source 不再
分配 consumer counter event，因此与 FCSR 使用相同 K-zero 过滤边界。旧的
Dynamic `156212` 周期不再作为强基线；现行值为 `155791`。

进一步加入拓扑感知的 Banked-Dynamic 强实现：使用
`bank=(x+2y) mod 5`，使同一 destination 的五个十字邻域 source 分别落入五个
counter bank；每个 bank 每拍只访问一个 counter。三行循环槽用 epoch 标记复用，
不再整行清零。该实现仍运行时维护 consumer count，不使用 FCSR 闭式最后消费者，
因此是强基线而非本文贡献。

## 3. 100-group 真实 RTL

证据边界：100 个 sample-disjoint、population-stage-weighted group，真实 raw Q/K、
真实 checkpoint 权重，`OUT_DIM=2` tile，不是 encoder。

| score / relation 组合 | cycles | 相对 QS+T450 |
|---|---:|---:|
| residual + T450 | 324605 | - |
| Query-Silent + T450 | 183379 | 1.0000x |
| Query-Silent + Dynamic-active | 155791 | 1.1771x |
| Query-Silent + FCSR-active | 155791 | 1.1771x |
| Query-Silent + Stripe | 160214 | 1.1446x |

关键纠偏：FCSR 与公平 Dynamic **完全同周期**。因此 FCSR 不能声称额外吞吐，
统一数据流相对 sealed T450 的收益来自在线有界转置；FCSR 的独特价值是以固定
拓扑闭式退休替代通用 consumer tracking。

### 3.1 负组解释

- 总体 `183379 -> 155791 = 1.1771x`；
- 33 个 loss 全部是空组，均为固定 `904 -> 906` 两周期开销；
- 67 个非空组全部获益，`153547 -> 125893 = 1.2197x`；
- 非空组 win/tie/loss 为 `67/0/0`。

### 3.2 守恒与验证

- score row `45000`；
- descriptor `11245`；
- term `74131`；
- Acc32 update `222649`；
- Acc32 mismatch `0`；
- Icarus 与 Verilator 100-group 逐组一致；
- Verilator `--assert` 通过；
- 8 seeds x 8 groups 随机输入/读间隙通过；
- 三项边界定向测试在 Icarus/Verilator 通过。
- 当前源码 FCSR/Dynamic/Stripe 三模式在含 20 周期连续反压和随机反压的同一
  leaf TB 下均通过；
- Banked-Dynamic 相对原 Dynamic 的逐周期 miter 在 8 个 Icarus seed 与 3 个
  Verilator `--assert` seed 下通过。
- Banked-Dynamic 在同一 100-group、真实 raw Q/K 与 checkpoint 权重、
  `OUT_DIM=2` 生产 tile 上为 `155791` cycles，与 flat Dynamic/FCSR 逐组一致，
  Acc32 mismatch `0`；另有 8-row 跨两次稀疏空洞的 generation-tag 定向回归。

这里的随机间隙仍未直接覆盖 term consumer 的长突发内部反压，也未覆盖连续多
window 无 reset 切换；这些仍属于验证完整度缺口。

## 4. 拓扑专用退休的物理代理

比较边界仅含 scheduler control，固定 `15x15x2` 端口、相同 3 ns SDC、
Yosys/ABC + Nangate45 + OpenSTA：

| scheduler | cells | 逻辑面积代理 | 路径(ns) | 3 ns |
|---|---:|---:|---:|---:|
| FCSR closed-form | 595 | 1042.454 | 1.255811 | MET |
| Banked-Dynamic（主对照） | 3901 | 5806.248 | 4.113876 | VIOLATED |
| flat Dynamic（敏感性） | 8357 | 10528.014 | 7.767917 | VIOLATED |

主对照 Banked-Dynamic/FCSR 逻辑面积代理为 `5.57x`，路径为 `3.28x`。两边计入相同
`1xfakeram45_64x32 + 5xfakeram45_64x15` 开放 payload 宏后，总面积代理比为
`1.85x`。flat Dynamic 的 `10.10x` 逻辑面积和计入宏后的 `2.70x` 只保留为
未分 bank 实现敏感性，不再作为主要对照。

Banked-Dynamic 的 279-bit counter/generation 状态已显式映射为寄存器。此前
1-bit epoch 会在某个 entry 跨两次稀疏空洞未更新时产生 ABA 别名，已由真实
100-group trace 暴露并改为覆盖整平面复用次数的 generation tag。位宽按
`$clog2(ceil(HEIGHT/3)+1)` 参数化，`HEIGHT=15` 时为 3 bit；每个 plane 重置，
因此不是固定“最多 7 代”的近似合同。共同的
3735-bit relation/K payload 未进入调度器逻辑表，只作相同 FakeRAM45 宏面积相加。
这仍只是结构筛选，不得称为 DC 面积、签核 STA、SRAM PPA 或能量结果。DC 阶段
还需比较寄存器化与真实小 SRAM/register-file counter 实现。

## 5. 论文主张

Local5 只保留一条统一贡献：

> 对固定五邻域二值注意力，输入可判定的 Query-Silent/IdentK 行绕过 residual
> score walk；其余 gate 在 destination 端产生后，经拓扑编译的三行有界
> ownership transpose 直接形成 source-atomic term，并驱动 TCFM5 投影。

其中：

- Query-Silent 是 score 端精确代数快路；
- 三行 frontier 改变 relation/K 的驻留对象；
- closed-form retirement 利用固定五邻域与 raster 次序，避免通用最后消费者跟踪；
- TCFM5 接收同一 source 的完整关系快照。

不能拆成四条创新，也不能把 `324605 -> 155791 = 2.0836x` 当作单机制收益。
