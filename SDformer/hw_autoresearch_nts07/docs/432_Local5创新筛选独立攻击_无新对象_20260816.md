# Local5 创新筛选独立攻击：没有新的 exact 物化对象

## QAT 两刀

按 payload 的 `C·K` 与 `sum(C·K)/sum(K)` 复算，和报告一致。

| 实验 | source term | K-weighted C | C>2 | 裁决 |
|---|---:|---:|---:|---|
| mean-collapse QAT200 | +0.793% | +0.125% | +5 | NO-GO |
| tail-gap C≤2 QAT200 | +1.612% | +0.661% | +12 | NO-GO |

都是 1 sample / 48 group / pre_g0。门限 ≥5% term 下降且 C>2 不升，两刀都反号。
同意：不进 RTL，不抬创新，Local5 仍只有
`QS → compiled inverse-stencil/FCSR → source-owned unique-gate → TCFM5`。

## 只回答那一件事

**没有。** 排除 cache/Memo、ECGB、leftover、source wavefront、dyadic、gate-QAT、
generic 2-wide、第三 stencil、online-denom 之后，再没有一个 exact、且真正改
物化对象/执行边界的候选。

系数融合也不算：它只是同一五邻域和
`Acc[d] += g(q,k_d)·k_s` 的分配律改写，product 已是 2.201×，4800 组里
**0 组**系数项更少；这是已淘汰的 late-gate/distributive 线，不是新边界。

当前对象已经吃掉这条拓扑上能 exact 改的四件事：Q==0 不打分、逆模板编译、
相等 gate 合并、五色 1RW 无冲突写。再往下只会回到宽化、缓存或训练改 C。
