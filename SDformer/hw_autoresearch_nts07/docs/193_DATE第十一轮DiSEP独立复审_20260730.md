# DATE 第十一轮 DiSEP 独立复审

## 1. 评分

独立 DATE 审稿结论：

> **Weak Reject，2.3 / 5**

DiSEP 架构新颖性：

> **2.2 / 5**

相对第十轮，Q/K 公平口径、inverse-direction 整数等价和 source-centric
统计合同已有实质改进；但没有真实 fullres profile、周期、RTL 和 PPA，不能
进入 Borderline。

---

## 2. 审稿人认可的差分

| 对比 | 可辩护差分 |
|---|---|
| stencil line buffer | line buffer驻留Q/K样本；DiSEP驻留归一化后的有向edge gate |
| 实体transpose | DiSEP使用固定方向逆地址，不生成第二份转置gate plane |
| Sanger score-stationary | DiSEP驻留final-gate relation，边界在normalize-to-project |
| FLAT/Prosperity | 不做近似或动态matcher，固定五点拓扑直接给出关系 |

审稿人认为真正可能成立的组合只能是：

```text
destination-major exact normalization
  + 同份edge plane无拷贝所有权切换
  + source-gate product grouping
```

单独的方向 bank、仿射地址或 source replay 都不新。

---

## 3. P0 问题

### 3.1 真实复用未知

随机参考的 term ratio 为：

```text
142520 / 143388 = 99.39%
```

product只减少0.61%，未达到进入RTL所需的 `<=80%`。这不是对Local5的
否定，而是说明随机gate不会自动形成复用；必须等待真实hardware-order gate。

### 3.2 原B2是弱基线

固定stencil本来就能用方向bank和逆地址读取，不一定需要实体transpose。
因此已新增：

- B2a：同一方向bank、同样逆地址、每条edge独立生成product；
- B2b：同一方向bank、标准五项比较/CSE；
- A0只有超过B2a/B2b才算架构收益。

### 3.3 全局unique不可直接实现

当前 `torch.unique` 只给理论term下界。物理实现最多比较一个source的五个
incoming gate，并受lane展开、destination list和Acc端口限制。真实cycle模型
和RTL不能使用全局排序/哈希的免费假设。

### 3.4 golden边界有限

当前整数参考不覆盖：

- score到Q1.7 gate的hardware-order；
- 32 lane和真实Acc位宽；
- 逐加饱和/截断；
- SRAM latency与ready/valid；
- stripe覆盖保护与随机反压。

---

## 4. 审稿决策

当前不写完整DiSEP RTL。顺序是：

1. 等待Local5 fullres post-G0 hardware-order profile；
2. 检查真实term ratio、p95 gate重复和fanout；
3. 加入B2a/B2b；
4. 只有通过 `term ratio <= 0.80` 才实现最小RTL。

当前双线排序仍为：

| 路线 | 判断 |
|---|---|
| Motion | profile和RTL边界更成熟，暂时更可能成为主线 |
| Local5 | 只有真实source-gate重复和同约束EDP成立后才可能反超 |

本轮评分没有因命名和包装提高。下一轮必须改变存储生命周期或执行组织，而不
只是继续扩充DiSEP地址逻辑。
