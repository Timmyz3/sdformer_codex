# DATE 独立审稿：DCTF-2C 架构原型

## 1. 总评

**Overall：2/5，Reject。**

当前工作是一个有价值、实现较完整的可综合架构原型，但尚不是达到 DATE 录用线的硬件论文证据包。积极面是：作者保留了 DCTF-1C 的负结果，在同一 RTL 功能边界下报告了 DCTF-2C 的周期收益，并对 3138 bit 上下文状态未计入开放逻辑面积这一事实作了明确披露。决定性问题是：核心 PPA 结论来自单个 `sample0/window0`、固定一拍存储、无反压 final、无 SDC/STA/SAIF/DC/SRAM 宏的 Nangate45 无约束逻辑代理；而“原子双上下文”在实现形态上仍主要是常规两槽 ping-pong 缓冲加协议检查。以当前材料提交 DATE，性能普适性、比较公平性和 novelty 均不足以支持接收。

## 3. 主要问题与优先级

### P0：直接拒稿项

1. **[直接拒稿] 目标工艺 PPA 证据缺失。** 当前面积是无 SDC 的 Nangate45 logic proxy，`$mem_v2` 不计面积；报告自己确认无 STA、SAIF、DC、P&R、SRAM 宏（四架构总表第 21-26 行；mapping 报告第 18-23 行）。因此 `1.158x` 面积归一吞吐不能支持目标工艺面积/吞吐、功耗、能量或 EDP 主张。
2. **[直接拒稿] 四候选没有物理等价。** Central96 只有 2 个 `$mem_v2`，DCTF-1C/2C 分别为 11/20；Central 的宽 Acc 尚未拆成与 DCTF 相同的六个 32-lane SRAM 宏。2C 额外 3138 bit 只做位数分账，没有宏面积、端口、周期和访问能量。逻辑面积分母系统性漏掉对 DCTF-2C 更敏感的存储成本。
3. **[直接拒稿] 性能结论只有一个真实样本/窗口。** 所有 `1.110x` 周期加速和 S3 的 `14.526%` 改善来自 H67 `sample0/window0`。这只能证明一个 case study，不能证明数据分布上的稳定优势，也无法排除 fanout、term 长度或 bank stall 的选择偏差。
4. **[直接拒稿] 若论文把“原子双上下文”作为独立核心创新，novelty 不成立。** RTL 是两个 context、head/tail 翻转、完整后可见、逐 destination 发射；这是两槽 ping-pong/小 FIFO 加提交位和协议 sideband 的典型实现。应用语义可作为组合的一部分，但不能把缓冲深度从 1 增到 2 本身包装成 DATE 级新机制。

### P1：必须在投稿前解决

1. **顶层非法 metadata 存在 ready/valid 活性风险。** `term_ready = adapter_term_ready && term_metadata_legal`，同时非法输入只置 `protocol_error`（`gatestack_dctf96_term_datapath_top.sv:182-186,513-515`）。按标准 ready/valid 合同，source 必须保持非法 `valid`，而 sink 永不 `ready`，可能永久阻塞；这与“错误 term 被原子丢弃”的广义表述不一致。必须明确非法 metadata 属于不允许输入，或给出可消费并丢弃的协议及活性证明。
2. **正确性验证宽度不足。** 压力报告只有 128 个确定性合成 term、696 个压力 destination；未做随机 flush、连续多类 malformed、functional/code coverage 或 formal。`EPOCH_W=4` 还依赖迟到响应少于 16 次 flush 的外部寿命合同，当前没有证明。
3. **缺少机制消融。** 至少需要 1C、2C、4C/通用小 FIFO，以及“无 whole-term 检查但相同缓冲深度”的对照，才能区分收益究竟来自原子语义、两槽容量、上游调度，还是单纯消除 1C 人工串行相序。
4. **吞吐没有换算到时间域。** 当前只比较周期；无约束映射无法判断 Central96 与 DCTF-2C 的 Fmax。若 DCTF 的控制、bitmap 或 context mux 降频，周期加速未必成为 samples/s 加速。
5. **Independent32 基线可能偏弱。** 三套 term client 引入明显重复控制和上游握手代价，但没有一个共享前端、三个独立 32-lane 后端且不带 DCTF fabric 语义的优化基线。现有 Independent32 更适合说明“直接复制昂贵”，不足以界定 DCTF 的最接近硬件替代方案。

### P2：论文质量与可复现性问题

1. 报告均值、median、p5/p95/p99、95% bootstrap CI，并公开每个 sample/window 的 term、destination、周期、stall、occupancy，而不是只给四阶段求和。
2. 固化工具版本、目标库/存储编译器版本、完整 SDC、DC/STA/功耗脚本、随机种子、RTL 提交哈希和原始日志索引。
3. 将协议断言从有限动态 SVA 扩展到关键 safety/liveness 属性：无 partial commit、无重复/遗漏、全局保序、反压稳定、flush 后旧 epoch 不可见、每个已接受合法 term 最终 retire。

## 4. 三条贡献成立程度

| 声称贡献 | 成立程度 | 审稿判断 |
|---|---|---|
| DCTF bank-local distributed projection | **部分成立，中等** | 窄命令分发、三路本地 weight/product/Acc 与多 reader 有序 retire 在 RTL 中形成了完整数据流，不只是双缓冲。但 bank-local 化、广播/多播和 consume mask 都是常见构件；新意只能来自它们与 H67 term 语义的特定联合及经 PPA 证明的收益。 |
| Whole-term atomic dual-context commit | **功能成立，novelty 弱** | 完整 term 验证后才可见、per-context 保存物理 sideband 是正确且必要的协议设计；然而两个 context 的 head/tail 交替和 collect/emit overlap 本质上仍是普通双缓冲。原子丢弃语义提高可靠性，但目前没有证明它产生了区别于等深 FIFO 的架构收益。 |
| H67 workload-driven SW/HW co-design | **方向成立，证据不足** | term/destination 表示和 S3 fanout 能解释为什么 overlap 有效，也避免把零值 dense MAC 当稀疏执行；但本次性能只覆盖一个窗口，上游 88.7%/82.5% profile 数字没有在所读材料中与多样本端到端硬件收益闭环。 |

总体上，这不是“仅仅一个普通双缓冲”项目，因为还包含 whole-term 验证、bank-local execution 和多消费者有序 fabric；但当前可量化的新收益几乎全部由 1C 到 2C 的常规解耦产生。若没有深度/协议消融和目标工艺 PPA，最合理的学术分类仍是**面向特定稀疏表示的常规机制组合与工程实现**，而非已被证实的新架构原理。

## 5. 四候选公平性与面积归一吞吐

功能层公平性尚可：四者使用同一 H67 输入、96 个 INT8 product lane 和完整 projection-final 边界，DCTF-1C 的负结果也降低了选择性报告嫌疑。但物理层公平性不成立：memory 数量/组织不同、Central Acc 未做同规格六宏拆分、2C 状态未进入面积、所有 memory 是固定一拍行为模型、final 永远 ready，且无共同 SDC/Fmax。周期数与开放逻辑面积相乘得到的“面积归一吞吐”混合了两个不同可信等级的代理量。

因此 `1.158x` **具有误导风险，不应作为摘要或主图中的 PPA 数字**。它最多可命名为“单 trace、等 lane、无约束逻辑代理下的 cycle/logic-area 指示值”，并与 SRAM-excluded 标签同表展示。正式比较必须用 `throughput = workload / post-STA time`，面积为 logic + 全部 SRAM/RF macro + 必要 interconnect/clock tree 的一致口径。

## 6. 达到 Weak Accept 的最小硬门槛

以下是最低合同，缺一项则仍为 Reject：

1. **多样本性能：** 至少 `100` 个相互独立 H67 样本，每个至少 `4` 个窗口，共 `>=400 sample-window`，完整回放 S0-S3；所有候选使用完全相同 trace。报告逐样本周期、term/destination、各 bank stall/occupancy、median/p95/p99 与 95% bootstrap CI。DCTF-2C 相对最强公平基线的几何平均吞吐提升 `>=8%`，95% CI 下界 `>1.0x`，且 p99 latency 不退化超过 `5%`。
2. **DC/SDC：** 选择并冻结一个论文目标工艺库；若采用 28/45nm 级标准单元，最低公开目标可设为 `500 MHz`（`2.0 ns`）。四候选使用同一 DC 版本、同一库、同一 compile effort；SDC 至少包含 2.0ns clock、`0.10 ns` uncertainty、统一 input/output delay、max transition/capacitance/fanout、明确 clock/false/multicycle path。`check_timing` 必须无 unconstrained endpoint、无未解释例外，DC elaboration/lint 无 latch、width 和 unresolved reference 错误。
3. **STA：** setup 在目标 slow corner（建议 SS、最低电压、125C）达到 `WNS >= 0`、`TNS = 0`；hold 在 fast corner（建议 FF、最高电压、-40C）达到 `WNS >= 0`、`TNS = 0`。同时报告每候选 Fmax，并以 Fmax 或共同闭合频率换算真实吞吐，不允许只比较 RTL cycles。
4. **SRAM/RF：** Central、Independent、DCTF-1C/2C 的 weight、bias、六个 Acc bank、fabric/context/token/seen 存储全部绑定同一 compiler 和等价端口合同。DCTF-2C 的 3138 bit 必须映射为明确的 SRAM/RF/register 方案，并报告 macro 面积、读写端口、访问延迟、动态/泄漏能量；Central Acc 必须拆成相同六个 32-lane 宏。任何无法生成宏的小阵列按实际 flop/latch 综合面积与功耗计入。
5. **SAIF 与功耗：** 对上述 `>=400` 个窗口中至少 `30` 个分层代表窗口生成门级 SAIF，覆盖低/中/高 term fanout 和 stall；SAIF 对设计内 sequential/combinational net 的注释覆盖率 `>=95%`。使用同一 PVT、频率、clock gating 和 memory power model，报告 internal/switching/leakage、clock、logic、SRAM、interconnect 分账。
6. **能量口径：** 主指标为 `nJ/projection` 和 `pJ/destination`，均包含 logic、clock、所有 SRAM/RF、weight/bias/final IO 活动；另报 `mm^2`、projections/s/mm²、EDP。最低结果门槛为：相对最强公平基线，总面积归一吞吐提升 `>=8%`，总能量/projection 降低 `>=5%`，EDP 降低 `>=10%`，三者的 95% CI 均不跨过无收益线。
7. **正确性：** 上述全部 `>=400` 个窗口 bit-exact；再运行至少 `10^6` 个随机合法 term 和 `10^5` 个 malformed/flush/backpressure 事件，functional coverage `100%` 命中已声明协议 corner，关键控制模块 line/branch/toggle coverage 各 `>=95%`，并用 formal 或等价强度证明无 partial commit、无重复/遗漏和全局保序。

`500 MHz` 是可执行的审稿门槛示例，不是从当前材料推导出的系统需求；正式论文必须先由 30 FPS/full-encoder 带宽反推并冻结 `F_target`，若反推目标更高，应采用更高者。

## 7. DC 与 DATE 就绪度

**能否进入 DC：可以进入探索性 DC。** RTL 已有参数化顶层、明确时钟/复位和开放映射成功记录，足以开始 elaboration、约束审计和 compile。但在把所有 memory 绑定为真实宏、解决非法 metadata 的 ready/valid 活性合同、补齐 SDC 和多 corner 约束前，不能把 DC 结果称为签核级 PPA。

**是否足够发 DATE：不够。** 当前适合内部 architecture milestone 或论文 artifact 的 early prototype；不适合作为 DATE 完整投稿的主硬件结果。若以当前证据投稿，最可能因 novelty 弱、单样本和 PPA/公平性缺失被直接拒稿。

## 8. PPDI 对 novelty 的影响

PPDI 当前明确处于 `[profile]`，只有逐 term 奇偶计数和 `30.270%` command-work 理论降低，没有 RTL 周期、正确性、时序、面积或能量结果。因此它**不能提高当前 DCTF-2C 投稿的 novelty 分数，也不能写入已实现贡献**。它最多说明后续设计空间仍有一个与 2C 正交、由 Acc 奇偶物理端口驱动的候选假设。只有 PPDI 完成 RTL、bit-exact、多样本周期及同口径 DC/STA/SAIF/SRAM 评估，并证明收益不是普通双发射/端口加宽后，才可能增强组合 novelty；否则反而会稀释当前论文主线。

## 9. 模拟审稿摘要

本文提出面向 H67 稀疏 term/destination 流的 DCTF bank-local projection，并以 whole-term 原子双上下文重叠收集与发射。实现具备清晰协议边界，单个真实窗口上相对 Central96 报告 1.110x 周期加速，完整 projection 输出零失配，且作者诚实保留 1C 负结果与未计入的 3138 bit 状态。然而，双上下文本身是常规 ping-pong 解耦，组合 novelty 尚未通过深度和协议消融建立；所有性能结论仅来自一个 sample/window，面积结果排除了不等价的 memory，并缺少共同 SDC、DC/STA、SAIF、SRAM 和功耗/能量评估。`1.158x` 面积归一吞吐因此不能作为 DATE 级 PPA 证据。工作作为架构原型有价值，但距离可发表结论仍需多样本统计、物理等价基线和目标工艺完整 PPA 闭环。**建议：Reject（2/5）。**
