# DCTF96三Bank Term数据通路开放映射代理

## 1. 目的与口径

本轮对`gatestack_dctf96_term_datapath_top`执行完整flatten的Nangate45开放库映射，并与此前独立测得的叶模块算术和比较。映射固定`Q=2`、`TOKENS=162`、`OUT_TILE=32`，完整读取以下五个RTL：

1. `gatestack_dctf_term_event_adapter.sv`；
2. `gatestack_dctf_term_fabric.sv`；
3. `gatestack_decoupled_product_engine.sv`；
4. `gatestack_dctf32_bank_executor.sv`；
5. `gatestack_dctf96_term_datapath_top.sv`。

Yosys顺序执行`proc; flatten; opt; memory -nomap; opt; techmap; opt; dfflibmap; abc; clean; check; stat`。结果目录保存Yosys版本、Nangate45 Liberty与五个RTL输入的SHA256、映射日志和非空mapped网表。

## 2. 已有RTL事实

此前RTL闭环已得到以下事实：

- Icarus自检仿真PASS；
- Verilator动态SVA PASS；
- Yosys hierarchy/check/stat PASS；
- Erie对RTL与TB检查PASS，均为`0 error / 0 warning`；
- 非法term在adapter前被拒绝，保持零副作用：不握手、不锁存、不接收event，也不产生command、weight request或Acc update；
- cross-supertile overlap用例允许后一term在前一term尚未被全部bank完成时进入，supertile随每条command驻留，三个bank的物理tile保持正确；
- flush后，三bank的旧epoch weight response均执行stale drop，不进入product、Acc或完成路径，计数为`1/1/1`。

Icarus与Verilator记录的`91/89`周期只来自synthetic TB。它们用于协议和反压场景的功能验证，不是H67真实工作负载周期，不能用于性能、吞吐或加速比外推。

## 3. 映射完整性判据

本轮结果必须同时满足：

1. mapped网表存在且非空；

5. `$mem_v2`单独计数，其面积不纳入Nangate45逻辑库面积值。

实际运行满足全部判据，mapped网表为`7467042`字节。最终统计为0个process，除5个`$mem_v2`外没有未映射`$`单元。

## 4. 叶模块算术和

比较基线不重新猜测叶模块，而是直接读取：

- `results/gatestack_dctf32_bank_executor_20260720/report.json`；
- `results/gatestack_dctf_frontend_20260720/report.json`。

算术和定义为：

~~~text
3 * executor_32 + adapter + fabric_q2
~~~

已有叶模块数字为：每个executor逻辑库面积值`20367.886`、`15643`个cell；adapter为`5731.236`、`3886`个cell、1个`$mem_v2`；Q2 fabric为`4475.184`、`2722`个cell。因此叶模块算术和为逻辑库面积值`71310.078`、`53537`个cell和1个`$mem_v2`。

完整flatten top与算术和结果如下：

| 口径 | 逻辑库面积值 | cell | `$mem_v2` |
|---|---:|---:|---:|
| 三个executor + adapter + Q2 fabric算术和 | 71310.078 | 53537 | 1 |
| 完整flatten top | 74071.690 | 55216 | 5 |
| top减算术和 | 2761.612 | 1679 | 4 |

`top/算术和`的逻辑库面积值比例为`1.038727`，净变化为`+3.873%`；cell比例为`1.031361`，净变化为`+3.136%`。4个新增`$mem_v2`只反映完整top在`memory -nomap`边界下保留了更多存储结构，不能用当前库面积差为它们赋值。

## 5. 差值解释纪律

完整flatten top减叶模块算术和的差值混合以下四类影响：

1. top新增的term完成tracker及三bank完成匹配；
2. input-channel与logical-supertile地址合同、非法term拒绝和sticky错误跟踪；
3. flatten后ABC跨原层次执行的逻辑共享、常量传播和重写；
4. 叶模块独立映射与集成映射之间的可观察输出裁剪差异。

因此该差值不能称为纯协调器面积、纯tracker面积、wrapper毛开销或物理互连面积。正差不等于可以独立归因的控制成本，负差也不代表协调逻辑“免费”。这里只能把它称为同库、同参数但不同优化上下文下的谨慎净差值。

## 6. 严格限制

本轮没有SDC、STA、SAIF、SRAM宏表征、Design Compiler或布局布线，也没有时钟树、互连寄生、PVT收敛和功耗分析。`$mem_v2`仅报告数量且不计面积。Nangate45 typical下的Yosys `dfflibmap + ABC`数字只能作为开放逻辑映射代理，不得称为ASIC PPA、论文最终面积、目标工艺面积或签核结果。
