# M45-r2：八上下文双目的 bank 融合物理调度规格

## 结论边界

M45-r2 是冻结 40 条真实 H67 ep35 记录上的 transaction-level 调度里程碑。它不是 RTL/VCS 周期，不是 SRAM 宏时序，也不是全网络或端到端加速比。只有独立验证器通过后，才能引用本文规定的 transaction-level 指标。

M45-r1 在修正 context 生命周期后，sample 0 的 K2-C4 integrated/source overhead 为 10.3319%，且 C8 相对 C4 改善 4.6906%。因此 r1 以 sample-0-only NO-GO 诊断封存；r2 不修改 r1 文件，而是把 K2-C8 作为新 primary，把 K2-C4 改为容量消融。

## 冻结执行顺序与资源

循环顺序严格为：

`operator → output_block → timestep → feature_tile → spatial parent DAG`

每个 timestep 的 300×96×3 B final accumulator frame 在 27 个 feature tile 间驻留。权重每个 timestep 重放一次，共 10 次；双 buffer 只允许在前一 tile 计算覆盖 384-cycle DMA 时隐藏等待，不允许把未建模 prefetch 当成免费。

Primary 为 K2-C8：8 个 source bank 每 bank 每周期至多发一个 source，一个 source response 可按独立正负号更新至多两个 destination。weight response 固定一周期。context 必须保持到 `response_ready`；只有完整的 96-lane signed19 vector 和 tag/control 进入 completion FIFO 后才可释放。completion FIFO entry 保持到 parent/final commit。

命令端口、输出端口、parent partial 端口和 final accumulator 端口均各自为单端口模型。metadata FIFO 和 completion FIFO 均为 16 entries。

## 容量账本

一个 context 使用 288 B vector 加 64 B metadata，共 352 B。8 contexts 为 2,816 B，比 M43 的 4 contexts 增加 1,408 B。

- 8-context local scratch：58,368 B
- 单 timestep final accumulator：86,400 B
- metadata FIFO：1,024 B
- completion FIFO：4,864 B
- 总本地容量：150,656 B
- 相对冻结 193,728 B residency 的余量：43,072 B

这里的 FIFO 存储不是免费状态；completion entry 按 288 B 完整 vector 加 16 B tag/control 逐项计账。后续 RTL 必须单独给 8-context 增量面积设门，当前容量 fit 不等于 PPA 通过。

## 配置与 kill gates

全 10 样本必须在同一脚本、同一输入身份下跑完四项：

- K1-C4：精确复现 M43 source cycles。
- K2-C8：primary。
- K2-C4：context capacity ablation。
- K4-C4：counterfactual killed ablation，不可作为主硬件。

K2-C8 必须同时满足：每个样本 integrated/source overhead 不超过 10%；每个样本 parent wait 不超过 5%；aggregate integrated cycles 相对 K1 至少降低 15%；p95 integrated cycles 不超过 15,495,075。C8 相对 C4 的 p95 改善必须至少 3%，以证明多出的 1,408 B context 状态有 transaction-level 必要性。K4-C4 若慢于 K2-C8，即作为 fanout 扩张无收益的负消融封存。

## M47 接口，不属于本结果

M45-r2 只留下 M47 的审计入口，不把其潜在收益写入 M45 数字。M47 将分别检查 19-bit bit-tight 双 timestep residency，以及 rolling bank-row retirement/versioned refill：一行权重必须等 timestep pair 两次消费均完成后才能版本化覆盖，带严格 refcount 和 fail-closed 检查。其目标是用 24,576 B 主 tile 加逐 bank 小 staging 替代 49,152 B 全 ping-pong，并用精确 packed frame、parent line、context/meta/FIFO 账本证明容量与 DMA 隐藏；在审计完成前不得声称 weight replay 从 10 降到 5。
