## 后台候选（不进入当前贡献表）

- TSBG：M1668 的 runtime/entity 闭包设计已通过双 Python 18/18，但原 M1669 评审 JSON 与 M1668 `validate_future_authorities()` 的 exact schema 不兼容，实测会在 capture 前 fail closed；授权已撤回，未消费 remote/GPU/attempt。当前正做 additive authority-shape successor；只有真实 40-sample binary capture 与 B2/B4/B8 同资源预模型通过后才判定 GO/NO-GO。
- S2/CCBS16：`epsilon=0.1` 的 30.168% 是候选块比例，不是 cycle/energy saving。M1643 已冻结 source-only paired evaluator：16×16、正 epsilon 每块 2 B metadata、epsilon=0 exact bypass，内部计算 40-sample/逐序列 AEE、ratio-of-sums cycle 与 weight/compute/psum 节省；只有 `overall ΔAEE≤0.02`、逐序列 `≤0.03`、metadata `≤2%`、同资源局部周期 `≥1.15×` 才能进入 C2 optional lossy mode；若 TSBG 准入，S2 基线必须包含 TSBG且禁止倍率叠乘。
