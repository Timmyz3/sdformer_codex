## 后台候选（不进入当前贡献表）

- TSBG：M1624 第一次调用因部署归档漏 `M1314/author_test.log` 在 attempt/GPU/model-load 前停止。M1647/M1648 随后证明 16 个 seal、116 个成员的 Git archive 闭包完整，但唯一 parent 调用又在 attempt/GPU/checkpoint 前发现未部署的 runtime result `M1257`；补齐它后的只读诊断进一步发现训练树 config 的 SHA 未变但 inode/mtime 已偏离冻结 selection identity。M1624/M1647 均禁止重跑且四个运行 namespace 均未生成。下一身份必须把 runtime data closure 与 `build_runtime()` 预演移到 parent budget 之前；无数据前不写性能、不做 RTL。
- S2/CCBS16：`epsilon=0.1` 的 30.168% 是候选块比例，不是 cycle/energy saving。M1643 已冻结 source-only paired evaluator：16×16、正 epsilon 每块 2 B metadata、epsilon=0 exact bypass，内部计算 40-sample/逐序列 AEE、ratio-of-sums cycle 与 weight/compute/psum 节省；只有 `overall ΔAEE≤0.02`、逐序列 `≤0.03`、metadata `≤2%`、同资源局部周期 `≥1.15×` 才能进入 C2 optional lossy mode；若 TSBG 准入，S2 基线必须包含 TSBG且禁止倍率叠乘。
