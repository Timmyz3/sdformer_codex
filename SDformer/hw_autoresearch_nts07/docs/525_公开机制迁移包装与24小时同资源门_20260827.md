## 2. 24 小时执行顺序

1. **先关 C3 公平分母**：M518 r6 静态门、VCS，随后 Fixed/rank3 同 Tcl DC。
2. **再关 C2 物理端点**：M519 K1/K8/K1x8 三点 DC；主判 throughput/mm²、面积和同峰值差，不重复宣传单 K1 倍率。
3. **补 decoder 完整性**：M511/M513 exact trace；TDR 先过 `1.30x` 理想门；M522 mapper DC；M523 只按 descriptor 功能收口。
4. **更新 C1 capture-gap**：不新开 Conv matcher；用当前 240 KiB/1R1W 负结果、官方 artifact 与真实 SRAM 共同形成 opportunity-to-capture 图。
5. **生成统一表**：Fixed、bit-sparse、ours 用同 H67/checkpoint/resource；Prosperity/Phi/FireFly-T 放外部/归一化辅表，跨网络只比可归一化指标，不计算“ours 相对它们”的伪倍率。

## 3. 论文句式模板

### C1

“Prosperity reveals product-level redundancy in binary SNNs. We instead study the capture gap that arises when exact parent/product reuse is deployed for signed event-flow sources under a finite 240-KiB, 1R1W memory system, and realize a source-owned dual-destination capture path.”

这里的新增对象是 signed source、dual destination、有限 scratch 和 completion；不是 product sparsity 本身。

### C2

“Inspired by multi-NZ decoders and temporally packed sparse dataflows, we introduce a typed K8 signed-source service that preserves analog values, timestep ownership and accumulator context while sharing state across Conv/FC endpoints.”

这里必须用 K1x8 等带宽对照。若 M519 只有面积收益，就把 claim 写成 state-sharing efficiency，不写 speedup。

### C3

“We decouple timestep/rank state service from source execution for analog ATLIF neurons and evaluate it against a matched Fixed-T10 hardware denominator.”

这里只有 M518 VCS/DC 和 checkpoint/accuracy 边界闭合后才可写倍率。
