# Motion 全分辨率 T450 组件闭环与 RQTB 晋级

## 1. 本轮结论

本轮完成了 Motion/H67 主线在 `480x640`、`window=2x15x15`、`T=450` 条件下的三类工作：

1. `[rtl]` 冻结 checkpoint 的 score/Shiftmax、ATLIF DP-TME 和真实权重 projection 三个组件均完成双仿真器回放；
2. `[prof]` 基于 100 个真实样本、12 个 attention block 的 ordered profile，重新评估时间等价性和可逆商流；
3. `[模型]` 使用 Phi/Prosperity 风格分账模型比较 direct、固定 term、hierarchical descriptor 和在线匹配 oracle。

当前架构决策如下：

- **RQTB 通过 profile admission，晋级最小 RTL；**
- **RQTB 的主目标是 descriptor/SCS/K-store 流量和动态能量，而不是 32-lane score 峰值吞吐；**
- **现有 hierarchical descriptor 不适合直接作为 Motion T450 的性能主贡献；**其模型平均周期比 direct 慢约 `2.27%`，必须作为负结果保留；
- **Motion 尚未达到 full-network RTL exact 或 ASIC PPA 完成度。**

## 5. TESC 与 RQTB

### 5.1 机制定义

TESC 先利用两个时间片的 score 等价关系：

- score 相等：保存一个 score class 和 `2-bit temporal mask`；
- score 不等：保存两个独立 descriptor；
- zero-K 仍保留 Shiftmax 分母 multiplicity；
- gated-K 输出按 active mask 从 K0/K1 bank 恢复原 token 顺序。

RQTB 是 TESC 的可逆流接口实现，不单独重复计为另一条论文贡献：

- common pair：一个 `16-bit` slot；
- split pair：两个 `16-bit` slot；
- 完整 packet 退休后才增加 pair 计数；
- common packet 向 SCS class histogram 注入 multiplicity=`2`；
- split packet 分别注入 multiplicity=`1`。

### 5.2 全分辨率结果

`[prof]+[模型]`：

| 指标 | 数值 |
|---|---:|
| score-equal pairs | `147,530,440 / 151,200,000` |
| active score equal rate | `92.6942%` |
| active descriptor reduction | `46.3471%` |
| 所有 descriptor reduction | `48.7865%` |
| lane work reduction | `44.4084%` |
| RQTB 16-bit slot reduction | `48.7865%` |
| descriptor+bank-gated-K bit reduction | `36.9349%` |
| SCS active-entry reduction | `20.9773%` |
| exp transaction reduction 模型 | `19.8196%` |
| K read-bit reduction | `33.1837%` |

K read-bit reduction 来自 active-mask bank gating，固定 TTB 强基线也允许使用，不能归因于 RQTB 独占创新。

### 5.3 吞吐边界

TESC 对不同 score lane 宽度的模型结果：

| lanes/cycle | speedup | cycle reduction |
|---:|---:|---:|
| 4 | `1.7045x` | `41.33%` |
| 8 | `1.5723x` | `36.40%` |
| 16 | `1.3345x` | `25.06%` |
| 32 | `1.0033x` | `0.33%` |

因此不能把 RQTB 写成“32-lane score engine 大幅加速”。它的主要价值应在：

1. descriptor SRAM/FIFO 容量；
2. SCS active-entry 和 exp 事务；
3. K-store 读流量；
4. 由上述三项带来的动态能量和面积归一吞吐。

### 5.4 Admission

| 门槛 | 实测 | 结果 |
|---|---:|---|
| slot reduction `>=25%` | `48.79%` | 通过 |
| active-entry reduction `>=10%` | `20.98%` | 通过 |
| exp reduction `>=10%` | `19.82%` | 通过 |
| fullres T450 身份 | 全部字段与 SHA 通过 | 通过 |

结论：**RQTB 进入最小 RTL，不直接进入论文主贡献。**只有在同 SRAM、同反压、同端口、同资源对照下获得非负面积归一吞吐，并使 score+SCS+K-store 动态能量至少降低 `15%`，才晋级主贡献。

## 7. 架构决策

### 7.1 晋级项

**Motion：RQTB/TESC-WD 最小 RTL。**

晋级理由不是“idea 听起来新”，而是三个真实条件同时成立：

1. T450 score 相等率 `97.57%`；
2. 可逆流 slot 减少 `48.79%`；
3. SCS active/exp 分别减少约 `20.98%/19.82%`。

### 7.2 暂缓项

**Motion hierarchical descriptor 暂缓。**它降低 fabric bit，但当前模型无法换成吞吐收益，不能继续按正贡献宣传。

**Phi 风格 pattern predictor 暂缓。**命中率 `0.5/0.75/0.9/0.95` 的高收益只是 oracle sweep，没有真实命中率 profile 和 predictor RTL，不可晋级。

### 7.3 Local5 状态

Local5 仍是当前算法主线候选，但硬件机制是否主推 TCFM5/Relation Memo，必须等同窗全-head ordered profile。当前结果只证明 pre-G0 数据上 descriptor 很有机会，同时暴露 p99 风险。

## 8. 下一项最小 RTL 合同

现有 `h67_temporal_quotient_shiftmax_gate_top` 已在合成 T450 数据上完成 baseline/quotient gated-K miter，但它仍使用寄存器数组的组合 K 读取，quotient descriptor 也没有经过物理可变长 slot FIFO。因此下一步不是重复实现 TESC 数学功能，而是验证 **RQTB 物理传输和同步存储是否把 profile 机会转化为可测收益**。

RQTB RTL 必须同时实现两个可公平比较的路径：

1. `Fixed-TTB32`：每个 temporal pair 固定两个 `16-bit` slot；
2. `RQTB16/32`：common 一个 slot、split 两个 slot。

两条路径必须共享：

- 同一套同步一拍 K0/K1 SRAM 模型；
- 同一 active-mask bank gating；
- 同一 SCS class histogram、exp LUT 和 gated-K backend；
- 同一 input/output random backpressure；
- 同一 FIFO 总 bit 容量或分别报告容量归一结果；
- 同一 clock/SDC 和 OpenROAD 宏规则。

必须检查：

- score class、multiplicity、active mask、pair sequence 全部 bit-exact；
- common/split packet 在反压下不可半退休；
- K0/K1 读取与 gated-K 输出顺序无重、无漏、无交换；
- Acc32 miter 零失配；
- cycle、stall、FIFO occupancy mean/p95/p99/max；
- VCD/SAIF 活动、SRAM read bits、exp requests；
- Yosys/OpenROAD 仅标为开放物理代理，不能称 ASIC PPA。
