# Local5 theta 折叠 v2 部署合同旁路实现

## 本轮问题

Local5 软件 `value_mode=threshold` 的值流是 `K_binary × theta_K(block)`，旧投影合同却直接量化 `W_projection`。旧 checkpoint 审计已经证明，即使 theta 最大只偏离 1 约 `4.59e-6`，仍会改变 80 个 INT8 权重码。因此必须先建立可执行的折叠合同，再继续扩大 RTL 集成范围。

活动中的 fullres watcher 仍绑定旧生产 producer。为避免修改脚本 SHA 干扰其 acceptance，本轮只新增旁路实现，不修改现有 profile/vector producer。

## 已完成实现

新增 `scripts/export_local5_theta_folded_projection_contract.py`，实现以下冻结顺序：

`W_eff(block) = theta_K(block) × W_projection_float(block)`

`W_int8, scale_exp2 = quantize_dyadic_int8_per_output_channel(W_eff)`

导出器执行：

1. 从 checkpoint state dict 匹配 12 个 Local5 attention block；
2. 对每个 block fail-closed 提取标量 `sn_k.spiking_neuron.thresh`；
3. 先做 theta 折叠，再做逐输出通道 dyadic INT8 量化；
4. 保存原始浮点 W、theta、有效浮点 W、INT8 W、scale exponent 和 bias；
5. 绑定 checkpoint SHA、payload SHA、导出器 SHA 和量化器 SHA；
6. 在 manifest 中明确当前只覆盖 per-head partial accumulator 之前的权重合同。

运行时 K 仍是 1-bit event；theta 被离线吸收到权重镜像，不增加事件位宽、运行时乘法器或 descriptor 动态字段。

## 尚未完成

1. 新 fullres rank-1 尚未释放，当前 manifest 只能证明机制可执行，不能成为正式部署权重；
2. v2 合同尚未接入生产 post-G0 profile、projection vector 和 acceptance；
3. 尚未用 v2 权重重跑 TCFM5/Direct Acc32 RTL；
4. 尚未连接 `score→relation→term→projection` 单顶层；
5. cross-head reduction、bias、no-running BN、requant、residual 仍在 scope 外。

## 下一步门槛

新 rank-1 释放后，先在不改变数值规则的前提下重跑 v2 导出器，并把 production acceptance 改为要求：

- schema 为 `local5_checkpoint_projection_contract_v2`；
- 12 个 theta、checkpoint、导出器与 payload SHA 完整绑定；
- projection golden 读取 v2 的折叠后 INT8 权重；
- 同一 checkpoint 的 projection Acc32 RTL 零失配。

完成上述门槛后，才能进入 source-major term builder 和 12-block scheduler 集成。本轮没有增加 DATE 架构创新点，只修复了阻断端到端 exact 的部署合同。

## 严格 DATE 评审

- 评分：`3/5`；推荐：`Reject（大修后重审）`。
- 允许表述：旧 checkpoint 的 theta-folded 离线合同旁路已实现并通过测试。
- 禁止表述：正式 Local5 部署冻结、attention-to-projection RTL exact、端到端 bit-exact。
- 创新性增量：0；完整度增量：约 `+0.3/5`。

评审认为当前最危险的问题不是数组或 SHA，而是旁路合同尚未被正式 producer、golden 和 RTL 消费。其次，硬编码 12 个 block 仍需由新 deploy manifest 反向验证，最终 checkpoint 也必须证明 `sn_k` 标量确实是 value scaling 的语义来源。

下一唯一优先项被冻结为：新 rank-1 释放后，把 v2 schema 接入 production acceptance，并用同一 folded payload 重建 projection golden、驱动 Direct/TCFM5 Acc32 RTL 零失配。在此之前不扩 12-block scheduler。
