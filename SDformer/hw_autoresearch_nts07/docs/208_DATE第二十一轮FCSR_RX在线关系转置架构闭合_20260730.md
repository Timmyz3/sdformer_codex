# DATE 第二十一轮 FCSR-RX 在线关系转置架构闭合

> 本文件是第二十一轮历史快照。partial-valid、平面握手、边界 SRAM 地址和
> Stripe-3/4 公平基线的后续整改及最新数字，以

## 1. 本轮结论

Local5 的第二项架构候选冻结为：

> **FCSR-RX（Frontier-Complete Source Retirement with Relation
> eXchange）**：针对固定五点 stencil，在编译期求出每个 source 的最后消费者，
> 用闭式 frontier 触发五方向 gate 的在线逆向读取与 K 原子快照，把
> destination-major attention 关系流转换为 source-major projection
> descriptor。

本轮不再把“退休 FSM”“三行缓冲”或“双缓冲”单独当创新。C2 的完整边界是：

```text
固定拓扑最后消费者
  + 三行 role-isolated gate/K ring
  + 逐 source 原子 snapshot
  + destination-major -> source-major 在线关系转置
```

当前裁决为：

- **架构机制：Conditional Go**；
- **可作为 QFIT 的 C2 子贡献**；
- **尚不能单独支撑整篇 DATE**；
- 必须与 C1 的 XBF-DBDR exact score fabric 集成后，再判断组合贡献强度。

## 2. 闭式生命周期

对 source `s=(y,x)`，合法消费者集合为：

```text
C(s) = {self, north, south, east, west} 中未越界的 destination
```

在 raster 顺序下：

1. 非底行 source `(y,x)` 在处理 destination `(y+1,x)` 时完整；
2. 底行 `(H-1,x-1)` 在处理 `(H-1,x)` 时完整；
3. 最后一个 source 在右下角 self 完整；
4. 单 destination 触发的最大退休 burst 为 3。

因此运行时不需要为每个 source 保存引用计数。关系和 K 的活跃范围只覆盖
三行：

```text
state = (K_W + 5 x GATE_W) x 3W
```

当前 `K_W=32`、`GATE_W=9`、`W=15`，共同数据状态为：

```text
(32 + 5x9) x 3x15 = 3465 bit
```

## 3. 公平基线整改

初版 Dynamic Frontier 使用全窗口 225 组计数器，造成不公平的变量索引选择
网络。根据独立审稿意见，本轮已改为：

```text
3 x W 个循环计数器
row slot 在未来 source 行首次进入 frontier 时失效
五候选仍按真实消费者计数
```

三种候选现在具有相同的 `O(W)` 数据生命周期：

| 候选 | 完整性判定 | 退休粒度 | 运行时依赖状态 |
|---|---|---|---|
| FCSR-RX | 坐标闭式规则 | source | 无 |
| Dynamic Frontier-RX | 三行引用计数 | source | `3W x 3 bit` |
| Nonblocking Stripe-RX | 行结束 | row | 两个 row context |

三者共用：

- 同一五方向 gate/K bank 接口和数据宽度；
- 同一 source descriptor 宽度；
- 同一单 read-issue/cycle 和单 descriptor/cycle 服务带宽；
- 同一输出反压；
- 同一 invalid-candidate mask。

## 4. 实体微架构

```text
destination raster stream
 {y,x,Kself,5 gates,valid mask}
             |
             +------> K ring:       3W x 32, 1R1W
             |
             +------> SELF gate:    3W x 9,  1R1W
             +------> N gate:       3W x 9,  1R1W
             +------> S gate:       3W x 9,  1R1W
             +------> E gate:       3W x 9,  1R1W
             +------> W gate:       3W x 9,  1R1W
             |
             v
      FCSR closed-form frontier
             |
             v
 inverse-direction 5-bank read
             |
             v
 atomic snapshot elastic slot
 {source_id,y,x,K,5 incoming gates,valid mask}
             |
             v
 source-term / projection consumer
```

五个 gate bank 角色隔离，每个 bank 每次 snapshot 只读一个地址。它不是五读口
SRAM。六个 bank 均为显式同步 `1R1W`：

```text
retire request
  -> one-cycle six-bank read
  -> six-response atomic join
  -> two-entry descriptor FIFO
```

同拍同址读写冻结为 `read-first`。定向 TB 已证明碰撞拍读出旧值、下一拍读出
新值。目标工艺必须选择支持 read-first 的 SRAM macro，或在宏不支持时加入同址
stall。

FCSR/Dynamic 使用三行 ring。Nonblocking Stripe 若在两个 row context 占用时仍
继续写下一行，三行 ring 会覆盖最老 source 尚未读取的 `y-1` relation。强
Stripe 因此使用四行 ring，并在两个 context 都占用时于下一行 `x=0` 前阻塞。
`H=5`、20 拍持续反压回卷测试已通过。

地址生成不在六个 bank 前分别计算 `%3/%4`。硬件只生成一次 source row slot，
其余地址由固定拓扑相对关系得到：

```text
source slot = row-slot LUT(y)
north destination slot = prev(source slot)
south destination slot = next(source slot)
east/west destination slot = source slot
```

该共享相对槽生成把首版重复 `%3` 的 FCSR-RX generic cells 从 18,145 降到
10,914。前者作为地址生成负结果保留，不能进入主表。

## 6. 周期结果

`15x15` 饱和 raster、一拍同步六 bank、两项 descriptor FIFO、无输出反压：

| 候选 | 周期 | 相对 FCSR | 原因 |
|---|---:|---:|---|
| FCSR | 243 | 1.000x | 逐源退休，加同步读/响应 drain |
| Dynamic Frontier | 243 | 1.000x | 同一逐源完成时刻 |
| Nonblocking Stripe | 258 | 1.062x | 整行释放与尾部 drain |

结论：

- FCSR **不比公平 Dynamic 更快**，收益是消除运行时依赖追踪；
- FCSR 比当前强 Stripe 快 15 拍，即 5.81% 周期降低；
- Stripe 局部 producer stall 更少，但端到端尾部排空更长；
- 该数字是规则流 RTL，不是 post-G0 部署 trace。

## 7. 结构结果

共同 relation-transpose leaf：

| 候选 | `$mem_v2` | 解析数据状态 | flat cells | flat regs | flat mux |
|---|---:|---:|---:|---:|---:|
| FCSR-RX | 12 | 3465 bit | 10,914 | 3,876 | 6,067 |
| Dynamic Frontier-RX | 12 | 3465 bit | 50,387 | 4,028 | 22,721 |
| Nonblocking Stripe-RX | 13 | 4620 bit | 11,521 | 4,993 | 5,701 |

可辩护结论：

- FCSR-RX 相对 Stripe-RX：generic cells `-5.27%`、regs `-22.37%`、
  relation memory bits `-25%`，同步周期减少 15 拍；
- FCSR-RX 相对 Dynamic-RX 同周期，但 Dynamic 的五候选动态计数形成更大
  选择网络；
- FCSR 与 Dynamic 的寄存器数接近，但 Dynamic 的五候选动态访问形成更大的
  选择网络。

不可辩护结论：

- 不能把 FCSR 相对 Dynamic 的 `-78.34% flat cells` 写成目标工艺面积收益；
- Dynamic 应在 DC 中分别比较寄存器化、banked counter macro 两种实现；
- Yosys 打平 SRAM 的 cells 不能进入论文 PPA 主表。

## 8. 架构创新差分

FCSR-RX 的可辩护差异不是“用了 line buffer”，而是：

1. **拓扑编译的生命周期**：最后消费者由 stencil 与 raster 顺序闭式给出，
   不由运行时引用计数、预测器或稀疏搜索发现；
2. **关系所有权转换**：attention 按 destination 产生 gate，projection 按
   source 复用 K；五个 role bank 在 source frontier 上完成在线转置；
3. **逐源原子可见性**：只有完整 K、合法 incoming gates 和真实边界 mask
   同时可用时才提交 descriptor；
4. **有界状态与控制解耦**：关系状态由三行几何上界决定，控制状态不随窗口
   面积增长；
5. **拓扑相对地址生成**：六 bank 共享一个 source row-slot，邻接地址只做
   `prev/next/same`，不复制通用取模或地址变换。

与借鉴工作的边界：

| 工作/范式 | 借鉴 | 本土化差异 |
|---|---|---|
| streaming stencil | 三行数据驻留 | 转置的是 attention edge relation，不是卷积 operand |
| Prosperity | 先识别 exact reuse relation | relation 由拓扑编译，不用运行时 matcher |
| Bishop TTB | metadata-first、时间/空间打包 | 不做 ECP 或密疏双核；frontier metadata 是确定的 |
| Phi pattern/residual | 固定 pattern 与 residual 分离 | pattern 是五点拓扑和生命周期，不是 learned codebook |
| sparse outer-product | source 驱动 scatter | destination 集合固定且在 frontier 原子生成 |

## 9. DATE 贡献表述

建议 C2 写成：

> We propose FCSR-RX, a bounded-lifetime online relation-transpose
> architecture that compiles the last-consumer frontier of a fixed
> stencil into source-atomic retirement. It converts destination-major
> attention gates into source-major projection descriptors using six
> role-isolated three-row banks, without per-source runtime dependency
> tracking or a full relation plane.

中文口径：

> 提出 FCSR-RX 有界生命周期在线关系转置架构，将固定 stencil 的最后消费者
> 编译为逐 source 原子退休，在六个角色隔离的三行 bank 上完成
> destination-major gate 到 source-major projection descriptor 的在线转换，
> 无需逐 source 运行时依赖计数或完整关系平面。

不能写：

- “首次提出 line buffer”；
- “比所有 Stripe 更快”；
- “面积降低 68.25%”；
- “已完成 SRAM/DC/PPA”。
