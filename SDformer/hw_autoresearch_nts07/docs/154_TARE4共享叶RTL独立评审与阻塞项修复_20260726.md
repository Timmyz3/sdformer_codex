## 1. 评审结论

第二轮独立 ASIC RTL/DATE 评审结论为 **CONDITIONAL PASS**：

- 未发现 `delta_bounded_classifier` 或 `alpha_xnor_delta4` 的明确功能错误；
- 允许进入 composite top 开发；
- 不允许直接冻结接口、进入论文 PPA 主表或宣称 TARE-4 已成立；
- 准入前必须补强 raw 证据、握手、lane-ID 合同和跨叶等价。

本报告记录评审 finding 与修复，不替代 DC/STA/SAIF 或真实网络回放。

## 4. 当前接口合同

### 4.1 classifier

- 单级弹性寄存器；
- stall 时输出稳定；
- consume/refill 可同拍；
- downstream 持续 ready 时达到一拍一项；
- 每个 accepted 输入最终恰好提交一次，reset 明确清除在途项；
- ZERO 也提交，不允许静默删除；
- SPARSE 输出升序、唯一且属于原 mask 的最多四个 lane；
- DENSE 保留完整 mask/payload，只允许进入 direct replay。

### 4.2 delta4

- 有效 lane ID 必须两两不同；
- H67 与 Local5 都计算同一 alpha-XNOR lane 新旧贡献差；
- 输出 signed 10-bit；
- 不执行最终 RNE；
- 不接受 dense 项；dense 项由 classifier 隔离。

## 5. 仍未关闭

以下内容不能由合成随机 TB 替代：

1. H67 冻结网络的 bit-vector 已覆盖四 stage B0 单窗口；仍缺多样本、
   多窗口和全部 12 个 block；
2. composite 中至少 13-bit signed `anchor_raw + delta` 合同；
3. zero、sparse、dense 三路径的真实 ordered replay 与下游反压；
4. Direct32、Direct32x2、TARE-4 同一 SDC/SRAM 规则的 DC/STA/SAIF；
5. linear priority、分段 prefix、蝶形 compactor 的物理 PPA；
6. Local5 G0/G1 后 ordered STT 和四方向联合 burst。

因此当前状态是“共享叶 RTL 通过准入验证”，不是“可直接 DC 发文章”。
