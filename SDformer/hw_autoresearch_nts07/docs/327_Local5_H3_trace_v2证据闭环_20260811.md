## 3. trace-v2 合同

CSV 在 v7 十列基础上增加 `payload`：

```text
cycle,event,tile,head,source,lane,out,delay,index,origin,payload
```

离线 verifier 对每条 response-accept 精确检查：

- relation：`head/source/index/delay` 与 outstanding request 一致；
- weight：`tile/head/lane/out/index/delay` 一致；
- final：`tile/source/out/index/delay` 一致；
- available/accept 的 payload 十六进制串完全相同；
- relation/weight 允许 accept 因反压晚于 available，但不得提前；
- final accept 必须恰好位于首次 valid 后 `delay+1` 周期。

TB 内仍保留 valid/payload 反压稳定 `$fatal`，离线 verifier 是第二条独立证据链。
