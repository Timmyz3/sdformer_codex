## 已闭合链路

入口：

```text
profile_nts11_hardware_p0.py
  --bit-trace-samples N
  --bit-trace-windows 1
  --bit-trace-all-blocks
```

端到端驱动：

```text
sim_h67/run_h67_ep35_multisample_real_rtl_pipeline.sh
```

链路按顺序执行：

1. 绑定 ep35 config/checkpoint SHA 的真实 full-resolution inference；
2. 每样本采集 12 个 attention block 的首个 T450 window，Q/K 为真实 32-bit lane 位图；
3. 审计 NPZ SHA、Q/K/gate shape、四 stage 与 `12*N` record 覆盖；
4. 生成 `(sample,stage,block,head)` 可追溯的 138*N 行向量；
5. 用同一向量运行 Icarus 与 Verilator `--assert` 的 Fixed2S/RQTB2S 公平回放；
6. fail-closed 汇总逐样本与逐 stage 的周期、slot、exp，并从逐行日志审计 stall
   与 synthetic Acc32 mismatch。

最终证据：

- trace 审计：`results/h67_ep35_multisample10_t450_real_rtl_bit_trace_audit/audit.md`；
- 向量：`tb_h67/vectors/h67_ep35_multisample10_t450_real_rtl/manifest.json`；
- RTL 密封包：`results/h67_ep35_multisample10_t450_real_rtl_frozen_replay_20260815/`；
- 详细裁决：`docs/409_Motion_ep35十样本真实RTL闭合_20260815.md`。

## 准入边界

- 默认 `N=10`，允许 `2..16`；该范围是本机 watchdog 合同，不是统计充分性结论。
- 当前选择连续 valid 样本的第一个 window，不称分层抽样或全数据集 RTL。
- 输出目录存在即失败，禁止覆盖旧证据。
- GPU 使用超过阈值即返回 75，不抢占训练或算法评估。
- `gate_q17` 属于冻结 hardware-order trace；NPZ 中 projection INT8 权重仍是候选 dyadic 编码，不能据此声称真实权重 Acc32 已闭环。
- 该流水线补验证与实验完整度，不提高架构创新分，也不改变封存主表。
