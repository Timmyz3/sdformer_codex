## 1. 当前结论

论文只保留三个组合贡献，不把每个 RTL 子模块拆成一个“创新点”：

1. **Signed-source execution fabric**：把 multi-NZ/event execution 迁移到 H67 的 signed analog ATLIF source，以 typed descriptor、K8 issue、共享 Acc24 context 和 fault-closed completion 覆盖 Conv/FC/decoder。
2. **Exact parent/product capture path**：把 Prosperity/Phi 的 product/pattern reuse 迁移到 source-owned parent、dual-destination update 和有限 scratch/commit 约束，并报告机会到真实资源执行之间的 capture gap。
3. **Phase-decoupled neuron service**：把 resident event/neuron service 迁移到 analog ATLIF 的 rank/timestep 状态；是否进入主贡献取决于 Fixed-T10 同资源 VCS/DC 公平基线。

RQTB/attention 只作完整网络覆盖和局部能量点；M519 FC2 endpoint、M522/M523 decoder frontend 是贡献 1 的支撑，不各自单列 novelty。

## 3. “借机制”能否构成新工作

借用成立的最低条件是同时满足：

- **引用清楚**：Prosperity/Phi/FireFly-T/LoAS/ELSA/SNE/OpenEye/Chang & Chang/GANAX 的原机制必须放在 related work 和消融里；
- **对象变化**：binary spike/product pattern 变为 signed analog source、光流跨时刻状态或 ConvTranspose destination scatter；
- **硬件约束变化**：加入真实 bank key、端口、有限容量、backpressure、destination context 和 completion 语义；
- **证据变化**：同一 H67 trace 上给 VCS/SVA、新思面积时序、memory-inclusive cycle/energy；
- **公平对照**：与相同 product lanes、bank/port、SRAM capacity 的强基线比较。

只把公开结构换名称、换网络层或加 FIFO，不足以构成贡献。当前 M523 因尚无 flattened tap-weight bank key 和多 destination state adapter，严格限定为 descriptor support；这是主动避免“包装式创新”被审稿人击穿。

## 5. 完成时间与 DATE accept 门

乐观需要 **4 天**，保守需要 **6--8 天**：

- 1--2 天：关 M518/M519/M522/M523 和 exact decoder trace；
- 2--4 天：建立 decoder-complete、同资源、memory-inclusive 的 Fixed/bit/ours 周期表；
- 4--6 天：SRAM/DRAM 能量分解、matched SAIF/PTPX、跨序列或事件密度分层；
- 6--8 天：独立 DATE 模拟评审、claim registry、表格和 artifact 冻结。

DATE accept 的最低硬门是：至少一个同资源、非重叠、decoder-complete 的 full-network 总周期结果 `>=1.10x`，最好 `>=1.15x`；核心 RTL 有 VCS/SVA 与 DC/STA；能量明确拆成 logic/SRAM/DRAM；至少三条 sequence 或低/中/高密度分层。未达到时不靠局部 `2--6x` 包装系统收益。

## 6. 当前模拟评审判断

以现在已封存证据投稿，约为 `3.2--3.4/5`，仍是 borderline reject：硬模块和 soundness 足够，系统性能表、memory-inclusive energy、decoder 完整性和多序列仍缺。若上述 accept 门闭合且无身份污染，合理目标是 `3.6--3.9/5` 的 weak accept 区间；达到这一档不要求再造第四个 generic sparse matcher，也不要求把系统倍率做成 2--4x。
