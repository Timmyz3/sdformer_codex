# ISCAS 2027 C1/C2/C3 统一叙事与准入表（2026-09-01）

本文档冻结投稿叙事，不修改 `docs/359`，也不把组件结果扩张为全系统结果。主稿采用三个贡献点；TSBG 只能嵌入 C2，decoder/RQTB 只承担覆盖与兼容性，不另立贡献。

## 一句话主线

面向 signed-analog spiking optical-flow workload，设计一套共享 typed-source/Acc24 执行底座，并分别解决容量受限卷积中的 product capture、FC 中的并发与权重交付、以及 Fixed-T10 ATLIF 的精确时序服务；所有性能、面积和能量数字均按组件边界、同资源基线和证据类型分列。

## 三个贡献点

### C1：capacity-constrained exact product capture

- 对象差：在 240 KiB、单口 parent scratch、signed residual 和 dead-write 约束下捕获 product reuse，不把官方 Prosperity 的理想机会冒充本项目实现。
- final ep34 十样本、四层 bottleneck Conv3x3、51.84 M source-row 的同账本结果：`382,848,700` vs strongest-zero `648,741,051` cycles，即 **1.694510x**，modeled time **-40.99%**；相对 same-coordinate bit 为 **1.688968x**。
- 理想 concurrent-1R1W ceiling 仅作机会：`341,057,992` cycles；可落地单口点相对该不可物理化 ceiling 的 cycle tax 为 **12.2533%**。该税值定义为 `382,848,700 / 341,057,992 - 1`，不另造“理想收益保留率”。
- 物理锚点：28 nm、3.0 ns、9 个 128x128 1RW SRAM、面积 **166,514.312 um2**。M1740/M1742 已正式准入：Formality 为 16,549/16,549 compare points PASS；PrimeTime setup **+0.027871 ns**、hold **+0.001827 ns**、TNS 0、violating paths 0。该结果仍是 pre-layout、ideal-clock、ZeroWireload 组件证据。
- 能量锚点：M1789 独立打铁 `99/100, P0/P1/P2=0/0/0`。完整 mapped C1 top（含 9 个 SRAM Liberty leaf）在 ep34-density-conditioned 定向 `64-row / 253-cycle / 759 ns` 窗口下为 **29.0763016 mW**、**22.0689129144 nJ/window**；internal/switching/leakage 为 `26.660183/1.74465036/0.671468437 mW`。`u_parent_scratch` 层次为 **10.5071545 mW / 36.1%**。该点为 stdcell `TT 0.9 V 25 C` + SRAM `SSG 0.9 V 125 C` 的 mixed-corner 组件估计，ideal clock、ZeroWireload、无 SPEF；不是 energy/frame、system energy、single-corner signoff 或 silicon measurement。
- 边界：1.694510x 是 local same-ledger cycle model，不是 RTL cycle、full network 或 system speedup；pre-layout timing 不是 post-layout signoff。

### C2：typed-signed K8 shared execution fabric with TSBG delivery

- 基础织物：K8 对等带宽 K1x8 为 `1913/1945` cycles，即 **1.016728x**；logic area `130,476.905/585,534.972 um2`，即 **-77.7166%**；throughput/mm2 为 **4.562720x**。
- 正确写法必须把周期和面积效率放在同一句；禁止把 K8 对单 K1 的倍率写成稀疏收益。
- TSBG 定位：只复用 weight-row fetch，不误复用 typed-signed product；B4/B8 在多个独立 Acc24 context 前做 bundle broadcast。它是 C2 的 weight-delivery specialization，不是第四个贡献。
- TSBG 准入门：相对 ordinary persistent same-capacity row buffer，局部周期至少 **1.15x**；或者周期退化不超过 5% 且 weight bytes 至少降低 30%。B4/B8 的 Acc24/context/FIFO 显式下界分别为 1,216 B 和 2,432 B；control/tag、物理面积和能量未计价前不得称同面积。
- 当前状态：ep34 40-sample capture 已生成并封存 11,040/11,040 FC frames，872,855,874 个非零 FC code 均为 `+/-1`。M1763/M1775 的 layer-private 软件筛选中，B4 相对 ordinary persistent row buffer 的 weight fetch 下降 **65.20%**、roofline proxy **2.904x**；B8 下降 **80.20%**、roofline proxy **5.122x**，四条真实 sequence 的 B8 proxy 为 `5.09--5.14x`。这些仍是 screening-only，`same_resource=false`；首个简化 RTL 因未使用真实 M803 独立通道和 typed-signed 语义已被 M1781 判定 `FAILED_DO_NOT_RELEASE`，真协议 successor 必须通过 VCS/DC/PTPX 后才能升格。

### C3：exact Fixed-T10 ATLIF service

- 作用：证明统一底座不只覆盖 Conv/FC，并提供网络需要的 Fixed-T10 analog ATLIF 精确服务。
- 现有物理锚点：**63,756.126 um2**；DC setup/hold **+0.000300/+0.034585 ns**；PT setup/hold **+0.000299/+0.030474 ns**；11,180 mapped compare points PASS；17 cycles/tile。
- 边界：当前无公平 speedup，不在摘要中制造倍率；贡献落在 exact service、协议闭合和算子覆盖。

## 兼容性证据

- Decoder：作为 typed-source/Acc24 覆盖对象；D0 actual prefix 只报 diagnostic cycle model，8700-shard 完整 replay 未完成前不写 decoder-complete。
- RQTB/attention：attention 仅约 0.59% 旧 envelope，放在兼容性或能量消融，不当系统性能贡献。
- S2/CCBS16：本轮主稿默认排除。只有 paired 40-sample `delta AEE <= 0.02`、逐序列 `<= 0.03`、metadata `<= 2%`、同资源局部周期 `>= 1.15x` 且基线包含已准入 TSBG 时，才允许作为 C2 optional lossy mode；不得新增第四个 bullet。

## 收口顺序

1. C1 Formality + PT + public-port mapped VCS/SAIF/PTPX 已闭合；M1789 准入的能量只进 component table。SRAM datasheet 仍只作独立 alternative/sensitivity，不做 top-minus-macro，不得称 whole-chip 或 energy/frame。
2. TSBG 已完成 B2/B4/B8 真数据 screening；当前仅推进 B8 true-protocol same-resource successor，依次过 source hammer、VCS、DC 和 energy 门。任一门失败即降为访存机会消融。
3. 更新组件主表和 ISCAS 图表；decoder 长 replay 继续后台，不阻塞组件稿。
4. TSBG 过门才进入 C2；未过门则冻结 C1/C2/C3，不再开新机制。

## 禁止表述

- “全网/系统 1.69x”或“RTL 实测 1.69x”。
- “K8 稀疏加速 4.56x”；4.56x 是等带宽 throughput/mm2。
- “TSBG production result”或“代表性功耗”，直到真数据分析和 mapped PTPX 分别通过。
- 将官方 Prosperity、理想 ceiling、组件周期或面积效率相乘。
- 将 pre-layout/ideal-clock/ZeroWireload 结果写成 post-layout、silicon 或 paper-PPA-ready。
