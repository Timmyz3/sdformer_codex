# H63: Symmetric-ATLIF Direct-Shiftmax Attention Protocol

Status: completed negative; no candidate promoted
Scope: DSEC only, full encoder, all 12 attention blocks

## Frozen constraints

1. Every installed neuron uses a symmetric threshold rule.
2. Attention is uniform across all 12 encoder blocks. No stage-wise or TX/SC mixture is allowed.
3. The primary candidates do not form `gate * K` and do not use K as a value/carrier stream.
4. No K-magnitude correction, target-rate controller, runtime mu schedule, or native QKFormer carrier is enabled.
5. Existing modules and historical experiments remain intact; implementation is additive and config-gated.

## Neuron semantics

- Symmetric ternary ATLIF: `h >= theta -> +theta`, `h <= -theta -> -theta`, otherwise zero.
- Symmetric binary ATLIF: `abs(h) >= theta -> theta`, otherwise zero. This is a one-bit magnitude event generated by equal positive and negative thresholds. The sign is intentionally not transported.
- Dense bipolar binary `{-theta,+theta}` is rejected without a run because its event activity is 100% by construction and cannot satisfy the spike-reduction objective.

The existing `official_atlif` binary path is a one-sided `{0,+theta}` emitter and therefore remains a historical TTX reference, not a valid H63 symmetric-neuron candidate.

## Direct-Shiftmax attention

For each token and head, split `head_dim=32` into `G` channel groups. For each group, form a pure binary TX score from equal-position Q/K events:

```text
binary score_g  = count(q=1 and k=1) + alpha0 * count(q=0 and k=0)
ternary score_g = count(q=k=+1 or q=k=-1) + alpha0 * count(q=k=0)
gate_g  = Shiftmax(score_g over tokens) * num_tokens - 1
output_channels_in_group_g = gate_g
```

The output is produced directly by Shiftmax and broadcast only within its group. It is not multiplied by K. The following projection and symmetric ATLIF remain unchanged.

The ternary score is still pure TX: opposite-polarity events contribute zero rather than an SC-style negative penalty. Positive-positive and negative-negative matches have identical weight.

STC uses the same TX evidence on both axes; it is not a TX/SC or stage-wise mixture. `G=8/32` are held and will run only if G4 is close to the promotion gate with a clear channel-capacity limitation.

## Evaluation and promotion gates

Common warm start: current DSEC TTX best epoch2 checkpoint. Each candidate must pass:

1. Chain smoke: `ATLIFTernaryPSN=105`, attention patches `=12`, saved checkpoint reload has `missing=0`, `unexpected=0`, and overlay keys match.
2. Activity smoke after 20 steps: global activity below 20%; otherwise stop as structurally incompatible.
3. 120-step train + valid10. Only candidates with valid10 AEE <= 2.2 and no NaN/Inf continue.
4. 360-step train + valid40. Promotion requires AEE <= 1.65 and a downward training trend. This is a proxy gate, not a paper result.
5. Full DSEC training is allowed only for the best valid40 candidate. The paper result must use standard valid825 and target AEE within 5% of NB0 while reducing total spikes by at least 20%.

If all direct candidates fail, the only permitted fallback is a uniform all12 dyadic shift-value path derived from BSA: Shiftmax powers-of-two shift the event/value stream. It must be reported as a fallback because it reintroduces a value carrier, although it uses shifts rather than general multiplication. No TX/SC mixture will be revived.

## Pre-screen recovery rule

The unscaled TTX warm start uses one-sided thresholds at `theta=1`. If switching to symmetric-binary magnitude events makes every direct candidate exceed 20% activity before training, the shared failure is attributed to neuron calibration rather than attention. In that case exactly one offline calibration is allowed: multiply all 105 loaded thresholds by 4, based on the prior BTTX-A4 observation that a magnitude-4 negative threshold restored activity to the TTX range. This is a fixed checkpoint transform, not a scale sweep or runtime target-rate controller. The transformed checkpoint must retain 210 overlay keys and reload with `missing=0, unexpected=0`.

If centered direct output (`gate-1`) fails through dominant negative firing, one raw-Shiftmax STC control is allowed because it matches the requested semantics literally:

```text
Y = 0.5 * (Shiftmax_N(token_score)*N + Shiftmax_D(channel_score)*D)
```

It adds no parameter and removes the subtractors. G4/G8 raw variants are not allowed unless raw STC first passes the activity gate.

## Literature basis

- QKFormer (NeurIPS 2024): linear spike-form Q-K token attention, but still gates K.
- Spike-driven Transformer (NeurIPS 2023): multiplication-free dynamic Q/K/V interactions via mask and addition, but changes the block to a QKV path.
- SpikeVideoFormer (ICML 2025): linear Hamming attention retains a V stream and has already shown weak DSEC valid40 results in H21/H35.
- Bipolar Self-Attention (NeurIPS 2025): ternary QK and Shiftmax, but applies Shiftmax weights to V through shifts.

These papers support integer/event score generation and shift-friendly normalization, but none establishes that a scalar normalized score alone preserves a full head feature. H63 therefore tests grouped direct output explicitly instead of claiming that equivalence.
