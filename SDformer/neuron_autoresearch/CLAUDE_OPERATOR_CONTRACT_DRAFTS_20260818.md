## D1：Motion T>2 时间商（Tetra/Quintuple Time Quotient）

**合同一句话**：时间商从 pair 变成 T=5 五元组（备选 T=4+pad12），每个时间槽位分数用规范融合式
`s_t = min(RNE16(64·o_t + sz_t + 16·m̄_t), 162)` 冻结，m̄_t 为窗口内运动边均值（m_t = popcount(K_{t-1}⊕K_t)）。

### 数学定义

- 窗口 (5,15,15)=1125 tokens（备选 (4,15,15)+pad12=900+180 pad）；SNN num_steps=10 → T=5 无 pad（10%5=0），位置编码 T 维按 5-slot 窗口重排
- 每个时间槽位 t：q_t=popcount(Q_t), k_t=popcount(K_t), o_t=popcount(Q_t&K_t), sz_t=32−q_t−k_t+o_t（容斥界约束：max(0,q+k−32)≤o≤min(q,k)）
- **规范融合式**（验证 I1 实测发现：拆解式 RNE16(64o+sz)+m̄ 与融合式在 RNE 平局商奇偶翻转处差 1 档，全域 2.74%；合同钉死融合式为唯一规范，硬件实现与部署必须同式）
- 槽位分解 `s_t = 4·o_t + r_t`，r_t∈{0,1,2} 唯一（验证 I2：物理域内无 s%4==3）
- 归一化对象：时间维 run-length 广播。eq 率 0.979（H82 rank-1 锚点）下 E[独立门/位置]：
  T=4 → 1.063/4（−73.4%），T=5 → 1.084/5（−78.3%）（验证 I6）

### 与现网合同的严格区别

| 维度 | 现网 H67 (2,15,15) | D1 (5,15,15) |
|---|---|---|
| 时间商结构 | pair (Q_t,K_t, K_t+1) | 五元组，4 条运动边 m_t |
| 分数对象 | 单分数含 16·m | 每槽 s_t = RNE16(64o_t+sz_t+16m̄_t) |
| 可见时间边 | 5/9 = 55.6% | 8/9 = 88.9%（验证 I7） |
| 存储对象 | RQTB pair 商 | 5-slot 时间商文件 |

### 新存储对象

**5-slot 时间商文件**：每位置 5 个 (o_t, sz_t, m_t) 记录，分数从记录精确重建（验证 I5：记录→分数双向可逆，物理域内反解 (s−m̄)→(o,r) 完全唯一）；motion 边 4 条与 H67 的 16·m 项兼容。

### 新执行对象

**时间维 run-length 广播执行**：eq 边（P(s_t==s_{t+1}|eq)=1）下的同一 Q7 类码沿 T 广播，每位置独立门数 1.084/5（eq=0.979）——广播执行器替代逐槽位执行。

### 硬件友好性论证

- 门数/exp-add 流量直接降 ~78%（位账见下）；Q7 163 档网格与现网相同，RNE16 融合式已在 RTL（analyze_binary_temporal_pair_arch）中存在，仅扩展 4 条运动边为 4 槽
- 硬件只新增"run-length 判定 + 广播"两条流水，无新算力路径

### 验证实验设计（可证伪）

1. **short 训练**（seed 0，不混 MDR/MVSEC/transfer 表）：窗口 (5,15,15) 同配置 short 跑通，标准 = loss 曲线形态与 T=2 基线同量级（不塌、不减半退化），step-1k 后 loss 单调下降
2. **全量 fullres ft**：valid825 对比锚点 Motion 1.3297@ep35 —— 通过标准 = AEE ≤ 1.3297·1.01 或下降
3. **运动边分布 dump 裁决**：rank-1 带 Q 标签 dump 实测 T=5 槽位分数 RLE 广播率 vs Bernoulli 界（验证 I6b 的独立假设）
4. **硬件位账（初步）**：eq=0.979 下 5 槽位广播 → 每位置独立门 1.084 个 vs 5 个 → 门存储/广播流量 −78.3%；时间边覆盖 +33.3pt（55.6%→88.9%）不增存储（m_t 边 4 条 × 5bit 与现网 1 条 × 5bit 相比，每窗口净增 15bit/1125 tokens，<2% 存储增量）

## D2：跨窗语义（Overlapping Sliding Window + Rolling Partition Function）

**合同一句话**：SWIN 非重叠 tile 改为 stride-12/窗口-15 重叠滑动窗（36% token 重叠重数 mult=2，90 token/窗边共享带），归一化分母用滚动恒等 `Z_{i+1} = Z_i − Σ_leave + Σ_enter`（整数幂和逐位精确），共享 token 身份成为跨窗 quotient 目录的机制基板。

### 数学定义

- 1D 重叠分区 `window_partition_overlap(total, 15, 12)`（含尾部 pad）；窗口链 (5 时间 × 4×4 空间)
- 滚动分母：Z = Σ 2^{s(m)} 整数幂和（验证 J1：增量式与全量重算逐位相等）
- 门集成恒等：Σ_t g_final(t) == #windows，等价形式 Σ_t mean(t)·mult(t) == #windows（验证 J2+J3，有理数 Fraction 精确）
- 类集下界：J(A,B) ≥ |classes(shared band)|/|A∪B|（验证 J4：合成 Motion C 分布 300 窗链恒成立，mean J=0.948 vs 现网 lag1 pooled 0.650）
- 目录贡献账：相邻窗目录交集中 55.0% 类码由共享带携带（验证 J5）

### 与现网合同的严格区别

- 现网 window_partition_v2 要求 D%window[0]==0、非重叠 tile，跨窗零共享（round2 否决"跨窗 quotient 持久"的身份死穴）
- D2 把"共享 token"写进合同：共享带 Q7 码按构造相同（J2），身份基板直接支撑硬件跨窗目录（J=0.84 类集持久）

### 新存储对象

**跨窗 quotient 目录**：共享带类码 + 目录差分（Δcatalog = 进出带类码增量）；每窗边 90 token 的身份码（3 条 x 带 + 3 条 y 带 × 15）持久化，目录写成本从 round2 实测 <1% 变为合同内稳定账。

### 新执行对象

**滚动分母增量执行器**：每新窗只重算 2×15×3=90 token 进入带的 exp 项（270/窗）而非 450 全量（验证 J6：exp-add 总流量 −4.8% 净；窗口数 +58.7% 被增量抵消）。

### 硬件友好性论证

- 增量流量 40% 带宽节省（450→270 exp-term/窗），Z 逐位精确无需近似；门集成恒等保证归一化无偏
- 目录读命中以身份类码为下限（J5），跨窗共享从"统计机会"变"合同保证"

### 验证实验设计（可证伪）

1. **short 训练**（seed 0）：重叠窗 short 跑通，loss 不塌标准同 D1
2. **全量 fullres ft**：valid825 对比——注意对比口径重建：Swin baseline 论文以非重叠 tile 报告，需同时报 dense 与 overlap 两版；通过标准 = overlap 版 AEE ≤ dense 版 × 1.02（含 1.01 训练方差）
3. **硬件位账（初步）**：窗口数 520→825（+58.7%），每窗 exp 项 450→270（−40%）；目录增量读 ≥55% 交集类码来自共享带（J5），跨窗目录持久账 = 共享带身份码 × 重数 2 的下限

**风险（排序考量的关键）**：改 Swin 分区本身 → baseline 对比口径要重建；计算量 +58.7% 窗口数（增量后净 exp 流量 −4.8% 但 token 处理总量上升）。

## D3：各向异性 stencil（A3S, Axis-Aligned Anisotropic Stencil）——Local5 线

**合同一句话**：Local5 的 5-lane stencil 分数加方向场偏移 ±Δ（Δ=1/16 = 8 个 1/128 网格档，网格精确位移），方向场 = 3×3 时域 XOR 梯度 argmax（2bit/pixel），对齐 lane +Δ、正交 −Δ，把"唯一门"从 1 组 ident-K 分裂为对齐/正交类。

### 数学定义

- 分数网格：Q7 1/128，LO=−2, HI=2；位移与分数量化 commute（验证 K2：200 组 clamp 外逐位相等）
- Δ=0 锚点恒等：A3S(Δ=0) 与现网 Local5 门逐位一致（验证 K1：10 组随机平面 torch.equal 通过）——消融与回滚锚点
- 方向场语义：匀速移动条 → 3×3 时域 XOR 梯度 argmax 对齐运动轴（验证 K3：E/W 轴 76-85%）
- 各向异性生效指标（验证 K4 实测修正）：2^s 门动态范围（s∈[0,1] 归一化后，max 2x）下**门质量再分配天然有界**，诚实指标为 **对齐 lane 量化分数 argmax 命中率**：自匹配平面（对应现网 q/k 高度相关 79.36%）运动承载像素上 91.2% vs 基线 0.0%
- ident-K 唯一门分裂（验证 K5：11250 个 ident-K 目的地全部从 1 组 → 3 偏移类 {self 0, 对齐 +Δ, 正交 −Δ}；折叠 self 进正交为 2 类权重）

### 与现网合同的严格区别

- 现网 Local5：5-lane 分数无方向偏好，ident-K 目的地唯一门（71.6% 非静默）
- D3：方向场把唯一门按运动轴分裂为对齐/正交两类（+Δ/−Δ 权重），gate-plane class 随运动方向分化

### 新存储对象

**方向场位图**：2bit/pixel（E/W/N/S 码）+ 对齐/正交双权重槽（Δ 固定参数，无需训练）；大小 2×15×15=450bit/窗口，<1% 现网存储增量。

### 新执行对象

**方向感知唯一门执行**：ident-K 目的地从 1 个唯一门 → 3 个偏移类（对齐 lane +Δ 类、正交 −Δ 类、self 0 类），raw16 广播 ×2（诚实成本已记账，验证 K5）；非 ident-K 目的地方向场 2bit 查表决定 lane 分组。

### 硬件友好性论证

- 无新乘加路径：方向场 = 时域 XOR popcount（现网 _binary_temporal_k_xor_popcount 已有）+ 3×3 空间差分 argmax（2bit 比较器 ×4）；偏移 = 固定 ±Δ 网格位移（与 Q7 量化 commute，验证 K2）
- Δ 可注入式训练（Δ=0 起调渐增），硬件参数完全复用 Local5 流水

### 验证实验设计（可证伪）

1. **short 训练**（seed 0）：现网 Local5 配置 + A3S，Δ 从 0 渐增至 1/16；loss 不塌标准同 D1；Δ=0 组必须与现网逐位等价（K1 锚点）
2. **全量 fullres ft**：valid825 对比锚点 Local5 1.2819@ep44 —— 通过标准 = AEE ≤ 1.2819·1.01 或下降
3. **C1 统计平面 dump 裁决**：方向场与 q/k 相关（q1[p+1]==k1[p] 79.36% 平面）的对应一致率，裁决方向场是否随运动语义收敛
4. **硬件位账（初步）**：ident-K 71.6% 目的地从 1 组唯一门 → 3 偏移类 → gate-plane 每目的地 +1 slot；raw16 广播 ×2；方向场 450bit/窗；总增量 <3% 现网 Local5 位账

## 排序推荐：D1 > D3 > D2

1. **D1（首选）**：round2/433 点名的唯一可证伪 4.0 类别——T>2 时间关系是现网 pair 合同的直接扩展、不动 Swin 架构、对比口径不变（valid825 锚点 1.3297 直接可比）；eq=0.979 下位账最强（广播 −78.3%），存储增量 <2%；CPU 恒等已全过（I1-I7），RNE 融合式规范是硬合同发现
2. **D3（次选）**：训练风险最低（Δ=0 逐位恒等锚点 + 可注入式训练），与 C1 统计平面正交；但创新幅度是"分数微调"级别——诚实指标修正为 winner 命中率（门质量再分配受 2^s 动态范围约束有界），对 4.0 的支撑强度弱于 D1
3. **D2（第三）**：433 价值最高（身份死穴的机制基板，跨窗目录从统计机会变合同保证）但验证成本最高：改 Swin 分区 → baseline 对比口径重建 + 窗口数 +58.7%；建议作为 D1 之后的第二轮候选（硬件跨窗目录配套）

**执行约定**（沿用队列文档）：seed 0；不混 MDR/MVSEC/transfer 表；short 验证先过再 fullres；GPU 队列一次一个任务，与 DATE 缺口审计 agent 协调。
