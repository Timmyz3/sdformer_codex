## 二、路线演进与关键发现

### 路线 1: E 系列 (完整神经元替换) → **死胡同**

```
E1(SN)  → E2(ATLIF)  → E3(LMHT)  → E4(TS-LIF)  → E5b(TSN)  → E6(NASN)
全 smoke   AEE 2.5-8.7  SOPs 9.7G   AEE 2.18       AEE 29.8    AEE 2.17
                                                    SOPs 25.9G   SOPs 33.3G
```

**结论: 15 次全替换, 0 次成功。** 最好的是 E4 (AEE +38%, SOPs +11%), 差距太大。SDformerFlow 的 PSN + 事件箱范式与所有已知神经元开源实现不兼容。

### 路线 2: G→H 系列 (部分插入 + 门控) → **最佳路线**

```
G1 (6 节点门控)           → 25% SOPs ↓, 仅 1.3% AEE ↑
H1 (36 节点门控扩展)       → 25% SOPs ↓ 但 AEE 崩塌 (2.67)
H3 (Q/K ATLIF 二元)       → 6% SOPs ↓, 精度保持
H4 (Q/K ATLIF 三元)       → 4% SOPs ↓, 精度改善 (AEE 1.54)
H6a (三元 attn + 二元 FFN) → 9% SOPs ↓, 精度改善 (AEE 1.55)
H8 (逐 block FFN 搜索)     → 进行中
```

**关键洞察:**

1. **部分插入 > 全替换**: G1 只改 6 个节点比 36 个节点的 H1 效果好得多
2. **三元只适用于 attention**: H4 Q/K 三元有效, H5 扩展到 FFN 就爆炸 (负脉冲泛滥)
3. **二元适用于 FFN**: H6a 证明 attention 三元 + FFN 二元是目前最佳组合
4. **全参数训练 > gate-only**: H6a 全参数训练比 H1 gate-only 训练精度保持更好
5. **A5 不应期的教训**: 硬性约束 (阻断发放) 不如软性约束 (阈值惩罚) 有效

### 路线 3: A 系列 (我引入的) 

```
A5 (不应期) → 完全失败 (SOPs +237%, AEE +494%)
A1 (FSN on G1) → 配置完整, 未跑
A6/A8 → 配置完整, 未跑
```

**A5 失败根因**: 不应期在 10 步序列中强制静默 k 步 → 剩余 10-k 步加倍发放来补偿。
