# 双线创新再筛选：Dyadic Gate 强基线否决与下一边界

## 1. 本轮裁决

本轮不改 `docs/359`、`docs/362`、`docs/366` 的封存主表，也不新增周期主张。

- Motion：MSSB5 经 SSR5 强基线纠偏后，只作为 RQTB 的 score-front CSE 支撑，
  不单列架构贡献；封存 `112589/94891/34099/28001` 不变。
- Local5 source-owned Q-silent wavefront、ECGB、digit-serial gate、leftover 第三路
  均保持 NO-GO。
- Local5 dyadic gate recoding 最终裁决为
  `NO_GO_AS_DATE_CONTRIBUTION / HOLD_AS_IMPLEMENTATION_OPTION`：先不写主线 RTL，
  只有将来同 SRAM/SDC/SAIF 证明其打赢 pinned-four 强基线时，才可作为电路消融。

## 2. Dyadic Gate 真实结构

候选利用 Q1.7 gate 的经验集中性：

```text
16/32 -> W << 4/5
15/31 -> (W << 4/5) - W
other -> exact multiplier fallback
```

在 sample-disjoint、stage-weighted 的 100-group 真实权重包中：

| gate 类 | term | 比例 |
|---|---:|---:|
| `16/32` shift-only | 52963 | 71.4451% |
| `15/31` shift-minus-W | 21123 | 28.4942% |
| exact escape | 45 | 0.0607% |

四码覆盖 `99.9393%` term 和 `99.9925%` relation entry。对全部 512 个 gate 与
256 个 signed INT8 weight 的 `131072` 组整数输入，宽路径软件等价检查 mismatch 为 0。
这只证明算术变换可 exact，不证明其是新架构或物理 Pareto。

## 3. OUT_DIM=2 强基线拆账

现行生产 tile 是 `OUT_DIM=2`，因此正文筛选只用 OUT2；OUT32 仅保留敏感性。

| 系统边界 | T450 relation/K + product state bit | 相对 raw+W4 |
|---|---:|---:|
| raw relation + W4 LRU | 42822 | 1.0000x |
| raw relation + dyadic arithmetic | 36900 | 0.8617x |
| symbol relation + dyadic arithmetic | 21480 | 0.5016x |
| symbol relation + pinned-four product | 24834 | 0.5800x |

这张表隔离了三种效果：

1. `raw + dyadic` 相对 W4 的变化主要是去掉 product cache；
2. `symbol + dyadic` 相对 `raw + dyadic` 的新增作用只来自 relation/K 存储对象
   `36900 -> 21480 bit`；
3. pinned-four 使用相同 3-bit symbol，但为每 lane 固定保存四个 13-bit common
   product。它只比 dyadic 多 `15.61%` 系统存储，却把公共 shift/sub 从每个 term
   执行改为每个 weight epoch/lane 预生成。

100-group OUT2 活动代理：

| 指标 | W4 LRU | pinned-four | dyadic |
|---|---:|---:|---:|
| data-array bit | 2609430 | 2147276 | 751984 |
| weight read bit | 88976 | 30096 | 751984 |
| product read bit | 2331380 | 1926236 | 0 |
| product write bit | 189074 | 190944 | 0 |
| vector subtract active | 0 | 3672 | 21123 |
| exact multiplier start/escape | 5561 | 45 | 45 |

`751984/2609430=0.2882x` 只是未加能量系数的数据阵列 bit 代理。它未计
decoder、shift/sub、escape lookup、时序寄存器和 SRAM 每 bit 能量；同时 dyadic 的
weight read 是 W4 的 `8.45x`。因此不能由该比值宣称能量优势。

## 4. 泛化与 exact 边界

四码不是 Shiftmax5 合法输入域的定理：RTL 接受一般 Q7 score/valid 组合，输出 gate
可远超四码或八码。现有集中性是冻结 checkpoint/workload 的经验性质。

| cohort | group | 四码 term 覆盖 | relation 覆盖 | group escape max | 裁决 |
|---|---:|---:|---:|---:|---|
| sample-disjoint population-v3 | 100 | 99.9393% | 99.9925% | 15 | conditional |
| stage-balanced 旧包 | 100 | 99.9532% | 99.9972% | 3 | conditional |
| sample100-v2 | 100 | 99.7238% | 99.9897% | 8 | NO-GO by preregistered 99.9% gate |
| post-G0 全量 profile | 4800 | 99.9433% | 99.9945% | 63 | conditional |

全量 4800-group profile 实际出现八码：
`13/14/15/16/28/29/31/32`。扩码表可以覆盖该 profile，但不能证明覆盖所有合法
输入，只会把四码后验拟合扩成八码后验拟合。100-group sidecar 的 max=15 也被全量
max=63 证伪；架构 exact 必须采用无损 spill、whole-frontier raw fallback 或合法域
容量上界，不能按 profile max 静态声称 exact。

此外，`docs/68` 已明确把 gate-code CSD product generator 定位为电路/微结构消融：
常系数移位加减本身不是 DATE 架构创新。

## 5. 为什么不进入主线 RTL

该候选当前只改变 relation 字段宽度和消费端常系数乘法；FCSR 拓扑、source-major
顺序和 TCFM5 退休边界均未改变。最危险的 pinned-four 基线尚未被物理结果击败，
而且候选不能从合法数值合同推出固定码表。

因此本轮不实现：

- 不写 symbol relation 主线 RTL；
- 不写第三套 escape cache；
- 不把四码/八码命名成新架构；
- 不把容量、bit activity 写成周期、能量、ASIC PPA 或 encoder 收益。

保留模型和单测作为未来 DC/SAIF 电路消融入口：

- `scripts/model_local5_dyadic_gate_projection.py`
- `scripts/test_model_local5_dyadic_gate_projection.py`
- `results/local5_dyadic_gate_projection_screen_20260814/`
- `results/local5_dyadic_gate_projection_full4800_20260814/`
- 两个 100-group holdout 结果包。

## 6. 下一项创新筛选边界

Local5 下一问不再是“怎样编码 9-bit gate”，而是：

> 能否让 `Shiftmax5` 的五路 destination gate 通过有限行 rolling inverse-stencil
> 直接变成 source-major 流，在保持 hardware-order 与 TCFM5 退休顺序的条件下，
> 消除当前 T450 relation materialization？

只有满足以下条件才继续：

1. 与当前 T450 FCSR、三行理论下界和同端口 destination-major 强基线比较；
2. 存储对象从全窗 relation 变为有证明上界的 rolling live frontier，而不是换名；
3. 每条合法 relation 恰好一次、边界 mask 和双 time-plane 顺序可证明；
4. 真实 trace 下无额外排序气泡，并接到 source-major term/TCFM5/Acc32；
5. 若 `docs/208` 已经完整实现同一合同，则停止，不重复造轮子，只补当前缺失证据。

Motion 下一轮不再扩 score CSE。可提升创新性的候选必须把 RQTB quotient 继续保持到
新的存储或调度边界，并且保留 destination identity；class-wise K folding 与公共 K
子向量小收益旧候选继续否决。
