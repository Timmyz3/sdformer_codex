# 双线活动时间轴与SAIF身份P0闭合（2026-08-14）

## 裁决

本轮只关闭功耗证据链P0，不增加架构机制，不修改`docs/359`。

- Motion两份VCD可作为目标PTPX的`paper_power_compute`输入候选；它们尚不是功耗结果。
- Local5 full VCD可作为`paper_power_with_io`输入候选；busy-only VCD仅作阶段活动诊断。
- 本机无`vcd2saif`、`dc_shell`、`fm_shell`或`pt_shell`，因此仍无SAIF、DC、STA或PTPX数字。

## Fail-Closed合同

`report_activity_vcd.py`现在要求：

1. workload索引唯一、连续、完整；Motion和Local5分别命中冻结账本；
2. 日志无`ERROR/FATAL`且恰好一条PASS；
3. VCD存在真实层次、timescale、翻转和`dump_active`；
4. `dump_active`积分时长精确等于`measured_cycles * clock_period`；
5. 论文功耗合同只有一个连续活动区间；
6. Motion只接受`paper_power_compute`，Local5 full只接受`paper_power_with_io`。

VCD转SAIF后，manifest必须携带实际activity-contract、源VCD和trace路径。生成端与审计端
均重新计算contract/VCD/trace SHA，并比较关键字段；占位哈希或脱离源文件的manifest失败。
PTPX后还必须满足唯一可解析的SAIF coverage sentinel和零未注释对象。目标PT若格式不同，
应适配解析器而不是放宽准入。
