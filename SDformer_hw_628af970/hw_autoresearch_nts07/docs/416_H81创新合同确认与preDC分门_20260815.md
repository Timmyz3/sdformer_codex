## 2. component-pre-DC 和 paper-system 分开：同意，但要钉标签

分开是对的。完整 block / encoder 不应挡住组件去服务器跑 DC。

必须同时钉死：

- component-pre-DC **不是**「只差 DC 就能投稿」。它只证明切片可综合、可等价、可带活动。
- `MEMORY_IMPL=0` / `ACC_MEMORY_IMPL=0` 的结果只能标 **`pre-macro` 逻辑 DC**。`PPA_ADMISSION=1` 在没有 `MACRO_DBS`+`EXPECTED_MACRO_REFS` 时失败，这是对的，不要绕开。
- 组件数值边界：周期可用已封存公平 VCD；功耗必须匹配层次的真实活动，不能只用 Acc32 checksum 自称 paper power。
- 分门不抬创新分。component-pre-DC 过了，Motion 仍是 3.2，Local5 仍是 3.1。
