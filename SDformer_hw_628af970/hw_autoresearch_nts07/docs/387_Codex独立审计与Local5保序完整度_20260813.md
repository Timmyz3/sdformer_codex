## 2. P0 SVA 修复

原 tile assertion bind 仍引用已从 RTL 删除的 `active_metadata_valid_q`，因此旧 `obj3` 回放不能证明当前源码可通过断言编译。

修复内容：

1. seal 仅允许在 `meta_count_q==0 && !score_out_valid` 时发生；
2. metadata 非空时，`score_out_ready` 必须等于 `backend_relation_ready`；
3. `score_out_valid` 必须伴随 metadata；
4. `meta_count_q<=2`；
5. 没有把旧单槽信号加回 RTL。

结果：当前源码 fresh `Verilator --assert` 编译通过，S3.B0 24-group 回放仍为 53084，score/gate/Acc32 零失配，无 assertion error。该数字不是新性能结果。

## 3. 重叠开关与机制消融

新增独立 `ENABLE_OVERLAP`/`ARCH_QSILENT_OVERLAP` 开关，默认值为 1，保持现行重叠行为。使用同一 100-group、真实 checkpoint theta-folded INT8 权重、TCFM5 latency-1 向量进行五配置消融：

| 配置 | Q==0 | ident-K | overlap | 周期 | 相对 residual |
|---|---:|---:|---:|---:|---:|
| residual | 0 | 0 | 0 | 324605 | 1.0000× |
| Q==0 serial | 1 | 0 | 0 | 191424 | 1.6957× |
| Q==0 overlap | 1 | 0 | 1 | 188014 | 1.7265× |
| Q==0 + ident-K serial | 1 | 1 | 0 | 184632 | 1.7581× |
| Q==0 + ident-K overlap | 1 | 1 | 1 | 183379 | 1.7701× |

边界：

- `191424` 精确复现 Q==0-only 封存快照；
- `184632` 的证据身份是关闭 overlap 的 ident-K 级联；
- overlap 对 Q==0-only 的额外周期改善为约 1.8%，属于工程流水支撑，不是独立 DATE 创新；
- `183379` 是新旁路消融，不替代 1.6957×、1.7581× 或十二窗 1.770×；
- 所有配置均完成 100-group score/gate/Acc32 检查，报告器强制 100 个连续 group、唯一 PASS 终态和封存锚点匹配。

## 4. Issue-order 与随机反压

叶模块新增两类保序检查：

1. `emit_fast` 只能在 fast 类型位于 retire head 时发生，`emit_base` 同理；
2. 独立两槽 tag shadow FIFO 必须与 RTL retire queue 计数和退休 tag 一致。

随机反压运行 8 个 seed，每个 seed 512 笔 residual/Q==0/ident-K 混合事务，共 4096 笔。结果：

- issue 4096，retire 4096；
- retire tag mismatch 0；
- 每个 seed 覆盖 153 到 206 个 output stall；
- 每个 seed覆盖 171 次 overlap accept；
- `Verilator --assert` 全部通过。

这是协议完整度证据，不是性能或创新数字。

## 5. 证据解析 fail-closed

本轮修复四处静默容错：

- Motion miter 要求 `FAIR_ROW` ID 从 0 连续、唯一、有序；
- Local5 leftover 四个 memh 必须等长且非空；
- leftover stage table 继承并校验输入决策，不再硬编码 `REJECT_WRITTEN`；
- DATE 双线表实际读取并锁定 Motion、Local5 100-group 与十二窗 JSON，不再只硬编码 Local5 字符串。

强化解析器重放后，Motion 仍为 28001/28001，Local5 仍为 2014/369/1279/308 和 `REJECT_WRITTEN`。

## 6. DATE 口径判断

本轮提升的是实现与验证可信度：

- 修复当前源码断言不可编译的 P0；
- 分离 Q==0、ident-K 与 overlap 的真实贡献；
- 补齐双槽有序退休在随机反压下的证据；
- 消除证据解析器静默补零和硬编码风险。

本轮没有形成新的架构主贡献。Local5 的可投稿主张仍是利用 Q==0 与相同 K 的代数可判定性，绕过 residual AXNOR walk，并保持 Shiftmax5、relation 与 Acc32 的 hardware-order exact 语义。普通双槽、FIFO、overlap 和断言不能单独列为贡献。

尚未闭合的硬缺口：

1. 同约束 DC/STA/SAIF 与 SRAM 宏规则；
2. Local5 多样本完整 window 分布，而不是 sample0 十二窗；
3. `OUT_DIM=2` tile 到完整输出通道、12-block encoder 的系统 Amdahl；
4. Local5 相对强架构基线的数据搬运、SRAM 访问和能量分解。

## 8. 独立 DATE 复评

subagent 审稿结论：**3/5，Borderline Reject**。

| 维度 | 分数 | 判断 |
|---|---:|---|
| 架构创新性 | 3.0/5 | Motion 较强；Local5 有领域特化价值，overlap 仍是常规流水技术 |
| 工作量 | 4.5/5 | 双线 RTL、真实 trace、消融、SVA 和口径审计超过玩具原型 |
| 验证可信度 | 4.0/5 | 已关闭已知保序缺陷，但 assertion-based simulation 不是 formal proof |
| 实验完整度 | 2.5/5 | 无同约束 PPA，Local5 仍为 `OUT_DIM=2`，部署外推弱 |
| 工程完整度 | 4.2/5 | 控制、开关、反压和拒混证据较完整 |

最严重的拒稿点：

1. cycle 公平尚未转化为同频率、同面积、同 SRAM 约束下的 latency/energy 公平；
2. Local5 只覆盖 `OUT_DIM=2` tile，Motion 多样本真实 RTL 与两线 full-encoder Amdahl 仍不足；
3. Local5 容易被归类为工作负载驱动的 exact constant folding，需要 PPA 和强基线证明系统价值。

下一轮唯一 P0：在具备商业工具的服务器上完成双线同约束 DC + STA + SAIF 主表。Motion 比较 Fixed2S/RQTB2S；Local5 比较 residual/Q==0 serial/Q==0+ident-K serial。必须统一工艺角、目标频率、SDC、SRAM macro 合同和真实 trace，并报告面积、slack/Fmax、动态与泄漏功耗、每 window 能量和 EDP。在此之前不新增 RTL 机制。
