## 3. 对创新叙事的影响

1. **主贡献不变**：可逆归一化域时间商流（TESC+RQTB 一条）。  
2. **主 RTL 锚点不变**：论文周期主数字仍是 Fixed2S→RQTB2S **1.185×**（138 row）。  
3. **多样本外推**：模型全局约 **1.17×**，profile 前后半均约 **1.17×**，最差 sample 约 **1.17×**。这只说明冻结模型对两个 workload 分区给出相近估计，不能替代多样本真实 RTL。  
4. **仍缺**：多样本 **真实** Icarus/Verilator Fixed2S 回放；真实权重 Acc32；SAIF 能量。

## 4. 禁止表述

- 不得把 1.17× 写成 `[rtl]` 或 full-encoder 加速  
- 不得把 sample50–99 写成模型训练/校准 held-out  
- 不得把校准集聚合 speedup 完全相等写成独立泛化证据  
- 不得用 TTB8-vs-RQTB2S 的 1.31× 冒充 Fixed2S 公平对照
