# 第十二轮关系平面架构：FCIP 与前沿 DiSEP

## 1. 架构主张

本轮将主张从“算子RTL、term格式、DCTF银行”上移到：

> **Exact Relation-Plane Transduction**：不把attention结果物化为逐token
> 记录，而将网络中确定的离散关系直接驻留为可交集、可逆索引、生命周期有界
> 的关系平面，并从该平面生成投影term。

两条算法线分别实例化为：

1. Motion：**Factorized Class-Lane Intersection Plane（FCIP）**；
2. Local5：**Deterministic-Frontier DiSEP（DF-DiSEP）**。

```text
Motion score ----> class bitmap x K-lane bitmap --AND--+
                                                       |
Local5 Shiftmax5 -> direction-gate frontier --inverse--+-->
                    segmented {gate,lane,destination} stream
                                   |
                                   v
                    product-stationary projection/Acc
```

DCTF、双context、bank-local Acc和descriptor继续作为实现支撑，但不再单列
论文创新。

## 2. Motion FCIP

### 2.1 数据表示与执行

FCIP以两个正交平面替代token-major active member SRAM与后续G1重建：

```text
active_class_bitmap[slot][destination]
K_lane_bitmap[lane][destination]
class_table[score_class] = {count, occupied, final_gate}
```

score到达时：

1. 所有候选更新 `class_table.count`，包含K-zero；
2. K非零候选分配active class slot并置destination bit；
3. 同一candidate的K写入32个lane bitmap；
4. normalization完成后得到class到final gate映射；
5. active class slot与32个K-lane平面按64-bit segment做AND；
6. 非空交集直接成为 `{gate,lane,destination bitmap}`。

因此取消：

```text
token-major member replay
  -> gated-K逐token生成
  -> G1 final-gate directory rebuild
```

### 2.2 exact fallback

FCIP只配S16 active class slot。H67 ordered profile100中：

| 指标 | 数值 |
|---|---:|
| S16 overflow row | 0.048065% |
| S16 overflow work | 0.062772% |

fallback合同：

```text
detect class slot 17
  -> abort FCIP row
  -> 清除未提交bitmap
  -> 从驻留Q/K重新生成score
  -> 当前ordered SCS+G1
  -> 原子提交
```

禁止fast path和fallback的部分结果混合写Acc。该whole-row replay借鉴Phi的
主表示/escape纪律和Bishop的metadata-first/fallback思想，但不引入近似。

### 2.3 物理segment工作

已有ordered profile只能给界：

| 指标 | mean | p95 | p99 | max |
|---|---:|---:|---:|---:|
| active class | 2.167 | 10 | 13 | 31 |
| class-lane term | 27.114 | 175 | 251 | 539 |
| class segment下界 | 2.167 | 10 | 13 | 31 |
| class segment上界 | 6.500 | 30 | 39 | 93 |
| class-lane segment下界 | 27.114 | 175 | 251 | 539 |
| class-lane segment上界 | 56.222 | 393 | 719 | 1299 |

已在算法profile hook新增真实字段：

- `projection_h67_factor_class_segments`；
- `projection_h67_factor_class_lane_segments`；
- 两者的histogram和ordered trace；
- segment固定64 token。

新增逻辑通过算法侧63项单元测试，包括同一class/lane跨两个segment的定向例。

### 2.4 存储逻辑bit账本

| T | 当前SCS+G1 | FCIP S16 | 比例 |
|---:|---:|---:|---:|
| 162 | 30,163 | 13,638 | 0.452 |
| 450 | 83,640 | 30,425 | 0.364 |

FCIP账本含163-entry class table、S16 active-class bitmap、32个K-lane
bitmap、slot元数据、segment occupancy、gate alias、epoch-valid和8项
fragment FIFO。未计macro对齐、RMW/多读端口、Q/K延长驻留、fallback控制、
双context、布线与时序，因此不能把逻辑bit减少直接写成面积收益。

仓库已有 `gatestack_transposed_bitmap_bank`，它直接物化
`{class,lane,destination}` 联合位图。FCIP必须与其公平比较：

```text
materialized relation: S x L x T bit，读出直接
factorized relation:   S x T + L x T bit，读时64-bit AND
```

FCIP的差分是以交集计算换联合关系存储，不是“首次提出转置位图”。

### 2.5 借鉴与本土化

| 来源 | 借鉴 | FCIP差分 |
|---|---|---|
| Prosperity | exact reuse | 不做subset matcher；score class与K lane直接因子交集 |
| Sanger | stationary score metadata | 驻留离散class relation并直接跨到projection |
| FLAT | 跨阶段融合 | 取消member replay与G1重建两个物化边界 |
| Bishop | metadata-first、fallback | whole-row exact replay，不做ECP和双核 |
| Phi | 主表示与escape | S16 fast representation加rare exact replay |
| FireFly-T | lane-parallel event执行 | 32 lane与K bitmap一一对应，非通用重构阵列 |

真正候选贡献是：

```text
class membership × K-lane membership 的exact因子分解
  + late class-to-gate rename
  + segmented intersection直接形成projection term
```

bitmap、AND、S16或fallback单独都不是贡献。

## 3. Local5 DF-DiSEP

### 3.1 确定性前沿退休

固定五点stencil给出：

> source `(y,x)` 的最晚依赖来自destination `(y+1,x)`；当该destination row
> 完成Shiftmax5后，source row `y` 的全部合法incoming gate已经确定。

因此可按光栅顺序：

```text
destination row y+1 final-gate commit
  -> source row y degree-complete
  -> inverse-direction read
  -> 五项gate grouping
  -> source term emit
  -> frontier row retire
```

gate storage从完整窗口变为三行方向ring：

| 几何 | 完整gate plane | 三行frontier | 比例 |
|---|---:|---:|---:|
| 2x9x9 | 7,290 bit | 1,215 bit | 0.167 |
| 2x15x15 | 20,250 bit | 2,025 bit | 0.100 |

两个时间平面顺序处理，禁止跨时刻halo。

### 3.2 反压与profile合同

三行ring只是无反压容量下界。实现必须有source-ready scoreboard、
frontier queue、ring overwrite保护和Phase-A stall；不能覆盖未消费gate。

真实profile还需：

- `disep_source_ready_lag_destinations_histogram`；
- `disep_live_gate_rows/entries_histogram`；
- `frontier_ready_sources_per_cycle`；
- `frontier_projection_queue_occupancy`；
- `frontier_overwrite_stall_cycles`；
- `halo_wait_cycles`；
- `projection_acc_conflict_ordered_trace`。

强基线为B1、B2a、B2b、完整窗口DiSEP、普通stripe DiSEP和DF-DiSEP。所有
方案连接同一projection/Acc后端，统一端口、lane、macro和反压。

### 3.3 借鉴与本土化

| 来源 | 借鉴 | DF-DiSEP差分 |
|---|---|---|
| FLAT | normalize/project融合 | 五点依赖给出确定的一行生产消费距离 |
| Sanger | stationary metadata | 驻留final edge-gate前沿，不是稀疏score |
| Prosperity | exact product reuse | 固定逆方向地址代替在线matcher |
| Bishop | metadata-first | degree-complete控制exact退休，不剪边 |
| FireFly-T | 有界事件发射 | fanout最大5并受frontier反压 |
| Phi | escape纪律 | 堵塞时stall或exact spill，不近似覆盖 |

## 4. 晋级门槛

### 4.1 FCIP

- fullres T450 S16 overflow row `<=0.1%`、work `<=0.2%`；
- 真实64-bit intersection+emit p99不超过token replay基线的1.10x；
- 含macro后存储面积不超过当前SCS+G1的0.90x；
- score-to-projection traffic下降至少20%；
- attention-to-projection EDP相对最佳SCS/ACQN基线改善至少15%；
- exact fallback零失配。

### 4.2 DF-DiSEP

- post-G0/fullres source-gate-lane term ratio `<=0.80`；
- p95仍有稳定gate复用；
- p99活跃frontier不超过三行，或stall代价可控；
- 相对B2a/B2b中最优者EDP改善至少15%；
- 相对B1完整周期退化不超过5%；
- T450随机反压下无覆盖、重复和丢失。

## 5. 当前优先级

1. Motion FCIP先进入真实segment profile和CPU逐拍模型；
2. Local5等待fullres hardware-order gate后立即跑source/frontier profile；
3. 两条线在通过各自数据门槛前均不写完整RTL；
4. DCTF作为共同后端公平固定，不再投入命名和包装；
5. 下一轮独立DATE复审只评价FCIP与DF-DiSEP两项。
