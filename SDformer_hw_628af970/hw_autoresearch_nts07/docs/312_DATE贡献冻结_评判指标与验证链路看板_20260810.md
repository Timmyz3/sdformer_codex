## 2. 贡献冻结（Contribution Freeze）

### 2.1 Motion（独立硬件架构线）

**C1（主贡献，只能算 1 条）**  
**可逆归一化域时间商流**（TESC + RQTB 合并表述）：

- 对双时刻 temporal pair 的整数 Q7 score 等价类取商；
- 相等则合并为带 temporal mask / multiplicity 的 slot；
- weighted-SCS + Shiftmax 保留分母 multiplicity；
- 在 gated-K 边界按 active mask **可逆展开**，不删有效 K、不做近似剪枝。

**C2（协同/支撑，可进同一数据流故事，不拆成并列“首次”）**

| 机制 | 角色 | 证据要点 |
|---|---|---|
| Motion-XOR Q7 score | 软硬件接口 / 算术友好 | 算法-硬件合同 |
| Weighted SCS + Q1.7 Shiftmax | 归一化后端 | 与 C1 共用 |
| Exact zero-K 三类注入（ZKQI） | 工作量门控消融 | 单独 **无周期收益**；须与扫描机制一起讲 |
| TTB8 有序跳扫 | 实现层吞吐 | **不得声称发明 TTB**；相对 RQTB2S 多样本模型约 1.31×（含 preload） |

**明确不是贡献**

- 普通 TTB / 16-bit FIFO / banking / ping-pong / 2S 前端（**公平基线组件**）
- K 双 bank active-mask 读（强基线可共享）
- FIFO depth DSE、OpenROAD 代理数字本身

**已否决（贡献列表删除）**

- TARE-W8/W16 任意-lane compactor
- 多分辨率 Bundle 静态粒度
- hierarchical descriptor 作性能主贡献
- pattern predictor oracle

**当前允许写的周期数字（主文）**

> ep35 sample0/window0、138 个真实 `N_tok=450` head-row 上，Fixed2S→RQTB2S
> **1.1865×**，周期 −15.72%，slot −45.09%，descriptor 级 exp/gate 重建活动
> −22.22%，gated-K/synthetic Acc32 零失配 `[rtl]`。

`exp/gate -22.22%` 不是唯一 class 数下降：两边唯一 class transaction 都是 1,317。
163-entry direct-index class cache 的理想强基线可令两边 exp/gate 求值次数相同，因此该
活动代理已撤出独立创新和能量主张；RQTB 的实测周期收益仍来自 slot、descriptor 和
FIFO/issue 压力的共同下降。

**禁止写法**

- “Motion 端到端 / full encoder 加速 1.1865×”
- 用 1.471×（单 slot 弱基线）作主结果
- 把 TESC 与 RQTB 写成两条创新
- 把 OpenROAD / Yosys 写成 ASIC PPA 或节能

## 3. 我们用哪些指标判断“硬件好不好”

指标分 **四级**：一级决定论文能不能立住；二级解释为什么好；三级是实现健康度；四级是禁止误用的代理量。

### 3.1 一级指标（论文成立门槛）

| 类别 | 主指标 | 当前双线状态（摘要） |
|---|---|---|
| **算法质量** | fullres valid825 AEE/AAE；hardware-order 与 float 差；spikes | equal+10 已完成；Local5/H67 均优于 NB0（算法表，非硬件周期） |
| **功能正确性** | RTL vs 金参考 **mismatch=0**（gated-K / Acc32 / score 等） | Motion 单窗强；Local5 canonical 数值覆盖 100/100；phase admission 未过 |
| **性能** | 周期/latency/frame、FPS；**mean / p95 / p99**（不能只报平均） | Motion：ep35 单窗 RTL 1.1865×；多样本多为模型；Local5：100-sample post-score RTL 1.496×/1.466×，但尚非完整链路 |
| **能量** | logic + SRAM + DRAM **energy/frame**、EDP | **基本缺失**（无目标工艺 SAIF/PTPX） |
| **面积/效率** | logic/SRAM 面积、FPS/mm²、面积归一吞吐 | 仅 `[open-pnr代理]` / Yosys；不可称 ASIC |

光流是实时任务：**p95/p99 与单窗均值同等重要**。稀疏执行最终必须回答 **是否真省电**，不能只报 slot 减少。

### 3.2 二级指标（解释机制收益）

| 数据流位置 | 应报指标 | Motion 现有 | Local5 现有 |
|---|---|---|---|
| attention 前端 | pair-empty、K-zero、score 等价率、lane work | 有 fullres `[prof]` | score/五邻域统计在补 joint-head |
| score→归一化 | slot 数、SCS active entry、exp 事务 | L1/L2 模型 + 单窗 RTL | Shiftmax5 叶级 |
| 存储 | Q/K/relation/Acc 读写 bit、bank 冲突、FIFO 占用 | 部分分账 | relation/Acc 有局部 |
| 投影后端 | term 数、bank 映射、驻留 hit/miss/fallback | gated-K 输出计数 | TCFM5/Linear5 100-sample RTL；full-profile 仅 exact-port model |
| 系统 | attention / projection / ATLIF / skip / IO 占比（Amdahl） | **未闭环** | **未闭环** |

### 3.3 三级指标（实现与物理健康）

| 指标 | 含义 | 工具 |
|---|---|---|
| lint / 可综合 | 无致命 lint；Yosys hierarchy/stat | Verilator lint、Yosys |
| 反压鲁棒 | 随机/固定 LFSR 反压下仍 bit-exact | Icarus + Verilator+SVA |
| SVA 覆盖 | 握手、restart 拒绝、容量等 | `verif_*` |
| 时序 | WNS/TNS、setup/hold、max-cap/max-slew | OpenROAD 代理 → 未来 DC/PT |
| DRC | 详细布线违例 | OpenROAD |
| 同约束对照 | 同 SRAM 宏、同 outline、同 SDC、同 trace | 强基线纪律 |

### 3.4 代理量（可用但不准冒充）

| 代理 | 允许用途 | 禁止 |
|---|---|---|
| VCD 位翻转 | 活动趋势 | 称动态功耗/节能 |
| Yosys 逻辑面积 | 结构筛选 | 称芯片面积 |
| OpenROAD Nangate + flop-memory | 可布线/时序趋势 | 称 28nm 签核 PPA |
| synthetic Acc32 checksum | 两端一致性 | 称真实权重投影精度 |
| canonical Q/K | 控制覆盖扩展 | 称真实 lane 身份 workload |

### 3.5 创新晋级的数值门槛（已在用）

**Motion RQTB（模型准入 → RTL → 物理）**

1. fullres slot ≥25%、active entry 与 exp ≥10%（模型层已过）
2. 与 Fixed2S **同接口、同反压** RTL 等价 + 周期收益（ep35 单窗 1.1865× 已有）
3. 同宏规则下面积归一吞吐不退化；score+SCS+K-store 动态能量 ≥15%（能量 **未过**）
4. 多样本 mean/p95/p99（Fixed2S vs RQTB2S 的 **真实 RTL 多样本仍缺**）

**新机制通用准入**

- 真实 profile 有结构性机会
- **强基线**下有独立收益（不能靠弱基线虚高）
- 数值语义可证明（exact 优先）
- 最小 RTL 能进同约束评估  
未满足 → 只标 `[待验证]`，不进贡献列表
