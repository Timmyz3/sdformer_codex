# DS-GASR 同步点单变量消融与第八轮门槛闭环

## 1. 目的

第八轮 DATE 评审指出，历史 blind-geometry 与 descriptor-synchronized 日志不是同一源码下的单变量消融，且原 mask-pruning 解释已被 profile 证伪。因此本轮不新增架构机制，只关闭因果证据缺口。

## 2. 同版本消融开关

`qfit_local5_1rw_active_projection_tile.sv` 新增编译期参数：

`GEOMETRY_SYNC_MODE`

- `0`：issue-side prepare。active-index 的 geometry 必须等 backend prepare 完成后，relation frontier 才发出 K/gate SRAM 读请求；
- `1`：descriptor-synchronized。relation SRAM 先读，完整 descriptor 返回后，FIFO2 与 backend geometry 双 ready 原子提交。

除该同步点外，两边保持相同：FIFO 深度、五着色映射、五个 GASR-2C bank、单端口 1RW 合同、role 集合、权重、向量、SVA和周期边界。

## 3. 一键入口与证据

入口：`sim_new_arch/run_local5_ds_gasr_sync_ablation.sh`。

结果：`results/local5_ds_gasr_sync_ablation_rtl_20260804/`。

脚本执行：

- 两模式 deterministic T450 profile100；
- 两模式随机输入/读回空泡 + SVA profile100；
- Acc32、descriptor、term、update和SRAM事务逐组一致性检查；
- Verilator/Yosys/Git版本记录；
- 全部 RTL、SVA和向量 manifest 的 SHA-256 记录。

## 4. 单变量结果

| 指标 | issue-side | DS-GASR | 变化 |
|---|---:|---:|---:|
| 总周期 | 122,360 | 119,348 | `1.025x` |
| descriptors | 9,427 | 9,427 | 相同 |
| terms | 53,085 | 53,085 | 相同 |
| updates | 166,080 | 166,080 | 相同 |
| SRAM reads | 23,662 | 23,662 | 相同 |
| SRAM writes | 36,848 | 36,848 | 相同 |
| Acc32 | PASS | PASS | 零失配 |

DS-GASR 将周期缩短 `2.46%`。由于工作量和SRAM访问集合完全相同，该差异可以归因于 prepare 同步点与 relation-read 请求路径的重排，而不是 mask pruning、稀疏度变化或少算。

## 5. 四 Stage 结果

| Stage | issue周期 | DS周期 | DS加速 |
|---:|---:|---:|---:|
| 0 | 26,566 | 26,053 | `1.020x` |
| 1 | 14,374 | 14,245 | `1.009x` |
| 2 | 36,127 | 35,172 | `1.027x` |
| 3 | 45,293 | 43,878 | `1.032x` |

四个 stage 均未退化。Stage 1 收益最小，说明同步点优化主要缓解较长或较密 source 流上的 prepare/read 串行暴露。

## 6. 第八轮门槛

| 门槛 | 结果 |
|---|---:|
| bit-exact 且工作量相同 | PASS |
| SRAM事务完全相同 | PASS |
| 聚合改善不低于2% | PASS，2.46% |
| 四stage均不退化 | PASS |
| 随机空泡与SVA | PASS |
| RTL/向量/工具哈希落盘 | PASS |

总判定：**允许把 descriptor-synchronized 调度保留为 DS-GASR 组合机制的一部分，并进入宏感知评估。**

## 7. 能宣称与不能宣称

现在允许宣称：

> `[rtl]` 在相同五bank GASR、相同逻辑1RW合同和完全相同SRAM访问集合下，把prepare从issue侧移到descriptor原子提交边界，在T450 profile100上将投影子系统聚合周期缩短2.46%，且四stage均不退化。

仍不能宣称：

- 芯片频率、面积、功耗或EDP改善；
- 完整网络FPS提升；
- DS-GASR本身删除了任何role；
- `OUT_DIM=2`的Yosys结构可外推部署`OUT_DIM=32`；
- 81.03%逻辑SRAM事务下降等于81.03%能耗下降。

## 8. 下一阶段候选

按照第八轮评审，下一步应进入部署位宽与宏感知评估，而不是立即实现runtime双模式：

1. `OUT_DIM=32`下验证direct/DS-GASR控制、Acc宽度和SRAM宽度；
2. direct/DS使用相同SRAM宏规则和SDC；
3. OpenROAD只作为物理代理，后续服务器补DC/STA/SAIF/PrimePower；
4. 若额外双槽和控制的面积/寄存器能量吞掉SRAM事务收益，则DS-GASR不得作为主贡献。
