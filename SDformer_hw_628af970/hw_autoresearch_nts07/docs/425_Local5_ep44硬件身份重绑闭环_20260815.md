# Local5 ep44 硬件身份重绑闭环

日期：2026-08-15。

## 结论

Local5 的硬件身份已经从旧 ep29 证据更新到 **ep44 checkpoint-bound 的组件级 RTL 证据**。本次闭环覆盖：

```text
ep44 raw Q/K
-> alpha-XNOR Q7 score
-> masked Shiftmax5 Q1.7 gate
-> inverse-stencil relation build
-> source-major term
-> TCFM5 / Linear5 projection
-> Acc32
```

该结论只适用于 100 个 outcome-independent qualified T450 group、真实 checkpoint INT8 权重和 `OUT_DIM=2` 输出切片。它不是完整 encoder、跨 head 输出或 foundry PPA 结果，也不增加 DATE 创新分。

## Claim 边界

可以写：

> Local5 ep44 的真实 Q/K、hardware-order score/gate、固定五邻域转置、source-major term 和真实 INT8 权重 Acc32，在 100 个合格 T450 group、`OUT_DIM=2` 下完成组件级 RTL bit-exact 重绑定。

不能写：

- full encoder 或完整 12-block 生产调度已闭合；
- 全输出通道、跨 head、bias、动态 BN、requant、residual 或 decoder 已闭合；
- ep44 已有 foundry DC/STA/SAIF/PTPX；
- 新的 ratio 替换 `docs/359` 封存主列；
- 本次重绑定提高了架构创新分；
- H81 已有 RTL。

内部 acceptance 的 `formal_qualification` 是历史 schema 字段。论文口径必须写成 `profile-qualified trace validation` 或 `trace-qualified bit-exact verification`，不能写成 formal model checker 对所有输入的证明。
