# Local 与 Motion 全系统创新启动及资产清单（2026-08-21）

## 当前决策

Local 与 Motion 不再限定在 attention 微结构。两条线共享一个全网络 binary
`Linear/Conv2d` tile 执行接口，但保持模型身份和结果分离：

- Local ep44：当前激活的 source-owned selected-weight accumulation；
- Motion/H67 ep35：保留上一时间步准确 Acc32，以 `+W` 处理 `0->1`，以 `-W` 处理
  `1->0`；
- selector：仅当 prior state 有效且 transition work 严格少于 current-nonzero work
  时走 Motion；sequence boundary、非法计数和周期 refresh 一律走 Local。

真实 s1/s10 trace 表明，Motion 不适合作为全网主引擎。因此收敛为：

- **Local 主引擎**：二值激活驱动的 selected-weight INT8 accumulation、weight
  segment multicast 和 Acc32 residency；
- **Motion 分层可选优化**：只在真实 trace 证明 transition work 更少的层开启；
- **attention 分工**：window reshape 后的 Q/K projection 可走 Local 二值 Linear，但因时间轴
  已重排而禁用 Motion；attention core/proj 继续走 RQTB 路径；
- 首层、预测头、浮点/非二值残差、BN/requant/residual/ATLIF 保留 bypass。

两条线都是精确算术变换，不修改网络输出；不把 Local 和 Motion
的 component ratio 相乘。

### 真实 operation-work 结果

| 身份 | 样本 | Local work | selector work | Local/selector | 节省 |
|---|---:|---:|---:|---:|---:|
| Motion/H67 ep35 | 1 | 32,324,334,446 | 31,514,205,170 | 1.025707x | 2.5063% |
| Motion/H67 ep35 | 10 | 318,936,020,722 | 310,640,413,576 | 1.026705x | 2.6010% |
| Local ep44 | 1 | 36,379,342,108 | 35,455,710,542 | 1.026050x | 2.5389% |
| Local ep44 | 10 | 359,573,240,182 | 350,143,786,148 | 1.026930x | 2.6224% |

上表是精确非零/转移项次数，**不是 cycle、latency 或 energy 实测**。Motion-only
在两条线都比 Local 更差；selector 仅在约 9.5%--10.7% 的可比行选 Motion。因此
Motion 的定位是“少数高收益层的延迟/能耗补丁”，全系统 2x 必须主要来自
Local 引擎并行度和存储交通优化。

H67 s10 绝对节省较大的层包括 patch-embed residual `resblock0.conv1`、
`S3.B0.mlp.fc2`、`S2.B0.mlp.fc1`、`S2.B3.mlp.fc1` 和 `S1.B1.mlp.fc1`。后续
Motion RTL/cycle model 先只对这类候选层开启。

36 个 `TEMPORAL_AXIS_UNQUALIFIED` 站点均是 attention 中已重排为
`[2, windows, 15, 15, C]` 的 Q/K/proj。其中 Q/K 仍可走 Local，但禁用 Motion；
proj 由现有 RQTB attention 路径替代，因此不是普通数据路径遗漏。H67 每样本另有
12 个、Local 每样本另有 7 个
`NON_BINARY_BYPASS`，对应首层、预测头和浮点/非二值残差路径。

## 新硬件与验证

`qfit_dual_line_tile_selector.sv` 已实现一项一出的可回压 selector，并带 sticky
protocol error 和 Local/Motion/工作量计数器。VCS/SVA 随机回归结果：

- 20,000 requests，46,449 cycles；
- Local 15,106，Motion 4,894；
- forced-local 10,768；
- 2 个非法 count 均 fail-safe 到 Local；
- motion、forced-local、tie 三个 cover 均命中；
- 无 assertion failure。

该随机比例只用于验证控制路径，不是网络 speedup。

`qfit_dual_line_source_streamer.sv` 已将 selector 决策落到可直接寻址 weight column
的 source-owned stream：

- Local：对 current bitmap 的每个 1-bit 发射 `index,+W`；
- Motion：对 `current XOR previous` 发射，`0->1` 为 `+W`，`1->0` 为
  `-W`；
- 空 tile 直接完成，输出支持任意 backpressure，并带 Local/Motion/正负
  source 计数器。

VCS/SVA 随机回归结果：

- 5,000 commands，225,153 cycles；
- Local/Motion 各 2,500 commands；
- 157,787 个 source token：118,617 正更新、39,170 负更新；
- 空 tile cover 68 次，Motion 负更新 cover 39,170 次；
- 顺序、符号、last、完成计数、stall 稳定性和 perf counter 全部通过。

后续已由 `qfit_dual_line_tile_executor.sv` 与
`qfit_dual_line_stateful_tile_top.sv` 完成 weight/Acc32 的 tile-level integration
miter；默认 256-bit/16-lane 集成结果和新思证据见文档 451。该版本的 weight array
仍是 flop-inferred 验证载体，显式 banked SRAM interface 属于 M2。

## 全系统结构 envelope

- 55/79 个非 attention-replaced operator 可进入 Local，其中 31 个具备 Motion
  可比状态，24 个 attention Q/K projection 为 Local-only；
- 覆盖当前 fixed system cycle envelope 的 57.3719%；
- Local 旧 1.783485× component anchor 若乐观应用于全部 eligible 工作，系统约
  1.338590×；
- 2× system 要求 eligible engine 达到 7.687553×，等价于最终有效工作量不超过
  当前 eligible work 的 13.0080%；
- 3× 在当前覆盖范围不可达。

## 还需要的资产

不再需要额外打包普通算法 Python：profiler、模型、DSEC loader、overlay 与配置都在 Git，
本机 sparse checkout 已展开所需目录。

不再缺 checkpoint、普通算法 Python、deploy config 或 pilot ordered trace。DSEC 数据集
保留在 GPU 服务器，不需要整体传到新思服务器。

真正还需要：

1. 每条线从低/中/高 density 层抽取少量 packed current/previous tile bitmap，生成
   VCS bit-exact descriptor/selector/Acc32 miter；不需要保存全网原始激活。
2. 从已有 ordered trace 生成 address/timestamp memory transaction，再接 DRAMsim3；这不
   需要新 checkpoint。
3. 已完成 bitmap source streamer 与 weight/Acc32 的 tile-level integration RTL；
   还需把当前 flop-inferred weight/state 换成显式 banked SRAM interface，并只为候选
   Motion 层保留 previous state。
4. 在同一 PDK/频率/SRAM 约束下运行 DC/STA、SAIF/PTPX 和存储模型，用综合数字
   替换 envelope。
5. 发文最终统计需将 s10 扩到多 DSEC sequence 和 100 样本，并做 event-density/
   equal-rate 分层；这是评估完整度，不是当前 RTL 开发阻塞。

GPU runbook：`system_handoff/scripts/run_dual_line_full_network_traces.sh`。默认
`SAMPLES=1` 且 GPU 使用超过 1 GiB 就退出；s1/s10 pilot 已通过，最终扩到 100
并增加跨 DSEC sequence 分层。

## 证据边界

当前可声称架构合同、Local/Motion 算术等价、结构覆盖、selector VCS/SVA，以及
s1/s10 真实全网 operation-work 统计。不能声称 1.3386x 或 2x 是全系统实测；
在统一 cycle/memory model 与 DC/PTPX 完成前，它们分别只是 envelope 和目标阈值。
