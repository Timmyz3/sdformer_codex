# H66 统一注意力候选硬件边界

**日期**：2026-07-11  
**状态**：精度优先软件筛选，尚未修改 TTX RTL  
**冻结范围**：105 个 one-sided binary ATLIF；encoder 12 个 attention block 使用同一公式

## 1. 术语边界

允许的 value 路径包括 `Shiftmax gate*K` 和 `attention weights@K`。禁止的 native QKFormer carrier 特指：

```text
Q_token = sn2_q(sum_channel(Q))
carrier = K * Q_token
output  = carrier * second_attention_gate
```

TTX 直接由 TX/alpha-XNOR score 生成 Shiftmax gate，再执行 `gate*K`，没有该 carrier。单边二值 ATLIF 只需要正阈值比较器；只有 signed ternary ATLIF 才要求共享幅值的正负对称阈值。

## 2. 候选硬件颗粒度

| candidate | retained blocks | replaced attention block | dominant new storage/compute | RTL decision |
|---|---|---|---|---|
| TTX | Q/K event SRAM、TX popcount、Shiftmax、K late-scale | none | scalar score/gate per token | frozen mainline |
| H66a full a-XNOR | Q/K event SRAM、Shiftmax、projection | scalar TX engine becomes pairwise Q/K score engine | up to `Nw x Nw` score rows plus weighted K accumulation | model only until valid40 |
| H66b Hamming linear | Q/K event SRAM、projection | TX+Shiftmax replaced by `K^T K` then Q accumulation | signed `D x D` accumulator per scheduled head | model only until H66a result |
| STAtten hold | Q/K/value event SRAM、projection | attention scheduler groups time and spatial tokens | temporal chunk buffer and `D x D` accumulator | no RTL yet |
| lateral inhibition hold | Q/K event path and projection | selector gains feed-forward/feedback suppression | feedback state SRAM and dependency control | no RTL yet |

## 3. Sign-off rule

No candidate changes `rtl_ttx/` during short screening. A candidate first needs valid40 AEE at most `1.65`; only then produce cycle/storage estimates against TTX. Full RTL replacement requires standard valid825 AEE within about 5% of NB0 and at least 20% fewer total spikes. This prevents an accuracy-only matrix candidate from silently displacing the hardware-feasible TTX mainline.

## 4. Profiler accounting warning

The current software SOP/energy profiler counts instrumented spike-producing layers but does not include explicit matrix operations executed inside the optional attention overlay. Consequently, H66a valid10 `estimated SOPs=2.1325G` excludes its pairwise `N x N x D` alpha-XNOR and weighted-K accumulation. It must not be compared with TTX hardware energy until a separate attention operation/cycle model is added. For TP-TTX and LR-TTX, the missing work is bounded at 2 and 5 comparisons per token respectively and can be added explicitly to the hardware model.

## 5. Fixed-window operation granularity

For one head in the frozen `T x H x W = 2 x 9 x 9` window, `N=162` and `D=32`:

| operator | alpha-XNOR bit classifications/head | relative to TTX | gate context | minimum extra K state |
|---|---:|---:|---|---|
| TTX | `N*D = 5,184` | 1x | one 162-token Shiftmax row | existing K window state |
| TP-TTX | `2*N*D = 10,368` | 2x | 162 independent 2-way rows | one 81-token temporal slice, `81*32` event bits/head |
| LR-TTX | `5*N*D = 25,920` before border pruning | 5x | 162 independent up-to-5-way rows | two spatial line buffers plus current row |
| H66a full matrix | `N*N*D = 839,808` | 162x | 162 rows of length 162 | full K window plus score-row state |

TP-TTX reduces pairwise classifications by `81x` versus H66a and keeps a deterministic two-candidate schedule. Its 120-step valid10 AEE `1.1656` slightly improves on H66a's `1.1766`, so it is the first candidate eligible for a detailed cycle/area model if valid40 remains competitive. No RTL source is changed before that confirmation.
