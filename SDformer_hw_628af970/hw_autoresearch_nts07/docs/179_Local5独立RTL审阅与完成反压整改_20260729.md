# Local5 独立 RTL 审阅与完成反压整改

## 1. 审阅结论

独立 RTL 审阅的初始结论为：

> **FAIL，不可直接交 DC。**

其中一个高优先级问题是实际 ready/valid 缺陷，另一个高优先级问题是新加入
空 mask TB 的金参考错误。两项均已修复并重跑。整改后的分层结论为：

- Local5 score-to-term 研究原型：**PASS**；
- Direct/TARE 同顶层消融：**PASS**；
- Local5 完整 DC handoff：**仍 FAIL**。

后者缺少的是全链目标库脚本、T450 accumulator、SRAM macro、SDC/STA/SAIF/LEC，
不能由局部 RTL 回归替代。

## 3. 完成反压缺陷

旧行为：

```text
row done -> row engine IDLE
         -> score top ST_FINISH 等待 done_ready
         -> row anchor_ready 提前拉高
         -> 新 anchor 可覆盖旧完成 tag
```

整改后：

```text
row done handshake
    -> done_tag_q 原子锁存
    -> ST_FINISH
    -> row_anchor_valid = 0
    -> external anchor_ready = 0
    -> stencil_done 握手
    -> ST_WAIT_EDGE 后才允许下一 anchor
```

必须同时门控 `row_anchor_valid` 与对外 `anchor_ready`。只门控 ready 会造成
“外部未握手、内部已接收”的隐式事务，不符合 ready/valid 合同。

## 5. 尚未达到 DC 的原因

1. `rtl_local5/filelist.f` 尚未冻结完整 TARE/窗口/projection 依赖；
2. 没有 Local5 专用 DC Tcl 和 SDC；
3. 没有目标工艺 SRAM macro 和 PVT；
4. 没有 T450 accumulator 真实深度和地址 449 readback；
5. 没有 STA、SAIF 功耗、目标库 LEC；
6. 没有随机 SRAM latency、active reset 和长时间全链压力。

因此本轮可签的是“研究原型 RTL 正确性”，不是“可直接做 DC 并形成论文 PPA”。
