# 双线独立架构重启：归一化域商流与双向五色关系前沿

> 日期：2026-08-03  
> 范围：Motion H67 与 Local5 两条独立硬件论文线  
> 证据约束：只使用本机文件、脚本、trace、RTL 和工具日志；外部 Claude 结果不计入完成度。  
> 当前证据：`[prof] + [exact-model] + [rtl] + [yosys-readable]`，不是目标工艺 PPA。

## 1. 本轮结论

本轮没有继续包装 DCTF，而是从真实 workload 中提取了两个不同的架构不变量，并把它们接到真实流水边界：

1. **Motion：归一化域 temporal quotient。** 两个时刻的 K 即使不同，也可能得到相同整数 Q7 score。只有 score 在 Shiftmax 归一化域可以合并，K 必须在 projection 前按 `active_mask` 展开。该边界把“全流水合并”改为“分域取商”，避免破坏 gated-K 语义。
2. **Local5：双向五色关系前沿。** 同一个 `bank(x,y)=(x+2y) mod 5` 映射同时保证 destination 的五点 source 集合写 active bitmap 无冲突，以及 source 的五个 destination 累加无冲突。前端只发射 active source，后端继续使用 TCFM-5。

两个机制目前均有独立核和集成前端 RTL，并通过 Icarus、Verilator+SVA、Yosys。它们仍不是完整 attention-to-projection 顶层，更不是可投稿终态。

## 2. Motion：TESC-WD

暂用名称：**Temporal-Equivalence Score Coalescing with Weighted Directory，TESC-WD**。

### 2.1 架构原则

基线按每个时刻分别生成：

```text
(Q0,K0,K1) -> score0 -> SCS entry0 -> gate0*K0
(Q1,K1,K0) -> score1 -> SCS entry1 -> gate1*K1
```

TESC-WD 改为：

```text
temporal pair
    -> 两个bit-exact Q7 score
    -> score0 == score1 ?
       | 是：{score, temporal_mask=11, active_mask={K1!=0,K0!=0}}
       | 否：{score0,01,*} + {score1,10,*}
    -> weighted SCS directory
       | histogram += popcount(temporal_mask)
       | active directory只存active_mask!=0的descriptor
    -> Shiftmax gate
    -> 按active_mask读取并展开K0/K1
```

关键点不是“相同数据去重”，而是**限定 quotient boundary**：

- 分母按 `temporal_mask` 的 multiplicity 计算，原 token 数不变；
- active 目录只减少重复 score/metadata，不删除 K；
- projection 必须以 pair ID 读取原 K-pair，再按 `active_mask` 展开；
- 与 TARE 的增量 score 是正交机制：TARE 减少 score lane 工作，TESC-WD 减少 SCS active entry 和指数事务。

### 2.2 本机 workload 证据

来源：`results/motion_temporal_equivalence_20260803/report.md`。

| 指标 | 结果 |
|---|---:|
| temporal pair | 54,432,000 |
| 双 K 有效 pair | 3,149,911 |
| 双 K 有效且 Q7 score 相等 | 2,738,242 |
| 双 K 有效 score 相等率 | 86.93% |
| SCS active entry | 12,327,067 -> 9,588,825 |
| active entry 降低 | 22.21% |
| 全 SCS 指数事务模型降低 | 19.40% |
| TARE 逐 lane score 工作降低 | 45.19% |

16-lane cycle 模型为 `1.335x`，32-lane全并行模型仅 `1.002x`。因此不能把 TESC 写成无条件性能提升：在宽 score 核上，它的价值主要来自 SCS 存储、指数运算和开关活动。

## 3. Local5：DCRF-TCFM

暂用名称：**Dual-Color Relation Frontier with Topology-Colored Fanout Multicast，DCRF-TCFM**。

### 3.1 双向五色不变量

Local5 五点拓扑的位序冻结为：

```text
bit[4:0] = {RIGHT, LEFT, DOWN, UP, SELF}
```

颜色函数：

```text
c(x,y) = (x + 2y) mod 5
```

对任意中心 `(x,y)`，SELF、UP、DOWN、LEFT、RIGHT 的颜色增量分别为 `0,-2,+2,-1,+1 mod 5`，恰好覆盖五种颜色。因此同一映射具备两个方向的无冲突性：

1. **destination -> source：** 一个 destination 的五个候选 source 可在一拍内并行 set 到五个 active bitmap bank；
2. **source -> destination：** 一个 source 的最多五个 destination 可在一拍内并行更新五个 Acc bank。

数据流：

```text
destination-major Local5 score
    -> gate!=0 && source-K!=0
    -> 五色 active-source bitmap并行set
    -> relation SRAM照常写入
seal
    -> 五个bank-local next-set-bit / zero skipper
    -> 仅active source发起六bank关系读
    -> source-major {K, five incoming gates}
    -> gate/lane term builder
    -> TCFM-5五路无冲突Acc更新
```

这不是在关系转置之后丢弃空 descriptor；active bit 必须在 destination-major score 阶段生成，才能真正省掉关系 SRAM 读取。

### 3.3 RTL 证据与发现的缺陷

新增模块：

- `rtl_qfit/qfit_dual_color_active_source_index.sv`；
- `rtl_qfit/qfit_dual_color_relation_frontier.sv`。

集成测试采用 5x5 窗口、精确关系转置和随机 descriptor 反压：

| 项目 | 结果 |
|---|---:|
| destination 写入 | 25 |
| active source 读出 | 9 |
| 避免的固定 source 读 | 16 |
| source 集合、坐标、K、五方向 gate | 逐项一致 |
| 重复 source 发射 | 0 |
| 五色 bank conflict | 0 |
| Icarus / Verilator+SVA / Yosys | 6项流程全部 PASS |

集成验证发现并修复了一个真实接口错误：原 active-index 注释规定 bit0 为 SELF，但坐标生成把 bit0 当 RIGHT。只看“最终覆盖所有 source”的计数测试无法发现；接入关系转置后出现 inactive source 发射，现已统一到冻结位序。

默认 15x15x2 参数下存储合同约为：

- active bitmap：`450 bit`；
- K store：`450 x 32 = 14.40 Kbit`；
- gate store：`450 x 5 x 9 = 20.25 Kbit`；
- valid store：`450 x 5 = 2.25 Kbit`；
- 合计约 `37.35 Kbit`。

其中关系存储不是新增净开销，固定扫描基线本来就需要 K/gate relation SRAM；新增核心状态主要是 450-bit 五色 active bitmap、每 bank walker 和控制。

### 3.4 文献机制与本土化差分

| 来源机制 | 借鉴 | 本工作差分 |
|---|---|---|
| 复旦 ISSCC 2023 in-memory butterfly zero skipper | bank-local 非零提取，避免规则扫描 | 不建立通用 butterfly 分发网；利用 Local5 五色拓扑把 skipper 分散到五个固定 bank |
| Bishop TTB metadata-first | 先读 metadata，再决定 payload 访问 | metadata 是精确 active-source 集，不做密度分流或近似剪枝 |

| TCFM-5 | 拓扑着色消除 Acc 写冲突 | 本轮新增同一颜色映射反向服务 active-source 建表，形成前后端双用不变量 |

## 4. 两条线现在能否各自支撑 DATE

### 4.1 Motion

可独立主张的组合是：

1. TARE 精确增量 Motion score；
2. TESC-WD 归一化域 quotient 与 weighted SCS；
3. HIFP/IBF 在 projection 域外提不变量。

其统一原则是**按数值不变量改变生命周期**，而不是 DCTF bank 数。当前最大风险是 TESC 还没有接到完整 exp/LUT/divide/gated-K，且 profile 仍是 W9/T162；在 W15/T450 与真实 SAIF 之前，独立 DATE 接收概率仍不足。

### 4.2 Local5

可独立主张的组合是：

1. 双向五色 active relation frontier；
2. source-major gate/lane term quotient；
3. TCFM-5 topology-colored fanout multicast。

其统一原则是**同一拓扑着色同时消除前端稀疏发现冲突和后端多播写冲突**。Local5 已有 fullres/post-G0 T450 profile，数据动机比 Motion 当前 T162 更接近部署；但只完成 5x5 集成 TB，尚未完成真实 450-source trace 回放和 OpenROAD。

## 5. 当前最小下一步

| 优先级 | Motion | Local5 |
|---:|---|---|
| 1 | TESC-WD 接完整 Shiftmax/gated-K，逐元素对照现有 row engine | DCRF 接 term builder + TCFM-5，回放真实 450-source ordered group |
| 2 | W15/T450 RTL-exact profile 完成后重跑 quotient 统计 | active-linear5 与 DCRF-TCFM 使用相同 SRAM latency/反压公平对照 |
| 3 | dense dual-score / TARE / TARE+TESC 同约束 OpenROAD+VCD | fixed-scan / bitmap-scan / bank-local-skip 同约束 OpenROAD+VCD |
| 4 | 报 mean/p95/p99、logic+SRAM energy、EDP | 报 mean/p95/p99、bank stall、SRAM read 和 EDP |

在以上闭环前，不新增第三种宏大架构名，也不宣称 Best Paper 水平。
