## 2. 公平合同

两边完全共享：

- qualified 100-sample 中 sample-disjoint、stage-weighted 100 groups；
- raw Q/K、Shiftmax5、Query-Silent/IdentK、rolling inverse-stencil frontier；
- source-owned gate quotient term stream；
- TCFM5 destination mask 与真实 checkpoint INT8 权重；
- `OUT_DIM=2` Acc32 tile。

唯一变化是 accumulator memory port：

| 配置 | Acc32 memory contract |
|---|---|
| 1R1W | 每 bank 独立一读一写接口 |
| 1RW | 每 bank 单端口；首次写直达，后续同地址更新执行 exact read-modify-write |

1RW wrapper 独立放在 `dc_handoff/rtl/date_local5_1rw_dc_top.sv`，未修改冻结 1R1W wrapper。

## 3. 生产 RTL 结果

证据：`results/local5_source_owned_same_port_ablation_v3_20260814/report.json`，SHA256 `d1daf05b5675da29f11359f22702bde277b9fe8321bb2e0aae6b320b49da4c66`。

| 指标 | 1R1W | 1RW |

| source-owned terms | 74,131 | 74,131 |
| destination updates | 222,649 | 222,649 |

- 1RW 周期开销为 `9.293%`。
- 33 个空组：`29,898 -> 29,931`，基本持平。

- 逐组 1RW slower/tie/faster 为 `96/0/4`；总开销来自非空组 single-port RMW stall，不是 workload 漂移。
- builder→backend term/update bind SVA 在两种 port 合同下均通过。

## 5. 负证据：busy-only 不能伪拼接

第一次 1RW compute-only 尝试产生 100 次 `$dumpon/$dumpoff`：

- busy `170,269`；measured `170,469`；
- VCD active interval `100`；
- `paper_power_eligible=false`，状态 `FAIL`。

证据保留于 `dc_handoff/runs/local5_1rw_activity_population100_busy/activity_contract.json`。没有放宽 single-interval 检查，也没有压缩 VCD 时间轴。若后续需要 compute-only PTPX，应逐组转换/评估后按真实能量求和，不能把多区间平均活动直接乘 busy cycles。

## 7. DATE 影响

- 架构创新：仍为 `3.1/5`。单端口适配与活动准入不属于新执行对象。
