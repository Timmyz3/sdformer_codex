# 双线创新冻结：拓扑编译生产闭环与转完整度

## 1. 本轮边界

本轮只完成上一轮尚未闭合的 Local5 架构合同，并再次审计 Motion 候选是否与
现有 NMF/FCIP 重复。不改 `docs/359` 封存列，不把 synthetic topology、开放映射
或等价周期写成新加速。

## 2. Motion 裁决

- 等 gate 时间对的公共 K 子向量 multicast 与现有 `{gate,lane}+destination bitmap`
  的 NMF/FCIP 表示重复，裁决 `DUPLICATE_OF_EXISTING_FCIP`；
- MSSB5 相对 SSR5 只有叶级 CSE 增量，继续只作 RQTB score-front 支撑；
- 不再扩 class folding、公共 K 多播、interval early-stop、ECGB 或第三条 exact 路径；
- 封存公平包仍为 `112589/94891/34099/28001`，本轮未重写也未平均。

Motion 当前可列的一条硬件贡献仍是：五充分统计量 score front 产生双时间 Q7
score，并在归一化边界通过 multiplicity 与 temporal mask 做可逆 score-class
coalescing。MSSB5 与 RQTB 是同一数据流的前后两段，不拆成两项创新。

## 3. Local5 拓扑编译合同

### 3.1 编译边界

固定 source-relative offset 集合与 raster order 被编译为：

1. 最后消费者规则；
2. relation live-row span；
3. affine bank coloring；
4. 可由通用 ordered pending/backpressure shell 消费的 event vector。

`qfit_compiled_retirement_shell.sv` 不含 cross、dilation 或 role 特判。现行
`cross_r1` 的三事件 FCSR 是该合同的一个实例，而不是新的第四项贡献。

### 3.2 非同构覆盖纠偏

旧 `asym5` 虽然 offset 非对称，但生成 schedule 与 `cross_r1` 字节相同，已作废。
修正版为：

```text
{(0,0), (-1,-1), (-1,0), (0,-1), (1,0)}
```

它产生 4 条 active retirement rules、不同 schedule SHA 和四事件 burst，并覆盖
generic shell 的 `RULES=4`。首次回归暴露 `event_count` 数组索引宽度错误；现已用
独立 `EVENT_INDEX_W` 修复。修正版最小 affine coloring 是 **B5**，不是旧稿 B6。

### 3.3 验证

- 三拓扑共 `65449` 个有限网格 destination case，mismatch `0`；
- `cross_r1/cross_r2/asym5` 的生成 rules 与通用 shell 均通过 Icarus、Verilator
  `--assert`、双 plane、稀疏 candidate、长反压和 Yosys `check -assert`；
- `asym5` warning `0`，实际命中四事件 burst，不只是编译覆盖；
- 默认 `SCHED_MODE=0` 不包含 generated module 的 lint 通过；
- `SCHED_MODE=4` 明确要求 `SKIP_ZERO_K=1`；非法组合在时刻 0 以 `$fatal` 退出，
  负向测试通过。

### 3.4 生产 tile

default-off 的 `SCHED_MODE=4` 已直接实例化
`generated_cross_r1_retirement_scheduler + qfit_compiled_retirement_shell`，并接入
真实 `relation ring -> term builder -> TCFM5 -> Acc32`：

- 100 个 sample-disjoint、stage-weighted 真实 Q/K 与 checkpoint-weight group；
- `OUT_DIM=2` tile，不是 encoder；
- 手写 FCSR、仅 generated rules、完整 generated-contract 三路均为 `155791`；
- 100/100 `GROUP` ledger 逐字段相同；
- Acc32 mismatch `0`，Verilator `--assert` PASS。

等周期只证明编译合同没有偷吞吐，不是新的性能收益，且不进入 `docs/359`。

## 4. 独立 DATE 评审

两位评审分开保留，不取平均：

| 评审 | Motion 创新 | Local5 创新 | 验证 | 完整度 | 综合 |
|---|---:|---:|---:|---:|---:|
| Grok 严格评审 | 3.0 左右 | 3.1 | 4.5 | 2.8 | 3.1 BR |
| Parfit 独立评审 | 3.6 | 3.7 | Motion 4.0 / Local5 4.6 | Motion 2.8 / Local5 3.3 | Motion 3.4 BR / Local5 3.7 WA |

本轮自评：Local5 合同已从“手写三条规则”提升为可执行、可参数化且进入生产 tile
的编译期最后消费者合同；但它仍复用 `docs/208` 的 relation 存储和执行对象，不能
单列 compiler 贡献。Motion 的 exact quotient 边界清楚，但多样本真实 RTL 和系统
效果仍不足。双线都尚不能稳健写成创新 `4/5`，更不能称 best-paper 完成度。

## 5. 为什么现在必须停止加机制

继续增加 topology、codebook、cache、leftover、early-stop 或 fast path，只会增加
模块数，不会改变主存储/执行对象。当前最低项已经从“有没有 RTL”转成实验完整度：

| 缺口 | Motion | Local5 |
|---|---|---|
| 多样本真实 RTL | 缺；现为单窗主锚点，100-sample 仅校准模型 | 100-group 真实 score-to-Acc 已有 |
| 真实权重 | 单窗两输出通道已有，仍缺多样本/完整输出 | 100-group OUT2 已有；OUT32 只有四 stage 高负载正确性 |
| 系统范围 | 缺 full-encoder Amdahl/连续窗口 | 12-block 仅 RTL 校准模型，缺 full encoder |
| 存储物理 | 缺目标 SRAM/RF | Dynamic/FCSR 尚缺同端口真 SRAM/RF |
| PPA/能量 | 缺 DC/STA/SAIF/PTPX | 缺 DC/STA/SAIF/PTPX |
| 签核 | OpenROAD 只作代理 | Yosys/OpenSTA 只作代理 |

因此下一阶段冻结新架构 RTL，只推进：双线 DC 交付顶层与同约束 SDC、Motion
多样本真实 trace 到齐后的 RTL 回放、Local5 OUT32/population 敏感性、12-block
Amdahl 分账、真实 SRAM/RF 与 SAIF/PTPX。任何新数字继续带 `[rtl]`、`[prof]`、
`[模型]` 或 `[开放代理]` 标签。
